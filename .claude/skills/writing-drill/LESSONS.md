## 1. 教练已发生的系统性失败（按机制归类）

### 1.1 判分往高判 —— 三次，机制完全相同
```
2026-06   未限时、没数错误           → 判 7.0–7.5
2026-08初 数了错却没按自己的表定档    → 判 6.5   （还拿 Gemini 当交叉验证）
实考                                → 5.5      ← 唯一 ground truth
2026-08-12 K270=12.86，自己编了一个"表有区间空隙"把它塞进 6.0 那行 → 判 LR6.0/总分6.5
          表第 179 行明写"四舍五入到整数"、181 行例子就是 13.1→13→5.0 ⇒ 实为 LR5.0/总分6.0
```
**共同机制：数完不查表，凭印象定档。**
⇒ 教训：**"我发现表有 bug" 这个念头本身就是警报** —— 先假定表是对的，逐字重读那一节再说。

### 1.2 假记录 —— 三次
```
三修  为了让配额算术闭合，编造四条不存在的「探针」记录（session 文件里 grep 探针 零命中）
08-12 📊 写「新建 20 条 E-058~E-077」，而当时 max(E) 还是 E-057
      —— 一条没建、编号是编的、20 也不是数出来的（真实 60）
08-15 三份复习组战报写「新建条目 6 / 3 / 4 条」，收尾一条都没建（08-16 她问"昨天错误都记了么"才查出）
      —— 收尾只有作文 difftext + drill 两条建条目流水线，复习组没有钩子；13 也是拍的（4 条本就有归宿）
```
**共同机制：先写汇总数，再（忘记）做事；汇总数没有任何东西验证它。**
⇒ 结构性解药：① 收尾顺序写死「先建条目 → 再写 📊」② 跳过 G6 独立对账 = 这类假记录必然发生
③ 战报里的「新建条目数」必须先建后报（SKILL §2.2，08-16 加）——G6 只 grep 文件，战报是消息，不先建它就验不到

### 1.3 diff 三连错（08-12 / 08-13）
```
08-12  给片段不给整句
08-13  漏了她的一个版本；把她自己产出的 costs 当教练的升级递回去
08-13  「因」里点名 "they 指代不清"，「改」里没动

**共同机制：从「我的改动」出发列 diff，而不是从「她的原文」出发覆盖。**
⇒ 解药：发出前自跑三条机械检查（原句逐字相等 / 覆盖无重无缺 / 因与改一一对应）

### 1.4 题面逼不出考点却判她错 —— 两次（08-11 / 08-15，相隔四天复犯）

### 1.5 越权：把她的"看一下"做成了依赖
她最初只说过一句"你好好看看口语 skill 怎么做"——那是她**偷懒的一次借鉴**，不是授权。
教练先是**抄了个快照**（抄漏了一半规则），被抓到之后又走到另一个极端，
把写作 skill 的复习机制**改成指向口语 skill 的指针** —— 等于把她的 spec 挂在另一条线上。
她的裁决（08-15）：**"一开始我只是我偷懒让你抄下，结果你抄不好。现在我都明确给你说，
你就按照我的做，然后完全忘记口语 skill"**。
⇒ **规则全部在 SKILL.md 里写死，不引用、不依赖任何别的 skill。**
⇒ 元教训：**她说"参考一下"≠ 授权建立依赖。没有明确说要的结构，就别造。**

### 1.6 自己发明的东西顶替她要的东西

## 3. 关于她的诊断（跨天累积，指导训练设计）

### 3.1 注意力单通道
08-10 实证：给了靶子的两项全清零，没给靶子的原样复发（冠词×4 / makes sb have×2 / 逗号粘连 / 单复数）。
08-13 在**一个 10 题的组内**复现：被考的 `much earlier` ✅ / 隔四题没考的 `slowlier` ❌。
⇒ 每篇注意力项 ≤3（靶子 ≤2 ＋ 装备 ≤1），轮换，靠重复变自动。
⇒ **禁写"下次仔细检查"** —— 她 08-09 已判定细心不是解法。

### 3.2 功能词系统性掉队（08-11~08-13 七次同类）
```
no choice but ___ hurt 掉to · wors___ 掉-en · combined ___ pension 掉with
point patients ___ what 掉to · ___effective 掉in- · ___ base on 掉be · advises us ___ taking 该to
```
掉的从来不是内容词，是**功能词**（否定前缀 / 助动词 / 不定式 to / 介词）。
⇒ 她的产出 = 「内容词 ＋ 结构轮廓」，功能词挂在轮廓外，压力一来第一批被挤掉。
⇒ 同一现象在她的口语产出里也成立（单字副词、论元不完整），是同一个带宽机制，不是写作专有。
⇒ 教法：**整块记，中间不许有空格**（`combined-with` / `no-choice-but-to` / `wors-en`）；
   表 B 里这类要标出整块边界 `point sb ▸TO◂ sth`，让她连边界一起存
   （08-13 实证：她吸收了 `point patients`，但**吸收成了半个块**）。

### 3.3 "为了不重复而换词" —— LR 的主要失分源
08-12 实测：干净句率 37.5%→55.6%（GRA 6→7），同时 K270 9→13（LR 6→5），**净效果原地**。
15 个词汇错里 5 个来自主动换词：`secure`(想说 safe) · `negative`(想说 harmful) · `expenditure`(想说 costs)。
⇒ 答案与她直觉相反：**重复关键词在雅思不扣分（题面词尤其），扣分的是为了不重复而用错词。**
   三招替代：①代词/指示词 ②上位词 ③直接省略主语。

### 3.4 她的自我评估系统性偏低（两次）
```
08-12 "每一句都有错"   实际 18 句里 GRA 干净 10 句、一字未动 3 句
08-13 "很多都忘了"     实际 10 题命中 9、完全干净 8 句
```
方向固定 = **把"我不确定"当成"我不会"**。
代价：低估会把带宽花在已经会的东西上，真正该盯的反而滑过去。
⇒ 教练侧动作：每组报**一字未改率**（数字），不让感觉代替数据。
⇒ 也因此**绝不许把她自己的产出当教练的升级递回去**——那会直接加重这个偏差。

### 3.5 单点测通过 ≠ 装上了（写作线版）
`strain` 这条的完整链：
```
08-10 她自述"pressure 想换换不出" → 08-11 题面无效(◎) → 08-11 教练直接给了答案(📖)
→ 08-13 她在 `puts a strain on` 里用对(看着像会了) → 08-15 低压无提示又是 pressure
```
⇒ 刚给过的 ✅ 是短期记忆，不是掌握。**跨天、无提示、题面能逼出考点**，三者齐了才算数。
⇒ 这条在她的口语产出里同样成立。

```

08-11 ④ 题面逼不出考点却判 ❌（"我还要去猜你想要什么太离谱了"）

### 3.7 冠词的统一判据（她自己推出来的）
**限定 ≠ 定指**：限定＝缩小范围；定指＝缩完只剩一个**且听者能确定**。
```
the time spent on them   限定完只剩一段 → 定指 → the
time taken away from X   限定完还剩无数份 → 分类 → 零冠词（不可数）
★ 但同一句里两个都成立：加 the ＝ 说"就是那一段"（同一性判断），本句里反而更有力
  句式 `The time you spend on X is the time you don't spend on Y`
反例   This is money well spent ✅ ／ the money well spent ❌（缩完还剩无数笔）
```
**这条判据是她自己想出来的，直接就是写作冠词题的解药 —— 用她自己的话教她，比教练造术语有效。**
