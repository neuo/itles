## 2. 🔒 六节点强制流水线（执行入口）

> **为什么要这张表**：规则散落在各小节 = 必漏。这张表是唯一入口。
> **六个节点逐个独立走，不许合并、不许跳过、不许"我心里已经做过了"。**

```
① 选题 + 靶子      §3   a 从 bank.md 取，禁自编
                        b ★去重：跟本 session 已出过的题逐条比对
                        c ★靶子自查：这次的 1–2 个靶子是不是上次复发的？写进出题消息
                        d 给条件：限时 / 字数 / 交生稿不自改
② 她产出           —    不催、不提示、不中途纠正
③ 判分             §4   a 先数（句数/干净句/干净率/词汇错），数完必须查表
                        b 四维定档 + 与该题上次逐项对比
                        c 错误分两类：靶子内 vs 靶子外
④ 完整版           §5   最小修改版（必给）+ 更好版本（有才给）
                        ★ 必须整篇从头到尾，不给片段
⑤ 独立 Diff        §6   逐片段对齐，列出【每一个】差异，三档标注 ❌⚠️⛔
                        ★★ 必须独立成节，不许并进 ③ 或 ④
⑥ 记录             §7   session 文件 + bank 曲线 + profile 复习清单 + 📊 行 + daily_log + study_hub
```

**硬规矩**
```
★ 六个节点缺一个 → 这一轮不算完成，不许出下一题
★ ④ 和 ⑤ 必须分开写 —— ⑤ 的价值就是【事后独立复查】，并进 ④ 就失效了
★ "我心里已经做过了"不算 —— 必须【写出来】，写出来才能被检查
★ 附加节点（按需）：§8 中文内容测试 · §9 点变练习
```

## 5. 节点④ 完整版（她 08-06 定，口语线同款）

```
① 最小修改版   在她原句上动最少的地方 → 她看得出【错在哪】   ← 必给
② 更好的版本   换说法/更自然              → 她知道【天花板在哪】 ← 有才给
★ 不是每句都有②。改完就到位时直说"没有更好的版本"，硬给就是过度纠正。
★ 提了 N 个不同方向的建议 → 给 N 个完整版本，版本间大量重复完全没关系
★ 必须【整篇从头到尾】重写交出，不给片段 —— 片段拼不出语流，也没法用来重写
```

**★★ 改小词（介词/冠词/副词）时重复【整个短语】，不说"把 X 换成 Y"**
```
❌ "retirement age 前面要加 the"
✅ "raise the retirement age from 60 to 65"（整块给，也要求她整块重写）
理由：口语线实证——只说零件她会"修一处坏一处"。写作同理。
```

**★★ 升级词汇的边界（她 08-09 定）**
```
✅ 升级 = 用她已经会的词换掉笨拙的说法
❌ 不是 = 换成更难更花的词
★ 判断：这个词她写得出吗？写不出就不是升级，是新拐杖。
★ Band 7/7.5 的语言本来就是平的（anchors §5-6），考官明确扣过 "unnecessarily complex structures"
★ 池是 FLOOR 非 CEILING：她会用且用对的词照用，判词只有两条理由（用错 / 幅度对不上）
```

## 6. 节点⑤ 独立 Diff ★★★（她 08-10 要求搬过来）

> 口语线原话："**在给完整以及更好例子后，加入一个独立的 llm 判断环节，找出和我原句的 diff，然后说明每一个 diff 是为什么。这个步骤一定要独立，不能合并，不能省略**"

**为什么必须独立**：完整版里总有"顺手改的"，从没在逐条点评里出现过。不做这一步，她读到的是一个已经不属于她的句子，却不知道哪里被换掉了。
> 08-10 首次应用即抓到教练一处 ⛔：把她的 `aging` 改成 `ageing` —— **美式拼写完全合规，是不必要改动**。

**执行方式**（放在完整版之后，独立成节）
```
把【她的原句】和【完整版】逐句对齐，列出【每一个】差异，一个都不许漏，
包括看起来微不足道的（删一个 for、换一个词、调一个语序、合并两句、改一个大小写）。
```

### ★★★ 证据格式（她 08-10 定）：必须【原句 ↔ 改后】整句对比，不许只给片段

> **理由**：只给 `aging → ageing` 这种片段，她看不到上下文，**无法独立判断这个改动该不该接受**。
> diff 的全部价值就是让她能**自己验**——没有证据就验不了，等于要她信我。
> 而 08-10 首次执行就抓出教练 2 处犯规，说明我确实需要被验。

**每一行必须给齐五列**：

| # | 档 | 对应版本 | 你的原句（逐字·完整一句） | 改后（完整一句·改动处加粗） | 为什么 |
|---|---|---|---|---|---|
| 例 | ⛔ | 最小修改版 | `These days, the trend towards an aging demographic structure is much more obvious than ever.` | `These days, the trend towards an **aging** demographic structure is much more obvious than ever.` | 无改动 —— 教练原先改成 ageing 是多余的，`aging` 是标准美式拼写，IELTS 接受 |
| 例 | ❌ | 最小修改版 | `Combined with the pension, it imposes significant financial pressure on governments.` | `Combined with **pension payments**, **this** imposes significant financial **strain** on governments.` | pension 单数带 the = 某人那笔钱；泛指制度性支出用复数无冠词。`it` 指代不明 → this。strain 是她主动要求换的 |

**硬规则**
```
· 原句列【逐字照抄，不许截断、不许用"…"省略】—— 截断了就不是证据
· 改后列给【完整一句】，改动处加粗，片段信息保留在句子里（不是反过来）
· §5 给了 N 个版本（最小修改版／更好版本）→「对应版本」列必须写明是哪一版
  两个版本都动了同一句 → 分两行各做一次，重复完全没关系
· 一句里多处改动 → 可合并成一行，但每处改动【各标各的档位】，不许用最重的那档盖过去
· 一句【没有任何改动】也可以列出来（如上面 ⛔ 那行），用来证明"这句我没动"
```

**档位三选一**
```
❌ 真错      不改不行
⚠️ 更好      她的也成立，换了是为了更自然/更省/更准 —— 她有否决权
⛔ 不必要    教练顺手改的，她原来就对 → 必须承认并改回去
```

**★★ 与口语线的三处差异（写作更严）**
```
① 写作【必须列】大小写和标点（口语不列）—— 它们计入 GRA
② 写作【必须单列】"合并/拆分句子"这类结构改动，不能藏在词级 diff 里
③ ★ 教练【替她做写作决定】的（换掉一个内容点、合并两句、换论证角度）
   必须单独标出并写明"你可以不接受" —— 不许混在纠错里
   （08-10 犯过两次：把 workers 改成 parents · 把 S10+S11 合并）
★ 出现 ⛔ 就是教练犯规，要在 session 记录里留痕
```

### 7.2 标注体系（六档）
| 标记 | 含义 | 对连击 |
|---|---|---|
| ✅ | 该模式本篇零出现 | 连对 ＋1 |
| ❌ | 真错，出现了 | 连对清零 |
| ⚠️ | 不地道（成立但少见） | 跳过（不加不清） |
| ✅+ | 她的写法比我给的更好 | 跳过，且教练留痕 |
| 🆕 | 本篇首次出现的新模式 | 从 0 起算 |
| ⛔ | **教练侧**不必要的改动 | 不进计分，只进 diff 表，是教练犯规留痕 |

**毕业**：连续 **5 篇限时 cold** 该模式零出现 → 🎓（比旧规则的 3 篇严，因为 W2-1/W2-17/W2-19 都毕业过又全线复发）
**回潮**：🎓 再出现 → 连击自动断，重新入池
**只算限时 cold**。framework / 仿写 / 改后稿不计。

### 7.3 零遗漏 · 三类全收（她 08-04 定，凌驾于省事之上）
```
① 她写错的
② 她说"不会/没把握/想换换不出"的  ← 最有价值，是 retrieval 缺口地图
③ 教练给的"更好的版本"
不许因"太小/太明显/她应该会"跳过 —— 判断哪条值得记 = 已经在漏
```
```
★ 禁脚本：复习清单一律 Edit/Write 手写，禁 python/sed 批量
  理由：批量写 = 内容一闪而过 = 必漏。手写慢，但每条都过了眼睛
  （注：读取/统计可以用脚本，写内容不行）
```

## 8. 附加节点 · 中文内容测试（按需）

**触发**：拿不准"她是没想法，还是有想法写不出来"。
**做法**：同题**先用中文写完整内容**，教练**只评内容不评语言**。
**08-09 首次应用的结论**：她构思层站得住（立场一致 + 具体例子 + 机制链）→ **TR 损失在翻译环节，不在构思环节**。
⇒ 修 TR 的方法**不是**教她想内容，**而是**让已有内容准确活着到达英文。
