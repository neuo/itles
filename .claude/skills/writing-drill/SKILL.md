# Writing Drill

## 0. 硬约束

```
0.1 /clear 或 compact 后第一个动作 = 完整重读本文件，读完才许出题/判分/记录。
    第二个动作 = 跑 `python3 writing-band7/drill2/drill.py stats` 恢复档案状态。
    ⛔ **不许整档重读 problems.md** —— 状态从脚本拿，条目正文只在抽中时按行号打开。
    本 session 的 scope 是【写作】，compact/clear 后照样有效，不许回头问练哪条线。

0.2 ⛔ 禁自行收工。流程走到哪一步都不许问"要不要收"，她明确指示才收。

0.2b 进度**按 sessions 文件核查**，⛔ 不从 daily_log 推断（daily_log 是 partial 记录）。

0.3 ⛔ 所有内容文件手工写。
    ★ 允许的脚本**只有两个**：
      · `pick_question.py`   抽作文题（读 bank.md，append drawn.log）
      · `drill.py`           抽复习题／统计／格式校验／记账／**交付物硬闸**／**双向搬迁**
                             （读档案，append drawn_review.log）
      （`tests/` 下是回归测试台，只跑临时副本、不碰真档案，⛔ 不算工作脚本）
    判据写死：**脚本可以【读档案 + 打印 + append 流水日志】，⛔ 绝不许产生任何一个字的内容**。
    ★ 例外只有三个子命令，**都只碰位置、⛔ 都不产生一个字**：
      · `drill.py append`：判定行的**行文仍然全部手写**，脚本只干两件机器活 ——
        ① 把写好的行插到正确位置　② 连对／连错／上次 三个数重算
        ★ **两个文件都能写** —— 复检队列要在 `graduated.md` 的毕业条目上
          记判定行（§4②b）。校验、写完自查照做，
          **任何一步不过就两个文件一起回滚**。
      ⛔ 它不改 🎓、不改状态、不碰条目正文、不碰成员出题账 —— 那些是判断，仍然手写。
      · `drill.py migrate`：problems.md ⇄ graduated.md **双向搬迁**，
        只按状态行第 1 格把**已有的整块字节**从一个文件挪到另一个文件（§3.3）。
      ⛔ 它不改状态、不改正文、不改任何一个数、不碰两个文件的头部说明块 ——
        谁毕业、谁降级仍然是教练手改状态行，脚本只认改完的结果。
      · `drill.py trigger`：把 session 里**当天实际用的中文题面**
        搬回条目的 `**中文触发点**` 节（§6 通则要求换题面，换出来的本来只活在 session 里）。
        判据：**只搬 session 的「### 题面」围栏里已经存在的中文**，逐字；
        除固定格式的包装（`（老触发点留档不删：…）` 一行 ＋ `⚠️ YYYY-MM-DD 换题面` 一行）
        外⛔不产生任何内容。老触发点**留档不删**，只压成一行。
      ⛔ 它不改状态、不改别的节、不改任何一个数、不碰历史记录；
        条目在 `graduated.md` ／ 题型 ＝ 词组 ／ 作文验 ⇒ **逐条跳过、其余照常写**
        （整批不写只发生在 rows 输入本身坏掉时）；
        已经搬过的**跳过**（幂等）；写完自校（条目正文除这一节外逐字节 ＋ 状态字段 ＋
        内部 check 无新增），**任何一条不过就整批回滚**。
      ⇒ 「记录禁脚本」防的是**漏记与代笔**；位置和算术是机器规则。
    「记录禁脚本」防的是漏记，只读工具不碰记录，反而让漏记查得出来。
    ⛔ 禁按行号编辑档案，一律按锚点字符串定位（`## #0015` 这种唯一串），改完回读确认。
    ★ **要改某条的正文（扩写规则／改标题／补成员账）⇒ 先 `drill.py show #NNNN` 拿全文，
      一次改完**。⛔ 禁「改一次看一次」。
    ★★ **每次写完 problems.md／graduated.md，当场跑
       `python3 writing-band7/drill2/drill.py check --changed`，ERROR 归零才算写完。**
       带着 ERROR 往下走 = 这一步没做完。
       （`--changed` 比的是 `git diff HEAD` ⇒ **commit 之前跑**；已 commit 的用 `--all`）

0.3b ★★ **一场 session 跨了自然日 ⇒ 所有带 `--date` 的子命令一律传【这场 session 开始那天】**
```
    drill.py pick   --type review --date YYYY-MM-DD     ← 不传就只认「今天已用」，昨天做完的组会被排回来
    drill.py used   --group N     --date YYYY-MM-DD     ← 不传就把定稿记到另一天的账上
    drill.py append --file rows.md --date YYYY-MM-DD    ← 判定行的日期，本来就一直要传
```
    ⚠️ 一个练习日 ＝ **有行为的那一场**（§1），⛔ 不是一个自然日。
    ⚠️ **judgement 行的日期也一律用 session 开始那天** —— 否则同一场里出现两个日期，
    　 §3.2 的「当天只结算一次」与 §3.6 的「有效上次」都会算错，log.md 那一行也对不上。
    ⚠️ `trigger` `migrate` `check` `stats` `count` `deliver` **不写日期**，⛔ 不需要这个参数。

0.4 报出的每个数必须同时贴出它数自哪些行。数不出来不许报。禁"大约/左右/估计"。
    口径有分歧报区间并说明。
    ★ 全档级的数（总数／在池／🎓／连对1／连对0／题面待补）**一律由 `drill.py stats` 产出**，
      ⛔ 不许口算、不许沿用上一组的旧值。★ **两条队列各到期多少 ＝ `drill.py pick` 打的**，
      ⛔ stats 里没有这个数。

    ★★ **除此以外的任何「有多少条 X」，一律跑 `drill.py count`**
```
      python3 writing-band7/drill2/drill.py count                      ← 全部类型一张表
      python3 writing-band7/drill2/drill.py count --type essay         ← 该类型的编号清单
      python3 writing-band7/drill2/drill.py count --type essay --detail ← 逐条详情
      python3 writing-band7/drill2/drill.py count --type fam:F08       ← 按族
```
    · 类型的**全套 slug 与口径写死在 §3.1 契约⑫**，脚本与那张表是同一份东西，
      改一处必须同步改另一处。⛔ 不许临时发明类型名。
    · ⛔ **禁用 grep 数条目**。grep 数的是"字符串出现了几次"，脚本数的是"符合口径的条目有几条" ——
      两者天生不等（同一条里写两遍、或那句话落在正文别处，grep 都会数错）。
    · ★★ **报这种数必须写清是【全档】还是【在池】口径** —— `count` 两个数并排打出来就是为这个。
      ⇒ 报数一律「类型 slug ＋ 口径 ＋ 数」三件齐。

0.5 先记录，后反馈 —— **记录 ＝ 当日 session 文件**。
    顺序写死：**① 判定 → ② 写 session 文件 → ③ 发反馈 → ④ 记 problems.md 账**。
    ⛔ 不许口头发完再补 session；⛔ 也不许为了等 problems.md 记完账而压着反馈不发。
    ★ ④ 记账时照抄 ② 里已定稿的判定即可，⛔ 不用再推一遍。
    ★ ④ 用 `drill.py append`（§0.3 §3.1 契约⑪）：判定行写进一个 rows 文件，一次落盘。
    她之后要求修改的，改完同步改两处文件。

    ⛔ 禁把交付物留在 session 文件里、聊天只发摘要。她看不到 = 没交付。

0.9a ★★★ **交付物硬闸 —— 发给她之前必须跑，ERROR 0 才许发**
```
     python3 writing-band7/drill2/drill.py deliver --session sessions/YYYY-MM-DD.md \
            [--section 组N|复检N|回看|新题|追加练]
```
    ⛔ **ERROR > 0 ⇒ 不许发。** 与 `check --changed` 同一个仪式：改完重跑，归零才算写完。

    ★ ⛔ 不许写"发出前先自查"的散文钩子 —— **规则写在散文里、闸不查它，就等于没有。**

    **它查什么（写死，与 `drill.py` 的 `DELIVER_SPECS` 是同一份东西，改一处必须同步改另一处）**
```
    ① 块数守恒    三版对照块的块数 **必须等于** 该节的句数／题数
                  （从「她的原文」的 S 编号或『共 N 句』数，没有就数「题面」的编号题）
    ② 块内五行齐   原句 ／ 最小修改 ／ └ 改了什么 ／ 更好版 ／ └ 为什么好 —— 缺一行报错
                  ⇒ 这一条同时把「只写改了哪几个字、不写为什么」堵死
    ③ 占位合法     〔未改〕〔没有更好的版本〕是合法值；标签后面空着 ⇒ 报错
    ④ 节交付件齐   复习组 6 件：题面 · 她的答案 · 判定表 · **顺带判定** · 三版对照块 ·
                  　　　　　战报（①–⑤ 五行齐）
                  **复检组**（§4③e）：题面 · 她的答案 · 判定表 · 顺带判定 · 战报四行；
                  　　　　　三版对照块是**条件性**的 —— 战报里「本组 ❌ N 条」的 N ＞ 0 才要求，
                  　　　　　且**块数 ＝ N**（⛔ 不是本组题数）；N ＝ 0 却写了块 ⇒ 也报错。
                  　　　　★★ **战报三行逐个与【判定表】对账**（编号集合都要一致）：
                  　　　　　 ✅ 行 ／ ❌ 行 ／ 回潮行。⛔ 战报的数是手打的、**判定表才是读数** ——
                  　　　　　 不对账的话「判定表判 ❌、战报写 ❌ 0 条、块也不写」照样 ERROR 0。
                  　　　　　 回潮行的编号必须**等于**判 ❌ 的那几条（🎓 吃 ❌ 就要当场回潮，§3.3）
                  **追加练**（§4.8）：头一行（扣分项／入口B ＋ 计划 M 题）· 允许集 · 找点
                  　　　　　· 三闸（闸1/2/3）· 重数
                  　　　　　每个 `#A<n>` 四件（原句／出处／要求／目标量）＋ 判定四件
                  　　　　　（答案／实际量／判定／三版对照块五行）；**词数由脚本数**，
                  　　　　　净增量 ≤ 0 ⇒ ERROR（除非块里写了 `作废　<理由>`）
                  　　　　　⛔ 追加练**不适用**本节的 ①块数守恒 与 ⑤摘要句黑名单；
                  　　　　　允许集（入口B 可省）与 重数（只在收官档）按档位豁免
                  回看   5 件：题面与条件 · 她的原文 · 三版对照块 · 最小修改版全文 · 更好版全文
                  　　　 ★ **回看节可以有多个**（与追加练同）—— 复习日本周期两篇新题都要回看。
                  　　　 　 每一节独立成节、各查自己的 5 件与**本节**「她的原文」的块数守恒
                  新题   8 件：题面与条件 · 她的原文 · 收稿 · 判分 · 对照 · 三版对照块 ·
                              最小修改版全文 · 更好版全文
    ⑤ 摘要句黑名单 三版对照块里出现「其余全部未改／其余略／以下略／不再逐一…」⇒ 报错
                  —— **未改也要逐块列出来**
    ⑥ 声明跳过的节（§4④ 全部新题都已回看过）⇒ 打 SKIP，不查
                  ★★ **只认「本节跳过」这四个字**。
                  ⚠️ 存量放行：2026-09-05 之前的 session 仍认 `按 §4④「D-1 没写新题就跳过」`
    ⑦ **新建条目的正文**（**条件性**；只查「组」「复检组」「新题」三种节）
                  触发条件 ＝ **该节自己报了「新建 ≥1 条」**：严格匹配 `新建　N 条` ／
                  　　　　　 `本组新建  N 条` ／ `新建 N 条：#0415 …` 这样的行（取该行第一个整数当 N，
                  　　　　　 该行里所有 `#dddd` ＝ 声明的编号）。⛔ 不兜底：
                  　　　　　 **找不到这样的行 ／ 报 0 条 ⇒ 这一条不适用、⛔ 不报错**
                  要求　　　 该节里要有一个 `###` 子件、标题的某一段以「新建条目」／「新建的条目」开头
                  　　　　　（`### 本组新建条目的正文` ✅），**且声明的每一个编号都要在这个子件的正文里出现**；
                  　　　　　 缺子件 ⇒ ERROR（§4③d③：⛔ 只报编号 ＝ 没交付）；少哪个编号 ⇒ ERROR 并点名
                  ⛔ 回看（只看不做）与追加练（建号走 §4.8 S10）**不吃这一条**
```

    **session 的标题锚点（脚本靠它切节，写歪了查不到 ⇒ 改 session，不改脚本）**
```
    节：  `## 复习 · 第 N 组`　`## 复检 · 第 N 组`　`## 回看…`　`## 新题…`　`## 追加练…`（可多个，各带标签）
          ★★ **所有节一律在【已知顶层节】处收口**（脚本里是 `KNOWN_H2`，

## 3. problems.md

### 3.1 条目格式

每条一个块，顺序写死：**编号与状态行 → 说明 → 中文触发点 → 历史记录**。

```markdown
## #0048 主语跨过长名词块后谓语被拉走
状态：在池 ｜ 连对 1 ｜ 连错 0 ｜ 毕业线 2 ｜ 上次 2026-08-22 ｜ 族 F04 ｜ 题型 整句

**问题是什么**
主语是 the number / the amount / the cost 这类单数中心词，后面跟一串 of 短语，
谓语跟着最近的复数名词走。中心词永远是 of 前面那个。

**怎么发现的**
2026-08-20 作文 T2-08 S5：`The amount of carbon dioxide produced by heavy industry,
power stations and international shipping are much greater…`

**我错在哪**
她的：the amount of … **are**
正确：the amount of … **is**
找中心词的办法：盖住所有 of / in / with 开头的短语，剩下那个名词才是主语。

**中文触发点**
这些机器的维修费用相当高。

### 历史记录
- 2026-08-20 ❌ 作文 T2-08 S5
  写成 `the amount of … are`。同一篇 S8 的 `the influence of ordinary people is` 是对的，
  说明不是不知道规则，是主语一长就丢。
- 2026-08-21 ❌ 作文 T1-05 S9
  写成 `The number of closures … were stable`。当天上午复习组第 3 题
  `The main problem these countries face is` 写对了，同一天复习组对、写作文时错。
- 2026-08-22 ✅ 复习组2 第 13 题
  写出 `The cost of repairing these machines is quite high`。
  这题的陷阱是最强形状（中心词单数、紧挨谓语的是复数），她没被拉走，也没把主语拆短绕过去。
```

连对连错  从历史记录逐行数出来。任何人拿这份档案都能重算出这两个数
毕业线    一律 2（§3.3）。这一格永远写 2

**1.2 用三问判定是不是同一条**

对每个候选编号，逐个问这三句。**三个都是"是"才算同一条。**

```
问1  改正的动作是不是同一个？
     droped→dropped 与 occured→occurred：都是"重读闭音节，后缀前双写末辅音" → 是
     whlie→while 与 fluctution→fluctuation：一个是字母顺序颠倒、一个是漏音节 → 否

问2  讲给她的那句规则，是不是同一句？
     能用完全相同的一句话把两个实例都解释掉 → 是
     要分两句话讲 → 否

问3  如果她掌握了其中一个，另一个会不会自动跟着对？
     会 → 是（同一条）
     不会 → 否（两条）
```

**1.3 反向验：找一个"一个对一个错"的实例**

```
如果能举出【一个真实句子，其中 A 犯了而 B 没犯】（或反过来）
⇒ 两者可以独立取值 ⇒ 不是同一条规则，不许合并。

实例（照这个标准判）：
· "名词堆" vs "长主语主谓一致"
  `The small size of the change in copper prices make…` 两条都犯
  `The cost of repairing these machines is quite high` 主语照样长，但谓语对了
  ⇒ 可独立取值 ⇒ 两条，不合并
· `the amount of … are` 与 `the number of … were`
  找不到"一个对一个错"的句子，中心词永远是 of 前面那个
  ⇒ 同一条，合并
```

**1.4 三个最常见的误判，先记住**

```
误判1  看句子不看规则
       "这次是 T1 那句、上次是 T2 那句" —— 句子不同不代表规则不同。判据只看规则。
误判2  被词面骗
       同一个词的两个不同问题不是同一条（`suggest` 的动词框架 vs `suggest` 的拼写）；
       不同词的同一个规则是同一条（`droped` 和 `transfered` 都是双写）。
误判3  怕"归错了"就新建
       ⇒ 拿不准时【先归入】，并在历史记录那一行注明「归入待确认」，收尾时复查。
```

### 3.6 ★★★ 召回机制 —— 一条梯子，毕业线只是中间一格

> **这一节是 §4 和 §8 的共同底座。** 学习日与复习日**不是两套取法**，
> 只差【配额】和【有没有新作文】两件事。取哪些、什么顺序，全由这一节定死。
> 别处一律指回这里，⛔ 不许在别的节里再写一份取题规则。

**一条梯子。格上的数字 ＝ 应等几个【练习日】**（§1：休息日不存在）。

```
  1   →   1   →   2   →  ┃毕业线 连对2┃  →   3   →   7   →  16   →  32   →  60
 首测未做  连错1   连对1                    🎓rc0   🎓rc1   🎓rc2   🎓rc3   🎓rc≥4
 连错≥2

rc（复检次数）＝ **毕业日之后**有「对」的**天数**（✅ ／ ◎✅ ／ 📋 顺带用对）
　　★ 📋 算 —— 她在作文里自发用对了，和一次复检通过同权
　　★ 按**天**不按行（§3.2 同日只结算一次，rc 跟同一个口径）
　　★ 回潮之后重新毕业 ⇒ 毕业日重算、**rc 归零**，梯子从 🎓rc0 重爬
★ 在池条目**历史掉过 ❌／📖 ⇒ 在梯子上降一格**；复检队列（🎓）⛔ 不降格
⛔ 全部从历史记录导出，档案里**零新字段** —— 不加"下次召回日"这种要人维护的格子。
```

**到期与排序**：

```
有效上次 ＝ 最后一行 ✅ ／ ◎✅ ／ ❌ ／ 📖 ／ △ ／ 📋 的日期
           ★ △ 算 —— 她答出来了、只是有更好的说法，考点那一次**被行使过**了
           ⛔ ◎− ／ 光杆 ◎ 不算（定义就是「这次题面有毛病、没测成」，不该把条目往后推）
           ⛔ ③ 建号行 ／ 📝 留痕行 ／ 被 §4.7 改判过的行 都不算
           ⚠️ 与状态行的「上次」不是一个口径：那一格是「上次被**处理**过」（③ 📝 也算），
              这里问的是「上次被**测**到」
到期     ＝ 距有效上次的练习日数 ≥ 应等间隔     （**今天算一个**练习日）
           从未测过 ⇒ 无条件到期
排序     ＝ 在池：逾期分（已等 ÷ 应等）降序 → 掉过的优先 → 编号升序（从未测过排最前）
           复检：复检次数少的优先 → 已等练习日多的优先 → 编号升序
           （确定性，同一天重跑逐字一样）
```

**两条队列，配额分开**（⇒ 复检永远饿不死，在池永远优先）：

| | 在池队列（未毕业） | 复检队列（🎓） |
|---|---|---|
| 学习日 | **≤3 组** | **1 组** |
| 复习日 | **≤5 组** | **3 组** |

```

     唯一的例外：**今天已经测过的不再算必出**（有效上次 ＝ 今天）—— 义务是"出完"，
       ⛔ 不是"同一天问两遍"；`pick` 会把这几条单列成「义务已尽」
   必出层排完还有余量 ⇒ 按逾期分补到 ≤3 ／ ≤5 组为止
★ 在池是【上限】，排不满就是没有；空出来的组数**下溢给复检**（⛔ 反向不成立）
★ 下溢**不设上限**
★ 一组 ＝ 10 条。组里的**词组条目照 §6.1 并成一道词组题** ⇒
  一组的【题数】可以少于【条数】，报数时两个都写
★★ **剔除口径（全档唯一一份，别处一律指回这里）**：
  退池 ／ 并入 · 挂作文验（题型 ＝ 作文验，§6）· **建号当天的**（次日起进队列，
  那时它站在「首测未做」格 ⇒ 间隔 1 ⇒ 次日必出）· 本场已 `used` 的
  ⛔ 题面待补的**不剔除** —— 那是出题前当场补，`pick` 只点名（§3.1 B4）
```

**⇒ 执行动作只有一条命令**（⛔ 教练不许自己挑题、不许自己排序）：

### 4.3.1 ★★★ 更好版的三条硬约束

> **更好版 ＝ 把【她那一句／那一篇】写得更好，不是教练另写一篇。**
> 复习组的更好版、作文的更好版，两条路一视同仁。

```

     更好版里必须**还在**。位置可以挪，说法可以换，⛔ 内容不许蒸发。
   · 更好版里的每一个信息点，必须能在她原文里**指出出处**。
     ⛔ 不许加她没写的意思、没写的数字、没写的细节。
   · ⛔ **不许把她的具体展开抽象成一句概括** —— 那是删内容，不是升级。
   ⇒ 发出前逐点对一遍：**她有的我有没有 · 我有的她有没有**。两个方向都对得上才算数。

② 词的档位**不许超过她自己的水平线** —— 她自己写出来的词，默认就是合法的

     a **她用错了**：搭配错／词义错／语域错 —— 必须当场指出错在哪

③ ⛔ **省字数不是理由。**

### 4.7 改判

教练推翻自己此前的判定或判分时：

```

5 当日 session 记一条改判行

```

## 5. 判分

```
铁律：先数后判。任何一项分给出之前，先把它依赖的数打印出来。

第1步 切句      按句号切，分号独立成句，逗号粘连算 1 句但记 1 个错

第3步 数词汇错  逐条列出标子类。K270 = K ÷ 实际词数 × 270，四舍五入，打印算式
第4步 数数据错  每个数字年份比例逐个回图核对，打印核对表。

　⛔ **重写触发点时，条目里原括号的每一个限定逐字带过去，一个都不许丢**
　★ 反过来也成立：**没发出去的限定不许拿来判她**（存档题面 ≠ 实际发出的题面）

★★ **题面的点名是【引导】，不是【判错的门】**（判据见 §3.2）
　她换一条合法的路、把意思送到了 ⇒ 算对（◎✅），**当场改题面**；
　改的方向是把目标英文词直接写进去，不是把题目出得更绕

★ **出题前先查这个考点的语言事实**
　凡是"只在某些语境里成立"的结构（如情态 dare 只活在否定与疑问里），
　题面必须落在它成立的那个语境里；落在不成立的语境 ⇒ 她两条路都不合法 ⇒ 整题作废

★★ **中文题面发出去之前，自己先直译一遍，确认落点是自然英文搭配**
　例 #0303：「取代大量**岗位**」，忠实直译只能落到 `replace jobs`——
　而 replace 的默认宾语是被顶替掉的**人**，`replace workers` 才是主流搭配。
　⇒ 落点别扭就**换中文**，不许等她翻出别扭的英文再判她。

★★ **语域类考点，中译英单点题测不了 —— 一律挂作文验**
　例 #0267：`a bit heavy` 在一个孤立的中文句子里是**完全正确的英语**，
　"口语词不该进作文"这件事**需要作文语境才存在**。
　⇒ 建条目时把两半分开写清：**能在单点题测的（选词/刻度/搭配）** vs **只能挂作文验的（语域）**。
　⇒ 不分清就会拿作文的标准去判一道中译英题 ⇒ 假错。

★ **词表型条目：一道题必须让 ≥2 个成员落地**，⛔ 不许只考一个词
　做法：中文题面写成多个半句／多句翻译，每个半句点一个成员
　出题前看条目底部的**成员出题账**（§3.5 第 3.5 步），挑没出过的成员；出完补一行

★ **从她作文里建的条目，题面必须换场景** —— 拿原句回去测的是记忆，不是产出
★ ⛔⛔ **她自发用过的块不自动挂作文验 —— 自发用过 ≠ 不用练**
　 ★ 自发用过的块会出现「自发用得出、被点名反而调不出」（#0289 yield · #0292 carry ·
　 　 #0297 accompanied by · #0446 smallholder）
　 ⇒ **换出题方式，⛔ 不是移出队列**：
```
　 ⛔ 中文块 → ？　　　　　（测"调不调得出" —— 这个读数在她身上无效）
　 ✅ **先给英文块，只让她写用法**（造句／写它的搭配与介词）
　 　 　 —— 与「连错 ≥2 的词组条目」的做法同一条
```

★★ **判定"这条根本出不了单点题"⇒ 两处一起写**
```
状态行     ｜ 题型 作文验            ← ★ 机器真源。`pick` 认的是这一格
中文触发点  ⛔ **挂作文验，不出单点题**（YYYY-MM-DD 定）—— <一句话理由>   ← 给人看的理由
```
　⇒ `pick` 认到就把它移出复习池，单列在计划顶部，提醒判作文时对着扫（§4⑤d）。
　★ 只写了题型格、没写理由行 ⇒ `check` 报 WARN（理由必须留下）。
　★ 只写了理由行、没标题型格 ⇒ `check` 列进**待回标**（`count --type ask-todo`）。
　　 **新判的必须两处一起写**。
　已知该挂的四类：
　　① 拼成**非词**的手滑（§3.2 复习组一律豁免 ⇒ 单点题判不了）· 大小写 · 排版空格
　　② 条目自己写着「留痕／无缺口可测」「第②类，不出中译英」的
　　③ 要**回图核**才知道错没错的 T1 数据类
　　④ 迁移进来的**教练侧流程观察**（§2 明令不进档案，留档不删、不召回）

组内排布
　★ **发现"这两条不能同组"⇒ 当场写进条目正文，写成这个句式：**
　　`⚠️ 这条不能和 #NNNN 同组 —— <理由>`
　　⇒ `drill.py pick` 每次都会扫这句话，两条同时抽到就打 ⛔ 禁配。
　　⛔ 写成别的说法（"最好别和…"）脚本认不出来 —— **认的只有「不能和 #NNNN」**
　· 提示关系查两层　考点层：同组两题的考点不许同词族、同块、同句两半、同语境
　　　　　　　　　　措辞层：同组两题的中文题面不许共享关键词
　· 同一编号在不同日子出题必须换新的中文触发点，老触发点留档不删
　· 回指指代类考点单句测不了，用两句话的题面或挂作文验
　· 主动被动类考点不许用两头都能用的动词（stop close open start change break）
　· 去重：脚本管（`用` 过的本日不再出），⛔ 不用再手工挂清单

⛔ **禁按连对数排出题优先级**
　选题的唯一依据 ＝ **§3.6 的召回队列**（队列排序 ＋ 必出层），⛔ 教练不许另立标准
　「连对 1 有 N 条」只当**预警**：一场毕业一大批时先怀疑判宽了
```

## 7. 靶子与装备

```
靶子 ≤2，跟她的错误模式走，从 problems.md 推，来源写出来。
上一个学习日的靶子继续用，直到它在一篇限时 cold 作文里清零。
复习组答对不算清零。

★★ **靶子是给一个【已确诊的漏洞】开的药，⛔ 不是给每段/每句加的一道工序**
```
⇒ 靶子1 ＝ **每段只留一个中心（中心句放段首）＋ 段尾不许换轴、不许搬别段的主题**
⇒ 段尾要不要再写一句回扣，按 scoring.md §2.3a 第 ⑤ 项的两秒判据现场判，⛔ 不是每段都写：
　 **盖住段尾那一句，这一段还看得出在答哪个问 ⇒ 不用写；盖住就看不出 ⇒ 必须写。**
⇒ 写靶子的时候自查一句：**这条靶子说的是"补上她漏掉的"，还是"每次都要多做一步"？**
　 是后者 ⇒ 措辞有问题，重写。
```

靶子不适用于本篇题型时停靠：不占名额、不计清零、不算失守，下一篇遇到适用题型再上。
题级风险单列：bank.md 里这题历史上的最大扣分项，写在出题消息的「本题历史」一行，不占靶子名额。

装备 ≤1，是一个**写的当下就改变产出**的动作，⛔ 不是一个表达、⛔ 更不是"交卷前再检查一遍"。

★★ **⛔ 检查型装备整类不许用**
```
**判据（发装备之前必过）**
　问一句：这个动作是**在写这一句的时候**改变她写出来的东西，还是**写完之后回头找错**？
　　前者 ⇒ 可以当装备　　后者 ⇒ ⛔ 作废，换掉
　⛔ 「交卷前扫一遍 X」「写完检查 Y」「回头核对 Z」一律不许进装备栏
　★ 找不到合格的装备 ⇒ **装备栏留空**，⛔ 不许硬凑一个检查动作填上

**为什么**
　目标是**一遍过**：检查只能捞出极少的问题，真正的解法是把能力提上来、让错误在产出时就不发生。
　⇒ 训练资源花在"下次这个位置直接写对"，⛔ 不花在"下次记得回头看"。
　⚠️ 与 §2⑤ 的 R 项不冲突：R 项是**教练每组必扫**的（教练的动作），
　　 ⛔ 不是塞给她在考场里执行的动作。
　⚠️ 与 §5「四问自审」也不冲突：那是**教练发出前**的自查，⛔ 不是她的写作工序。
```

每篇收尾写"用上没有、用对没有"（装备栏为空则写「本篇无装备」）。
★ **§4.8 追加练**是【判分之后的补练】，⛔ 不是给她带进考场的动作 ⇒ 与装备栏无关，不占名额。
写作过程中的注意力项 ≤3 = 靶子 ≤2 + 装备 ≤1（**装备栏可以是空的**）。
```

## 8. 复习日流程

> 与学习日**同一条队列、同一套排序**（§3.6），差别只有两件：**配额更大** ＋ **⛔ 不写新作文**。

```
① 开场：跑 `drill.py stats` ＋ `drill.py pick --type review`。
   配额 ＝ **在池 ≤5 组 ＋ 复检 3 组（＋ 在池排不满时下溢过来的）**。
   清单由脚本列出（剔除口径见 §3.6），照抄进 session。
② 复习：每组走 §4③；**复检组走 §4③e**（✅ 只记一行，❌ 才走三版对照块）。
   ⛔ 每组不用重跑 pick（开场已一次分好，组号脚本自己数）。
③ 回看：本周期全部新题整套输出，全文 —— **复习日按本条走**，⛔ 不按 §4④ 的「只回看一篇」。
   ★ 它回看过的那几篇**同样计入「已回看」**（§4④ 认的就是 `## 回看` 标题行上的题号）
     ⇒ 下一个学习日的 §4④ 自动跳过它们。**每一节的标题行都要写上题号**：
     ✅ `## 回看 · T2-22（本周期 D1 · 2026-08-29）`　⛔ `## 回看（§4④）`（那样等于没回看）
④ 问题档 review，四件事（a 就是 §3.5 第 4 步的全档版）：
   a 重复项合并。**跑 `python3 writing-band7/drill2/drill.py list` 把全档按族列一遍**
     （非 detail，一条一行），再逐族看有没有该并的；可疑的用 `dedup` 与 `show` 坐实。
     合并 = 留最早号，其余标「并入 #xxxx」，历史记录搬进保留号，合并后跑 `check --changed`
     ★ **必须跨已毕业一起判** —— 🎓 占全档六成以上，只在未毕业里判重等于没判
   b 判词矛盾排查：同一个点在不同条目里有没有互相打架的判词，有就订正并留痕
   c 全档每条从历史记录重数连对连错、确认毕业线全部是 2、上次与最后一条历史行对得上
     ⇒ **跑 `python3 writing-band7/drill2/drill.py check --all` ＋ `drill.py stats`**（两文件一起过）。
       脚本报出的每一条 ERROR 逐条结清，结清过程写进 session；⛔ 不许只贴输出不处理
   d 每篇作文的分数在全库所有出现处 grep 一遍，与 bank 曲线行字面比对
   ④ 必须跑在当日全部写入完成之后
⑤ 收尾同 §4⑥（含 `migrate` 双向搬迁），周期号 +1
复习日不写新作文。
```

## 9. session 文件格式

文件名 `sessions/YYYY-MM-DD.md`，一天一个文件。按此顺序写，缺节算记录不合格。

```markdown
# YYYY-MM-DD · D2 · 周期 N

## 开场           今天类型 · 两条队列各到期多少／今天出几组 · 必出层是哪几条 ·
　　　　　　　　　清单逐条列编号 · 靶子与装备及其来源
## 复习 · 第 N 组  pick 决策卡要点 · 题面 · 她的答案（逐字抄，一个字不改）
                 ★ 组里有词组条目 ⇒ 那几条并成一道**词组题**记在本组里，写清
                   「中文块 → 她的英文块 → ✅/❌」逐块一行，各块的判定分别记到各自编号
　　　　　　　　　· 三件事全文（§4③ a · bc · d）
## 复检 · 第 N 组（M 题 / K 条）
　　　　　　　　　🎓 那条队列（§3.6 §4②b）。⚠️ **两个数都写** —— 词组条目并成一道题
　　　　　　　　　⇒ 题数 ≤ 条数，只报题数会把覆盖量报小
　　　　　　　　　· 题面 · 她的答案 · 判定表 · 顺带判定 · 战报四行（§4③e）
　　　　　　　　　· 三版对照块：**只给判 ❌ 的那几条**（全 ✅ ⇒ 整个子件都不写）
## 回看 · <题号>  最近一篇【没被回看过】的新题，整套全文（§4④，跑 `drill.py lookback` 算）
　　　　　　　　　★★ **题号必须写在这一行 `##` 标题上**（`## 回看 · T1-15（…）`）——
　　　　　　　　　　 §4④ 认的就是标题行上的题号；写成 `## 回看（§4④）` ＝ 这一篇永远算没回看过
## 新题           题面与条件 · 判分八步（数与算式全打印）· 对照 problems.md 扫全文的结果
　　　　　　　　　· 三版对照块（§4⑤e）
## 追加练         §4.8。可多个、各带标签：入口B 的跟在对应组之后，入口A 的跟在新题之后
## 教练侧         本场的流程问题、判错又改的、她质疑成立的
## 收尾           新建条目复查（§3.5 第4步）· 建了哪些编号 · 改了哪些状态
                 · **migrate 搬了哪几条（两个方向）＋ 行数增减 ＋ git numstat** · 四条校验的结果
```
