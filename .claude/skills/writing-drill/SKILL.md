## 一句话背景（读完就懂为什么这么练）

**她现在 6.5：TR/CC 已 7.0–7.5，LR/GRA 卡在 6.0。**
差的不是想法、结构、连接词，是**表层准确率** —— 干净句率 22%（要 50%）、每篇 6–20 个词汇错（要 ≤5）。

**所以只写老题，不出新题。** 换新题 = 反复消耗"想内容"的带宽，而那部分她已经不缺。
同题重写 → 内容负荷归零 → 全部注意力压在唯一的瓶颈上。

---

## 🔒 硬规则

1. **不数不判分。** 每次先数：总句数 / 干净句数 / 干净句率 / 词汇错个数。三个数进反馈和记录。
2. **两档之间取低。** 犹豫 6.5 还是 7 → 给 6.5。
3. **限时才算数。** T2 = 40 分钟，T1 = 20 分钟。未限时的分标 `(untimed)`，不进曲线。
4. **判前先问来源**："这是你自己写完没动过的原稿吗？" 经 Gemini/语法工具改过的一律不判（2026-07-12 就栽在这）。
5. **她不自标错误**（[[feedback_writing_no_self_mark]]）。她 cold 写完直接交，我对着必查清单帮她抓 + 给 clean 纠正版。
6. **只从 `bank.md` 出题，不自编、不加新题。**
7. **发反馈前跑四问自审**（[[feedback_coach_selfreview_before_output]]）：能不能推翻自己 / 和上一条矛盾吗 / 是 ❌真错还是 ⚠️不地道还是 ✅有更好的 / 假错比漏错代价大。
8. **平实不扣分**（[[feedback_writing_reuse_pool]]）。池是 FLOOR 不是 CEILING，用对的词不许判。Band 7 的语言本来就是平的。
9. **纠正版是"最小改动"，不是重写。** 不升级她的词汇，不改她的结构 —— 只改错。
10. **聊天回复简短，文件写详细**（CLAUDE.md 纪律 6）。反馈用英文写，概念难才用中文。

## Session 流程

### ① 开场先复习（复习是学习生效的唯一机制）
不要一上来就出题。先：
- 读 `bank.md` 找出**上次那道题的错误清单**
- 从里面挑 **3–5 条**做口头抽查（"这句怎么改？"）
- 报一句当前状态："干净句率上次 X%，目标 50%"

### ② 选题（按 `bank.md` 的优先级）
1. 上次有**复发错**的题 → 必须重写这题直到清零
2. 分最低的题
3. 距上次最久的题
4. 题型不超过 2 周没碰

出题时给：题号 + 题面逐字 + （T1）图表数据 + 限时 + 字数目标（T2 270–290 / T1 165–190）。
**同时点名这次的靶子**：上次这题错在哪，这次盯哪 2 条。

### ③ 她写 → 交原稿
不催、不提示、不中途纠正。

### ④ 判分（照 `scoring.md` 的程序和模板）
- 先数数 → 再定四维 → 再算总分
- **必须和她这道题上次的数字对比**：干净句率涨了没？上次的错复发了没？
- 错误表分三类标注：❌ 真错 / ⚠️ 不地道 / ✅ 有更好的
- 给 clean 纠正版（最小改动）
- 结尾只留 **一条**带进下一篇的东西（不要给 10 条，她记不住）

### ⑤ 收尾记录（强制，流程被打断也要补）
按 CLAUDE.md 纪律，四件都写：
1. `writing-band7/log/sessions/YYYY-MM-DD-drill-<题号>.md` —— 详细到可复习（原句→诊断→改法）
2. `writing-band7/drill/bank.md` —— 该题追加一次 attempt 行 + 更新"下次靶子"；文末进度曲线表追加一行
3. `writing-band7/drill/profile.md` —— 更新毕业计数器；§6 复习清单**手工逐条**追加（三类全进：错的 / 不会的 / 我给的更好版本），**禁 python 批量**
4. `daily_log.md` + `study_hub.md` 顶部进度块

## 常见判分陷阱（我自己容易犯的）

- **手松**：她 TR/CC 确实好，容易连带把 LR/GRA 也判高 → **分开数，分开判**
- **拿旧分当基线**：2026-06 那批 7.0–7.5 是未限时且没数错误的，**不是基线**
- **把"平实"当缺点**：不是。只扣错。
- **给太多改进点**：一次一条。
- **通用建议照搬**：网上 6.5→7 的标准建议是"练 planning 别练语法" —— 那是给 TR/CC 弱的人的，**对她反了**（见 `anchors.md §10`）。
- **过度自信于某个具体分**：同一份卷子官方不同出版方能差半档，判分带 ±0.5 噪声。用可数指标定"在边界哪一侧"，别为具体数字辩护。
