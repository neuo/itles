## 0. 一页速查
```
周期 = 4 个练习日：学习 学习 学习 付息    ★ 只数【有行为的日子】，休息/没练直接跳过
      D-1 / D-3 ＝ lab/sessions/ 里按日期倒数第 1 / 第 3 个文件

召回 ＝ **一条梯子**（§3.5）：应等几个练习日，由条目现在站在梯子哪一格决定
       到期 ＝ 已等练习日 ≥ 应等间隔　⇒ 取哪些、什么顺序全由 `lab.py pick` 出
       复检排序 ＝ 复检次数少的优先 → 已等练习日多的优先　｜　已毕业条目 ⛔ 不降格
       两条队列：**在池**（未毕业）＋ **复检**（🎓）—— 毕业不是冻结，只是往梯子上爬一格

学习日  ① 在池组 ≤3 组（10 题一组）　①b 复检组 1 组　★ 组完题先过 §6.5 审核表才许发
        ② 回看（跑 `lab.py lookback` 定哪几篇 ＝ **全部没回看过的**，只读）
        ③ ⚡ 免测：⛔ 不主动问 —— 她在回答里说「这条会了」才记（§4③）
        ④ 新题 1 道（脚本抽）——【保底做】，她累了也做这一道
        ⑤ 收尾核对
付息日  a 在池组 ≤5 组　⓪ 回看本周期全部自由产出（位置 ＝ **a 之后 a2 之前**）
        a2 复检组 3 组　c 问题文件 review（合并去重）　d 整题重答 0–X 道
        ⛔ **付息日不出新题**
★ 在池是【上限】，排不满就是没有；空出来的组数**下溢给复检**（⛔ 反向不成立）
★ 她随时喊停。**没出完的不记账** —— 下一场自动排更前，队列自己管。

问题 = 她犯的错 ＋ 她说得不地道 ＋ 她主动提出的（来源不限：复习/新题/重答一视同仁）
每条问题：唯一编号 · 题面 · 状态行（连对/连错/上次复习）紧挨日志 · 每次被测追加一行日志
三档（推进 streak）：✅ 对 ｜ ❌ 错（**"忘了/不会"也是 ❌**）｜ ◎ **只用于"教练把题面搞坏了"**（复检组没有 ◎：题面出坏了记 ✅）
　　★ ⚪ 是记号不是档位（形态类专用）｜ 📖 不新发，只在读历史日志时认它
　　★ 同一条同一天被产出多次 ⇒ **每次各记一行、各算一次**，不挑"以谁为准"
　　★ 她答得合法但不是条目预期 ⇒ **算 ✅ ＋ 当场改题面**，不记 ◎
　　★ **形态类条目 ＝ 只记录、不出题**：在哪儿掉都只记 ⚪，不记 ❌／不掉毕业（§3.4）
**连对 2 → 毕业**：**只改状态行标「🎓 已毕业」，条目和日志留在原地**
★★ 毕业 ＝ **退出在池队列、转进复检队列**（§3.5），召回间隔拉长到 3→7→16→32→60 个练习日
　　⛔ **不是冻结、不是不再出现**；再犯 → 状态行改回，连对清零，rc 归零

每一题（复习和新题一样）：最小修改版 ＋ 更好版 ＋ diff
★★★ 顺序写死：先写 session 文件 → 再把反馈发给她
```

## 0.1 脚本 —— 机械部分交给 `lab/lab.py`

```
0.1.1 /clear 或 compact 后第一个动作 ＝ 完整重读本文件；第二个动作 ＝ 跑
        python3 speaking-band7/lab/lab.py stats
      ⛔ **不许整档重读 problems.md** —— 状态从脚本拿，条目正文只在抽中时 `show` 打开。

0.1.2 ⛔ 所有内容文件手工写。允许的脚本只有两个：
        · `coach/pick_question.py`  抽新题（防教练挑题）
        · `lab/lab.py`              抽复习题／统计／查重／格式校验／记账
      判据写死：**脚本可以【读档案 ＋ 打印 ＋ append 流水】，⛔ 绝不许产生任何一个字的内容**。
      ★ 例外只有两个子命令，**都只碰位置、⛔ 都不产生一个字**：
        · `lab.py append`：判定行的**行文仍然全部手写**，脚本只干两件机器活 ——
          ① 把写好的行按日期插到正确位置　② 连对／连错／上次 三个数重算
          ⛔ 它不改 🎓、不改状态、不碰条目正文（四节／成员出题账）—— 那些是判断，仍然手写。
          ★ **两个文件都能写**（problems.md ＋ graduated.md）——
            毕业条目的连对/连错本来就冻结在毕业日，写进去只动「上次」一个字段。
            自查不过 ⇒ **两个文件一起整批回滚**。
        · `lab.py migrate`：problems.md ⇄ graduated.md **双向搬迁**，
          只按状态行的 🎓 把**已有的整块字节**从一个文件挪到另一个（§3.3）。
          ⛔ 不改状态、不改正文、不改任何一个数、不碰两个文件的头部与收尾节；
          搬完自校（正文逐字节 · 状态字段 · check 报告 · 编号升序），不过就**两个文件整批回滚**。
      ⇒ 「记录禁脚本」防的是**漏记与代笔**；位置和算术是机器规则，
        让教练每次重推一遍 ＝ 每次重犯一遍。

0.1.3 ★★ **每次写完 problems.md／graduated.md，当场跑**
        python3 speaking-band7/lab/lab.py check --changed
      **ERROR 归零才算写完**。带着 ERROR 往下走 ＝ 这一步没做完。
      （`--changed` 比的是 `git diff HEAD` ⇒ commit 之前跑；已 commit 的用 `--all`）
      ⛔ **跑过 `migrate` 的那一次不要用 `--changed`** —— 整体位移会让 git diff 把大批
        没动过的条目算成"改过"，存量行被按新文法查 ⇒ 全是假阳性。那次用 `--all`。

0.1.4 全档级的数（总数／🎓／未毕业／可出题／连对1／连错≥2／重答队列）
      **一律由 `lab.py stats` 产出并逐条列编号**，⛔ 不许口算、不许沿用上一组的旧值。

0.1.5 ★★ **除此以外的任何「有多少条 X」，一律跑 `lab.py count`**

        python3 speaking-band7/lab/lab.py count --type drawable    ← 该类型的编号清单
        python3 speaking-band7/lab/lab.py count --type kind:搭配 --detail
      · ⛔ **禁用 grep 数条目。** grep 数的是"字符串出现了几次"，脚本数的是"符合口径的
        条目有几条" —— 两者天生不等，且两个错可能互相抵消、凑出一个看着对的数。
      · ★★ 报这种数必须写清是【全档】还是【未毕业】口径 —— `count` 两个数并排打就是为这个。
      · 类型的全套 slug 由 `count` 不带参数时打印，**⛔ 不许临时发明类型名**。

0.1.6 ★ **改过 `lab.py` ⇒ 先跑回归测试，全绿才许拿去动真档案**

      ★★ **测试 ⛔ 不许依赖真档案/真 session 的内容**
        判据：**测试红了要么是脚本坏了、要么是测试坏了，⛔ 不许是"今天的练习内容变了"。**

## 1. 周期与日子
```
固定循环：L1 → L2 → L3 → R(付息日) → L1 → …
只数【有行为的日子】：休息、没练 ＝ 那天不存在，跳过不占位
可数依据 ＝ lab/sessions/ 的文件名（一天一文件 YYYY-MM-DD.md）：
   D-1 ＝ 倒数第 1 个文件的日期　　D-3 ＝ 倒数第 3 个文件的日期
   今天是第几个学习日 ＝ 数上一个付息日之后有几个 session 文件
```
- 开场第一动作：`ls speaking-band7/lab/sessions/` 定位今天是 L1/L2/L3/R —— **数文件，零推导**。
  每个文件首行写着它是 L1/L2/L3/R；找到最后一个 R，它之后有几个文件，今天就是第几个学习日。
- 早期回填文件里的条目用**旧号 B×××** 记，换算：`grep -n "旧号 B107b" speaking-band7/lab/problems.md`

## 2. 什么算"问题"
```
① 她犯的错          语法 · 搭配 · 时态/单复数/冠词/介词 · 结构　（**拼写不算**，见 §2.1）
② 她说得不地道      字面能懂但 local 不这么说 —— 尤其【句型和词组】
③ 她主动提出的      她问"这个怎么说更好""这句是不是怪"
来源不限：复习题里的、新题里的、重答里的，一样建条目一样复习
```
**不算问题**：打字材料里的句读（句号 vs 逗号不构成口语证据）· 教练判错后撤销的（当场撤，不留条目）。

### ★★★ 2.1 单词拼错【一律不算错】
```
① 拼错 → **不建条目、不记档位、不写进 ❌**；顶多在 diff 里顺一句正确拼法，不展开
② 已经存在的拼写类条目 → 状态行加 `｜拼写类·不召回`，**永不进复习组**（她自己 review）
③ 唯一例外：**她主动说"这个要记"** —— 那时才建条目/记档位
④ 边界（教练必须分清，判错就是在浪费她的带宽）：
   ✗ 拼写   同一个词写歪：`eaiser`／`additive`（想说 addictive）／`recieve` ⇒ **不算**
   ✓ 选词   调出来的是**另一个词**：`virtual` 想说 vital（#255）· `look up` 想说 look for ⇒ **照常算**
   判据一句话：**她脑子里调的词对不对**，不看字母拼没拼准
```

## 3. 问题文件 `lab/problems.md`

### 3.1 格式：一条问题一个块 ＝ 一张**知识卡**，不是一行账

> **状态行 → 四节正文 → 历史行**，`lab.py check` 硬查（契约⑪–⑭）。

```markdown
### 336 · get TO ＋ 地点（到达；⛔ get the destination）
类型 搭配 ｜ 新建 2026-09-11
状态 连对0 连错0 上次— 未毕业 ｜ 题型 词组

**问题是什么**
**get to** ＋ 地点 ＝ 到达（get 后面挂地点必须有 to）。
同一格里的邻居（别串）：arrive **at／in** ＋ 地点 · reach ＋ 地点（不带介词）· get **home／here／there**（副词，不带 to）
判据一句话：get 后面是**地点名词**吗？是 ⇒ 补 to；是 home／here／there ⇒ 不补。
★ 与 🎓#81（get TO know sb）分工：那条的 to 是不定式，本条是介词 ⇒ 两条规则，各走各的。

**怎么发现的**
2026-09-11 付息日 d 段重答 R10（P3 · How does technology help people make plans?）：
她写 `like how to get the destination`。
查重（§3.1 判重三步）：
　① 目标形式 dedup "get to" ⇒ 命中 #81（不定式 to）⇒ 否，两条规则
　② 中文题面 dedup "目的地" ⇒ 零命中　⇒ 保留新建

**我错在哪**
她的：how to get the destination　　正确：how to get **to** the destination
找法：写完 get ＋ 名词，回头问一句 —— 这个名词是地点吗？是就补 to。

**题面**
"到目的地怎么走"（"到"用 **get** 说）

- 2026-09-11 新建 · 付息日 d 段重答 R10 · 触发原话 `how to get the destination`
- 2026-09-13 ✅ 在池第 1 组 · `how to get to the destination`
- 备注 判重：dedup "get to"／"目的地" ⇒ 只命中 #81，见上
```

**字段规则（口语版）**
```

元信息      `类型 X ｜ 旧号 B… ／ 新建 YYYY-MM-DD`（＋ 可选：与 #N 题面互斥 · ⭐ 她自产 · 从 #N 拆出）
            ⛔ 题面**不**写在这一行（v3 只认题面节；两处都写 ⇒ check ERROR）
状态行      同契约③；**题型格必写**（v3 条目缺题型 ⇒ ERROR）
问题是什么   写规则／目标块**本身** ＋ 同一格里的邻居（别串）＋ 判据一句话 ＋ 与相邻条目的分工
            ⛔ 不写她那次怎么错、不写句子 —— 那是下面两节的事
怎么发现的   日期 ＋ 场合（哪组哪题／新题 bank:NNN／重答 RN）＋ **她的原话逐字** ＋ 判重三步逐条写（B0）
            旧 B 表迁移、原始触发句没存的写「旧 B 表迁移，触发句未存」—— ⛔ 不许编
我错在哪    她的 vs 正确，再写**找法**（产出前问自己的那一句）；形态类写「检查触发」
题面        出题用，按 §6.0 题型写：整句 ＝ 完整中文句、句末标点收尾；词组 ＝ 中文块、不带句号；
            提示写在（…）里；★ 开头的行是教练注释（目标形式／沿革），
            ⛔ 不进发题稿；合并条一成员一行 ①②…
成员出题账   只有合并条要：一成员一行 `① feedback ｜ 09-07 ✅ · 09-10 ✅` 或 `① advice ｜ 未出过`，出一次补一次

历史行      同契约④；建号那一行：她犯错建的写 `❌ 首犯 · 场合 · 原话`，她点名要学／教练给的更好版写 `新建 · 场合 · 原话`
```
- **状态由日志重放而来**，两边不一致时以日志为准、重算状态行（数字必须可复算）。
- 每次被测/每次犯错都**追加一行日志**，一行一次，不合并、不写"以此类推"。
- 发现新问题 → **先搜全文能不能归到已有条目** → 归不上才新建编号。
  ★★ **判重三步**
```
① 先把【目标英文形式】写出来（不是中文题面）—— 这一条到底要她产出哪个词/词组/结构
② 用那个英文形式 grep，**范围必须含已毕业条目**
   `grep -n "look for\|no questions" problems.md`  ← 已毕业的占一半以上，漏搜它们＝必然重复
   中文题面也扫一遍：`grep -n "七天无理由" problems.md`（同题面几乎一定是同考点）
③ 判据三档：
   · 同一个【词 / 词组】          → 同一条（drive past ≡ drive past sth）

   · 只是像、目标形式不同        → 两条，但**当场改题面互斥**，写明互斥关系
⛔ 判成"新条目"之前必须能说出：**它和最接近的那条差在哪个词/哪条规则上**。说不出 ＝ 就是重复。
```
- ★★ **建号程序 B0–B6**
```

B4 题面当场写出：整句写完整中文句、词组写中文块。

- ★★ **一条 ＝ 一个考点**
```

⛔ 捆绑条目（如 #95 #75 #68）必然与别的号重叠，且三个块掉一个整条清零
   ⇒ 她被反复测已经会的那两个

- **新建条目当天不测**，次日起进池（当天教完当天测 ＝ 假 ✅）。

★★ **机器契约（`lab.py check` 逐条硬查的就是下面这些，写歪了脚本读不出来）**

> ⛔ **脚本一律严格匹配，不做兜底。** 写歪了就是解析不出来 ⇒ `check` 报错 ⇒ **改档案，不改脚本**。

```

   ⛔ 日期行不许写在 `- 备注` 之后；⛔ 日期不许乱序
⑥ 代码围栏 条目内 ``` 必须成对
   ⛔ 漏一个就把后面整片条目吞成代码块
⑦ 连对连错 ＝ 按 §3.3 **逐条历史判定行重放**出来的值
   · 已毕业条目**冻结在毕业那一天**：毕业后的 ✅ 是自发命中证据，只留痕、不推进数字
⑧ 上次     ＝ **最后一次被测**的日期（判定行 ✅❌📖◎；⚪ 与留痕/备注行不算）
   · 从未被测过写 `—`

   ⛔ 块体里不许顶格写 `状态 ` 或 `### `
⑩ 改判     推翻旧判定时，原行留痕不删，**在那一行行尾**补

⑪ ★ 正文四节  状态行之后、第一条历史行之前，顺序写死：

   · 正文四节里 ⛔ 不许顶格写 `- `（那是历史行／备注的记号）—— 列点用「·」或缩进两格

⑫ ★ 题面节   题面主体写在 "…" 里，提示写在（…）里，★ 开头的行**及其缩进续行**是教练注释；合并条只认编号句 ①②…
   · 不带日期的尾块行（`- 旧账 …`／`- ⚠️ …`／`- ★ …`／`- ⇒ …`／`- **检查触发**`）一律放在**四节之后**，

   · 题面节必须有引号句；**永不出题的**（形态类／只记录／拼写类）写说明即可
   · v3 条目状态行**必须有题型格**（升级时一起回标）
   · ⛔ 元信息行里不许再有题面字段（两处都写 ⇒ ERROR）—— 题面只有一个真源
⑬ ★ 成员出题账 状态行带 `合并条·出题多句覆盖` ⇒ 必挂；一成员一行，不许空；挂了却没标合并条 ⇒ WARN
⑭ ★ 存量口径 2026-09-12 起新建的条目缺四节 ⇒ ERROR；更早的一行式存量 ⇒ 列「存量提示」，
   清单 `lab.py count --type body-legacy`，进度看 `stats` 的「正文四节」行
   · 升级 ＝ **逐条手写**四节（⛔ 禁脚本、禁批量、⛔ 禁编造：正文与历史里没有的信息写「未存」）；
     升级时把题面从元信息行搬进题面节、题型一起回标、合并条挂成员出题账
   · `append` 遇到没有历史行的条目插在正文最后一行之后；`migrate` 整块搬，四节跟着走；

⇒ 写完当场跑 `python3 speaking-band7/lab/lab.py check --changed`，ERROR 必须为 0（§0.1.3）

### ★★★ 3.2b 更地道的表达一律建号，一个表达一条；**禁止伞形条目**
```
本质：她要学的是**更地道的表达**。diff-2 里每一处 ⚠️（她的说法能懂、也合法，但有更地道的说法），
只要那个更地道的说法是一个**能学的表达**，就按那个表达建号 —— 真错（❌）与不地道（⚠️）一视同仁。

能学的表达 ＝ 换个话题还能原样拿来用的一个词／词组／固定块／搭配／句型：
   · 词组：Through the internet → online ｜ run with your imagination → let your imagination run wild
   · 搭配：cooking at home is more delicious → the food tastes better（"好吃"挂在吃的东西上）
   · 句型：For office workers, they … → Office workers …（中文话题句，英语让 X 直接当主语）
不建号，只进 diff-2：
   · 只是删掉一个多余的词、调一下语序、换一个同级近义词
   · 她的说法母语者也照样常说（＝ 教练的个人偏好，§7 四问①）
   · 书面词降级（有现成口语版却先调出书面版）⇒ 仍走 §7 书面登记（🎓#206），不另建号

⛔ **禁止开伞形条目**：「直译搭配」「用词不地道」「表达生硬」「中式英语」这一类。
   它们的考点是**开放集合** —— 每冒出一个新实例就把 streak 清零，**结构上永远毕不了业**。
   ⇒ 一条只装**一个**表达；说不出"要学的是哪一个表达" ＝ 别建。❌／⚠️ 怎么分档见 methods.md M36／M37。
★ 这条对**所有**类别生效：凡是考点收敛不成"一个表达／一条规则"的，都不许建条目。
```

### ★★★ 3.2c 合并条目的出题规则
```
① **允许合并**：同一条规则下的多个"错词"可以并成一条规则条
   例：#261 action／feedback／advice／information／knowledge／research／progress
       全是"这一小撮抽象名词不可数"这**一条规则** ⇒ 合成一条，不用一个词开一个号
   ★ 这是对 §3.1「一条 ＝ 一个考点」的**限定解释**：规则相同 ＝ 一个考点，成员不同不算多考点

② **出题必须多句覆盖**（硬规则）：合并条每次出题**不许只出一个成员的一句话**，
   必须给**多个句子、覆盖这条下的全部成员**
   —— 只出一个词，她错的那个成员永远测不到，而已经会的那个被反复考

③ **顽固成员单独摘出来**：某个成员反复掉 ⇒ **把它单拆成一条新条目**，
   **老条目（剩下的成员）照常走连击、够线就毕业**
   ⇒ 这样"顽固的那一个"不会再把"已经会的那几个"一起拖回池子

④ **条目上要有标记**：合并条的状态行加 `｜合并条·出题多句覆盖`，正文**必挂 `**成员出题账**`**（§3.1 契约⑬）
   —— 一成员一行、出一次补一次；出题前先看账，挑没出过／最久没出的成员。
   ★★ **有机器闸**：题面自成一段的合并条，`lab.py prompts --verify <发题稿>` 要求
      **每一个编号句都逐字出现在发题稿里** —— 少一句直接 ERROR ⇒ ⛔ 不许发题。

⑤ 与 §3.2b（禁伞形条目）的分界线，一句话：
   **成员数得出来 ＝ 有限集合 ⇒ 可以合并**（#261 那七个词、#268 那七个动词）
   **成员数不出来 ＝ 开放集合 ⇒ 禁止建条目**（"任何从中文直译出来的搭配"）
```

### 3.3 档位与连击

**推进 streak 的是 ✅ ❌ ⚡ 三个**（⚡ 见 §4③：来源是自评不是测试，另记校准数）；
**◎ 不推进**（它的定义就是"这次没测成"）；⚪ 是记号不是档位；📖 只读历史。

| 记号 | 含义 | 连对 | 连错 |
|---|---|---|---|
| ✅ | 对（考点位置一字不差） | ＋1 | 清零 |
| ❌ | 错（**"忘了/不会"也是 ❌**） | 清零 | ＋1 |
| ◎ | 在池组里题面本身有毛病（教练现编／截断／缺主语），本次作废；**复检组不用 ◎，题面出坏了记 ✅** | 不动 | 不动 |
| ⚡ | **她自评通过（免测）** ＝ 一次通过（§4③）。在池推进连对／毕业推进 rc；等待时钟照样清零 | ＋1 | 清零 |
| ⚪ | **记号，不是档位**：形态类在任何地方掉了都只记它（§3.4②） | 不动 | 不动 |
| 📖 | ⛔ **不新发**（"不会就错" ⇒ 一律记 ❌）。只在读历史日志时认它 | — | — |

- **标记打在条目上，不打在整句上**：一句话可以同时给 A 条 ✅、B 条 ❌。
- ★★★ **她答得合法但不是条目预期 ⇒ 记 ✅，不记 ◎**
```
硬顺序：① 判她这句是否**符合题面**（题面点名了什么就照什么判）
        ② 符合 → **记 ✅**（照常 ＋1 连对，照常毕业）
        ③ **当场改题面**回写 problems.md，让下次能逼出条目真正的目标形式
        ④ 日志里写清楚：她答的是什么／目标形式是什么／题面改成了什么
⇒ 「◎ 不动连击」只保留给**教练自己把题面搞坏**的情况（现编/截断/缺主语）
```
- ◎ 的当场动作：**当天就改题面**（回写 problems.md），次日再测。
- 同一天同一条被产出多次：**每一次都追加一行日志、每一次都算一次记录**，不挑"以谁为准"。
- **毕业**：
```
★★★ **连对 2 → 毕业，所有情况统一**
`状态 连对2 连错0 上次YYYY-MM-DD ｜ **🎓 已毕业 YYYY-MM-DD**`
条目留在 problems.md **原地不动**，全部日志行（行为行）一行不删、一行不移
★★★ **毕业 ＝ 换一条队列**：离开在池队列、进**复检队列**，召回间隔按 §3.5 的梯子
   3 → 7 → 16 → 32 → 60 个练习日走，每通过一次复检（✅ 或 ⚡）往上爬一格。
毕业 ＝ 换队列，**不等于**记录搬家 —— 历史必须跟着条目走
她可直接指定（"这句毕业了，别问了"）→ 记「🎓·她指定」
★★ **搬家 ＝ `graduated.md`，由脚本每天收尾做**
   毕业当天教练**只在原地改状态行**，条目与日志一个字不动 —— ⛔ 教练全程不手工搬文件。
   搬迁 ＝ 收尾跑一次 `python3 speaking-band7/lab/lab.py migrate`（§11 第 ② 件）：
     · problems.md 里状态有 🎓  ⇒ 搬进 graduated.md
     · graduated.md 里已无 🎓   ⇒ 搬回 problems.md（＝ 回潮的）
   脚本只挪**已有的整块字节**，⛔ 不改状态、不改正文、不改任何一个数、不碰头部与收尾节；
   搬完自校（正文逐字节 · 状态字段 · check 报告 · 编号升序），不过就**两个文件整批回滚**。
   ⛔ 教练不许手工搬 —— 手搬一次就要重新证一次没搬丢。
   脚本把 problems.md ＋ graduated.md **当一个档案读** ⇒ 搬没搬都不影响任何一个数。
   回潮 ⇒ 在条目原地把状态行改回未毕业，当天收尾 `migrate` 自动把它搬回 problems.md
   ★ `append` **两个文件都能写**（§0.1.2）—— 复检天天在毕业条目上记判定行。
❌ 除 graduated.md 外一条文件都不许再开：不建别的"已毕业"清单
计数口径：**一律 `lab.py stats` ／ `lab.py count`（§0.1.5）**
```
- **回潮**：已毕业条目再犯（复检里判 ❌ 或自由产出里掉）→ **状态行改回未毕业、连对清零，
  日志接着往下记**（条目本来就没动过）。它自动离开复检队列、回到在池队列，
  ⛔ 不需要任何新规则；重新毕业时 rc 从 0 重算（§3.5）。
  ★ `lab.py append` 会把「🎓 吃到 ❌ 该回潮」当 ★ 待办打出来，⛔ **它不代改** —— 状态是判断。
  ★★★ **唯一例外 ＝ 形态类条目：在哪儿掉都不回潮，只记 ⚪**（§3.4②，形态类优先于本条）。
  判据：它的失败是"产出时检查没跑"，不是不会 ⇒ 掉回池子等于让她重练已经会的。

### 3.4 ★★ 形态类条目 ＝ 只记录、不出题
```
判据（自我分诊）：**把这个点单独问她一次**——
   答得出 → 她会，缺口在"产出时检查不运行" ⇒ **形态类**
   答不出 → 真缺口 ⇒ 照常复习
形态类 ＝ 主谓一致 · 时态标记 · 单复数/限定词 · 冠词/指称 · 比较级 · 否定标记 · 不规则动词变形

① ★★★ **永不出题**：⛔ 不进召回队列（§3.5 的剔除口径第一条），学习日付息日一视同仁
② ★★★ **在哪儿掉都只记 ⚪**：中译英复习 · 自由产出 · 新题 · 重答，一视同仁 ——
   不记 ❌／不判档位／不动状态行／不掉毕业／不回潮／**不计入当篇真错数和密度**
   ⇒ 教练的动作只剩两个：**点出来 ＋ 复述那条检查触发**
③ 每条必须写一行**检查触发**（写完什么，回头看什么），产出后逐条扫
④ 条目状态行标记 `⚪ **只记录·不出题**`（旧标记 `｜形态类·不召回` 等效，出题时一律跳过）
⑤ ★★★ **历史不回扫**：08-25 之前记下的 ❌／连错／累错／"顽固"标记一律原样保留，
   不撤销、不重算 —— 只当历史读，不再驱动任何出题

★★ **执行自查（落 ❌ 之前必跑）**：凡"词尾差几个字母／形态标记漏掉"那一类，先反问一句 ——
   **"同一篇里她有没有把同一个形态做对过？"有 ⇒ 一律 ⚪，不许记 ❌。**
   （＝ 上面判据"单独问她一次"的省时版：在同一篇里找她自己已经给出的答案）
★ §7 四问①在形态类上换方向：不是"试造母语句推翻自己"，是**"试着证明她其实会"**
⚠️ 例外：她自己说"这条我真不确定"时，可以临时召回一次
```

### 3.5 ★★★ 召回机制 —— 一条梯子，毕业线只是中间一格

> **这一节是 §4 和 §5 的共同底座**：学习日和付息日**不是两套取法**，
> 只差【配额】和【有没有新题】两件事。取哪些、什么顺序，全由这一节定死。

**一条梯子。格上的数字 ＝ 应等几个【练习日】**（⛔ 不是自然日：休息日不存在）。

```
  1   →   1   →   2   →  ┃毕业线┃  →   3   →   7   →  16   →  32   →  60
 首测未做  连错1   连对1               🎓rc0   🎓rc1   🎓rc2   🎓rc3  🎓rc≥4
 连错≥2

rc（复检次数）＝ 毕业日**之后**的 ✅ 与 ⚡ 行数（全部导出，零新字段）
　　★ 自由产出里的**自发命中也算**；⛔ 但它不推进连对/连错（那两个数冻结在毕业日）
★ 在池条目**历史掉过 ❌ ⇒ 在梯子上降一格**；复检队列（🎓）⛔ 不降格
```

           ⚠️ 与状态行的「上次」不是一个口径：那个是「上次被出题」，含 ◎
到期     ＝ 距有效上次的练习日数 ≥ 应等间隔      （**今天算一个**练习日）

★ 类型标签（词组/搭配/语法/结构）⛔ 不等于题型 —— 看考点：类型「搭配」的 #302 考点靠句子现形 ⇒ 整句

什么时候写：**建号时顺手判**；存量条目**抽到时回标**（`pick`／`prompts` 会打「⚠️ 未标」）；
　　　　　　付息日 c 段清 `lab.py count --type ask-unmarked` 的剩余。
⛔ 回标是判断 ⇒ 手写状态行；`append`／`migrate` 都不碰这一格。

★★★ **题面形式跟着题型走，有机器闸（`lab.py check`，写歪就 ERROR）**：
  题型 词组 ⇒ 引号句是【块】：⛔ 带句号 · ⛔ 提示里出现「当主语／说一句／一句话／整句／完整句／说完」
  题型 整句 ⇒ 引号句是【完整句】：有主语、能独立成句、**句末标点收尾**（标点是机器代理，主语靠人）
```

**★ 词组题怎么出（口语场景，与写作线的两处不同都在这里）**
```
题面      中文块 → 英文块。⛔ 不写整句、⛔ 不加句号、⛔ 不要求"人当主语"
          复检可打包（§6.1，一题最多 6 条）；在池组照常一条一题
提示      ★ 与写作线**相反**：写作线词组题一律零提示（给英文词 ＝ 给答案）；
          本线的提示是**把答案唯一化**的工具（§6②），词组题**照常允许** ——
            词数（"三个词的块"）· 首字母（"**m** 开头"）· 起头词（"用 **get** 起头"）·
            词性（"用一个形容词"）· ⛔ 排除项（"不许用 make／throw"）
          ⛔ 两条红线：不许把考点本身给出来；**不许改变要她产出的形式**（＝ 6.0 的机器闸）
判定      ✅ 块的字面对 ｜ ❌ 调不出／调错块
          ★ **块内固定的小词照判**（leave **a** mess 的 a、the cause **of** 的 of 是块的一部分）
          ★ 块外的时态／主谓一致／单复数 ⇒ 形态类，只记 ⚪（§3.4）；⛔ 拼写不算（§2.1，与写作线不同）
换题面    同一编号在不同日子可以换搭配语境，但**必须先改档案再出题**（§6 第一条）
```

① 题面【主体】的粒度，按考点实际落在哪里定 —— ⛔ 不看条目的类型标签，看考点本身。

★★★ **判据只有一句**：
   **她只答一个词/词组，能不能覆盖考点？**
       能  ⇒ **词组题**：题面就是那个中文词/词组，⛔ 一个整句都不许给
       不能 ⇒ **整句题**：题面是完整句，因为考点必须靠句子才现形
     （语序 · 冠词 · 主谓一致 · 主从挂接 · 并列同形 · 时态平面 · 块在句中的位置 · 两个块各就各位）

★★★ **缩短的硬前提：中文词组必须还能【映射回】那个英文块** ——
   缩完之后回头念一遍中文，**想不到那个英文块 ⇒ 缩过头了，退回整句**。
   ⛔ 反例：#261① 原句「风险小了，大家就更愿意干。」→ take action，
     被缩成「更愿意干」⇒ 光看这四个字没人会想到 take action ⇒ **题面坏了，判 ◎ 不是判 ❌**。

★ 另一条自查：**"把考点单独摆出来，句子还剩什么？"**
  剩下的全是噪音 ⇒ 缩到词/块；剩下的正是考点赖以现形的东西 ⇒ 整句。
★ 反例：考 addictive 一个形容词，却让她翻"这个游戏太上瘾了。"——
  多出来的 this game／too 全是噪音，还平白多出被判"没到考点"的机会。
★ 反例：
  考 "全信" 这个块，题面却给整句「AI 不能全信。」⇒ 她只想答 trust it completely 却被迫翻整句；
  考 though **挂在句尾**（＝ 位置，不是词），类型却标着"词组"⇒ 标签与考点不一致，等于让她猜。
  ⇒ **类型标签必须跟考点一致**：考位置/搭配框/挂接 ⇒ 结构；考一个词的选择 ⇒ 词汇；考一个块 ⇒ 词组。

★★★ **题面必须自足**：⛔ 不许引用只有条目正文才知道的东西。
   反例：#207 题面写「（四种说法各说一次）」，而那四种说法**在档案里根本不存在**
   ⇒ 任何人都答不出来 ⇒ 判 ◎，当天把内容补回来再出。

② 题面【提示】不受粒度限制 —— **括号里想加多少加多少**，唯一目的是把答案框死：
   可点词性（形容词）· 首字母 · 用哪个词起头 · ⛔ 不许用哪个词 · 结构限定 · 互斥关系
   ⛔ 红线一：**不许把考点本身直接给出来**（§6 第二译法那条）。
   ⛔ 红线二：**提示⛔不许改变要她产出的形式** ——
      词组题的括号里写「人当主语说」，等于用提示把它改成了整句题，而题面主体一个字没动，
      粒度检查只看主体就永远看不见。要改形式 ⇒ 去改主体 ＋ 改状态行的题型格（§6.0，有机器闸）。
   ⇒ §6.5 第 7 项（第二译法）绝大多数直接靠提示收敛，不必改主体。

③ 缩到词/块之后仍然要**唯一可判**：光给"收拾"不行（clear／tidy／pack 都对），
   给"把桌上收拾了"就够（动词＋宾语焊死）。判据：**看得出她该产出哪一个形式**。

★★★ **缩短的两个已知代价（⛔ 缩之前必查）**：
   ① **丢消歧上下文 ⇒ 与别的条目撞车**
      #136「他终于说了实话。」缩成裸块「说了实话」⇒ 与 🎓#232「说实话」只差一个"了"
      ⇒ 她答 to be honest 完全合理 ⇒ 判 ◎、当天改回。
      ⇒ 缩之前问一句：**这个裸词组，和全档别的条目撞不撞？**
   ② **丢消歧上下文 ⇒ 合法答案变多，判定必须跟着放宽**
      #86 原题面「出去玩之前可以先查查住哪儿。」缩成两个裸块「出去玩」／「查住哪儿」，
      第二个块脱离了 trip 语境 ⇒ `a place to live` 是**完全合法且符合题面**的答案。
      教练却拿条目的目标形式（where to stay）去卡她 ⇒ **判错，当场改判 ✅**。
   ⇒ ★★ **判定的唯一依据是【缩短后的题面】，⛔ 不是条目的目标形式**（§3.3 硬顺序①）。
     判据：**回答在语言层面是对的、且符合题面 ⇒ 就是对；⛔ 不让她去猜教练想要什么。**
     ⇒ 想让某个形式成为唯一答案 ⇒ **去题面里加提示**（§6②，提示不受限制），
       ⛔ 不许靠判定去补题面的缺口。

④ 复检打包题（§6.1）因此天然变短：一道题就是一串中文词/词组，一条二十秒过一遍。
```

· ★★ **复习组只出中译英，不出"用英文答几句"那种自由作答题**
  —— 那类考点 ⛔ 不建号：判据进 methods.md，**只在新题／重答的自由产出里对着扫**
· 出题前自查：这句中文有没有第二个同样合法的译法？有 → 当场在题面点名
 （可点目标词/句型/块/结构限定；不许整句给答案）。形态类（主谓一致/时态/冠词）不点名
· **取哪些、什么顺序 ＝ §3.5（`lab.py pick` 出，⛔ 教练不许自己挑、不许自己排）**
  剔除口径见 §3.5，⛔ 不在这里另写一份。
· ★★ **合并条（状态行带 `合并条·出题多句覆盖`）：一次必须出多个句子、覆盖全部成员**（§3.2c）
  —— 只出一句 ＝ 违规。某个成员反复掉 ⇒ 单拆成新条目，老条目照常走连击
· 组内防撞：同一条目最多 1 题；同族（同规则/同词族）最多 2 题；相邻两题不测同一个词
· ⛔ **不顺延**：没出完的下一场自动排更前
· 复习中译英 ＝ accuracy 检查，允许慢慢想，不计流利度；
  新题/重答 ＝ 自由产出，禁中文触发，打字数据不得用于任何流利度结论（含用词数评长度）
· 她答"忘了/不会" → 立刻给答案＋思路，不追问；**记 ❌**
```

## 6.1 ★★★ 复检题（复检队列专用）

> 复检的目的是**定位**不是教：290 条毕业条目里哪些还在。
> 一条过一遍只要二十秒，**贵的只有"掉"的那部分**，而掉了之后走的还是原来那套流程。

```
① 打包：`词组 / 词汇 / 搭配` 三类可并成**一道中译英词组串**，一题最多 6 条
   ⛔ 永不打包：合并条（§3.2c 出题须多句覆盖）· 题面待补的 · 语法/结构/句型/减法型
   ★ 打包只**往后捎**：每道题的头一条永远是队列里当下最靠前的那一条，
     被捎上的都排在它后面，⛔ 绝不会把靠前的条目往后压
② 一组 ＝ 10 **题**，覆盖 10–60 **条** ⇒ ★ 报数必须**两个数都写**：`N 题 / K 条`
③ 只有两档：对 ✅ ／ 不对 ❌（"忘了/不会"是 ❌）
   ★ 题面被教练出坏了 ⇒ 记 ✅，当天改题面
   ★ 判定行写死 `判定 #NNN ✅／❌ <考点>`，**符号只认这两个、⛔ 不许加粗**
   · ✅ ⇒ 只记一行日志，⛔ 不给三件套
   · ❌ ⇒ 当场回潮 ＋ **走全套三件套**（它已经是在池条目了）
④ ★ **逐条对账**：打包题最大的风险 ＝ 某个成员被悄悄漏判 ⇒
   块头列了几条，就必须有几行 `判定 #NNN …`。`deliver` 硬查这一条（§9.1）
⑤ 一个块里**最多一条 ❌** —— 多了就拆成各自的块，各走各的三件套
⑥ 题面照旧逐字取自档案（`lab.py prompts`），⛔ 打包不改题面、不合并题面
```

## 6.5 ★★★ 发题前审核（独立节点）
```
硬顺序：① 组题 → ② **审核表写进 session 文件** → ③ 有 ✗ 就地改、改完重审 → ④ 发给她
⛔ 审核表没写完不许发题。⛔ 不许"心里过了一遍"——必须逐条写出 ✅／✗ 和证据。
```

|---|---|---|
| 1 | 队列可复算 | 照抄 `pick` 打印的：进队列 N ／今天到期 N（在池 N ／复检 N）／本组每题的排序依据（在池：逾期分；复检：复检次数 ＋ 已等） |

| 3 | 剔除口径 | 照抄 `pick` 打印的「⛔ 不进队列」那几行（口径唯一定义在 §3.5） |
| 4 | 两条队列没混 | 在池组里没有 🎓 · 复检组里没有未毕业条目 —— 两条队列判定规则不一样（§4①c） |

## 7. 每一题的输出 —— 复习题与新题一视同仁

**三件套 ＝ ① 最小修改版 ② 更好版 ③ diff** —— 每一题的输出，本节定义。
**四件套 ＝ 题目原文 ＋ 她的原话逐字 ＋ 三件套** —— 回看时读的那一整套（§4② §5⓪）。
```
① 最小修改版   只放 ❌ 的修正，在她原句上动最少；她无真错时逐字等于原句
② 更好版       **接着她的内容和语法结构往上加** —— 只有当她那句真的生硬时才换说法；
               没有就写【无更好版本】五个字（不许留空/不许"同上"）
③ diff         ★★★ **分两段，每段都先摆两行完整句，再逐处给理由**：
               **diff-1  原句 → 最小修改版**（只有 ❌ 的修正 ＝ "我错在哪，最少改什么就对了"）
               **diff-2  最小修改版 → 更好版**（只有 ⚠️ 的升级 ＝ "对了之后还能怎么更好"）
               每段的硬格式：① 第一行 ＝ **完整的起点句** ② 第二行 ＝ **完整的终点句**
                             ③ 下面逐处列差异，**每处一句理由**
               ★ **那一段完全没有改动** → 只写一行 `无 diff（＝上一版）`，不必把同一句再摆两遍；
               　 但**只要有一处改动，那一段就必须摆两行完整句**
               ⛔ 不许只写 `xxx → yyy（理由）` 就完事 —— **看不到完整句就不算 diff**
               ⛔ 不许把两段并成一段 —— 她要的是"错→对"和"对→更好"**两件事分开看**
               ★ 多句的自由产出（P2/P3）：**逐句走这两段**，一句一组，不合并
```
### ★★★ 三件套是【发给她】的，不是只写进文件
```
★★★ **唯一例外 ＝ 复检组判 ✅ 的题**：只回一行
   `#NNN ✅ <目标形式>`，⛔ 不给三件套 —— 复检的目的是定位不是教，
   给了三件套一组就要写几十遍，那正是这个机制跑不动的原因。
   **复检判 ❌ 的题照样走全套**（它当场回潮，已经是在池条目了）。
除此以外，每一题、每一道，都要在**聊天里**给她三件套 —— 包括全对的题：
   全对的写法（两段 diff 都空）：`原句 … ｜判定 ✅ 考点：… ｜最小改 ＝原句 ｜更好版 无更好版本 ｜diff-1 无 diff ｜diff-2 无 diff`
   —— **压成一行就行**，但六项一项都不许省；只要任一段有改动，那一段就按 §7③ 摆完整句
   ★★ **闸认这个写法**：`deliver` 把一行里 ｜ 分隔的各段当独立行读。
⛔ 不许只挑"有改动的"发、其余只报数
★★★ **回看（§4② §5⓪）转述旧四件套时，聊天里同样要摆完整** ——
   diff 两段摆完整句（起点句 ＋ 终点句各一整行）＋ 最小改／更好版给**全文，一句都不省**。
   ⛔ 不许压成单行箭头（`deadline → deadlines`）、⛔ 不许用 `…` 拼接片段 ——
   压缩摘录 ＝ §4② 禁止的"重新推导"，她看到的就不再是当时那一版了。
   ★ 做法：`lookback --pending`／`--print`／`--cycle` 打出原文 → 原样贴进 session 的回看节（`deliver` 逐字查，§9.1⑦）
     → 聊天里发的就是贴进去的那一段，⛔ 不另写一版
   ★★ **一次全发完**（§4②②b）：几篇就一次发几篇、每篇发到底 —— ⛔ 不许分条挤、⛔ 不许问"剩下的还看不看"
```
### ★★★ 聊天里一律用【代码块】整体输出
```
① 复习题一组   → **一个** ``` 块装完 10 题（不许每题一个块、不许块外散着写）
② 新题         → **一个** ``` 块装题目原文（P2 连 bullets 一起放进去）
③ 每题的三件套 → **一个** ``` 块装完：原句 / 判定 / 最小修改版 / 更好版 / **diff-1** / **diff-2** 全在同一个块里
④ 块外只留最少的连接句（"第 N 组"、"本组 ✅x/y"），方法论一个字都不进
⑤ 块内不用 markdown 粗体/表格（复制出来是噪音）—— 用纯文本对齐、用 ✅❌⚠️ 做标记
```

```

判定     ✅／❌ ＋ 一句话
最小改   …（无错时写"＝原句"）

  原句   …………………………完整句…………………………
  最小改 …………………………完整句…………………………
  · aaa → bbb    ❌ 理由（可迁移的规则/判据，不许只判对错）
  · （无改动就写：无 diff）

diff-2  最小改 → 更好版
  最小改 …………………………完整句…………………………
  更好版 …………………………完整句…………………………
  · ccc → ddd    ⚠️ 理由
  · （无改动就写：无 diff）
```
⛔ **两段都必须摆完整句** —— 只写 `aaa → bbb（理由）` 不算 diff。
⛔ **复习题和自由产出一视同仁**，一题都不许省（复检组的 ✅ 题除外，见上）。
**质量硬约束**
```
· 更好版必须长在她的句子上：主语与句序跟原文一一对应；整段重构的另起「另一种说法」栏
· ❌ 必须给可迁移的理由（规则/判据/同族清单），不许只判对错
· 小词纠正重复整个词组（说 "go on a trip"，不说 "to 改成 on"）
· 更好版准入三条：保留她的主语和信息 · 改动可指认到具体位置 · 说得出为什么
· 升级不提高词汇难度：换她已会的实义动词，不塞新难词
· diff 三档：❌ 真错 ／ ⚠️ 更好 ／ ⛔ 教练不必要的改动（⛔ 只留痕在 session 文件，不在聊天里展开）
· ⚠️ 给出的更地道说法是一个能学的表达 ⇒ 按 §3.2b 建号，进【本篇新建条目】／【本组新建条目】
```

某层无对象 → 写"本层无对象"，不硬造
```

## ④ 收尾核对
★ 前缀（`①` `①b` `a` `a2` `⓪` `③b` …）**所有节一个口径**，脚本一律认。

```
