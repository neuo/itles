## 1. 周期与日子

```
固定循环：L1 → L2 → L3 → R(付息日) → L1 → …
只数【有行为的日子】：休息、没练 ＝ 那天不存在，跳过不占位
可数依据 ＝ lab/sessions/ 的文件名（一天一文件 YYYY-MM-DD.md）：
   D-1 ＝ 倒数第 1 个文件的日期　　D-3 ＝ 倒数第 3 个文件的日期
   今天是第几个学习日 ＝ 数上一个付息日之后有几个 session 文件
```
- 开场第一动作：`ls speaking-band7/lab/sessions/` 定位今天是 L1/L2/L3/R —— **数文件，零推导**。
  每个文件首行写着它是 L1/L2/L3/R；找到最后一个 R，它之后有几个文件，今天就是第几个学习日。
- 已回填三天：`2026-08-15`(L1) `2026-08-16`(L2) `2026-08-17`(R) —— 所以**下一次练习自然是新周期 L1**，
  D-1 ＝ 08-17（付息日，取它 a/b 段被测到的条目 ＋ 回看它 d 段两道重答的四件套），D-3 ＝ 08-15。
  ⚠️ 回填文件里的条目用**旧号 B×××** 记，换算：`grep -n "旧号 B107b" speaking-band7/lab/problems.md`

## 2. 什么算"问题"

```
① 她犯的错          语法 · 搭配 · 拼写 · 时态/单复数/冠词/介词 · 结构
② 她说得不地道      字面能懂但 local 不这么说 —— 尤其【句型和词组】
③ 她主动提出的      她问"这个怎么说更好""这句是不是怪"
来源不限：复习题里的、新题里的、重答里的，一样建条目一样复习
```
**不算问题**：单纯打字手误（同一个词反复错拼才算拼写问题）· 打字材料里的句读
（句号 vs 逗号不构成口语证据）· 教练判错后撤销的（当场撤，不留条目）。

## 3. 问题文件 `lab/problems.md`

### 3.1 格式：一条问题一个块，状态行紧挨日志行
```markdown
### 12 · keep patient → stay patient
类型 搭配 ｜ 题面 "他劝我耐心点。"（点名：用 stay 说） ｜ 旧号 B117b
状态 连对2 连错0 上次2026-08-19 未毕业
- 2026-08-11 首犯 · 新题 · `I keep patient` → stay patient
- 2026-08-16 ❌ 复习 · 又写成 keep
- 2026-08-19 ✅ 复习
```
- **状态由日志重放而来**，两边不一致时以日志为准、重算状态行（数字必须可复算）。
- 每次被测/每次犯错都**追加一行日志**，一行一次，不合并、不写"以此类推"。
- 发现新问题 → **先搜全文能不能归到已有条目** → 归不上才新建编号。
- **新建条目当天不测**，次日起进池（当天教完当天测 ＝ 假 ✅）。

### 3.2 归类粒度
```
词汇 / 搭配 / 词组 / 拼写 → 按【具体的词或词组】一条一号（keep patient 和 bury into 是两条）
语法 / 结构             → 按【规则】一条一号（will lost 和 didn't found 同属"助动词后接原形"）
```

### 3.3 四档标记与连击

| 档 | 含义 | 连对 | 连错 |
|---|---|---|---|
| ✅ | 对（考点位置一字不差） | ＋1 | 清零 |
| ❌ | 错 | 清零 | ＋1 |
| 📖 | 给了答案才会 | 清零 | 不加 |
| ◎ | 题面没逼出考点（她答了合法的别的说法） | 不动 | 不动 |

- **标记打在条目上，不打在整句上**：一句话可以同时给 A 条 ✅、B 条 ❌。
- ◎ 的当场动作：**当天就在题面里点名或改题面**（回写 problems.md），次日再测。
- 同一天先对后错：两次都是 cold 时以最后一次为准；教练给过答案后的重说不改当天标记。
- **毕业（她 2026-08-19 定，原话："毕业了只需要标准已毕业（改状态行），但是行为行不移除"）**：
```
连对 3 → **只改状态行**：`状态 连对3 连错0 上次YYYY-MM-DD ｜ **🎓 已毕业 YYYY-MM-DD**`
条目留在 problems.md **原地不动**，全部日志行（行为行）一行不删、一行不移
毕业 ＝ 复习不再召回，**不等于**记录搬家 —— 历史必须跟着条目走
她可直接指定（"这句毕业了，别问了"）→ 记「🎓·她指定」
★ **零 ❌ 线（08-19 起）**：一条条目的日志里**从来没有过 ❌**，今天又答对 ⇒ **连对 2 就毕业**
  （📖／◎ 不算 ❌）。有过 ❌ 的照旧要连对 3。
  依据 ＝ 她 08-19 原话"没错的都赶紧毕业了，不知道回答多少次了"；
  目的 ＝ 不让"她本来就会的"反复占出题名额，同时真错过的仍然要练够
❌ 一条文件都不许再开：不搬条目、不留墓碑行、不建"已毕业"清单
   （08-19 教练搬过一次并留墓碑，当天被她驳回、7 条全部还原，那个归档文件已删）
计数口径（认状态行，别认正文里提到的字样）：
  条目总数 `grep -c "^### " problems.md` ｜ 已毕业 `grep -c "^状态.*🎓" problems.md` ｜ 未毕业 ＝ 两者相减
```
- **回潮**：已毕业条目在任何产出里再犯 → **状态行改回未毕业、连对清零，日志接着往下记**（条目本来就没动过）。

## 4. 学习日流程

### ① 复习 D-1 ＋ D-3
- **对象**：那两天 session 文件里**被测到的全部未毕业条目**（含当天新建的、回潮的、
  以及答对了但连对未满 3 的）。
- 10 题一组，一组答完再讲评再出下一组；**她随时喊停**，没出完的进顺延队列（§6）。

### ② 回看 D-1 新题（只读，她不产出、不计分）
四件套**逐字取自 D-1 的 session 文件，禁止重新推导**：
```
① 题目原文（P2 含 bullets）　② 她的原话逐字　③ 最小修改版 ＋ 更好版　④ 分句 diff
```
D-1 是付息日 ⇒ 没有"新题"，但**有 d 段的整题重答，回看它们**（重答与新题同规格）；
两者都没有才写一句"D-1 无自由产出"跳过。

### ③ 新题 1 道
- 开场时就跑 `python3 speaking-band7/coach/pick_question.py` 抽定（不先发题面）。
  抽到什么练什么：不重抽、不换题、不自编。
- 走全套：cold 产出 → 五层诊断 → 三件套 → 每处问题归号 → 落盘。
- **保底做**：她喊停复习之后，仍要跑完回看 ＋ 这 1 道新题再收工。

### ④ 收尾核对（写进 session 文件，不发给她）
```
1 落号对账：本日每处问题都归了号？「N 处 → N 个编号」，一处可挂已有号（数的是落点）
2 落盘对账：每道题的三件套在 session 文件里都看得见？
3 顺延差集：顺延队列与上一轮比，少掉的每一条写出去向（出过／再顺延）
4 状态回写：problems.md 里今天动过的条目，日志行＋状态行都更新了？
5 报数一行（§8）＋ 更新 study_hub.md 顶部进度块 ＋ daily_log.md
```

## 5. 付息日流程

```
⓪ 回看   本周期 3 道新题的四件套（只读，逐字取自 session 文件）
a 本周期全量   L1+L2+L3 全部出现过的未毕业条目，10 题一组，她喊停为止
b 向前抽样    更早周期的未毕业条目：
     · 排序 ＝ 距上次被测最久的优先
     · 兜底不变量 ＝ 任何未毕业条目不许连续两个付息日都没被测到
       （没抽到的进顺延队列，下个付息日最优先）
c 问题文件 review   重复项合并：
     · 判重 ＝ 两条的【目标产出形式】逐字相同才算重复；像但不同 → 改题面区分，不合并
     · 做法 ＝ 保留小编号，被并条目的全部日志按时间序并入，一行不删；状态按并后日志重算
     · 留痕 ＝ 被并编号写「→ 已并入 #N（日期）」，编号不复用不删除
     · **合并只在付息日做**，平时禁止顺手合并
     · 合并记录写进 cycles.md
d 整题重答    从 redo_queue.md 取（最久没重答的优先），0–X 道，她说停就停
     重答 ＝ 自由产出：走三件套 ＋ 落号 ＋ 落盘，与新题同规格
```

## 6. 出题规则

```
· 10 题一组
· 题面【逐字取自 problems.md 的题面字段】——要改题面先改文件再出题，
  不许存在"只在消息里、不在文件里"的题面
· 题面必须是完整句（"他家离马路远远的。"，✗"离马路远远的"）
· 出题前自查：这句中文有没有第二个同样合法的译法？有 → 当场在题面点名
 （可点目标词/句型/块/结构限定；不许整句给答案）。形态类（主谓一致/时态/冠词）不点名
· 组内排序：① 连错≥2 → ② 连对2（差一次毕业）→ ③ 距上次被测最久 → ④ 其余
· 组内防撞：同一条目最多 1 题；同族（同规则/同词族）最多 2 题；相邻两题不测同一个词
· 讲评泄题扫描：上一组讲评给过的判据/目标块，命中的条目本组不出（顺延，写明原因）
· 顺延 ≠ 丢掉：每轮顺延队列与上一轮做差集，少掉的每条写出去向
· 复习中译英 ＝ accuracy 检查，允许慢慢想，不计流利度；
  新题/重答 ＝ 自由产出，禁中文触发，打字数据不得用于任何流利度结论（含用词数评长度）
· 她答"忘了/不会" → 立刻给答案＋思路，不追问；记 📖，下次先 cold 测
```

## 7. 每一题的输出 —— 复习题与新题一视同仁

```
① 最小修改版   只放 ❌ 的修正，在她原句上动最少；她无真错时逐字等于原句
② 更好版       **接着她的内容和语法结构往上加**（她 08-19 原话："继续我内容和语法结构，
               如果太生硬了，就给更地道的"）——只有当她那句真的生硬时才换说法；
               没有就写【无更好版本】五个字（不许留空/不许"同上"）
③ diff         先摆【原句】【改后】两行完整句，再逐片段列差异，每处给理由；
               零 diff 的句子也摆原句，写"无 diff"
```
### ★★★ 三件套是【发给她】的，不是只写进文件（她 2026-08-19 定）
```
每一题、每一道，都要在**聊天里**给她三件套 —— 包括全对的题：
   全对的写法：`原句 → ＝原句 ｜【无更好版本】｜无 diff（✅ 考点：…）` 一行也行，但不许省
❌ 已废：聊天里只挑"有改动的"发、其余只报数
   （08-19 教练这么干了五组，她当场发现："最小修改、更高、每句 diff，现在都没了"）
⚠️ §9 的"聊天回复保持简短"**只管方法论那一侧** —— 条目编号、排序理由、顺延决策、
   犯规留痕、泄题扫描这些不进聊天；**逐题的语言反馈不在"简短"的适用范围内**。
```
**质量硬约束（v1 实证有效，全部保留）**
```
· 更好版必须长在她的句子上：主语与句序跟原文一一对应；整段重构的另起「另一种说法」栏
· ❌ 必须给可迁移的理由（规则/判据/同族清单），不许只判对错
· 小词纠正重复整个词组（说 "go on a trip"，不说 "to 改成 on"）
· 更好版准入三条：保留她的主语和信息 · 改动可指认到具体位置 · 说得出为什么
· 升级不提高词汇难度：换她已会的实义动词，不塞新难词
· diff 三档：❌ 真错 ／ ⚠️ 更好 ／ ⛔ 教练不必要的改动（⛔ 只留痕在 session 文件，不在聊天里展开）
```
**五层诊断**（每道自由产出题全过，不许只做层1）：
```
层1 语法搭配 ｜ 层2 词的精确度 ｜ 层3 衔接语气 ｜ 层4 逻辑层次 ｜ 层5 内容深度（"为什么"那层）
＋理解侧冗余七条（修饰语贴近 · 并列同形 · 分词逻辑主语＝主句主语 · 比较对象对齐 ·
  一句里时态同一平面 · 代词指代唯一 · 关系从句紧贴先行词）
某层无对象 → 写"本层无对象"，不硬造
```
**输出前四问自审**（每条纠正、每个语言判断发出前）：
```
① 真是错吗？试造一个母语者会说的句子来推翻自己 ② 是不是在延续上一条判断？
③ 判的是哪一层（形态/搭配/语义/语用）？ ④ 档位对吗：❌ 真错 ／ ⚠️ 不地道 ／ ✅ 有更好的
假错的代价 > 漏错。**她的怀疑比教练的推理值钱 —— 她一提异议，先当她是对的。**
```

### ★★★ 顺序写死
```
诊断做完 → 先把本题记录（原话逐字＋诊断＋三件套）写进当天 session 文件 → 才把反馈发给她
判据：下个复习日能【读到】当天给的东西，而不是【重新写】一遍
```

- **session 文件只装三样**（她 08-19 定，"skill 这些都要记录到 session 中么"）：
```
① 出题表   本组题面（逐字）＋ 条目号　　② 逐题记录   原话逐字 → 档位 → 三件套
③ 当天战报 数字 ＋ **一行**教练犯规 ＋ **一行**顺延队列

   —— 规则进本 SKILL（唯一真源），cycles.md 只留一行索引（日期＋她的原话＋改了 §几）
   理由：下次复习读的是题，方法论挡在题中间等于每次都要跳过；
        且规则写两个地方迟早对不上（graduated.md 就是这么死的）
```
- session 文件**必须详细到可复习**（每题：题面 → 她原话逐字 → 档位 → 三件套）；
