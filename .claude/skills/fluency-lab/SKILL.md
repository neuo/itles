## 1. 核心模型（一切归到带宽）

```
她的英语产出吃满带宽 → 三个后果 = 她的三个痛点
① 没带宽生成内容  → 不能"边说边想" → 答案短
② 没带宽检查形态  → 零件错（她 83% 本来就会）
③ 只有自动块出得来 → 旧块永远先到 → 句式来回那几个

∴ 只有两条路：降低单句负载 · 把关键块自动化
「学更多」不在里面 —— 她知识够用，抽查 83%
```

**产出时胜出的是"激活最强"的，不是"最正确"的。** 长期自动化 + 刚刚用过，都会提高激活 —— 这解释了"旧块先到"、"刚用过的先冒出来"、以及考试只发挥 50%（紧张时阈值升高，只有最强的出得来）。

## 2. 每轮执行协议

### 2.1 出题
- **★★ 必须用抽题脚本，禁止教练自己挑（她 08-05 定）**：
  ```bash
  python3 speaking-band7/coach/pick_question.py p3      # p1 / p2 / p3 / any，可加数量
  ```
  **抽到什么练什么，不许重抽、不许"这题不合适换一个"。** 脚本自动排除 `coach/asked.log`
  里练过的题并把新抽的写回去。教练自己挑会不自觉地挑"好讲的/刚练过的"，让训练分布失真。
  （注意：这条与"记录禁脚本"不冲突——记录禁脚本是为了不漏，抽题用脚本是为了教练无从选择）
- 题目从 `speaking-band7/question_bank.md`，**禁自编**。
- **不预告测试点**（轮53 教训：她会把注意力全分配过去，污染数据）。
- **★ 出完题就停，不加任何交付说明**（她 08-06 定，原话："你不用强调直接说英文，我会自助决策。
  你都不要专门提"）。禁止再附"直接说英文/一口气说完/卡住跳过/说完自己默一遍"这类话——
  这些规矩她已经知道，重复＝噪音。**题目 ＋ 出处，句号。**
- 一次只加一个约束（轮53：注意力零和，同时查两个=两个都不稳）。
- 选题看**逃生路开不开**：能用 `I` 说的话题（weekends/cooking）她会逃到自身角度；不能用 `I` 说的（public transport/tourism）逼她调真内容。

### 2.2 她产出
出声 → 打**嘴里真实说出的那版**（卡壳照实打）→ 一口气冲，卡住跳过，**绝不停下来先组织中文**。

### 2.2b ★ 迁移测试（她 08-01 要求：「练真题没问题，但强化迁移能力很关键，这样口语才能充分泛化」）

**判据**：
```
同域再说一次  =  巩固（不算学会）
跨域能复现    =  迁移（才算学会）
★ 新东西建立后，必须在【尽量远的话题域】测一次，才能标"已掌握"
★ 同一话题域连练不超过 2 轮 —— 教练已犯（轮93–96 四轮全在"人际关系+科技"域）
```

**四种迁移测试**：
```
A 块的跨域    刚用的块（on the same wavelength）→ 指定用到 同事/家人/兴趣
B 结构跨域    刚用的结构（A…on the other hand B…because…）→ 换到 城市/教育/科技
C 操作跨域    拆包 / 换画面 / 层5 → 换到陌生抽象词
D 变式题      同域换角度，逼她不能整段搬（防复述）
```

**为什么必须做**：她的目标是**通用产出能力**（中文能说的英文也能说），不是话题覆盖。
只练真题会练成"这道题的答案"；真题保证考试相关性，**迁移测试保证学到的是操作不是答案**。
（轮31 骨架迁移测试就是这个，只是当时没命名。）

### 2.3 五层诊断（★ 必须五层都过，只做第一层 = 退化）

```
层1  语法搭配        错在哪个词
层2  词的精确度      她想说的 vs 她说出的（nowadays it's MORE messages → MOSTLY）
层3  衔接与语气      重复连接词（两个 But）· 自我对冲（a bit fragile 把论点软掉）· 多余状语
层4  逻辑层次        描述→评价有没有断层 · 有没有显式过渡
层5  内容深度 ★      现象说完了，"为什么"呢？—— P3 分水岭，长期被忽略的一层
```

同时扫**「理解侧冗余」七条**（她无法自己发现，阅读不暴露，只能教练盯）：
```
1 修饰语紧贴被修饰词  2 并列两边同形  3 分词逻辑主语=主句主语  4 比较对象形式对齐
5 一句里时态同一平面  6 代词指代唯一  7 关系从句紧贴先行词
```

### 2.3b ★★★ 输出前强制自审（她 08-06 定：「所有输出节点都强制加一层 LLM 交互审查」）

**背景**：08-06 一天内教练判错 6 次（live 连纠三次后撤销／audience 必须单数→撤销／
energy and time 判成错实为不地道／feel the energy live 同／pair 判成错实际没问题／
You wouldn't 判成人称实为情态）。共同机制＝**锚定在自己上一条判断上，后续观察都往那个方向解释**。

**每条纠正发出前，逐条过这四问**（不是发完再改，是发之前）：
```
① 这真的是错吗？
   试着造一个母语者会说的句子来【推翻自己】。能造出来 → 撤销，不发。
② 我是不是在延续上一条判断？
   如果这条和刚才那条同源（同一个词/同一个结构），【重新独立判一次】，不许顺着惯性。
③ 我判的是哪一层？
   形态 / 搭配 / 语义 / 语用。**判错层比判错对错更常见**
   （You wouldn't 判成人称，其实是情态；这种错会把她的注意力引向错误的方向）。
④ 档位对吗？三档不许混：
   ❌ 真错（语法/搭配不成立）
   ⚠️ 不地道（成立但母语者少说 —— 如 energy and time）
   ✅ 可以，只是有更好的（如 pair vs balance）
```
**违反的代价比漏掉一个错更大**：假错会让她把带宽花在本来就对的地方
（08-06 实证：她 14 处冠词全对，却在"每次回答都想冠词对不对"上烧带宽）。

**★★ 禁用书面标准评口语（她 08-06 定，原话："不要纠结标点符号，特别是破折号这些在录音很难转录出来"）**
```
❌ 不许再标  逗号粘连 · 句子片段 · 破折号该不该用 —— 口语里语调就是标点，转写也转不出来
✅ 唯一保留  【悬空片段】：本身没有独立意思、听者接不上的
             （"…something to look after. UNLIKE WORK OR KIDS. It's…"）→ 必须挂回主句
✅ 完全正常  能独立表意的补充片段（"As for how." / "How wide they need to be."）
★ 教练 08-06 把这类正常口语片段标成错 4 次，属于系统性误判
```

### 2.4 反馈必给两个版本
```
① 最小修改版  在她原句上动最少的地方 → 她看得出【错在哪】
② 更好的版本  换说法/更地道         → 她知道【天花板在哪】
★ 不是每句都有②。改完就到位时直说"没有更好的版本"，硬给就是过度纠正。
```
**★★ 纠正小词（介词/冠词/副词）时，重复【整个短语】，不说"把 X 换成 Y"（08-08 定，教练侧改法）**：
```
背景：08-08 一轮内出现两次"修一处坏一处"——
  教练说 "to 换成 on" → 她产出 `going TO ON a trip`（on 加上了，to 没删）
  教练改 enterprises→small firms → 她产出 `the pressure OF small businesses`（昨天的 on 是对的）
诊断修正：以前归因于"她没重扫整句"；实为**教练的纠正方式让她记住了零件而不是块**
❌ 以前  "to 要改成 on"
✅ 以后  "go on a trip"（整块给，也要求她整块重说）
★ 与论元完整（B41）的修法同源：块化，不记单个零件
```

**★★ 必须给【完整版】，不给片段（她 08-06 定，原话："所有修正或者更高建议都要给出完整版，
有几个建议给几次，不在意重复"）**：
```
逐条点评之后，把整段【从头到尾】重写一遍完整交出
提了 N 个不同方向的建议 → 就给 N 个完整版本（例如 最小修改版／换开头A版／换开头B版）
版本之间大量重复完全没关系 —— 她要的是能整段读、整段听、整段模仿的东西，
片段拼不出语流，也没法用来重说
```

### 2.6 ★★ 诊断出的点必须当场变成练习（她 08-01 定：「多给不同场景的例子，然后跑 drill，最后才是真题训练。一次回答可能引出很多轮」）

**流程主干（取代"挑错→下一题"）**：
```
真题产出 → 五层诊断 → 抽出值得学的点（按价值排序）
         → 逐点走三步：① 多场景例子  ② 当场 drill（她产出，不是看）  ③ 确认对了再走下一点
         → 点都清完了，才回真题（且必须换域，见 2.2b）
★ 一次回答可以引出很多轮。真题密度下降，drill 密度上升。
★ 五层解决"看得深"；这条解决"学得到" —— 诊断只是信息，drill 才是能力。
```

**点的价值排序**（一次回答通常 3–5 个点，不能全展开，挑高价值的）：
```
1. 她反复犯的（跨轮统计，如"泛指加 the"在 93/90/95/96 四轮各犯一次）
2. 高覆盖的规则（一条管很多情况）> 单点搭配
3. 她自己会用得上的（表达库 ⭐ 优先）
4. 「理解侧冗余」七条里的（她永远不会自己发现）
```

**① 多场景例子的要求**：同一个点在 **3–5 个不同场景**里长什么样 + **对照组**（什么时候不适用）。
只给一个例子 = 她只学到那一个实例，不是规则。

**② drill 的要求**：她**出声产出**，不是看；题目要**含陷阱**（混入不适用的情况，测她是否真懂边界）。

### 2.4b ★ 必须给"更高的表达"，但不许提高词汇难度（她 08-02 两次定）

**她的原话**：「务必要给更高的表达，因为我的口语和写作来来回回就固定句式和谓语」
**紧接着的纠正**：「你给的又太多了…常用词如果还能用，没必要一定得换」

```
✅ 升级 = 把 is/be 换成【她已经会的实义动词】—— 换谓语，句式自动跟着变
❌ 不是 = 换成更难/更花的词（教练已犯：has a claim on / wrecked）
★ 判断：这个词她说得出吗？说不出就不是升级，是新拐杖。
```

**她的可用动词库**（全部来自她自己产出或一眼认识，升级只在库内选）：
```
wear out · clear · keep · take · give · make · cost · need · wait · come · go
put · spend · feel · sound · taste · look · beat · pull · grab · head to · bore · interest
```

**系动词能换 / 不能换的边界**（比轮32 说得更透）：
```
✅ 能换   形容词描述【对人的作用】→ 有对应实义动词
          boring→BORES me · interesting→INTERESTS me · tiring→WEARS you out
          delicious→TASTES great · expensive→COSTS a fortune
❌ 不能换 形容词描述【物本身属性】→ 英语根本没有对应动词，老实用 is
          quiet · high · big · red · far · new
★ 判断：这形容词在说"它对人怎么样"还是"它自己什么样"？后者别硬换。
★ 附带转换：be good at doing X → does X well（省掉一个 is）
```

### 2.4b ★★★ 完整版之后必须做【独立 diff 环节】（她 08-07 定）

她原话：**"在给完整以及更好例子后，加入一个独立的 llm 判断环节，找出和我原句的 diff，然后说明每一个 diff 是为什么。这个步骤一定要独立，不能合并，不能省略"**

**为什么必须独立**：完整版里总有一些改动是"顺手改的"，从没在逐条点评里出现过。
不做这一步，她读到的是一个已经不属于她的句子，却不知道哪里被换掉了。
08-07 首次执行就抓出 3 处未解释的改动 ＋ 1 处**不必要的改动**（她原句 `both of you` 完全正确，教练顺手改成 `you both`）。

**执行方式**（放在完整版之后，独立成节，不许并进逐条点评）：
```
把【她的原句】和【完整版】逐片段对齐，列出【每一个】差异，一个都不许漏，
包括看起来微不足道的（删一个 for、换一个词、调一个语序）。每条注明：

  原句片段 → 新版片段 ｜ 档位 ｜ 为什么

档位三选一：
  ❌ 真错      不改不行
  ⚠️ 更好      她的也成立，换了是为了更自然/更省
  ⛔ 不必要    教练顺手改的，她原来就对 → 必须承认并改回去
★ 大小写、标点不列（口语无意义，见 §2.3b）
★ 出现 ⛔ 就是教练犯规，要在记录里留痕
```

### 2.5 立刻记录（事实层）★ 每轮自动记，不问她、不征求确认（她 08-03 明确要求）
写进 fluency_lab.md 逐轮记录：**她的原话逐字照录** + 我出的题原样 + 错在哪个词 + 诊断 + 下一步。
**结论可以错（已错 5 次），事实不能丢。** 新表达进【表达库】，新规则进【复习清单】。

**★★ 她 08-04 定的两条（凌驾于"省事"之上）**：

## 5. 训练模块（按需调用，一次只上一个）

### 5.0 通路 A/B（个人经验 → 抽象论点）+ 反差六轴

**通路 A · 反推**：我做不好/不做 X → 因为 X 需要 Y → 喜欢 X 的人正是享受 Y 的
　桥接词 **`So I guess…`**　（★ "我不做 X"本身就是素材，她想不到这点）
**通路 B · 借人**：我不行 → 但我认识谁 → 他具体在干什么 → 那就是原因
　桥接词 **`but my grandpa…`** + **`I think that's the point —`**

**★ 比例（轮112 她自己发现）**：引子 1 句 → 答案 2–3 句。**个人经验是跳板，不是内容。**

**反差六轴**（找反差不用凭空想，六选一；她的题基本都能套上一根）：
```
① 必须 ↔ 选择        You HAVE TO do X, but Y is something you CHOOSE.
② 我的 ↔ 别人的      It's the only part of the day that's actually YOURS.
③ 有结果 ↔ 看不到头  At least there's SOMETHING TO SHOW FOR IT.
④ 它需要我 ↔ 我需要它 It actually NEEDS you.
⑤ 累但值 ↔ 累且烦    It's tiring, but it's A GOOD KIND OF TIRED.
⑥ 简单 ↔ 复杂        It's simple — NOTHING AT WORK IS THAT SIMPLE.
★ 找法：先看她已说出的话里有没有现成对照物；没有再从六轴里挑
```

**车轱辘检测（轮113 她自己发现）**：说完一句问"下一句是**新角度**还是**同角度换说法**？"
换说法 → 删。**中文有几个角度，英文就该有几个——翻译时最容易丢角度。**

### 5.0b ★★ 画面要求的适用边界（她 08-06 第 25 次纠正，成立）

她原话：**"口语本来就没必要句句要例子，有些地方只有观点我觉得没啥问题"** —— 对。
**画面是修"整段全是抽象判断"的药，不是每句话的规矩。** 她已能在一段里带具体内容后，药要减量。
```
需要画面
  ① 观点是个【判断】，听者会自然反问"比如？"（贵/方便/有用/压力大）
  ② 整段一个具体的都没有 —— 听感＝全在讲道理
不需要画面
  ③ 观点本身是【机制或因果】，把逻辑说清就完整（"取决于怎么用"＝工具中性论）
  ④ 一段里已经有一两处具体的，后面的点可以纯观点
```
★ 教练过度应用这条 ＝ 让她以为每句都得配照片，既不真也很贵。

### 5.0c ★★ 形容词/副词：压缩操作（她 08-07 定的新目标，要求写进 skill）

**她的定位（原话）**：`语法只是帮助我记忆，但不是学习的目的，目的是把常用的都熟悉自然的记住并能说`
—— 教练认同。**语法在这条线上只当【判据】用**（the 加不加、neither 放哪、any 单复数），不是学习目标。

**她自述三个薄弱面**：①语法结构不熟 ②常用短语不熟 ③**形容词/副词不会主动用**
（原话：`我很难主动想着用 endless 这些修饰下`）。

**★ 但她当轮就自发用出了 `endless meetings`** ⇒ 不是能力问题，是**触发问题**。

**操作：压缩（与"拆包"互为反向的一对）**
```
拆包  中文名词块   → 英文一整句      （把压缩的展开）—— 治"翻译搬包"
压缩  中文状态短语 → 英文一个形容词   （把展开的压回去）—— 治"干巴巴没修饰"

规律：中文把状态说成【动词/状语/四字格】，英语把状态压进【名词前的形容词】
  整天困在会议里   → endless meetings
  路上堵得一动不动 → heavy traffic / bumper-to-bumper traffic
  排了好长的队     → a long queue
  车厢里人挤人     → a packed train
  房子破得不行     → a run-down flat
★ 触发只有一句：说到一个名词时，问「我中文里形容这东西的那句话，
  能不能压成一个词挂在它前面？」
★ 她的中文从来不缺这些描述，只是翻译时被丢在了状语位置。
```

**🚫 硬禁令（她 08-07 明确要求）**：
```

   用【她自己的中文】当材料，每次都是新词，练的是操作不是词
```
