### 0.2 选条目：不许抽样，但可以顺延

```

b. 提取【全部】B 号，**教练自己列清单自查**
   ★★ 这份清单【不发给她】（审计冲突#5）：发给她 ＝ 提前公布全部考点 ＋ 让她做列举题，

   她喊停时没出完的进顺延队列

★★ 合并的唯一合法范围（审计冲突#2 / 违规#5#6 / 含糊#7）
   ✅ 可删：同一个 B 号下面重复的【题面】
   ❌ 不许删也不许并：不同 B 号的【条目】。题面撞车 → 改题面，不删条目
   理由：每个 B 号要独立拿到自己的 ✅/❌，并掉就永远拿不到连击

★★★ **两个号内容确实重复时怎么办**（第3轮审计 C#10 / 新违规 B5 —— 原来只禁不给出口，
     导致教练只能在"并"和"放着不管"之间选，最后做成了"停用"＝变相删条目）
```
第一步 判是不是真重复：两个号的【考点】是否完全相同？
      不同（只是题面像） → 改被动方的题面，两个号都留着照常出
      完全相同           → 走第二步
第二步 **拆考点、不停用任何一个号**：
      把重复的内容按子考点分配给两个号，让它们的【题面互斥、各测各的】
      例：B44/B188 都写"often vs usually" → B44 只测 often（经常）、
          B188 只测 usually（通常情况下），两条题面互斥，两个号各走各的 streak
★ **一方停用即违规**。历史 📊 行里出现过的号，永远不许作废
★ 撤销一次误合并时，**恢复原号，不许新建 xxxold 之类的僵尸号**（第3轮审计 B15）
```

★★ 组内顺序（08-11 改：全量之后，这套规则从【筛选】降级为【排序】）
   全量出题意味着没有条目会被排除，所以配额不再是"谁进得来"，而是"谁先出"——

   ★★★ **毕业候选（连对2）【跨批取】**，不受 D-1/D-3 批次限制（第3轮审计 B3 的死锁修复保留）

### 0.3 出题方式

```
分层（08-02 实证的记忆规律）
   规则类 / 表达类  → 她产出过的，记得住一半 → 中译英测
   操作类 / 方法论  → 教练讲的，几乎全忘   → 【做出来】测，不能靠"说出方法名"
   ★ 清单里必须按【规则/表达/操作】三分标注，操作类要写明测法（审计存疑#14）

只考【用】，不考判断、不考列举（08-05 双实证：判断题和列举题都给假的"会了"）

★★ 中译英的边界（审计冲突#1：禁令1 禁中文触发 vs 复习全用中译英）
   复习中译英    ＝ accuracy 检查，【不计流利度】，允许她慢慢想
   自由产出/真题  ＝ 禁中文触发，走情境/画面/英文提问
   ★ 两者目的不同，不冲突。禁令1 管的是流利训练，不管 accuracy 检查

★★ 复习题的题面来源（审计冲突#3 —— 原来"禁自编"与"复习必然自编"直接打架）
   真题    走 pick_question.py，禁自编
   复习题  中文题面【逐字复用 B 表的"抽查方式"列】，不许现编
   ★ 这同时解决出处问题：出处 ＝ B 号，但 **B 号只记进 fluency_lab.md，
     不出现在发给她的消息里**（禁令6c：编号是方法论层，她记不住）（审计违规#12/冲突#6）

★★ 减法型规则的定义（审计含糊#6：原来只有两个样例，边界靠猜，且是永久豁免）
   定义：考点是"不产出某个形式"，且【没有对应的正面产出】
        ✅ 是：删掉 a bit · 别用 is important 的壳
        ❌ 不是：without no（有正面产出 with no / without，可测）—— 审计违规#4
   处理：不出中译英题，挂到当日自由产出题下当场抓；📊 记 ◎ 不记 ❌
        ★ 豁免必须写明【替代测法】和【归池日期】，不许永久豁免
```

### 0.4 学习日的新题 ＝ 3 道（她 2026-08-11 定，原为 1 道）

```
为什么学习日必须有自由产出题：减法型规则、操作类、"改完当场重说"都只能在自由产出场景里测，
否则这些点永远拿不到 ✅、永远出不了池、也永远不会被报数看见。
学习日结构：复习 D-1＋D-3 全部 → 【新题 3 道（走脚本）】→ 由她决定加练还是停

★★ **抽签动作在节点① 就做完，不许推迟**（第2轮审计 C#11 / 新违规#8）
   在节点① 一并跑 `python3 speaking-band7/coach/pick_question.py 3` 抽出 3 道，写进当天记录。
   **不发给她的只是【题面】，不是【抽签动作】** ——
   推迟抽签 ＝ 把操作类的唯一出口一起推迟（操作类只能"做出来"测，全挂在这些题下）。
   "怕提前写 asked.log / 怕暴露"不成立：§2.1 已禁预告，抽了不给看即可。
★ 3 道逐道走完整六节点流水线（§2），不许合并诊断、不许一次发三道再一起批
```

**⚠️ 3 道带来的连带后果（必须记账，不许假装没有）**
```
重答队列每周期净增 10 道：新题 3×5 ＝ 15 道进队列，专门复习日只重答 5 道
⇒ 队列会持续变长。这是【设计接受的结果】，不是漏记：
  · 重答对象按「最久没重答的优先」排序，不许挑好答的
  · 队列长度每个复习日报一次数，让她自己决定要不要调 5 这个数

## 1. 核心模型（一切归到带宽）

```
她的英语产出吃满带宽 → 三个后果 = 她的三个痛点
① 没带宽生成内容  → 不能"边说边想" → 答案短
② 没带宽检查形态  → 零件错（她 83% 本来就会）
③ 只有自动块出得来 → 旧块永远先到 → 句式来回那几个

∴ 只有两条路：降低单句负载 · 把关键块自动化
「学更多」不在里面 —— 她知识够用，抽查 83%
```

**产出时胜出的是"激活最强"的，不是"最正确"的。** 长期自动化 + 刚刚用过，都会提高激活 —— 这解释了"旧块先到"、"刚用过的先冒出来"、以及考试只发挥 50%（紧张时阈值升高，只有最强的出得来）。

## 2. 每轮 / 每 Block 的强制流水线

> **⚠️ 为什么要这张表（08-10 教练一次违反三条）**：Block C 没给完整版也没做 diff／出了跟 Block A
> 重复的题／出了 12 题而不是 10 题。**根因不是规则不对，是规则散落在各小节、没有一条强制顺序串起来。**
> 这张表就是执行入口。**六个节点逐个独立走，不许合并、不许跳过、不许"心里已经想过了"。**

```
① 选题        2.1   a 抽题脚本／从 📊 日志取复习候选
                    b ★去重：跟【本 session 已出过的全部题】逐条比对，重复的删
                    c ★切成【10 题一组】，多了不出，少了可以
                    d ★题面自查：这道中文能不能逼出考点？逼不出就改题面（否则又是 ◎）
② 她产出      2.2
③ 验收        2.3   五层诊断 ＋ 理解侧冗余七条
              2.3b  四问自审 ＋ 六档标注（✅◎△❌🆕📖）
④ 完整版      2.4   整段从头到尾重写；N 个方向给 N 个完整版
              2.4c  内容要求：更高的表达但不提高词汇难度
⑤ Diff        2.5   逐片段对齐，列出【每一个】差异，三档标注
⑥ 记录＋报数  2.6   逐轮记录（原话逐字）＋ append 📊 行 ＋ 报数
```

**硬规矩**
```
★ 六个节点缺一个 → 这一轮不算完成，不许出下一组题
★ ④ 和 ⑤ 必须分开写出来 —— ⑤ 的价值就在于它是【事后独立复查】，并进 ④ 就失效了
★ "我心里已经做过了"不算 —— 必须【写出来】，写出来才能被检查
★ 附加节点（按需，不在主流水线里）：2.2b 迁移测试 · 2.7 点变练习
```

技巧5 ★ 降级必须在【中文层】做完（中文抽象→中文具体→再翻），第一步不占带宽
```
