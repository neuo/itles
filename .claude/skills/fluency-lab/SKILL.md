## 0. 一页速查
```

      D-1 / D-3 ＝ lab/sessions/ 里按日期倒数第 1 / 第 3 个文件

学习日  ① 复习 D-1 ＋ D-3 被测到的未毕业条目里的【必进池四类】（10 题一组，她喊停为止）
           ★ 每组组完题必须先过 §6.5【发题前审核表】9 项，写进 session 文件才允许发
        ② 回看 D-1 新题四件套（只读，她不产出）
        ③ 新题 1 道（脚本抽）——【保底做】，她累了也做这一道
        ④ 收尾核对
付息日  a 复习本周期全部出现过的问题（10 题一组）
        ⓪ 回看本周期全部自由产出的四件套（只读）　★ 位置＝**a 之后 b 之前**（她 08-23 定）

问题 = 她犯的错 ＋ 她说得不地道 ＋ 她主动提出的（来源不限：复习/新题/重答一视同仁）
每条问题：唯一编号 · 题面 · 状态行（连对/连错/上次复习）紧挨日志 · 每次被测追加一行日志
三档（推进 streak）：✅ 对 ｜ ❌ 错（**"忘了/不会"也是 ❌**）｜ ◎ **只用于"教练把题面搞坏了"**
　　★ ⚪ 是记号不是档位（形态类专用）｜ 📖 已于 08-23 停用，只在读历史日志时认它
　　★ 同一条同一天被产出多次 ⇒ **每次各记一行、各算一次**，不挑"以谁为准"（她 08-23 定）
　　★ 她答得合法但不是条目预期 ⇒ **算 ✅ ＋ 当场改题面**（08-20 定），不再记 ◎

复习不再召回；再犯 → 状态行改回，连对清零

每一题（复习和新题一样）：最小修改版 ＋ 更好版 ＋ diff
★★★ 顺序写死：先写 session 文件 → 再把反馈发给她

## 1. 周期与日子
```
固定循环：L1 → L2 → L3 → R(付息日) → L1 → …
只数【有行为的日子】：休息、没练 ＝ 那天不存在，跳过不占位
可数依据 ＝ lab/sessions/ 的文件名（一天一文件 YYYY-MM-DD.md）：
   D-1 ＝ 倒数第 1 个文件的日期　　D-3 ＝ 倒数第 3 个文件的日期
   今天是第几个学习日 ＝ 数上一个付息日之后有几个 session 文件
```
- 开场第一动作：`ls speaking-band7/lab/sessions/` 定位今天是 L1/L2/L3/R —— **数文件，零推导**。
  每个文件首行写着它是 L1/L2/L3/R；找到最后一个 R，它之后有几个文件，今天就是第几个学习日。
- 早期回填文件里的条目用**旧号 B×××** 记，换算：`grep -n "旧号 B107b" speaking-band7/lab/problems.md`

## 2. 什么算"问题"
```
① 她犯的错          语法 · 搭配 · 时态/单复数/冠词/介词 · 结构　（**拼写不算**，见 §2.1）
② 她说得不地道      字面能懂但 local 不这么说 —— 尤其【句型和词组】
③ 她主动提出的      她问"这个怎么说更好""这句是不是怪"
来源不限：复习题里的、新题里的、重答里的，一样建条目一样复习
```
**不算问题**：打字材料里的句读（句号 vs 逗号不构成口语证据）· 教练判错后撤销的（当场撤，不留条目）。

### ★★★ 2.1 单词拼错【一律不算错】（她 2026-08-20 定）
```
① 拼错 → **不建条目、不记档位、不写进 ❌**；顶多在 diff 里顺一句正确拼法，不展开
② 已经存在的拼写类条目 → 状态行加 `｜拼写类·不召回`，**永不进复习组**（她自己 review）
③ 唯一例外：**她主动说"这个要记"** —— 那时才建条目/记档位
④ 边界（教练必须分清，判错就是在浪费她的带宽）：
   ✗ 拼写   同一个词写歪：`eaiser`／`additive`（想说 addictive）／`recieve` ⇒ **不算**
   ✓ 选词   调出来的是**另一个词**：`virtual` 想说 vital（#255）· `look up` 想说 look for ⇒ **照常算**
   判据一句话：**她脑子里调的词对不对**，不看字母拼没拼准
```

## 3. 问题文件 `lab/problems.md`

### 3.1 格式：一条问题一个块，状态行紧挨日志行
```markdown
### 12 · keep patient → stay patient
类型 搭配 ｜ 题面 "他劝我耐心点。"（点名：用 stay 说） ｜ 旧号 B117b
状态 连对2 连错0 上次2026-08-19 未毕业
- 2026-08-11 首犯 · 新题 · `I keep patient` → stay patient
- 2026-08-16 ❌ 复习 · 又写成 keep
- 2026-08-19 ✅ 复习
```
- **状态由日志重放而来**，两边不一致时以日志为准、重算状态行（数字必须可复算）。
- 每次被测/每次犯错都**追加一行日志**，一行一次，不合并、不写"以此类推"。
- 发现新问题 → **先搜全文能不能归到已有条目** → 归不上才新建编号。
  ★★ **判重三步**
```
① 先把【目标英文形式】写出来（不是中文题面）—— 这一条到底要她产出哪个词/词组/结构
② 用那个英文形式 grep，**范围必须含已毕业条目**
   `grep -n "look for\|no questions" problems.md`  ← 已毕业的占一半以上，漏搜它们＝必然重复
   中文题面也扫一遍：`grep -n "七天无理由" problems.md`（同题面几乎一定是同考点）
③ 判据三档：
   · 同一个【词 / 词组】          → 同一条（drive past ≡ drive past sth）
   · 同一条【规则】              → 同一条（get sb to do ≡ "哪些动词后面带 to"）
   · 只是像、目标形式不同        → 两条，但**当场改题面互斥**，写明互斥关系
⛔ 判成"新条目"之前必须能说出：**它和最接近的那条差在哪个词/哪条规则上**。说不出 ＝ 就是重复。
```
- ★★ **一条 ＝ 一个考点**
```
一条条目只准装【一个】目标形式或【一条】规则。
⛔ 捆绑条目（迁移遗留，如 #95 #75 #68）必然与别的号重叠，且三个块掉一个整条清零
   ⇒ 她被反复测已经会的那两个
⇒ 遇到捆绑条目：**拆号**，每个块一条，各走各的连击（拆出来的子条从 0 起算，不继承）
```
- **新建条目当天不测**，次日起进池（当天教完当天测 ＝ 假 ✅）。

### 3.2 归类粒度
```
词汇 / 搭配 / 词组 → 按【具体的词或词组】一条一号（keep patient 和 bury into 是两条）　★ 拼写不建条目（§2.1）
语法 / 结构             → 按【规则】一条一号（will lost 和 didn't found 同属"助动词后接原形"）
```
### ★★★ 3.2b 直译类问题一律 case by case 建，**禁止伞形条目**（她 2026-08-21 定）
```
⛔ **禁止开伞形条目**：「直译搭配」「用词不地道」「表达生硬」「中式英语」这一类。
   它们的考点是**开放集合** —— 每冒出一个新实例就把 streak 清零，**结构上永远毕不了业**。
   （判据留在 methods.md M36／M37）

✅ **正确做法：先判这一次到底是哪一样不会，按那一样建**
   · 是某个【词组】不会用  → 按**那个词组**建一条（more convenient to find → **easier to find**）
   · 是某个【句型】不会用  → 按**那个句型**建一条
   · 两样都不是，只是这次翻得生硬 → **不建条目**，diff 里给更好版就完了（判据走 M36／M37）

★ 自查一句话：**说得出"她不会的是哪个词组／哪个句型"就建；说不出 ＝ 别拿伞形条目顶上。**
★ 这条对**所有**类别生效，不只直译：凡是考点无法收敛成"一个词组／一条规则"的，都不许建条目。
```


### ★★★ 3.2c 合并条目的出题规则（她 2026-08-23 定）
```
① **允许合并**：同一条规则下的多个"错词"可以并成一条规则条
   例：#261 action／feedback／advice／information／knowledge／research／progress
       全是"这一小撮抽象名词不可数"这**一条规则** ⇒ 合成一条，不用一个词开一个号
   ★ 这是对 §3.1「一条 ＝ 一个考点」的**限定解释**：规则相同 ＝ 一个考点，成员不同不算多考点

② **出题必须多句覆盖**（硬规则）：合并条每次出题**不许只出一个成员的一句话**，
   必须给**多个句子、覆盖这条下的全部成员**
   —— 只出一个词，她错的那个成员永远测不到，而已经会的那个被反复考

③ **顽固成员单独摘出来**：某个成员反复掉 ⇒ **把它单拆成一条新条目**，
   **老条目（剩下的成员）照常走连击、够线就毕业**
   ⇒ 这样"顽固的那一个"不会再把"已经会的那几个"一起拖回池子

④ **条目上要有标记**：合并条的状态行加 `｜合并条·出题多句覆盖`；
   §6.5 审核表出题时逐条核 —— 只出一句就是 ✗

⑤ 与 §3.2b（禁伞形条目）的分界线，一句话：
   **成员数得出来 ＝ 有限集合 ⇒ 可以合并**（#261 那七个词、#268 那七个动词）
   **成员数不出来 ＝ 开放集合 ⇒ 禁止建条目**（"任何从中文直译出来的搭配" ⇒ #157 已迁出 methods.md）
```

### 3.3 档位与连击

**推进 streak 的只有三档**（✅ ❌ ◎）；⚪ 是记号不是档位；📖 只读历史。

| 记号 | 含义 | 连对 | 连错 |
|---|---|---|---|
| ✅ | 对（考点位置一字不差） | ＋1 | 清零 |
| ❌ | 错（**"忘了/不会"也是 ❌**） | 清零 | ＋1 |
| ◎ | **只剩一种用法**：题面本身有毛病（教练现编／截断／缺主语），本次作废 | 不动 | 不动 |
| ⚪ | **记号，不是档位**：形态类在任何地方掉了都只记它（§3.4②） | 不动 | 不动 |
| 📖 | ⛔ **2026-08-23 起停用**（"不会就错" ⇒ 一律记 ❌）。只保留读历史日志用，不再新发 | — | — |

- **标记打在条目上，不打在整句上**：一句话可以同时给 A 条 ✅、B 条 ❌。
- ★★★ **她答得合法但不是条目预期 ⇒ 记 ✅，不记 ◎**（她 2026-08-20 定）
```
硬顺序：① 判她这句是否**符合题面**（题面点名了什么就照什么判）
        ② 符合 → **记 ✅**（照常 ＋1 连对，照常毕业）
        ③ **当场改题面**回写 problems.md，让下次能逼出条目真正的目标形式
        ④ 日志里写清楚：她答的是什么／目标形式是什么／题面改成了什么
⇒ 「◎ 不动连击」只保留给**教练自己把题面搞坏**的情况（现编/截断/缺主语）
```
- ◎ 的当场动作：**当天就改题面**（回写 problems.md），次日再测。
- 同一天同一条被产出多次：**每一次都追加一行日志、每一次都算一次记录**，不挑"以谁为准"（她 2026-08-23 定）。
- **毕业**：
```
★★★ **连对 2 → 毕业，所有情况统一**（她 2026-08-20 定）
`状态 连对2 连错0 上次YYYY-MM-DD ｜ **🎓 已毕业 YYYY-MM-DD**`
条目留在 problems.md **原地不动**，全部日志行（行为行）一行不删、一行不移
毕业 ＝ 复习不再召回，**不等于**记录搬家 —— 历史必须跟着条目走
她可直接指定（"这句毕业了，别问了"）→ 记「🎓·她指定」
❌ 一条文件都不许再开：不搬条目、不留墓碑行、不建"已毕业"清单
计数口径（认状态行，别认正文里提到的字样）：
  条目总数 `grep -c "^### " problems.md` ｜ 已毕业 `grep -c "^状态.*🎓" problems.md` ｜ 未毕业 ＝ 两者相减
```
- **回潮**：已毕业条目在任何产出里再犯 → **状态行改回未毕业、连对清零，日志接着往下记**（条目本来就没动过）。
  ★★★ **唯一例外 ＝ 形态类条目：在哪儿掉都不回潮，只记 ⚪**（§3.4②，形态类优先于本条）。
  判据：它的失败是"产出时检查没跑"，不是不会 ⇒ 掉回池子等于让她重练已经会的。

### 3.4 ★★ 形态类条目 ＝ 只记录、不出题（她 2026-08-19 定 → 08-27 定型）
```
判据（自我分诊）：**把这个点单独问她一次**——
   答得出 → 她会，缺口在"产出时检查不运行" ⇒ **形态类**
   答不出 → 真缺口 ⇒ 照常复习
形态类 ＝ 主谓一致 · 时态标记 · 单复数/限定词 · 冠词/指称 · 比较级 · 否定标记 · 不规则动词变形

① ★★★ **永不出题**：不进任何复习组，**含付息日 a 段和 b 段**（§5 的"全量"对它们不适用）
② ★★★ **在哪儿掉都只记 ⚪**：中译英复习 · 自由产出 · 新题 · 重答，一视同仁 ——
   不记 ❌／不判档位／不动状态行／不掉毕业／不回潮／**不计入当篇真错数和密度**
   ⇒ 教练的动作只剩两个：**点出来 ＋ 复述那条检查触发**
③ 每条必须写一行**检查触发**（写完什么，回头看什么），产出后逐条扫
④ 条目状态行标记 `⚪ **只记录·不出题**`（旧标记 `｜形态类·不召回` 等效，出题时一律跳过）
⑤ ★★★ **历史不回扫**：08-25 之前记下的 ❌／连错／累错／"顽固"标记一律原样保留，
   不撤销、不重算 —— 只当历史读，不再驱动任何出题

★★ **执行自查（落 ❌ 之前必跑）**：凡"词尾差几个字母／形态标记漏掉"那一类，先反问一句 ——
   **"同一篇里她有没有把同一个形态做对过？"有 ⇒ 一律 ⚪，不许记 ❌。**
   （＝ 上面判据"单独问她一次"的省时版：在同一篇里找她自己已经给出的答案）
★ §7 四问①在形态类上换方向：不是"试造母语句推翻自己"，是**"试着证明她其实会"**
⚠️ 例外：她自己说"这条我真不确定"时，可以临时召回一次
```

## 4. 学习日流程

### ① 复习 D-1 ＋ D-3
- **对象（她 2026-08-19 改，原来是"全部未毕业条目"）**：那两天被测到的未毕业条目里，**只取必进池四类**：
```
必进池 ① 历史上有过 ❌ 或 📖 的（**含"新建那次的犯错"**——新建条目次日必进池）
       ② **连对1（差一次毕业）**      ③ 回潮的（毕业后再犯）   ④ 改过题面、欠一次重测的
不进池 **连对0 且日志里从来没掉过的** —— 典型是"她答对了、教练只是给了更好版"那种
       （不是缺口，只是次数没攒够）
       ⇒ 召回路径：**付息日 a 段**（本周期全量）＋ b 段"最久没测优先"＋
         兜底不变量"不许连续两个付息日没被测到"；
         **加速通道 ＝ 在自由产出里自发出现就当场记 ✅**，不用等
★★★ **加速通道的边界**（教练 2026-08-27 提案 → **她当场认可**："可以只记录"）：
   自发命中的如果是**她本来就稳的那一半**、而**这条刚掉的那一格根本没被测到**
   ⇒ **只记 ⚪，不推进连对**（状态行一个字不动）
   实证 ＝ 🎓#236（目的用 to do）：08-27 在 R5 掉的是【名词后面挂目的】（a reason ___ bring），
     同日在 R7 自发用对的两处是【状语位】（on Amazon to buy／slow down to ask）——
     那正是她 08-10/13/15 三次 ✅ 全都拿到的那一半
   ⛔ 不这么切，条目会**在从没修过掉的那一格的情况下重新毕业** ＝ 假毕业
   ⇒ 配套动作：**回潮后的复测必须用能测到"掉的那一格"的题面**（不够就当场补一句题面）
```
- 10 题一组，一组答完再讲评再出下一组；**她随时喊停**，没出完的进顺延队列（§6）。

### ② 回看 D-1 新题（只读，她不产出、不计分）
四件套**逐字取自 D-1 的 session 文件，禁止重新推导**：
```
① 题目原文（P2 含 bullets）　② 她的原话逐字　③ 最小修改版 ＋ 更好版　④ 分句 diff
```

## 7. 每一题的输出 —— 复习题与新题一视同仁

**三件套 ＝ ① 最小修改版 ② 更好版 ③ diff** —— 每一题的输出，本节定义。
**四件套 ＝ 题目原文 ＋ 她的原话逐字 ＋ 三件套** —— 回看时读的那一整套（§4② §5⓪）。
```
① 最小修改版   只放 ❌ 的修正，在她原句上动最少；她无真错时逐字等于原句
② 更好版       **接着她的内容和语法结构往上加** —— 只有当她那句真的生硬时才换说法；
               没有就写【无更好版本】五个字（不许留空/不许"同上"）
③ diff         ★★★ **分两段，每段都先摆两行完整句，再逐处给理由**（她 2026-08-23 定）：
               **diff-1  原句 → 最小修改版**（只有 ❌ 的修正 ＝ "我错在哪，最少改什么就对了"）
               **diff-2  最小修改版 → 更好版**（只有 ⚠️ 的升级 ＝ "对了之后还能怎么更好"）
               每段的硬格式：① 第一行 ＝ **完整的起点句** ② 第二行 ＝ **完整的终点句**
                             ③ 下面逐处列差异，**每处一句理由**
               ★ **那一段完全没有改动** → 只写一行 `无 diff（＝上一版）`，不必把同一句再摆两遍；
               　 但**只要有一处改动，那一段就必须摆两行完整句**
               ⛔ 不许只写 `xxx → yyy（理由）` 就完事 —— **看不到完整句就不算 diff**
               ⛔ 不许把两段并成一段 —— 她要的是"错→对"和"对→更好"**两件事分开看**
               ★ 多句的自由产出（P2/P3）：**逐句走这两段**，一句一组，不合并
```
### ★★★ 三件套是【发给她】的，不是只写进文件（她 2026-08-19 定）
```
每一题、每一道，都要在**聊天里**给她三件套 —— 包括全对的题：
   全对的写法（两段 diff 都空）：`原句 … ｜判定 ✅ 考点：… ｜最小改 ＝原句 ｜更好版 无更好版本 ｜diff-1 无 diff ｜diff-2 无 diff`
   —— 可以压成几行，但**六项一项都不许省**；只要任一段有改动，那一段就按 §7③ 摆完整句
⛔ 不许只挑"有改动的"发、其余只报数
```
### ★★★ 聊天里一律用【代码块】整体输出（她 2026-08-20 定，为了能一次性复制）
```
① 复习题一组   → **一个** ``` 块装完 10 题（不许每题一个块、不许块外散着写）
② 新题         → **一个** ``` 块装题目原文（P2 连 bullets 一起放进去）
③ 每题的三件套 → **一个** ``` 块装完：原句 / 判定 / 最小修改版 / 更好版 / **diff-1** / **diff-2** 全在同一个块里
④ 块外只留最少的连接句（"第 N 组"、"本组 ✅x/y"），方法论一个字都不进
⑤ 块内不用 markdown 粗体/表格（复制出来是噪音）—— 用纯文本对齐、用 ✅❌⚠️ 做标记
```
**块内固定骨架**（每题一块，照抄这个顺序）：
```
[N] 题面或题干

判定     ✅／❌ ＋ 一句话
最小改   …（无错时写"＝原句"）

diff-1  原句 → 最小改
  原句   …………………………完整句…………………………
  最小改 …………………………完整句…………………………
  · aaa → bbb    ❌ 理由（可迁移的规则/判据，不许只判对错）
  · （无改动就写：无 diff）

diff-2  最小改 → 更好版
  最小改 …………………………完整句…………………………
  更好版 …………………………完整句…………………………
  · ccc → ddd    ⚠️ 理由
  · （无改动就写：无 diff）
```
⛔ **两段都必须摆完整句** —— 只写 `aaa → bbb（理由）` 不算 diff。
⛔ **复习题和自由产出一视同仁**，一题都不许省。
**质量硬约束**
