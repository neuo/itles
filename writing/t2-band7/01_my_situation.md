## 2. 语言能力分布（不均衡）

```
强 ──────────────────────────────── 弱
阅读（passive）    听力     口语     写作（active）
   ✅           ⚠️       ❌       ❌
理工科背景       关键词     一输出   想得到
逻辑分析强       能抓到     就死机   说不出
                 句意串
                 不起来
```

**核心问题**：**input >> output**。能看懂复杂文章不等于能写出 Band 7 文章。

**底层瓶颈精确命名（5/18 W1 Day 2 仿写中发现）**：**主动语言重组能力（Active Reformulation Flexibility）**——把**同一个意思**用**多种新方式**表达的能力。不是查同义词，是**从概念层重新建构语言**。

**症状表（5/18 仿写 Intro 时全部触发）**：
1. 中文 paraphrase 也卡（不只是英语问题）
2. Frame 混用（META frame 当 Object frame 用 → "it's debated that what..." 模式冲突）
3. 抽骨架不完整（漏 WHY → View A 的 WHAT 接到 View B 的 WHY 上）
4. 表达只想得到 1 种说法（"3-版本测试"立刻暴露）
5. "想得到说不出"——这是同一根的不同表现

**为什么你（理工科逻辑强）特别卡这里**：
- 科学思维 = **精确**（一个意思一种说法）↔ 语言灵活性 = **多样性**（一个意思多种说法）
- 工程师习惯 = **复用熟悉模式** ↔ 写作灵活性 = **离开舒适区主动重组**
- 30 年阅读 << 几百小时主动写作 → flexibility 没机会练

**解决路径（详见 [`05_path.md`](05_path.md) "Daily Paraphrase Drill"）**：
- Level 1（立刻）：「抽 → 重组」framework + Object vs META frame 区分 + DBV 防混 checklist
- Level 2（每天 5 min）：Paraphrase Drill（1 句 × 中英各 3 版本）
- Level 3（长期）：Phrase capture 习惯 + active reading

→ 不是 magic，是**复利**。30 天 × 5 min = 180 个 paraphrase 样本 → frame 空间从 1 种扩到 4-5 种。

**具体表现**（5/17 自己确认）：
- 看 Band 7 范文 → "嗯，这写得不错，能看懂"
- 让你写 → **"除了几个常用句型，一出新场景就死机"**——意思是你已有少量自动化句型可调用（比如 "I think X is important because Y"），但一遇到新的语法/逻辑组合就卡死
- 让你写 → 句子写不完整、立场摇摆、想到的论点落不到笔上、TEEL 写到 Example 就忘记 Link

**这不是知识不够，是产出通路没建立**。**这也正是 §4 工具集策略的设计原因**：把 25 衔接 + 8 句式 + 5 opener 练到肌肉记忆，就等于把"能调用的自动化句型"从几个扩到几十个，**死机的边界就被往外推**。

## 3. 学习风格特征

| 特征 | 含义 | 训练上怎么用 |
|------|------|------------|
| 理工科逻辑强 | 喜欢"为什么这么做"的解释，反感无理由的规则 | 每个工具都给"为什么用这个不用那个"的理由 |
| 语言靠重复积累 | 看一次记不住，要练 5-10 次才进肌肉记忆 | 限量工具集 + 反复用同一套，不贪新 |
| 听英语先翻译成中文 | 正常过渡阶段，**说明 active 通路尚未自动化** | 写作训练目标之一是把"想中文→译英文"压缩到"直接想英文句式" |
| 可接受少量背词，不想多花时间 | **每天 5 min 上限**——超过就不愿意做 | 不依赖话题词汇表；只**每天 5 min 微复习** §4.4 升级词 + 当周范文里的 collocation（写到肌肉记忆，不扩新词）|
| 喜欢清晰的"完成标准" | 不喜欢"差不多就行"，要明确的合格线 | 每个训练单元都给明确的 pass/fail 标准 |

## 4. 从 5.5-6 到 7 的 Gap 分析（按评分维度）

| IELTS 维度 | 现状（推断）| Band 7 标准 | Gap |
|-----------|------------|-----------|-----|
| **TR（Task Response）任务回应** | 立场可能摇摆；可能漏题目的一部分；论据展开不够 | 立场贯穿全文；所有题目部分都回应；论据有展开 | **"立场贯穿"** 这件事必须刻意训 |
| **CC（Coherence & Cohesion）连贯衔接** | 段落结构未稳定建立；衔接词可能只会 Firstly/Secondly | 4 段结构清晰；衔接词有变化且自然 | **TEEL 公式自动化** + **限量工具集用熟** |
| **LR（Lexical Resource）词汇** | 中级词够用；可能有口语化词（people→individuals 之类）；偶尔用错 | 有少量 less common 词；错误偶发 | **不靠扩词汇**，靠**精准使用中级词** + **正确的 collocation** |
| **GRA（Grammar）语法** | 简单句为主；可能有 5.5 级硬伤（冠词/可数不可数/run-on）| 复杂句和简单句混合；多数句子无错误 | **修硬伤** + **稳定使用 2-3 种复杂句结构**（不需要 Band 8+ 的 cleft/inversion）|

## 6. 我的成功路径假设

如果 4-5 周内做到下面这些，就能稳定 Band 6.5，有机会 7：

1. **TEEL 写到肌肉记忆**——闭眼能默写 4 段骨架
2. **5 种题型都能 30 秒判出 + 调出对应骨架**
3. **限量工具集（约 25 个衔接词 + 6-8 个句式 + 5 个 opener）用熟**——不假思索就能调
4. **立场表达自动化**——任何 DBV/AD 题都能在 Intro 第三句锁定立场
5. **每个 Body 段写完都本能加 L**——不会漏
6. **40 min 内能写出 270-285 词的完整文章，无 5.5 级硬伤**

这 6 条全做到 = Band 6.5 稳，Band 7 可冲。

## 7. 训练原则（先于具体路径）

| 原则 | 含义 |
|------|------|
| **少而精，反复练** | 限量工具集（25 衔接 + 8 句式 + 5 opener），用到自动化，再扩 |
| **🌟 Write earlier, learn through use**（5/17 加，suzy 反馈驱动）| **不要先全背工具集再写**——孤立记忆 1 周衰减 < 30%。读最少必要 → 立刻写 → 错误驱动复读 → v2 改进。基于 testing effect / 主动检索 |
| **🌟 Tools as cheat sheet, not as scripture** | §4 工具集写作时 keep open，**用到的工具自然记住**，没用到的工具说明对你不重要 |
| **每个范文仿写 2 遍（v1 + v2）** | v1 烂 → 对比找 3 gap → v2 针对修。**第二次永远比第一次进步明显** |
| **脚手架渐进** | 仿写（看着写）→ 骨架填充（看着模板写）→ Cold production（裸写）。**禁止跳级** |
| **每次都给即时反馈** | 写完不放 24 小时，立刻对照范文 + 我给的反馈 |
| **结构 > 词汇** | 同等时间投入，结构训练的提分回报远大于词汇拓展 |
| **错误模式比单错重要** | 同一个错犯 3 次 → 进 error_log → 下次写之前先看一眼 |
