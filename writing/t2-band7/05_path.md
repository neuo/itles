# 05. 5 周训练路径（write-earlier 版）

> **2026-05-17 重写**——按 suzy 的反馈："全部背下来意义不大，需要在实践中反复练习"。
> 旧版本是 "5 天 read/memorize → 然后写"，违反 testing effect。
> 新版本是 **"读最少必要，立刻写，错误驱动复读"**。

---

## 设计原则（新）

| 原则 | 含义 |
|------|------|
| **Write earlier** | Day 2 就开始仿写，不要 5 天后才动笔 |
| **Tools as cheat sheet** | §4 工具集**不需要全背**——写作时 keep open，用到的自然记，没用到的说明不重要 |
| **每个范文仿写 2 遍** | v1 烂 → 对比 → 找 3 个最大 gap → v2 改进。第二次永远比第一次进步明显 |
| **Errors drive reading** | 不预读所有工具集；写完根据错误模式去查对应章节，**比预读高效 10 倍** |
| **Skim → write → study** | 范文先 15 min 看结构，立刻仿写；细节标注**写完后再读**消化才有效 |

## 仿写 2 遍循环（核心机制）

每个范文都按这个 2 天循环走：

### Day A — v1（第 1 次仿写，60-75 min）

```
Step 1 (10 min)  打开 examples/0N_*.md
                 只看：题目 + 范文 + 4 维度评分检查
                 跳过：工具集对应、详细标注、"为什么是 Band 7"
                 目标：拿到 4 段骨架 + 看到 [T][E][Ex][L] 位置
                 ❌ 不要背范文文字

Step 2 (30 min)  自己写同题（限时）
                 工具集 04_toolkit.md keep open 当 cheat sheet
                 写 250+ 词
                 写完不要回看范文先

Step 3 (20-30 min)  对比 + 找 3 个最大 gap
                    对照范文的 "4 维度评分检查" 14 项清单
                    标 ✅/❌
                    挑 3 个最大缺口（不是全部）写到 log/errors.md
                    例如：gap = "Body 2 没 L" / "立场摇摆" / "用了 a lot of"
```

### Day B — v2（针对 3 个 gap 重写同题，70-80 min）

```
Step 1 (15-20 min)  针对 3 个 gap 翻 04_toolkit.md 对应章节
                    Gap "Body 2 没 L" → 翻 03 题型 §1-5 看 L 模板
                    Gap "立场摇摆" → 翻 02_band7_target.md TR 部分
                    Gap "用了 a lot of" → 翻 04_toolkit.md §4 升级词
                    ❌ 不要全读，只读对应 gap

Step 2 (30 min)  同题再写一遍（v2）
                 刻意修 3 个 gap
                 工具集仍 keep open
                 写 250-285 词

Step 3 (20-30 min)  v2 对比范文 + 对比 v1
                    14 项清单再打勾 → 比 v1 多了几项？
                    3 个 gap 修了几个？
                    如果还有 gap 没修——继续记 errors.md，下次再练
```

**为什么 v2 这么重要**：v1 是把骨架装进脑子；v2 是把"我知道但没做到"变成"我下次会注意"。**v2 跳过 = 训练效率减半**。

## 🌟 Daily Paraphrase Drill（每天，独立于 90 min）— 5 min

> **2026-05-18 修订**：原"5-min 微复习"（passive 翻 toolkit）**已替换**——passive 看不解决 suzy 的核心瓶颈"主动语言重组能力（Active Reformulation Flexibility）"。改为 active drill 直接练那块肌肉。
>
> Passive review 仍然可以发生——但在写作时通过 cheat sheet（04_toolkit.md keep open）organic 发生，不需要单独 5 min。

### 5-min Drill 流程

```
Step 1 (1 min)  选 1 句话
                来源：今天范文 / 你刚写的句 / 新闻一句 / 微博一句 任选
                
Step 2 (1 min)  中文写 3 个版本
                （如果中文都难想 → 先在中文层面 unlock 才能进英文）
                
Step 3 (2 min)  英文写 3 个版本
                用不同的 frame（Object / META / Conditional / ...）
                用不同的 WHO / ACTION / WHAT 词
                
Step 4 (1 min)  标"哪个最 Band 7" + 抄进 log/active_phrases.md
                每周末翻一遍清单复习
```

### 为什么这个比"背词"更重要

| 你的瓶颈 | Passive vocab review | Active paraphrase drill |
|---------|---------------------|------------------------|
| 词汇量不够 | ⚠️ 部分有帮助 | ✅ 反复 expose 等效 |
| Frame 选择空间窄 | ❌ 没帮助 | ✅ 直接练 |
| "想得到说不出" | ❌ 没帮助 | ✅ 直接练 |
| 中文 paraphrase 也卡 | ❌ 完全无关 | ✅ 中文层先 unlock |

### 4 周积累目标

- 每天 5 min × 30 天 = **30 句 × 6 版本（中+英）= 180 个 paraphrase 样本**
- 到 6/20 考前，**任何 paraphrase 不卡** —— frame 空间从 1 种扩大到 4-5 种

### Drill 记录

每次结果存 `log/active_phrases.md`。每周末翻一遍找规律（你常卡哪类句、常 unlock 哪种 frame）。

## 训练原则（每周复盘提醒）

1. **每个范文必 v1+v2** — 跳过 v2 = 效率减半
2. **工具集是 cheat sheet 不是经书** — 写时 keep open，写后查 gap
3. **errors.md 才是真宝** — 重复出现的错才是要修的，单次错可以忽略
4. **40 min 是铁律**（W4+）— 哪怕没写完也停笔
5. **不要追求每篇 14 项全 ✅** — 平均提升比单次满分重要

---

## 周复盘格式（每周六 30 min）

打开 log/sessions/ 看本周所有 session，问自己：

1. 本周 v1+v2 几篇完成 ✅/❌
2. 14 项清单平均完成度（v2）比上周进步几项
3. errors.md 哪个错模式毕业了 🎓
4. errors.md 哪个错模式仍反复出现
5. 下周第 1 件要做的事

写下来，存 `log/sessions/YYYY-MM-DD-weekly.md`。
