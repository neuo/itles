# 结构化自检 Routine（3 遍扫）

> **2026-05-20 建立**。suzy 的决定：CDI 机考**没有任何拼写/语法工具**——靠 Grammarly = 练考场上不存在的拐杖。自检能力才是考试的真实技能。
>
> **核心原则**：通读 ≠ 自检。通读抓不到自己的错（大脑自动脑补成对的）。必须**分遍扫，每遍只盯一类**。

---

## 为什么"读一遍"没用

| 你以为 | 实际 |
|--------|------|
| 通读一遍能发现错 | ❌ 大脑把 "ofter" 自动读成 "often"——脑补 |
| 检查 = 再看一次 | ❌ 同样的注意力模式只会重复同样的盲区 |
| 一遍同时查所有 | ❌ 注意力分散，每类都查不深 |

→ **解药**：分遍，每遍**只盯一类错**，用不同的"扫描模式"。

---

## 考试 40 min 时间分配

```
5 min   规划（题型判断 + 立场 + 4 段骨架的 T 句先列出来）
30 min  写作
5 min   自检（3 遍扫）← 本文档
```

**5 min 自检不可省**——这是 12/14 → 13-14/14 的最后一档。

---

## 3 遍扫（5 min）

### 遍 1（2 min）— 逻辑 + 完整性

**扫描模式**：一句一句读，每句读完**停一下**问 2 个问题：
1. "我想说的就是这个意思吗？"（抓 W2-5 逻辑写反——如 "students with skills are difficult" 想说的是 without）
2. "这句主谓宾齐吗？有没有写残？"（抓残句 / run-on）

**重点盯**：
- W2-5 致命错（逻辑反 / 词写错——music 写成 English 那种）
- W2-11 comma splice（两个完整句用逗号粘 → 改分号/破折号/加连词）

### 遍 2（2 min）— 拼写 + 单复数

**扫描模式**：**手指点着，逐词读**——强迫眼睛真的看每个词，不让大脑脑补。

**两件事同时做**：
1. **拼写**：每个词看清楚。特别盯你的高频错词清单（见下）
2. **单复数**：每碰到一个**名词**，停一下问"这里该单数还是复数？"

**重点盯**：
- W2-1 拼写——你的高频错词：
  - `often`（曾错 ofter）
  - `extent`（名词，曾错 extend）
  - `decrease`（曾错 descreases）
  - `digital`（曾错 Digit）
  - `examples`（曾漏 s）
  - `rely`（曾错 relay）
  - `fast food`（两个词，曾连写 Fastfood）
  - `succeed`（动词，曾错 success）
  - `wider`（曾错 wilder）
  - `This`（曾错 The）
- W2-2 单复数——泛指用复数（student→students）；不可数不加 s（information/advice）；主谓一致（they lower 不是 it lowers）

### 遍 3（1 min）— Collocation 怀疑标记

**扫描模式**：快速扫，**不是要"改对"，是要"标出怀疑"**。

任何"我不太确定这个搭配地不地道"的地方——**做个记号**（高亮/下划线/写个问号）。

**重点盯**（你已踩过的 collocation 坑）：
- 介词：harmful **to**（不是 for）/ adapt **to** / put attention **on** / focus particularly **on**
- adj/noun：`be more imaginative`（不是 show more imaginative）/ `show imagination`（noun）
- 动词搭配：`go on to`（不是 get on to）/ `develop people`（不是 foster people）

**遍 3 的真相**：你**没有 native 语感**，自己抓不准 collocation 对错——**没关系**。你只需要"**感觉哪里怪 → 标记**"。标记的地方发我，我确认。久了你的"语感雷达"越来越准。

| 错误类 | 谁负责 | 你自检能做到吗 |
|--------|--------|--------------|
| W2-5 逻辑写反 / 残句 | **你**（遍 1）| ✅ 能——规则明确，回读抓得到 |
| W2-11 comma splice | **你**（遍 1）| ✅ 能——问"两个完整句吗" |
| W2-1 拼写 | **你**（遍 2）| ✅ 能——逐词点读抓得到 |
| W2-2 单复数 | **你**（遍 2）| ✅ 能——名词指认抓得到 |

→ **遍 1-2 是你的主战场**（规则明确，纯靠注意力）。**遍 3 你只标记**。结构层交给 Claude。

## 自检率追踪（每篇仿写后 Claude 记）

每篇仿写，Claude 记两个数：
- **self-caught**：你自检抓到并改对的错
- **Claude-caught**：你漏了、Claude 才抓的错

**自检率 = self-caught / (self-caught + Claude-caught)**

| 时间 | 目标自检率 |
|------|----------|
| 5/21 起步 | ~30% |
| 2 周后（6 月初）| ~70% |
| 考前（6/19）| ~85%（遍 1-2 的错基本自己抓干净）|

→ 自检率上升 = 你**考场上的真实能力**上升（考场没工具，自检率就是你的实际硬伤控制力）。

## 和工具的关系

**练习阶段**：可以偶尔用 LanguageTool / Grammarly **验证**自己的自检（自检完再用工具扫，看漏了什么）——但**先自检，工具只做事后验证**，不能反过来。

**考试**：纯自检，无工具。所以**练习就要练纯自检**。

→ 工具是"事后验证你的自检准不准"，不是"替你检查"。
