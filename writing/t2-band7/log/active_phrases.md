# Active Phrases — 从仿写和 Daily Drill 捞的"我希望我能写出来"清单

> **用途**：把"看得懂但写不出"的中级表达从 passive 池子搬到 active 池子。
> **来源**：① 仿写后从范文捞 1-2 个；② 每日 Paraphrase Drill 选出最 Band 7 的 1 个。
> **使用**：按下面 Ebbinghaus schedule 反复主动调用——这是 anti-forgetting 的核心。

---

## 🌟 Ebbinghaus 复检表（5/18 加，对抗记忆遗忘）

每个新捞的 phrase **从捞到当天起算**：

| 复检日 | 动作 | 通过标准 |
|--------|------|---------|
| **D+0**（当天）| 录入清单，写出原句 context | — |
| **D+1** | Daily Drill 中**主动用**它写 1 句 | 能用即可（哪怕生硬）|
| **D+3** | 再用 1 次（写作或 Drill）| 流畅度提升 |
| **D+7** | 能否**不看清单**写出该 phrase？ | ✅ = 间隔扩大到 D+14；❌ = 回 D+3 |
| **D+14** | 能否在新句子里自由调用？ | ✅ = 间隔扩大到 D+30；❌ = 回 D+7 |
| **D+30** | 自然出现在 essay 里 | ✅ = 🎓 进 active 池，不再追踪 |

→ 这是 Anki 算法的精简版，专为 5 周时间窗设计。

**为什么 D+1/3/7/14/30**：Ebbinghaus 曲线显示遗忘最严重的窗口在前 24h 和前 7 天。复检密度向前压。

## 清单

### 2026-05-18 仿写 Example 01 Body 1（首次捕获）

#### Phrase 1: `may struggle to find stable work`
- 原句 context：替"hard to get a stable job"（L1 直译）
- 为什么 Band 7：`X may struggle to do Y` 是表"X 难做 Y"的 Band 7 标准句型，避免中式 `X is difficult to do Y`
- 复检：D+1 (5/19) [ ] / D+3 (5/21) [ ] / D+7 (5/25) [ ] / D+14 (6/1) [ ] / D+30 (6/17) [ ] 🎓

#### Phrase 2: `become increasingly competitive`
- 原句 context：替"more and more competitive"
- 为什么 Band 7：`become increasingly + adj` 是中级 collocation，比 `more and more` 紧致
- 复检：D+1 (5/19) [ ] / D+3 (5/21) [ ] / D+7 (5/25) [ ] / D+14 (6/1) [ ] / D+30 (6/17) [ ] 🎓

#### Phrase 3: `focus particularly on`
- 原句 context：替"specially focus on"（specially 词义错）
- 为什么 Band 7：`focus particularly on X` 中 particularly 是 mid-level intensifier，比 specifically 自然
- 复检：D+1 (5/19) [ ] / D+3 (5/21) [ ] / D+7 (5/25) [ ] / D+14 (6/1) [ ] / D+30 (6/17) [ ] 🎓

## 每周日复盘（30 min）

打开本清单，逐条核对：
1. 本周捞了几个 phrase？
2. 每个 phrase 的复检打勾到哪个 D？
3. 没打勾的：是没用上还是忘了？没用 = 下周强制用进 essay
4. 用错的：写错 = 还没真懂，回 Paraphrase Drill 重练
5. 毕业了几个 🎓？

**毕业标准**：D+30 通过 = 🎓，从清单顶部移到 §"已毕业 phrase"区。
