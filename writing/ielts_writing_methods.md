## 你的起点和目标

| 项目 | 现状 | 10周后目标 |
|---|---|---|
| Task 1（小作文） | 有guide但没写过 | 20min内写完150+词，结构清晰，6.5分 |
| Task 2（大作文） | 有guide但没写过 | 40min内写完250+词，论点有展开，6.5分 |
| 整体 | 零输出 | 60min内完成T1+T2，稳定6.5 |

**提分路径**：写作不需要最早启动——第3周开始阅读输入，第4周开始限时练习。用"先读后写"策略：没有方法论就盲写只会强化错误，先建立正确的结构认知再动笔。

## 三个核心训练法

> 和口语一样拆成三个递进的训练法：**范文输入法**、**限时仿写法**、**模考法**。前一个是后一个的前置条件。

---

### 训练一：范文输入法（被动输入，45-60分钟/天）

**目标**：建立写作的结构认知——知道Task 1和Task 2各自怎么写、什么结构、什么句式可用。

**什么时候用**：第3周（写作输入周）。只读不写。

#### 完整流程（7天）

```
Day 1：Task 1 基础框架（45min）
  Step 1 · 读 Task 1 Guide — Skill 1-2（30min）
    - Skill 1：四段式结构（改写题目→总览→Body 1→Body 2）
    - Skill 2：同义改写技巧（题目→第1段，不能照抄）
    - 边读边标记：每个Skill的核心句式抄1句
  Step 2 · 用自己的话总结四段结构（15min）
    - 写下每段的功能和大约词数

Day 2：Task 1 数据描述技巧（45min）
  Step 1 · 读 Task 1 Guide — Skill 3-4（30min）
    - Skill 3：Overview写法（概括总体趋势，不写具体数字）
    - Skill 4：常用句式库（上升/下降/波动/稳定/最高/最低）
  Step 2 · 把句式库中的10个核心表达抄下来读3遍（15min）
    - 上升：increased / rose / climbed / grew
    - 下降：decreased / fell / dropped / declined
    - 波动：fluctuated / varied
    - 稳定：remained stable / stayed constant
    - 约数：approximately / roughly / just over / slightly under

Day 3：Task 1 进阶技巧（45min）
  Step 1 · 读 Task 1 Guide — Skill 5-7（30min）
    - Skill 5：时态选择（过去/现在/将来看图表时间轴）
    - Skill 6：数据筛选（选最突出的3-4个数据点，不要面面俱到）
    - Skill 7：约数表达（around / approximately / just under/over）
  Step 2 · 自测：看一个Line Chart，口头说出四段各写什么（15min）

Day 4：Task 1 范文精读（60min）
  Step 1 · 读 Line Chart 和 Bar Chart 范文（30min）
    - 不是泛读——逐句看：这句在哪个段？用了什么句式？
    - 标记好句（至少标5句）
  Step 2 · 读 Pie Chart 和 Table 范文（30min）
    - 同样逐句分析+标记好句
  同时参考：third/雅思小作文万能句式、词汇总结.pdf

Day 5：Task 1 特殊图型 + Task 2 入门（60min）
  Step 1 · 读 Process Diagram 和 Map 范文（20min）
    - 注意：Process用被动语态，Map用方位词
  Step 2 · 读 Task 2 Guide — Skill 1-3（40min）
    - Skill 1：审题（判断题型A/B/C + 划关键词）
    - Skill 2：列提纲（4段结构：开头→Body 1→Body 2→结尾）
    - Skill 3：段落公式（主题句+理由+例子+小结）

Day 6：Task 2 结构深化（60min）
  Step 1 · 读 Task 2 Guide — Skill 4-6（30min）
    - Skill 4：开头段写法（改写题目+表明立场，≤50词）
    - Skill 5：结尾段写法（重申立场，≤30词，不加新观点）
    - Skill 6：衔接词使用（段间+段内）
  Step 2 · 读 Task 2 Guide — Skill 7-8 + Type A范文（30min）
    - Skill 7：语法要点（复杂句比例、常见错误）
    - Skill 8：常见评分陷阱
    - 逐句分析1篇Type A范文
  同时参考：third/雅思精简版写作高频词汇-edited.pdf

Day 7：Task 2 范文 + 总结（60min）
  Step 1 · 读 Type B + Type C 范文（30min）
    - Type A（双边讨论）：两边都写，最后表态
    - Type B（同意/不同意）：明确立场+两段论证
    - Type C（问题+原因+方案）：分析原因+给出建议
  Step 2 · 用自己的话写1页总结笔记（30min）
    - Task 1 的四段结构 + 5个核心数据表达
    - Task 2 的三种题型 + 段落公式
  同时参考：third/雅思大作文十大话题及相关词汇-edited.pdf
```

#### 范文输入法的内部验收

| 检查项 | 达标标准 |
|---|---|
| Task 1 结构 | 说出四段各自的功能和大约词数 |
| Task 1 句式 | 背出上升/下降/波动/稳定/约数各1个表达 |
| Task 2 题型 | 说出三种题型的名称和结构差异 |
| Task 2 段落公式 | 说出段落公式：主题句+理由+例子+小结 |
| 范文分析 | 能指出一篇范文中每段的功能 |

**验收通过 → 进入训练二：限时仿写法**

### 训练二：限时仿写法（主动输出，60分钟/天）

**目标**：从"看懂范文"到"自己能写"——在限定时间内写出结构清晰、词汇准确的文章。

**什么时候用**：第4周（Task 1），第6-7周（Task 2）。

**前置条件**：训练一范文输入法验收通过。

#### Task 1 限时仿写流程（35min/篇 含复盘）

```
Step 1 · 审题+规划（3min）
  - 看图，30秒判断图表类型和时态
  - 写下：总体趋势是什么？（一句话）
  - 列出2-3个最突出的数据特征

Step 2 · 写作（17min）
  - 第1段：改写题目（2句，≤30词）
  - 第2段：总览Overview（2句，概括总体趋势，不写具体数字）
  - 第3段：Body 1（3-4句，描述主要特征+数据）
  - 第4段：Body 2（3-4句，描述次要特征+数据）
  - 目标：≥ 150词

Step 3 · 检查（2min）
  - 快速通读：时态一致？数据准确？拼写错误？

Step 4 · 自评（13min）
  - 对照评分标准逐项打分：
    □ Task Achievement：有Overview吗？覆盖主要特征了吗？
    □ Coherence：四段结构清晰？衔接词使用了吗？
    □ Lexical Resource：有同义改写吗？约数表达用了吗？有没有重复用词？
    □ Grammar：时态/主谓一致/有复杂句吗？
  - 标记最大的1-2个问题，下一篇重点改进
```

#### Task 2 限时仿写流程（55min/篇 含复盘）

```
Step 1 · 审题（2min）
  - 判断题型：Type A / Type B / Type C
  - 划出题目关键词，确保不跑题

Step 2 · 列提纲（3min）
  - 开头段：改写题目+表明立场（1句）
  - Body 1：主要论点+理由+例子
  - Body 2：次要论点/对立面+理由+例子
  - 结尾段：重申立场（1句）

Step 3 · 写作（35min）
  - 开头段：3句，≤50词
  - Body 1：5-6句，≤100词
  - Body 2：5-6句，≤100词
  - 结尾段：2句，≤30词
  - 目标：≥ 250词

Step 4 · 检查（2min）
  - 论点是否回应了题目？每段有没有跑题？
  - 语法快查：时态、主谓一致、there is/are

Step 5 · 自评（13min）
  - 对照评分标准逐项打分：
    □ Task Response：正面回答了问题吗？立场清晰吗？
    □ Coherence：段落逻辑？衔接词？
    □ Lexical Resource：话题词汇够吗？有没有重复用词？
    □ Grammar：复杂句比例？错误密度？
  - 标记最大1-2个问题
```

#### 仿写训练节奏

```
第4周（Task 1 仿写）：
  Day 1：仿写 Line Chart（看范文→合上→自己写→对照）
  Day 2：仿写 Bar Chart
  Day 3：限时20min写1篇 Task 1（Line/Bar任选）→ 自评
  Day 4：仿写 Pie Chart / Table
  Day 5：限时20min写1篇 Task 1（Pie/Table）→ 自评
  Day 6：限时20min写1篇 Task 1（Process/Map）→ 自评
  Day 7：自评本周3篇限时作文 → 总结个人常犯错误

第6周（Task 2 框架+仿写）：
  Day 1-3：读Guide + 分析范文（每天1种题型）
  Day 4-6：每天限时40min写1篇（Type A→B→C各1篇）
  Day 7：三篇横向对比 → 总结个人弱点

第7周（Task 2 话题+限时练）：
  每天选1个话题 → 积累话题词汇 → 限时40min写1篇
  覆盖：Education / Technology / Environment / Government&Health / Crime&Globalisation
  第7天：限时60min连写 T1(20min) + T2(40min)
```

#### 限时仿写法的内部验收

| 检查项 | 达标标准 |
|---|---|
| Task 1 时间 | 20min内写完150+词 |
| Task 1 结构 | 四段完整，有Overview，数据有筛选 |
| Task 2 时间 | 40min内写完250+词 |
| Task 2 结构 | 四段完整，论点回应题目，有理由+例子 |
| 审题速度 | T1审题+规划≤3min，T2审题+列提纲≤5min |
| 自评能力 | 能对照4项标准逐项打分 |

**验收通过 → 进入训练三：模考法**

### 训练三：模考法（评估，120分钟/天 含复盘）

**目标**：完整模拟考试写作环节（60min T1+T2），找到并修补最后薄弱点。

**什么时候用**：第8周。考前阶段定期进行。

**前置条件**：训练二限时仿写法验收通过。

#### 完整流程

```
Step 1 · 模考（60min 严格限时）
  - T1：20min（审题2min + 写作17min + 检查1min）
  - T2：40min（审题+提纲5min + 写作33min + 检查2min）
  - 不允许超时，到时间立刻停笔

Step 2 · 逐项自评（30min）
  T1 评分：
    □ Task Achievement（是否有效回应，有无Overview）
    □ Coherence（段落衔接，信息组织）
    □ Lexical Resource（词汇多样性，同义替换）
    □ Grammar（复杂句，错误密度）
  T2 评分：
    □ Task Response（是否正面回答，立场是否清晰一致）
    □ Coherence（论证逻辑，段落过渡）
    □ Lexical Resource（话题词汇，用词精准度）
    □ Grammar（句型多样性，准确度）

Step 3 · 制作纠错卡（15min）
  - 把反复出现的错误写成卡片
  - 格式：错误类型 | 错误示例 | 正确写法
  - 每次模考前翻一遍纠错卡

Step 4 · 针对性补练（15min）
  - 最弱的1个评分维度，找1篇范文重读
  - 或针对最弱话题重写1段Body
```

#### 模考训练节奏

```
第8周：
  Day 1：模考1（限时60min T1+T2）
  Day 2：自评模考1 + 逐项打分 + 制作纠错卡
  Day 3：模考2（换话题）
  Day 4：自评 + 对比模考1进步
  Day 5：模考3
  Day 6：总结三次模考共性错误 + 纠错卡更新
  Day 7：针对弱点话题限时写1篇
```

#### 模考法的内部验收

| 检查项 | 达标标准 |
|---|---|
| 模考次数 | ≥3次 |
| 时间控制 | T1 20min + T2 40min 不超时 |
| T1 质量 | 150+词，四段完整，数据准确 |
| T2 质量 | 250+词，论点清晰，语法错误≤3处/篇 |
| 纠错卡 | 已制作，反复错误已识别 |

## 三个训练法的依赖关系

```
训练一：范文输入法（第3周，只读不写）
  ↓ 内部验收通过
训练二：限时仿写法
  ├─ Task 1 仿写（第4周）
  └─ Task 2 仿写（第6-7周）
  ↓ 验收通过
训练三：模考法（第8周）
```

## Task 1 六种图表类型速查

| 图表类型 | 时态 | Overview重点 | 常见陷阱 |
|----------|------|-------------|---------|
| Line Chart | 看时间轴 | 总体趋势（上升/下降/波动） | 不要逐年描述，选关键转折点 |
| Bar Chart | 看时间轴 | 最大/最小差异 | 分组对比，不要逐条描述 |
| Pie Chart | 通常无时间 | 最大/最小占比 | 必须写百分比，注意"其他"类 |
| Table | 看时间轴 | 极值+趋势 | 数据多，必须筛选，不能全写 |
| Process | 无时间 | 几个阶段+起终点 | 用被动语态+顺序词 |
| Map | 看是否有时间 | 主要变化+不变的部分 | 用方位词（north/adjacent to） |

## Task 2 三种题型速查

| 题型 | 关键词 | 结构 | 注意事项 |
|------|--------|------|---------|
| Type A 双边讨论 | Discuss both views and give your opinion | 开头→View A→View B→结尾（你的立场） | 两边都要写，不能只写一边 |
| Type B 同意/不同意 | To what extent do you agree or disagree | 开头（立场）→理由1→理由2→结尾 | 立场要贯穿始终，不能两头摇摆 |
| Type C 问题分析 | What are the causes/problems? What solutions? | 开头→原因/问题→解决方案→结尾 | 原因和方案要对应 |
