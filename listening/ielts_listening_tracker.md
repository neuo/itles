## 四、卡点词复习

> - **D+1**：第二天做新题前重听卡点句（2分钟），听出来了填日期
> - **D+7**：一周后统一重听本周卡点（5分钟），听出来了填日期
> - **D+30**：月底回顾，还听不出的改状态为"顽固卡点"，加入每日复习

## 五、审题教训（每次做题后积累）

> 考前翻一遍这个表，比做新题更有用。

| 日期 | 来源 | 教训 | 触发题型 |
|------|------|------|----------|
| 4/7 | S1 Q9 | **reference number / booking code 可能是数字+字母混合**，审题时预设"可能有字母"，不要听到字母就蒙 | 编号题 |
| 4/7 | S1 Q9 | **看空格在句子里的语法位置**："A ___ deposit" 空格需要修饰名词的成分，纯数字 20 不合语法，20% 才通 | 填空题 |
| 4/7 | S1 Q2 | **maximum / up to 对应第一个数字就是答案**，后面的数字是补充说明不要改 | 数字题 |
| 4/7 | S1 Q7 | **听到 actually / oh / sorry 就集中注意力**，后面跟的是纠正后的真正答案 | 数字纠正题 |
| 4/7 | S1 Q5-6 | **多选题不要听到选项关键词就选，要听后面的免费/收费信号**。免费：no extra charge / included / part of the package。收费：extra / costs / pay for / by the hour | 多选题 |
| 4/9 | S1 Q3 | **先说正确答案再说 don't + 干扰项是经典陷阱**。green button（答案）→ don't press red（干扰）。听到颜色/数字后注意后面有没有否定词 | 否定陷阱 |
| 4/9 | S1 Q8-10 | **答案写完前多等半秒，确认修饰词是否完整**。bottle tops 不是 bottle，silver paper 不是 paper，Undersea Worlds 不是 undersea | 填空题 |
| 4/9 | S2 Q13-14 | **匹配题：听到题目关键词后，抓紧跟的动作词配对**。fewer seats = reduced / twice as many = doubled / two large rooms = increased in size | 匹配题 |
| 4/12 | S1 Q4(C5T3) | **审题词汇要认识**：arrange = 安排/办理。"Customer wishes to arrange ___" 问的是付款方式，答案是 credit/cash/loan 这类词 | 填空题 |
| 4/12 | S1 Q4(C5T3) | **第一次听到的答案别改**，除非有纠正信号（sorry/I mean/actually）。听到 credit 就写，后面出现 credit card 是另一个语境 | 填空题 |
| 4/12 | S1 Q6(C5T2) | **"up to / the earliest / maximum" 对应最大值**，不要被中间的数字带走。24/6/48 三个数字，up to 对应 48 | 数字题 |
| 4/14 | S1 Q2(C5T4) | **追问＝答案在后面**。先给模糊范围(after 7pm)，再被追问"best time"时才给精确答案(9-9:30)。第一个信息是背景，第二个才是答案 | 填空题 |
| 4/14 | S1 Q3(C5T4) | **审题词汇：intended = 打算的、计划中的**。intended length of stay = 打算住多久。跟 arrange 一样属于审题没看懂导致抓错信息（抓了 four months 而不是 a year） | 填空题 |
| 4/14 | S1 Q9(C5T4) | **"I'd go up to a hundred" 整句没听到**。£60-80 听到了但后面的 but 转折句漏了。精听时重点听句46的节奏 | 数字题 |
| 4/15 | S1 Q2(C5T4)精听 | **英式时间表达要熟**：half past = 半点，quarter past = 一刻，quarter to = 差一刻。"between 9 and half past" = 9:00-9:30。不是词汇问题，是这套表达模式没练过 | 时间题 |
| 4/16 | S1 Q3(C14T2) | **"started off as ... a few years ago / I'm ... now" 时间陷阱**：题目问 "works as a ___"（现在式），答案永远是 now 后面那个（manager），不是 started off 的（waitress）。和 C5T3S1 Q4 同类陷阱（第一次听到的不一定是答案） | 填空题 |
| 4/16 | S1 Q6(C14T2) | **"ONE WORD AND/OR A NUMBER" 规则**：可以是 1个词、1个数字、或两者组合。"3 weeks" 完全合规。审题时看清规则的 and/or | 审题规则 |
| 4/16 | S1 Q10(C14T2) | **结尾走神 = 漏听签到题**。医疗对话最后一题"do you take any medication" → "I take vitamins"。S1 末尾要保持注意力到底 | 漏听 |
| 4/16 | S2 Q11(C14T2) | **"Before X 发生时" = 只看 X 之前的事**。Q11 问 "Before Queen Elizabeth visited"，正确答案是访问前新建房子（B），不是访问后的火灾（C）。选项里出现的所有动作要按时间排序 | 时间序列陷阱 |
| 4/16 | S2 Q17-20(C14T2) | **方向介词区分**：past the bridge = 走过桥旁边（不过桥）；over/across the bridge = 真的过桥；before/after the bridge = 还没到/已过。"past" ≠ "过" | 地图题方向 |
| 4/16 | S2 Q18(C14T2) | **多步指令听全才能定位**："in the direction of X but turn right before you get there" = 朝 X 方向走 → 没到就右转。听到第一步就跳就会错 | 地图题多步 |
| 4/16 | S2 Q19(C14T2) | **"the other side from X" = X 的对面**。从入口 → 城堡另一边 + 过桥 = 跨越河流到对岸（A）。两个位置参照（对面 + 过桥）要叠加 | 地图题位置 |
| 4/17 | S2 Q15-20(C14T3) | **S2 匹配题 = "具体描述 → 抽象概念"的转译**，所有答案都是 paraphrase。听到 "take back to youth" 要立即跳到 "past times"；听到 "hardly saw anyone→go out" 要跳到 "escape isolation"。词面直译会全军覆没 | S2 匹配题 |
| 4/17 | S2 Q16(C14T3) | **干扰项陷阱：似是而非的"某人的故事"**。Consuela 段里有"encourages them"被误读成"自己解决"，其实那是 Alexei 的答案。听完整段再匹配，别听到关键词就下手 | 匹配题干扰 |
| 4/17 | S2 Q20(C14T3) | **6→7 匹配题至少 1 个选项是纯 distractor**（谁都不对应）。C14T3S2 的 B "rediscover skills" 就是纯干扰。不确定时宁愿漏选也别乱塞 | 匹配题干扰 |
