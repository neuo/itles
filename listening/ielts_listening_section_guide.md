# 雅思听力 Section 专项 + 题型专项训练手册

> 本手册是 `ielts_listening_methods.md`（核心方法）的补充。
> 核心方法教你"怎么练"，本手册教你"每种题怎么做"。

---

## 全局：雅思听力的6大题型

无论出现在哪个Section，雅思听力一共就这6种题型。先整体了解，后面按Section展开具体打法。

```
1. 填空题（Form / Note / Table / Summary / Sentence Completion）
   → 听到什么填什么，注意词数限制和拼写
   → 占比最大，S1几乎全是填空，S4也以填空为主

2. 选择题（Multiple Choice，单选或多选）
   → 单选：A/B/C三选一
   → 多选：5-7个选项选2-3个
   → S2/S3最常出，也是同义替换最密集的题型

3. 匹配题（Matching）
   → 把信息和选项一一配对
   → S3最常出，考"谁说了什么"或"什么对应什么"

4. 地图/平面图题（Map / Plan Labelling）
   → 看图标注位置，听方位词
   → S2最常出，偶尔S1

5. 流程图/图表填空（Flow Chart / Diagram Labelling）
   → 看流程图填缺失步骤
   → S3/S4偶尔出现

6. 简答题（Short Answer）
   → 直接回答问题，1-3个词
   → 不常出，偶尔在S1/S2
```

# Part 1：Section 专项训练

## S1 专项：日常对话，你的保底分

### S1 是什么

两个人的对话，场景是日常生活——租房、报名、预约、咨询、投诉等。语速最慢，词汇最简单，是你必须拿 8-10 分的部分。

### S1 常见场景和你需要听的信息类型

```
场景              需要听什么                     陷阱
─────────────────────────────────────────────────────────
租房咨询     地址、房租、日期、设施            纠正信息（先说错再改）
旅行预订     目的地、价格、出发时间、酒店名    数字干扰（先说一个价格再改）
课程报名     课程名、时间、费用、导师名        拼写生僻人名/地名
会员注册     姓名、地址、电话、邮箱、会员类型  字母听写（邮箱地址）
医疗预约     症状、日期、医生名、药名          专有名词拼写
图书馆       借书、还书日期、罚款、卡号        日期格式
银行/保险    账户类型、金额、条件              数字（大额数字容易听混）
投诉/报修    问题描述、地址、参考编号          地址拼写（街道名）
```

### S1 最核心的技能：个人信息听写

S1 有大量的名字、地址、电话号码、邮编需要你准确听写。这些是纯拼写题，不涉及理解——但拼错就是0分。

#### 字母听写：易混音辨析

```
机考特别重要：你要在键盘上快速准确地打出来

最易混的字母对：
  A /eɪ/ vs E /iː/ vs I /aɪ/
  → 听到 /eɪ/ = A，听到 /iː/ = E，听到 /aɪ/ = I

  M /em/ vs N /en/
  → M 嘴巴闭合鼻音，N 舌头顶上颚

  B /biː/ vs D /diː/ vs P /piː/ vs T /tiː/
  → B 双唇爆破，D 舌尖爆破，P 送气双唇，T 送气舌尖

  G /dʒiː/ vs J /dʒeɪ/
  → G 元音是 /iː/，J 元音是 /eɪ/——区别在元音

  S /es/ vs F /ef/ vs X /eks/
  → S 以 /s/ 开头，F 以 /e/ 开头，X 以 /e/ 开头但结尾 /ks/

练习方法：
1. 用剑桥真题S1中所有涉及拼写的题，把音频中拼字母的片段单独截出来
2. 反复听，边听边在键盘上打
3. 特别练上面列出的易混对
4. 目标：听到字母后0.5秒内能敲对键
```

#### 数字听写：高频数字陷阱

```
容易混的数字：
  13 /θɜːˈtiːn/ vs 30 /ˈθɜːti/
  14 /fɔːˈtiːn/ vs 40 /ˈfɔːti/
  15 /fɪfˈtiːn/ vs 50 /ˈfɪfti/
  → 区别在重音位置：-teen 重音在后，-ty 重音在前

  0 的说法：
  zero（数学/科学）
  oh /əʊ/（电话号码/房间号）
  nought（英式，不常用）
  nil（比分）
  → S1 中电话号码里的 0 通常说 oh

  电话号码听写规则：
  - 通常两个两个念：oh-seven, eight-nine
  - 两个相同数字连续：double seven = 77
  - 三个相同数字连续：triple five = 555
  - 机考时直接打数字，不用拼写

  日期格式：
  - 音频说 "the fifteenth of March" = 15 March 或 15th March
  - 音频说 "March fifteen" = March 15
  - 机考填空只需要打数字+月份，不用纠结格式

  金额：
  - £4.50 读作 "four pounds fifty" 或 "four fifty"
  - $1,500 读作 "one thousand five hundred" 或 "fifteen hundred"
  - 注意千位和百位的混淆：five hundred (500) vs five thousand (5000)

练习方法：
1. 每天花5分钟用真题音频练数字听写
2. 重点练 -teen vs -ty 的辨析
3. 练习电话号码的快速打字
```

#### 地址听写：常见街道/地名格式

```
英国地址格式：
  [门牌号] [街道名] [街道类型]
  例：27 Bank Road / 15 Rosemead Avenue / 3 Whitfield Cottage

常见街道类型（需要拼对）：
  Road / Street / Avenue / Lane / Drive / Close
  Crescent / Terrace / Way / Court / Place / Gardens

常见地名后缀：
  -bury / -ham / -ford / -ley / -field / -ton / -bridge
  例：Canterbury / Birmingham / Oxford / Bradley / Sheffield

邮编格式（英国）：
  两段式：AB12 3CD
  音频通常逐字母+数字念

练习方法：
1. 从剑桥真题S1中收集所有地址拼写题
2. 不看答案，重新听写
3. 把常见街道类型和地名后缀背下来
```

### S1 专项训练计划

```
第1周：
  Day 1-2：数字听写专项（-teen/-ty、电话号码、金额）——每天15分钟
  Day 3-4：字母拼写专项（人名地名邮箱地址）——每天15分钟
  Day 5-7：完整S1做题（做题法全流程），重点验证数字和拼写是否改善

第2周：
  Day 1-3：审题速度训练——计时审题S1，目标 ≤ 30秒
  Day 4-7：每天1套S1做题+复盘，目标正确率 ≥ 8/10

第3-4周：
  S1减少到隔天1套（维持），转为S2为主
```

## S2 专项：独白介绍，你的攻坚重点

### S2 是什么

一个人的独白，场景是公共信息——导游介绍景点、工作人员介绍设施、活动组织者说明安排。语速比S1快，信息密度高，没有对话节奏帮你喘息。

### S2 为什么难

```
1. 独白连续说，没有停顿换人的"喘息点"
2. 一段话里塞多个答案，间隔很短
3. 大量使用同义替换（S2是同义替换最密集的Section）
4. 地图题/平面图题主要出在S2（方位词是全新的挑战）
```

### S2 常见场景

```
场景                   特点                          常见题型
───────────────────────────────────────────────────────────
景点/博物馆介绍     方位描述多，按参观路线展开      地图题 + 选择题
社区设施介绍       功能区域说明，开放时间            地图题 + 填空
活动/节日说明      时间安排、注意事项                选择题 + 填空
课程/培训介绍      课程内容、适合人群、费用          选择题 + 匹配
健康/安全须知      规则、步骤、建议                  填空 + 选择
旅游行程说明      每天安排、注意事项                 填空 + 选择
```

### S2 关键技能：地图/平面图题

地图题是很多人的噩梦，但它其实是最有规律可循的题型。

#### 方位词速查表（必须背熟）

```
基础方位：
  on the left / on the right
  at the top / at the bottom
  in the middle / in the centre
  at the front / at the back

相对位置：
  next to = beside = adjacent to       "紧挨着"
  opposite = across from = facing       "正对面"
  between A and B                       "在A和B之间"
  behind / in front of                  "在后面 / 在前面"
  near / close to / not far from        "附近"
  at the corner / on the corner         "在角落"
  at the end of                         "在尽头"

方向移动：
  go straight / go along / continue     "直走"
  turn left / turn right                "左转 / 右转"
  go past = walk past = pass            "走过（不进去）"
  go through                            "穿过"
  cross (the road)                      "过（马路）"
  at the junction / at the intersection "在交叉路口"
  take the first/second turning         "在第一个/第二个转弯处转"

楼层/区域：
  ground floor / first floor / second floor
  wing (east wing / west wing)          "侧楼"
  entrance / exit / main door           "入口/出口/正门"
  corridor / hallway                    "走廊"
  staircase / lift (elevator)           "楼梯/电梯"
```

#### 地图题做题步骤（机考版）

```
Step 1：看图建立方向感（音频前，30秒）

  a. 找到"你在哪"——通常图上标了 entrance 或 "You are here"
  b. 确定上下左右——图上是否标了 North？如果没标，默认上北下南
  c. 快速记住已标注的地标（已有名字的建筑/道路），它们是定位锚点
  d. 数一数要填几个空，大致估计音频会按什么顺序走

Step 2：听的时候跟着"走"

  a. 音频会按一条路线依次介绍，从入口开始
  b. 每听到一个方位词（left/right/opposite/next to），
     在脑中（或用手指在屏幕上）跟着走
  c. 答案通常在说完方位词之后立刻出现
  d. 机考点击/拖拽选择对应标签——确认后立刻看下一个空

Step 3：常见陷阱

  a. "on your left"——是说话人的左边，不是你看图时的左边
     → 要从说话人的视角（面朝行走方向）来判断左右
  b. 音频可能跳过某些区域不按你预期的顺序——
     → 听到新地标名就立刻在图上定位
  c. 多余信息——音频提到一个地方但不是答案（只是路过）
     → "go past the café" = 走过咖啡厅，café不是答案

练习方法：
1. 从剑桥真题中找出所有S2地图题（约每2-3套题出1次）
2. 先不做题，只听音频，在图上用手指跟着"走"
3. 再重新听一遍，这次做题
4. 做完后在原文中标出所有方位词
5. 背不熟的方位词加入复习清单
```

### S2 选择题技巧

```
S2的选择题是同义替换地狱——三个选项通常在音频中都会被提到，
但只有一个是正确答案。

做题步骤：

1. 审题时标记每个选项的关键词
   → 知道要听什么

2. 听的时候不要听到A选项的词就选A
   → S2最常见的套路：先提到A，再否定A，最后说B才是答案

3. 等整个题的信息说完再做选择
   → 听到 but / however / actually 等转折词时特别注意

4. 多选题（选2或3个）的特殊策略：
   → 审题时5-7个选项都过一遍，预判哪些最可能
   → 听到确认一个就立刻选上（机考可以点击），继续听下一个
   → 注意题目是否说了 "TWO answers" 还是 "THREE answers"

常见干扰套路：
  套路1：先肯定A，再用but否定 → 答案不是A
  套路2：提到B，说"曾经是这样"（used to / in the past）→ 答案不是B
  套路3：提到C，说"有人这样认为但其实不是"→ 答案不是C
  套路4：用不同的词说了和D一样的意思 → 答案是D的同义替换
```

### S2 专项训练计划

```
第2-3周（和S1穿插进行）：
  Day 1-3：每天做1套S2 + 精听全段
           第一套不用技巧纯测 → 第二套开始用审题预判
  Day 4-5：地图题专项——收集3-5套地图题连续做
           每套做完后在原文中标注所有方位词
  Day 6-7：选择题专项——收集3-5套选择题
           做完后分析每题的干扰项套路

第4周：
  每天1套S2（限时），要求正确率 ≥ 7/10
  把所有S2的同义替换整理到synonym bank
```

## S3 专项：学术讨论，听懂"谁同意谁"

### S3 是什么

2-4个人的学术讨论——学生讨论作业、学生和导师讨论研究方案、小组讨论项目选题。有多个说话人，需要区分每个人的观点。

### S3 为什么难

```
1. 说话人切换快，需要分辨"谁说了什么"
2. 观点可能变化——一个人先同意后又反对
3. 匹配题需要边听边在多个选项间跳转
4. 学术词汇比S1/S2多
5. 语速接近正常英语对话
```

### S3 常见场景

```
场景                     核心考点
───────────────────────────────────────────
学生讨论作业/项目      每人负责什么、意见分歧、最终决定
学生和导师讨论        导师建议 vs 学生想法、修改方向
课程选择/评价         各门课的优缺点、推荐理由
研究方法讨论          不同方法的对比、选择哪种
实习/工作经验分享      经历、感受、建议
```

### S3 关键技能：匹配题

匹配题是S3最常出也最难的题型。通常给你5-7个问题和A-G个选项，要你把每个问题和正确选项配对。

```
匹配题做题步骤：

Step 1：审题时分清"两轴"
  → 一轴是问题（通常是人名或主题）
  → 另一轴是选项（通常是观点或评价）
  → 例：A说了什么？B说了什么？C说了什么？
       选项：i.同意方案 ii.反对方案 iii.提出替代 iv.没有意见

Step 2：预判谁先说话
  → 如果题目按 A→B→C 排列，音频通常也按这个顺序
  → 但不绝对！有时B会突然插话

Step 3：听的时候用草稿区记笔记
  → 机考可以在屏幕草稿区写
  → 格式：A-agree / B-disagree / C-suggest new
  → 简写即可，不用完整句子

Step 4：注意态度变化
  → S3最大的坑：一个人先说"I think X is good"（你以为是同意）
     然后说"but actually I've changed my mind"（其实是反对）
  → 永远听完整段再确认

常见态度词：
  同意：I agree / that's a good point / exactly / right / I think so too
  反对：I'm not sure about that / I disagree / I don't think / well, actually
  犹豫：maybe / perhaps / I'm not convinced / it depends
  让步：you have a point but / I see what you mean however
  建议：why don't we / how about / I suggest / what if we
```

### S3 多选题技巧

```
S3的多选题通常是"选2个"或"选3个"——从5-7个选项中选。

策略：
1. 审题时标记每个选项的关键词
2. 听的时候用排除法——音频说到某个选项但否定了 → 划掉
3. 被肯定的选项立刻记下来
4. 注意：正确选项在音频中出现的顺序可能和选项列表不同
5. 如果最后不确定，选那个音频中正面评价最多的
```

### S3 专项训练计划

```
第3周末首次接触（在周测中做S3，记录基线分），第6周正式攻坚：

  Week 3周末：做1套S3记基线分，不精听，看原文理解即可
  Week 4-5：偶尔做1套S3保持接触，不做专项训练
  Week 6（正式攻坚）：
  Day 1-2：精听1-2段S3（用精听法全流程），适应多人讨论节奏
  Day 3-4：匹配题专项——收集3-4套匹配题连续练
           做完后在原文中标注每个说话人的关键句
  Day 5-7：多选题专项+完整S3做题+精听错题段落
```

## S4 专项：学术讲座，抓住关键线索就够

### S4 是什么

一个人的学术讲座/演讲，话题涉及各种学科——生物、历史、社会学、环境科学等。没有对话，一口气说到底，中间没有停顿。

### S4 为什么难

```
1. 纯独白，无停顿，一口气30题（实际10题但信息量巨大）
2. 学术词汇多——但答案通常不是难词
3. 信息密度最高的Section
4. 没有检查时间——S4结束后考试就结束了（机考只有约2分钟检查全卷）
```

### S4 的一个关键认知：答案通常是简单词

```
很多人怕S4是因为听到一堆学术词就慌了。但其实：

音频中的难词：photosynthesis, biodiversity, urbanisation
→ 这些通常不是答案，只是背景描述

答案通常是：water, cost, birds, safety, plastic, children
→ 日常词汇，你一定认识

所以S4的策略不是"听懂每个学术词"，而是：
1. 通过审题知道答案大概是什么类型的词
2. 在学术词汇的"包围"中找到那个简单的答案词
3. 信号词 + 答案词的位置感比词汇量更重要
```

### S4 以填空题为主：句子填空 / 笔记填空 / 摘要填空

```
S4填空题做题步骤：

Step 1：审题时预判答案词性（极其重要）
  看填空前后的语法结构：

  "The main ___ of the research was..."
  → 空格后是of，前面是The main → 答案是名词（aim / focus / purpose）

  "Researchers found that the population ___ significantly"
  → 空格后是significantly → 答案是动词过去式（increased / decreased / changed）

  "This approach is particularly ___ for small businesses"
  → 空格前是is particularly → 答案是形容词（useful / effective / suitable）

Step 2：注意词数限制
  题目说 "NO MORE THAN TWO WORDS" → 最多2个词
  题目说 "NO MORE THAN TWO WORDS AND/OR A NUMBER" → 可以2词+1数字
  题目说 "ONE WORD ONLY" → 严格1个词

  常见错误：
  ✗ "bus stop" 写成 "the bus stop"（多了the，超词数）
  ✗ "7 days" 写成 "seven days"（数字可以用阿拉伯数字，更安全）

Step 3：答案出现的位置规律
  S4的填空题通常按音频顺序出（题号和音频顺序一致）
  每道题之间大约有20-30秒的音频间隔
  如果超过30秒还没听到答案线索——可能已经过了，果断放弃看下一题

Step 4：用前后文交叉验证
  填完之后快速检查：这个词放进去语法对吗？意思通吗？
  例：空格需要名词但你填了形容词 → 一定是错的
```

### S4 笔记式题目的结构线索

```
S4经常给一个笔记大纲，让你填空。大纲本身就是"解题地图"：

原题示例：
  History of chocolate
  - Origins: first used by the ___ people
  - Brought to Europe in the ___ century
  - Modern production
    • Main ingredient grown in ___
    • Process involves ___ and roasting

利用大纲结构：
1. 大纲的标题/小标题 = 音频的段落分界
   → 听到 "let's now look at modern production" = 进入第三段
2. 每个 bullet point 的顺序 = 音频的出题顺序
3. 已知信息 = 定位锚点
   → "brought to Europe" 出现时 → 下一个答案就是 "century"

这比盲听高效得多——你知道音频结构，就知道答案什么时候来。
```

### S4 专项训练计划

```
第6周入门，第7-8周攻坚：

  Week 6：做2-3套S4（只做题记基线分，不精听）
          做完看原文标答案位置和信号词，熟悉S4的"答案通常是简单词"规律

  Week 7：
  Day 1-2：填空预判专项——拿5套S4题目，不放音频
           只练"看填空→预判词性和答案类型"，计时2分钟
  Day 3-5：完整做题+精听（挑每套最难的1段精听，不用全精听）
  Day 6-7：完整套题模考，看S4得分趋势

  Week 8：S4纳入完整套题模考，重点看得分是否稳定
  Week 9-10：只做完整套题，S4不再单独训练
```

# Part 2：题型专项训练

> 以下按题型展开，补充上面各Section未覆盖的技巧细节。

---

## 题型1：填空题（所有Section都会出）

### 通用规则

```
1. 答案一定来自音频原词（不用自己改词）
2. 注意词数限制——超出直接0分
3. 大小写：机考通常不区分，但人名/地名首字母大写更安全
4. 拼写：必须100%正确，没有"差不多"——错一个字母就是0分
5. 答案大多是名词，偶尔是形容词或数字
```

### 填空题三步法

```
Step 1：看空格前后，预判答案类型
  名词？动词？形容词？数字？
  单数还是复数？（看前面是 a 还是 many/several）

Step 2：听到空格前的关键词（或其同义替换）时集中注意力
  答案通常紧跟在关键词后面

Step 3：听到答案立刻打字，然后眼睛跳到下一题
  不要回头检查拼写——考试最后2分钟统一检查
```

### 表格填空特殊技巧

```
表格填空题（Table Completion）：

表格有行和列，答案分散在不同格子里。

关键：搞清楚音频是按行走还是按列走
  → 大多数情况按行走（一行讲完再讲下一行）
  → 偶尔按列走（所有行的第一列说完，再说第二列）

做题时：
1. 先看表格结构，确定行/列分别代表什么
2. 用已填的内容作为定位锚点
3. 听到某行/列的锚点词时，该行/列的空格答案即将出现
```

---

## 题型2：选择题（S2/S3为主）

### 单选题（A/B/C三选一）

```
审题三步：
1. 读题干，划关键词
2. 读三个选项，标出每个选项的核心区别
3. 预判：题目问的是事实？原因？观点？建议？

做题规则：
- 三个选项在音频中通常都会被提到
- 正确答案往往不是第一个被提到的
- 听到 but/however/actually 后面的内容最重要
- 如果两个选项在音频中被明确否定 → 第三个就是答案（排除法）

常见选项陷阱：
  选项A的原词出现了但被否定 → A是干扰项
  选项B的原词出现了但说的是"过去的情况" → B是干扰项
  选项C的意思出现了但用了不同的词 → C是答案（同义替换）
```

### 多选题（选2-3个）

```
比单选难，因为需要同时追踪更多信息。

策略：
1. 审题时把所有选项过一遍，心里排个"可能性排序"
2. 听的时候确认一个就立刻选上，不要等全部听完
3. 被否定的选项立刻排除（在草稿上划掉）
4. 如果听完还缺1个选项不确定 → 选没被提到的那个
   （多选题中被否定的选项通常会被明确提到，没提到的反而可能是对的）
```

---

## 题型3：匹配题（S3为主）

```
审题：
1. 搞清楚匹配的两个维度是什么
   例：人名 ←→ 观点 / 研究方法 ←→ 优缺点
2. 选项比问题多——有些选项是多余的（干扰）
3. 每个选项可能只用一次，也可能重复使用（看题目说明）

做题：
1. 按音频顺序走——第一个问题的答案先出现
2. 听到某个人说话时，立刻关注他的观点/态度
3. 不确定就先跳过，等后面的线索反推

关键态度词复习（匹配题常考"态度"）：
  正面：effective / beneficial / worthwhile / impressive / valuable
  负面：problematic / limited / unreliable / insufficient / flawed
  中性：acceptable / reasonable / mixed / debatable
```

---

## 题型4：流程图 / 图表填空（S3/S4偶尔出）

```
流程图有箭头指示顺序，答案按箭头方向依次出现。

审题：
1. 顺着箭头快速读一遍流程
2. 看每个空格的前后文，预判答案类型
3. 注意分支——有些流程有"如果是/如果否"的分叉

做题：
1. 答案严格按流程顺序出现——错过一个不要回头
2. 因果关系词是线索：
   leads to / results in / causes / then / next / after that / finally
3. 注意过程动词：
   mix / heat / pour / filter / dry / measure / weigh / add / remove / test
```

# Part 4：遗漏检查清单

以下是你在练习中需要持续注意的细节，如果不专门练很容易一直丢分：

```
□ 单复数：答案是 student 还是 students？听前面的限定词（a/the/many/some）
□ 时态：题目问"将要做什么"→ 答案可能包含 will/going to
□ 连字符词：答案如 well-known / part-time 算1个词还是2个？→ 看题目的词数限制
□ 缩写：Dr / Mr / Mrs / St (Saint/Street) 在填空题中可以用
□ 答案超出词数怎么办：砍掉不必要的冠词/介词
   例：限制1词，答案是 the library → 填 library
□ 数字 vs 文字：$ 5 million → 填 5 million（混合格式最安全）
□ 首字母大写：人名、地名、月份、星期必须大写
   → Monday 不能写 monday
   → 其他词机考一般不严格要求大写，但统一更安全
```

# Part 5：答案格式规范（机考必背）

> 机考直接打字，格式错 = 0分。以下是所有填空题可能涉及的格式要求。

## 日期格式

```
音频说的                    可以填的（都对）          不能填的
─────────────────────────────────────────────────────────────
the fifteenth of March     15 March / 15th March     March the fifteenth
March fifteen              March 15 / March 15th     15/3（不标准）
the third of July          3 July / 3rd July / July 3

规则：
- 日+月 或 月+日 都可以
- 用数字（15）比拼写（fifteen）更安全——拼写不出错
- 可以加 st/nd/rd/th（1st, 2nd, 3rd, 4th）也可以不加
- 不要用 15/03 这种纯数字格式
- 月份必须拼写完整（March，不能写 Mar）
```

## 时间格式

```
音频说的                可以填的              注意
────────────────────────────────────────────────
half past two          2:30 / 2.30           不写 2:30pm 除非题目要求
quarter to nine        8:45                   不是 9:45！
ten past seven         7:10
nine o'clock           9:00 / 9 o'clock

规则：
- 用数字格式最安全：7:30 / 9:15 / 10:45
- am/pm 通常不用写，除非题目或上下文要求区分
- half past = :30 / quarter past = :15 / quarter to = :45
- "to"的陷阱：quarter to nine = 8:45（不是9:45）
```

## 金额格式

```
音频说的                       可以填的               注意
──────────────────────────────────────────────────────────
four pounds fifty              £4.50 / 4.50           看题目是否已有£符号
thirty-five dollars            $35 / 35               同上
one thousand five hundred      1,500 / 1500           千位逗号可有可无
two and a half million         2.5 million            不要写 2,500,000

规则：
- 如果题目前面已经印了 £ 或 $，你只填数字
- 如果没有印，你要自己加货币符号
- 小数：£4.50 不要写成 £4.5（虽然意思一样，完整格式更安全）
```

## 电话号码格式

```
音频说的                      填法
──────────────────────────────────────────
oh-seven-seven-four...       0774...（用数字）
double six                   66
triple oh                    000
oh-one-six-one              0161

规则：
- 直接打数字，不用空格也行：07745628391
- 也可以按段打：0774 562 8391
- "oh" = 0 / "double" = 两个相同数字 / "triple" = 三个
```

## 地址格式

```
音频说的                       填法
──────────────────────────────────────────────
twenty-seven Bank Road        27 Bank Road
Flat B, fifteen High Street   Flat B, 15 High Street

规则：
- 门牌号用数字（27 不用 twenty-seven）
- 街道名首字母大写（Bank Road 不是 bank road）
- Flat/Apartment 后面的字母大写（Flat B）
- 邮编按音频格式照写：CB2 4RT
```

# Part 6：简答题做题指南

> 简答题在剑14-18中出现频率在增加，不能忽略。

```
简答题 = 直接回答一个问题，用1-3个词

和填空题的区别：
- 填空题：把答案嵌入一个句子
- 简答题：直接回答问题（没有上下文帮你预判）

题目示例：
  "What TWO changes has the museum made recently?"
  → 答案1：extended opening hours
  → 答案2：new café

做题步骤：
1. 读题时注意问的是 What/Where/When/How many/Who
   → What = 名词/事物
   → Where = 地点
   → When = 时间
   → How many = 数字
   → Who = 人名/角色

2. 注意 TWO/THREE 这种数字要求——确保你写够了

3. 答案来自音频原词，不需要自己改写

4. 词数限制和填空题一样严格
```

# Part 7：连读弱读训练方法

> methods 手册列了连读弱读的例子但没教怎么练。这里补上。

## 为什么要专门练连读弱读

```
你已经认识 "want to" 这两个词，但音频说 /wɒnə/ 你就听不出。
这不是词汇量问题——是"音频里的发音"和"你脑子里的发音"不匹配。
解决方法：让你脑子里的发音更新为真实发音。
```

## 连读弱读专项训练法（每天10分钟）

```
Step 1：选材料（2分钟）
  从你精听时标🔴的句子中，挑出5句含连读/弱读的

Step 2：慢速跟读（3分钟）
  放0.75x倍速（大多数播放器支持），跟着读
  每句读3遍，嘴巴模仿音频的连接方式
  重点感受哪些音被"吃掉"了、哪些词"粘"在了一起

Step 3：正常速度跟读（3分钟）
  回到1.0x，跟着读
  如果跟不上，说明你嘴巴还没习惯——继续慢速多练几遍

Step 4：盲听验证（2分钟）
  不看原文，只听——现在能听出来了吗？
  能 → 这句过关
  不能 → 明天继续练这句

关键：连读弱读的突破靠"嘴巴记忆"——你自己能说出来，就一定能听出来。
所以跟读比听更重要。
```

## 高频连读弱读模式（背下来直接提升识别率）

```
功能词弱读（这些词在句中几乎听不见）：
  a → /ə/               I have a cat → /aɪ hæv ə kæt/
  the → /ðə/            the book → /ðə bʊk/
  of → /əv/ 或 /ə/      a lot of people → /ə lɒt ə piːpl/
  to → /tə/             I want to go → /aɪ wɒnə gəʊ/
  for → /fə/            for example → /fər ɪgzɑːmpl/
  and → /ən/ 或 /n/      fish and chips → /fɪʃ n tʃɪps/
  can → /kən/           I can do it → /aɪ kən duː ɪt/
  have → /əv/           should have → /ʃʊdəv/
  are → /ə/             they are → /ðeə/
  was → /wəz/           it was good → /ɪt wəz gʊd/
  been → /bɪn/          has been → /həz bɪn/
  him → /ɪm/            tell him → /tel ɪm/
  her → /ə/ 或 /ɜː/     give her → /gɪv ə/
  them → /ðəm/ 或 /əm/   tell them → /tel əm/

高频连读组合：
  want to → wanna        /wɒnə/
  going to → gonna       /gənə/
  got to → gotta         /gɒtə/
  kind of → kinda        /kaɪndə/
  sort of → sorta        /sɔːtə/
  lots of → lotsa        /lɒtsə/
  out of → outta         /aʊtə/
  don't know → dunno     /dʌnəʊ/
  give me → gimme        /gɪmi/
  let me → lemme         /lemi/

爆破音省略（t/d在特定位置消失）：
  last time → /lɑːs taɪm/       t消失
  next day → /neks deɪ/          t消失
  must be → /mʌs bi/             t消失
  old man → /əʊl mæn/            d消失
  cold night → /kəʊl naɪt/       d消失
  hand bag → /hæm bæg/           d变m
  good boy → /gʊb bɔɪ/           d变b
```

# Part 9：注意力和集中力训练

> S2跟不上一个重要原因是注意力断了。以下是实用的注意力训练方法。

## 为什么注意力会断

```
听力考试30分钟连续听，大脑很容易在以下时刻"掉线"：
1. 刚做完一题，松了口气 → 下一题开头漏听了
2. 遇到一个听不懂的词，大脑开始"想这个词什么意思" → 后面3-4秒漏听
3. S2独白太长，中间没有换人的节奏变化 → 大脑自动"降档"
4. 写上一个答案时注意力从"听"转到"写" → 回不来了
```

## 注意力专项训练

### 训练1：关键词狙击（每天5分钟）

```
目的：训练"在持续音频流中捕捉特定词"的能力

做法：
1. 选一段3分钟的音频（BBC News / TED 都可以，不一定要真题）
2. 开始前给自己定一个"目标词"，比如 "and"
3. 播放音频，每听到 "and" 就敲一下桌子
4. 统计你敲了几次 → 和实际次数对比
5. 第二天换一个目标词（the / but / so / because）

进阶：
- 同时追踪两个词（ and + but）
- 用真题音频做，目标词改为信号词（however / actually / but）
```

### 训练2：强制不回头（每周2次）

```
目的：训练"错过一题不影响下一题"的心理韧性

做法：
1. 做一套新的S2
2. 规则：每道题只有一次机会——听到就写，没听到就空着
3. 不允许纠结、不允许回想、不允许暂停
4. 做完后统计：主动放弃了几题？后面的题因为放弃前面的而做对了几题？

道理：
- 纠结一道题 = 连带丢2-3题
- 学会"止损"是听力考试最重要的心理技能
- 这个训练练的不是听力，而是心态
```

### 训练3：持续听力耐力（每周1次）

```
目的：训练连续听30分钟不走神的耐力

做法：
1. 用完整的4个Section做一次模考（40分钟）
2. 在草稿纸上画一条时间线
3. 每次发现自己走神了，在时间线上标记一个X
4. 做完后看：走神主要发生在哪个Section？第几分钟？

常见模式：
- S1→S2切换时走神 → 需要练"切换警觉"
- S2中间走神 → 需要更多S2独白精听来适应
- S3后半段走神 → 注意力极限约15-20分钟，需要练持久力
- S4开头走神 → 可能是"放弃心态"——觉得S4太难就不认真听了

改善：
- 如果极限在15分钟 → 每天做15分钟持续听力，逐周增加5分钟
- 考前能坚持35分钟不走神就够了
```

# Part 10：考试应急策略

> 考试中什么情况都可能发生。提前准备好应急方案，不慌。

## 应急情况1：某道题完全没听到

```
处理方式：
1. 不要回想——立刻看下一题
2. 在该题旁边点"flag for review"标记
3. 考试最后2分钟回来处理：
   - 填空题：根据语法和上下文猜一个合理的词
   - 选择题：排除明显不对的，从剩下的里选
   - 千万不要留空——猜错不扣分，空着一定0分
```

## 应急情况2：连续2-3题没跟上（掉队了）

```
处理方式：
1. 深呼吸一次（1秒钟）
2. 看当前最近的题号——找到你应该在做的那道题
3. 看那道题的关键词——重新"装雷达"
4. 从这道题开始跟——前面掉的题全部放弃，最后再处理
5. 绝不能在掉队的状态下试图"往回听"——越追越慌
```

## 应急情况3：拼写不确定

```
处理方式：
1. 先打你觉得最可能的拼写
2. 点"flag for review"标记
3. 最后2分钟回来时：
   - 如果想到正确拼写 → 改
   - 如果还是不确定 → 保留原来的，不要改成更不确定的
4. 常见纠结：accommodation (双c双m) / environment (有n) / Wednesday (有d)
```

## 应急情况4：地图题完全看不懂方向

```
处理方式：
1. 找 entrance / "You are here" —— 这是起点
2. 只关注"起点附近"的第一个答案
3. 听到第一个方位词时在图上定位 → 从这里开始跟
4. 如果还是跟不上 → 听到建筑/设施名就在图上找最近的空格填
5. 地图题通常5题，拿到2-3题就可以了
```

## 应急情况5：S4开头就懵了

```
处理方式：
1. S4一般前2题最简单 → 集中精力先拿这2题
2. 中间实在听不懂也不放弃 → 听信号词（first/also/finally）→ 可能蒙到
3. 最后2题有时反而因为是总结部分会变简单
4. 填空题凭语法猜：看空格需要名词/动词/形容词，填一个合理的
5. S4拿4/10就是胜利——不要追求完美
```

## 考试最后2分钟检查优先级

```
倒计时开始后，按以下顺序检查：

第一优先（30秒）：检查所有标记了flag的题
  → 能确认就确认，不能确认就凭直觉选/填

第二优先（30秒）：检查所有填空题的拼写
  → 快速扫一遍，明显的拼写错误改掉
  → 特别注意：accommodation / environment / Wednesday / library

第三优先（30秒）：检查大小写和格式
  → 人名/地名首字母大写
  → 日期格式正确
  → 数字没有打多/打少一个0

第四优先（30秒）：确认没有漏题
  → 快速扫一遍所有题号，确认每题都有答案
  → 空着的立刻填一个——任何答案都比空着好
```
