> **目标**：5.5–6 (≈22/40) → **6.5+ (26/40)**。家测过关线 **27–28**（考场通常 -1~-2）。

> **性质**：练的是**考试执行系统**，不是听力本身。考完即弃，不带进口语训练。

## 2. P4 双遍法（核心操作，每个 P4 ≈ 30 分钟）

> 你的 A/B 实验已出结果：抓词模式 6 分，理解模式 4 分。本法 = 抓词 2.0（结构化锚定）。
> 全程自检问题：做完能复述讲座内容吗？**能复述太多 = 模式错了**（带宽花在理解上）；只记得抓了哪些点 = 对。

**第 1 步 · 预读（D1–3 给 90 秒，D4–5 压到 60 秒，D6 起 45 秒 = 考试真实量）**
- notes 就是讲座大纲，标题白送结构——先扫标题知道"剧情"
- 每空标词性+类别，用速记：`[n]`名词 `[n-s]`可能复数 `[num]`数字 `[%]`比例 `[年]`年代 `[材]`材料 `[地]`地点
- **圈锚**：空前 2–3 个词划线。这是你的埋伏点

**第 2 步 · 第一遍限时播放（不暂停）**
- 注意力永远只挂在**下一个锚**上，不听讲座
- 锚响 → 抓紧随的**重读名词** → 立刻转移到下一个锚
- 信号词当 GPS：`Firstly / Another / Now let's turn to / Finally` = 换段 = 下一空要来了；丢了用它重新定位
- 每空 ~25 秒预算。**一次停留 = 连丢 2 个**。丢了立刻跳下一锚，考完再哭

**第 3 步 · 对答案**，一遍分入轨迹表（§6）

**第 4 步 · 归因**：每个错题按 §5 六类填一个字

**第 5 步 · 开 tapescript 标锚句**
- 给每个答案（对的错的都标）划出它所在的句子，确认："如果我守在锚上，抓得到吗？"
- 注意锚会被**轻度替换**——练的就是认出替换后的锚：

```
Notes: The main cause of coastal erosion is ______            预判: [n]
音频: "...the primary reason the coastline is wearing away is, in fact, wind."
锚替换: cause→reason / coastal erosion→coastline wearing away
答案 = wind（锚后第一个重读名词）
```

**第 6 步 · 错句跟读出声 ×3**
- 只跟错题的答案句，模仿连读弱读，存入错句表（§6）。这是本周唯一的"真听力"成分，单位是句子不是孤立词

**第 7 步 · 立刻重做第二遍**（可看题，不看 script）
- **验收：≥9/10**。低于 9 = 第 5 步没做透，回去重标锚

## 3. P1 提分操作（6 → 8，每天 1 个，~20 分钟）

流程同双遍法（预读→限时→归因→标锚→跟读→重做），另加 P1 专属注意：

- 预判每空类型：时间 / 价格 / 人名 / 电话 / 日期 / 名词
- 人名地名会逐字母拼读：盯 double（"double t"）、易混对（A/E、G/J、M/N、13/30、15/50）
- **改口陷阱**：先给的信息常被改（`actually / oh sorry / no, wait`）——听到改口词，前面写的作废
- 尾音 -s：听到复数必写 s，漏写 = 0 分
- **D1 的 P1 是诊断**：看 6 分丢在哪类——
  - 丢在 **写**（拼错/数字错）→ D2 起每天加 10' 自制听写：重放做过 P1 的拼读/报数段落，只写字母和数字
  - 丢在 **骗**（改口）→ 不加练，主练时把"等改口"设为单焦点
  - 丢在 **位/认** → 双遍法本身会修

## 4. 整卷日操作（D3 / D5 / D6）

1. **限时整卷 ~32 分钟**，全程执行纪律：
   - 一切非答案时段（例题、开场白、part 间隙）**只往后预读，不回看**
   - 预读优先级：P1 全部 → P4 前 5 空的锚 → P2/P3 题干关键词
   - 丢题止损：漏了立刻下一题锚点。**连环丢 2+ 题 = 事故**，复盘必查
2. **P2/P3 维持纪律**（不投入，但别流血）：
   - P3 开头 10 秒绑定声音↔人名（问 "What does Emma think" 认错人全崩）
   - 选择题：选项原词在音频出现 = 多半是坑，答案是被替换说法的那个
   - 地图：先定入口/START；方位闭集出声读一遍再开始：`go past / opposite / next to / just after / at the far end / in the corner / across from / clockwise`
   - 配对：题目项按顺序原词报出 → 抓选项的同义替换
3. **结尾 2 分钟四查**（CDI 只有这 2 分钟，无誊写时间）：字数限制 / 拼写 / 单复数 / 代回空里读通不通。**只改客观错，不凭感觉改**
4. **全卷归因**（40 分钟）：每错一个字归类入表 → P4 与 P1 错题走双遍法第 5–6 步（标锚+跟读）→ P2/P3 错题只归因不深修

## 5. 归因体系（六类，每错必归，只归一类）

| 字 | 定义 | 判据 | 修法 |
|---|---|---|---|
| **位** | 音频到锚点时人不在（还在处理上一题/上一句） | 事后看 script："这句放的时候我在干嘛" 答不上来 | 纪律：丢题止损，单焦点盯 |
| **认** | 守在锚上了，但锚词或答案词耳朵没认出（眼熟耳生） | 看 script 全认识，听的时候没反应 | 错句跟读 ×3 + 次日重放 |
| **预** | 预读时词性/类别判错，抓错方向 | 预判标记 vs 正确答案对不上 | 预读步骤放慢，检查预判 |
| **写** | 抓到了，拼错/单复数/超字数 | 答案词对，形式错 | P1 自制听写 + 四查 |
| **骗** | （选择/配对）被原词干扰项或改口骗 | 选了音频里原词出现的那项 | 记住三律：原词=坑 / but 后翻转 / 先说被改 |
| **真** | script 里的词本来就不认识 | 看了 script 也不懂 | **放掉**，不修（一周买不来） |

**验收逻辑**：位 / 预 / 写 / 骗 四类是纯技巧错，**D5 前必须清到 ≤2 个/套**；剩下 认+真 ≤ 13 个/套 → 数学上自动 ≥27。

## 7. 复习机制（三层，谁都不省）

1. **次日开场 15'**：
   - **重放昨日 P4 音频一遍，只重填曾错的空**（整段照放，不暂停）——这是声学复习，不是看文本
   - 错句表昨日新增句：出声跟读一轮，遮住答案词回忆
   - 仍不顺的句子标 ⭐，⭐句每天都进开场复习直到顺
2. **当日第二遍重做**：双遍法自带（≥9/10 才算过）
3. **D7 隔期验收**：重做 D1 的两个 P4（一遍模式）——**≥9/10 = 本周学习留存达标**；<8 说明复习层漏了

## 9. 硬规则（贴墙）

1. 不试图听懂。自检：只记得抓了哪些点 = 对
2. 一次停留 = 连丢 2 个。丢了立刻下一锚
3. 只往后预读，永不回看
4. 每错必归因，每归因必入表——**分数从复盘来，不从做题量来**
5. 错句必出声跟读，次日必重放。孤立词听写一个不做
6. 真类错误放掉，零内疚

## 10. 考试日执行卡（CDI，考前读两遍）

- 开考先调音量
- 每段"look at questions"时间 + 例题 + 开场白：**全部用来往后预读**（P1 全读 → P4 前 5 锚 → 其余题干）
- P4 预读不完没关系：前 5 空深读圈锚，后 5 空靠信号词 GPS 现场跟
- 改口词一响（actually / oh sorry）：前面的作废
- P3 开头 10 秒：声音绑人名
- 选择题拿不准：排掉"音频原词"项，选替换说法项，立刻走
- 连丢警报：意识到丢了 2 个 → 深呼吸一次，眼睛直接跳到下一题锚点
- 最后 2 分钟四查：字数 / 拼写 / 单复数 / 代回读通。只改客观错
- 打字：边听边敲，先敲下来再管拼写，四查时统一修
