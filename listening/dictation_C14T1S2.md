## 错误分类汇总

### 🔴 卡点词（完全没听到/不认识）— 需加入复习

| 卡点词 | 含义 | 出现语境 |
|--------|------|----------|
| resources | 资源 | human resources manager |
| statutory | 法定的 | statutory public holidays |
| probationary | 试用期的 | probationary three-month period |
| eligible | 有资格的 | eligible for this |
| permitted | 被允许的 | be permitted to do this |
| circumstances | 情况、状况 | personal circumstances |
| commitments | 承诺、事务 | commitments outside work |
| subsidised | 补贴的 | heavily subsidised canteen |
| packed lunch | 自带午餐 | no packed lunch policy |
| unhygienic | 不卫生的 | which is unhygienic |
| apprentice | 学徒（人） | being an apprentice |
| scheme | 方案、计划 | apprenticeship scheme |
| take it up | 接受（机会） | take it up if possible |
| run through | 过一遍 | run through a few policies |
| make the most of | 充分利用 | make the most of that opportunity |

### 🔴 致命错误（考试直接丢分的）

| 你写的 | 原文 | 问题 |
|--------|------|------|
| 6-week | six-month | month听成week |
| available | unavailable | un-前缀没听到，意思反了 |
| illegible | eligible | 听成了完全不同的词 |
| what not to do | if you're not sure what to do | 意思完全反了 |

### 🟡 高频语法/词形问题

- **不可数名词**: advice不加s, information不加s
- **单复数大量遗漏**: clothes/cloth, phones/phone, meals/meal, areas/area, trainers/trainer
- **冠词大量漏听**: a, an, the 的弱读几乎全丢
- **'ll (will) 反复漏掉**: you'll → you, there'll → there, we've → we
- **experience vs experienced**: 名词和形容词搞混

### 🟡 连读/弱读陷阱

| 原文 | 你听成 | 原因 |
|------|--------|------|
| You're here | You heard | /jɔː hɪə/ 连读 |
| There will | That'll | /ðeə wɪl/ → /ðætl/ |
| I'd like to | I'll | 缩读叠加弱读 |
| have already asked | may already ask | have弱读/əv/听成may |

## 总结

**整体水平判断**: 大意能跟上约70%，但细节丢失严重。前半段（一般建议+mentor）明显好于后半段（公司政策），说明后半段语速加快时跟不上了。

**最大的三个问题**:

1. **关键词听反/听混** — unavailable→available, eligible→illegible, six-month→6-week。这三个错误在考试中全部会直接丢分，而且都出现在答案密集区。
2. **功能词/弱读全面丢失** — a, the, that, with, of, 'll 几乎每句都漏。虽然单独不影响理解，但积累起来导致你无法还原完整句子结构，进而影响对长句的记忆。
3. **生词断层** — statutory, probationary, eligible, subsidised, unhygienic, commitments, circumstances 这些S2常见词你不认识，导致整个句子崩溃。

**下一步行动**:
1. 卡点词15个全部加入间隔复习（D+1/D+7/D+30）
2. un- / in- / im- 前缀专项：练习区分 available/unavailable, eligible/ineligible, possible/impossible
3. 数字专项：month/week/year 要反复确认，考试中出现数字附近的单位词是高频陷阱
