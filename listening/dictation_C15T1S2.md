## 🧠 核心诊断：working memory 爆仓 vs 理解能力

suzy 自己诊断："**听到了但写时忘了**"（特别点了 "to it" / "quite" 两处）

这不是 listening comprehension 问题，是 **working memory buffer 溢出**：
- 听到时：短时缓存能存一两个词，但后面的词挤进来就覆盖
- 写出来时：只能捞最熟悉的词出来，中间的 function words 被挤掉

对应训练方向：
1. **段落再切短 1 档**（原来 8 秒 → 现在 5-6 秒）—— 减少 buffer 压力
2. **听时用简写代替全写**（TM 代 tour manager, IoM 代 Isle of Man）—— 腾 CPU
3. **跟读让发音进入肌肉记忆** —— 熟悉的发音不占 working memory，相当于扩容
4. **D+1 / D+7 跟读复习** —— 同段反复听直到整句自动化

## 审题教训（加入 tracker）

1. **"not X" 是强反驳信号**：考题里写 "not X not 979"，意味着答案和 X 必有**显著差异**（不是 ±2 年的调整）。预判要 think big（跨度可能几百年）。

2. **第一信息句定位法（Q12/Q18 通用）**：题目问的动作（meet / provides）第一次出现在主句，后面 Some people / Or / another option 引导的是**备选/干扰**。别被第二信息拐走。

3. **预判词群**：预判时要能批量召回同类词（pass / ticket / card / voucher / permit），不能只想到一个。主动检索能力是口语和听力的共同瓶颈。

4. **electric vs electronic 一字母差**：electric = 电力驱动的（train/car/vehicle）；electronic = 电子产品的（device/music）。火车/地铁的修饰词必然是 electric。
