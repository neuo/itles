**🎯 Q15 observatory trip → F swimming possible**

[18] 🔴 Afterwards we'll head down to Sunset Beach, where **you can have a dip in the ocean** if you want before we head off back to the hotel.

**🎯 Q16 horse riding → B suitable for beginners**

[19] Finally, there's horse riding.

## 核心学习点（入同义替换本 S2 匹配题专区）

### 今日新增 paraphrase 组（6 组）

| 具体描述（原文） | 抽象选项（题目） | 场景 |
|-----------------|----------------|-----|
| places left / spaces available | fully booked (否定) | 预订/票务 |
| have a dip (in the ocean/pool) | swimming (possible) | 游泳/海滨 |
| using hands instead of cutlery | knives and forks not used | 餐饮 |
| never been on X before / first-timer | suitable for beginners | 活动门槛 |
| keen X-er + even if never done before | both experienced & beginners welcome | 活动门槛 |
| free of charge / completely free | no charge / no cost | 费用 |

### Q20 E 陷阱复习（动词辨析）

- **knock off their horses** = 把对方撞下马（骑士比武 jousting）
- **horse races** = 赛马（比速度）
- 听到 "horse" + 动词时，要听动词才能判断活动性质

### Band 7 核心词

- cutlery（餐具）/ utensils（器具）
- medieval（中世纪的）
- jousting / tournament（骑士比武）
- equestrian（马术的）
- canter（马慢跑）
- have a dip（下水游一下）
- drop（名词：落差）—— 700-metre drop = 落差 700 米

## 对比分析：Q11-16 配对题错误模式

4 道错题全是"具体描述 → 抽象概念"的转译失败。suzy 的大脑在处理 S2 匹配/选项题时，还停在"词面匹配"层，没进入"语义归纳"层。

**训练方向**：精听时不只听"是什么"，还要问自己"这在选项里会被说成什么"。每听完一段，在脑内先造 paraphrase：
- 听到 "have a dip" → 先问自己"这在选项里会是 swim"
- 听到 "never been on a horse" → 先问自己"这在选项里会是 beginners"
- 听到 "places left" → 先问自己"否定版就是 fully booked"

这个训练比单纯精听更有针对性，建议**精听时暂停在 paraphrase 信号句，自己先猜选项怎么说，再看答案**。
