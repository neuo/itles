## 你的起点和目标

| 项目 | 现状 | 10周后目标 |
|---|---|---|
| 总分 | 4.5 | 6.5-7 |
| S1 | 能听懂但抓不住答案 | 稳定 9-10/10 |
| S2 | 跟不上语速 | 稳定 7-8/10 |
| S3 | 未测试 | ≥ 5/10 |
| S4 | 未测试 | ≥ 4/10 |

**提分路径**：S1+S2拿到16-17/20就是6分底盘，S3+S4再拿7-8/20就到6.5。前4周全力攻S1和S2性价比最高。

## 机考 vs 纸考：你必须知道的区别

雅思机考（CDI）的听力和纸考有几个关键区别，直接影响训练策略：

```
1. 没有额外誊写时间
   纸考结束后有10分钟把答案抄到答题卡上，机考没有。
   音频播完你就交卷了。
   → 影响：必须边听边打字，不能"先记草稿再誊写"
   → 训练重点：打字速度和准确性，缩写速记能力

2. 答案直接打字输入
   填空题直接在屏幕上打字，选择题点选。
   → 好处：不用担心手写潦草被判错
   → 坏处：拼写错误更容易出现（没有手写的"肌肉记忆"辅助）
   → 训练重点：高频答案词的拼写必须练到自动化

3. 可以在屏幕上高亮/做笔记
   机考界面可以高亮题目文字，也可以做电子笔记。
   → 好处：审题划关键词更方便
   → 训练建议：平时用电脑练题，习惯屏幕阅读+打字输入的节奏

4. 每个 Section 结束有短暂检查时间（约30秒）
   但不像纸考那样有完整的回看时间。
   → 策略：边做边确认，不要留空等回头填

5. Section 之间的读题时间和纸考一样
   每个 Section 开始前有时间看题。
   → 策略：和纸考一样要抢时间预读下一个 Section 的题
```

### 机考打字练习建议

```
如果你打字速度不够快：
- 用在线打字练习（推荐 keybr.com 或 typing.com）每天练10分钟
- 重点练习听力高频答案词的拼写（见本手册"必须能拼对的词"部分）
- 练习时模拟考试场景：听音频 → 立刻切到输入框打字 → 立刻切回听

缩写速记（草稿区用，最后有时间再补全）：
- Monday → Mon / Wednesday → Wed
- swimming pool → sw pool
- September → Sep
- 地址类直接打数字+首字母：15 Park Road → 15 PR
- 打完每个答案后立刻眼睛回到题目，不要检查拼写（最后统一检查）
```

## 两个核心训练法

> 以前分了5个方法（A-E），实际练习时太发散。现在合并为两个：**做题法**和**精听法**，每次训练就做其中一个，简单明确。

---

### 训练一：做题法（审题→做题→复盘，45-50分钟/套）

**每次做新的真题时用这个流程。覆盖了审题预判、答案定位、同义替换积累。**

#### Phase 1：审题预判（音频播放前，5-8分钟）

拿到题目后，在音频播放前完成三件事：

**第一件：划关键词**

逐题划出"定位锚点"——帮你在音频流中快速定位答案位置的词。

```
划什么：
✓ 专有名词（人名/地名/机构名）——音频通常不替换
✓ 数字（年份/价格/百分比/时间）——答案本身或附近
✓ 限定词（only/all/most/first/main/at least）——决定答案范围
✓ 否定词（not/never/except/without）——容易听反
✓ 并列/对比结构（A and B / A or B / A rather than B）

不划什么（太泛的词没有定位价值）：
✗ people / things / place / good / like
```

举例：
```
题目：The total cost of the trip including lunch is £_____
划词：total cost / trip / including lunch / £_____
预判：答案是一个价格数字，注意"including lunch"是限定——
      音频可能先说不含午餐的价格（干扰），再说含午餐的总价（答案）
```

**第二件：预判同义替换**

对划出的关键词，快速想1-2个音频可能用的替代说法。不需要写下来，心里过一遍就行。

这一步的重点是：**让大脑提前"装好雷达"**，听的时候就能自动捕捉替换词。

```
题目说 cost → 脑中闪过 price / fee / charge
题目说 near → 脑中闪过 close to / next to / a short walk from
题目说 improve → 脑中闪过 enhance / boost / get better
题目说 many students → 脑中闪过 a large number of / quite a few learners
```

做不到？没关系，看完本手册后面的「同义替换速查表」背熟，自然就能做到了。

**第三件：标陷阱区**

以下题型特别容易出陷阱，要提前标记提醒自己：

```
陷阱1：纠正信息
  题目问地址/时间/价格 → 音频先说一个错的，再纠正
  信号词：sorry, I mean... / no, wait / actually it's / let me correct that
  应对：听到纠正信号词，之前写的答案立刻划掉，等新答案

陷阱2：干扰选项
  选择题中2-3个选项都会在音频中被提到
  应对：不要听到第一个选项就选，等说完再定

陷阱3：否定/排除
  题目问 "NOT included" / "EXCEPT"
  应对：在题目旁边画个大大的 ✗ 提醒自己是排除题
```

#### Phase 2：做题（跟音频走，约30分钟）

```
边听边做的要点：

1. 眼睛永远比耳朵快一步
   在听当前题的答案时，余光已经在看下一题
   这样下一题开始时你已经知道要听什么

2. 听到答案立刻输入，不要犹豫
   先打出来，哪怕不确定拼写——空着比打错更亏
   机考可以回头改，但漏听了就没机会了

3. 没听到就放弃，立刻跟下一题
   纠结一道题会连带丢2-3题
   不确定的题打个大概，标记一下，最后检查时再想

4. 注意信号词——答案前的"预警"
   转折：but / however / actually / in fact（答案常在转折后）
   纠正：sorry, I mean / no wait / let me correct that
   强调：the main thing is / the key point / what's important
   列举：first / also / another / finally（多个答案连续来）
   总结：so / basically / the point is
```

#### Phase 3：复盘（做完后，10-15分钟）

这是最关键的环节——做题不复盘等于白做。

```
Step 1 · 对答案 + 错因分类（5分钟）

每道错题归入以下一类（可以重叠）：
  A. 审题问题——没划到关键词 / 没注意限定词 / 看错题
  B. 同义替换——关键词被替换了没反应过来
  C. 语速漏听——听到了附近内容但关键词一闪而过
  D. 拼写错误——听对了但打错了
  E. 陷阱中招——听到纠正信息没改 / 选了干扰项

把错因填入 ielts_listening_tracker.md

Step 2 · 补同义替换本（5分钟）

打开答案和原文，找出所有存在同义替换的题（不只是错题）
记入 ielts_synonym_bank.xlsx：

  格式：题目原词 | 音频用词 | 出处
  例：advantages | benefits | 剑14 T1 S2 Q15

完全没想到的替换打★标记

Step 3 · 看原文标答案位置（5分钟，选做）

在 transcript 中找到每个答案所在的句子
观察：答案前面的信号词是什么？你听的时候注意到了吗？
把好用的信号词记下来，加强信号词敏感度
```

#### 做题法的训练节奏

```
第1-2周：每天1套S1+S2（约50分钟含复盘）
第3-4周：每天1套S2，每2天加1套S1验证（约50分钟）
第5-8周：每2天1套完整题（约60分钟含复盘）
第9-10周：隔天1套完整模考（严格限时）
```

### 训练二：精听法（听写→对照→跟读→加速，30-40分钟/段）

**做完题之后用这个流程。挑错题所在的段落做精听，提升真正的听力理解力。**

#### Step 1：盲听抓大意（3分钟）

不看原文，完整听一遍要精听的段落。在纸上/屏幕上快速写：
```
这段在讲什么（一句话）：______________________
听到的关键词：______________________
```
听不懂也没关系，这一步只是热身。

#### Step 2：逐句听写（12-15分钟）

**这是精听的核心，也是提分最快的训练。**

```
操作：
1. 播放一句 → 暂停
2. 打出你听到的完整句子（机考练打字，一举两得）
3. 听不出的地方打 [?]
4. 同一句最多放3遍——3遍还听不出就标 [?] 往下走
5. 不要死磕，保持节奏

你会大量遇到的"听不出"现象：

连读（两个词粘在一起）：
  want to → /wɒnə/ (wanna)
  going to → /gənə/ (gonna)
  kind of → /kaɪndə/ (kinda)
  a lot of → /əlɒtəv/
  would you → /wʊdʒu/
  did you → /dɪdʒu/
  don't you → /dəʊntʃu/

弱读（功能词被压到几乎听不见）：
  and → /ən/ or /n/
  for → /fə/
  of → /əv/ or /ə/
  to → /tə/
  the → /ðə/
  a → /ə/
  have → /əv/ (在 could have, should have 中)
  been → /bɪn/ (几乎像 bin)

吞音（某些音被"吃掉"）：
  last time → /lɑːs taɪm/ (t消失)
  next day → /neks deɪ/ (t消失)
  must be → /mʌs bi/ (t消失)
  hand bag → /hæm bæg/ (d变m)
  want back → /wɒm bæk/ (t变m)

缩读（缩写的口语发音）：
  would have → would've → /wʊdəv/
  should not have → shouldn't've → /ʃʊdntəv/
  I will → I'll → /aɪl/
  they are → they're → /ðeə/
  it is → it's → /ɪts/
  we have → we've → /wiːv/
```

#### Step 3：对照原文 + 分类错误（5分钟）

打开 transcript 逐句对照。用三种标记：

```
🔴 完全没听到 = 生词 or 连读吞音 or 语速太快
   → 这个词/短语加入精听本，下次精听前先复习

🟡 听到了但打错 = 拼写问题 or 理解偏差
   → 拼写错的词加入"必须能拼对的词"列表

🟢 听到了也对了但做题时没用上 = 审题/定位问题
   → 说明做题流程需要加强，不是听力能力问题
```

数一数三种颜色的比例：
- 🔴超过50% → 听力基础要补，继续精听，同时扩充词汇
- 🟡超过30% → 拼写是短板，每天花10分钟专练拼写
- 🟢超过30% → 听力没问题，把时间给做题法的审题预判

#### Step 4：跟读 + 加速重听（10分钟）

```
第一遍：看原文跟读（3分钟）
  - 模仿语速、节奏、语调
  - 特别注意标🔴的词——大声读出来，让嘴巴和耳朵同时记住

第二遍：不看原文，1.0x正常速度听（2分钟）
  - 确认标🔴的词现在能听出来
  - 如果还不行，标记为"顽固词"，后续重点攻

第三遍：1.25x倍速听（2分钟）
  - 在已经听懂的基础上加速
  - 训练大脑处理速度

第四遍：回到1.0x（2分钟）
  - 你会发现正常速度突然变"慢"了——这就是加速训练的效果

注意：倍速训练只用已精听过的材料。没精听过的新材料不要加速，那只会越听越糊涂。
```

#### Step 5：卡点词间隔复习

精听做完了不代表真的记住了。语言和理科不一样——理解了不等于自动化了，需要间隔重复才能真正变成你的。

```
每次精听结束后的完整流程：

1. 发精听结果给 Claude → Claude 做逐句对照分析，输出：
   - 🔴 卡点词列表（生词/连读/语速）
   - 🟡 语法/词形/弱读问题
   - 致命错误标注（考试会丢分的）

2. Claude 自动执行：
   - 卡点词录入 ielts_listening_tracker.md（含 D+1/D+7/D+30 复习追踪）
   - 拼写类卡点词加入练习 app「精听卡点词」分类
   - 精听记录存入 listening/dictation_[材料名].md

3. 你只需要做的事：
   - 当天：去 app 练几个最陌生的卡点词拼写（5分钟）
   - D+1：跟读复习卡点句（见下方具体操作）
   - D+7：1.1x 加速听同一段
   - D+30：1.25x 过一遍，全听懂就毕业
```

**D+1 跟读复习操作（10分钟，不是被动重听）：**

```
打开精听过的音频，只做卡点句（6-8句）：
1. 放一句 → 暂停 → 看着原文跟读一遍（注意模仿语速节奏）
2. 同一句 → 不看原文再跟一遍
3. 跟不出来的 = 还没消化，标"顽固"，继续每天跟读
4. 跟出来的 = 短期已掌握，等 D+7 再验证

为什么是跟读不是重听：
  纯重听容易变成"背景音"，大脑不投入注意力就没效果。
  跟读逼你嘴巴跟上，听不清就说不出来，大脑没法偷懒。
```

**D+7 加速复习（5分钟）：**

```
同一段音频，1.1x 速听一遍。
还有听不出的 → tracker 标"顽固卡点"，加入每日跟读。
```

**D+30 毕业测试（3分钟）：**

```
1.25x 速过一遍，基本全听懂就从复习列表毕业。
```

为什么是这个节奏：认知科学里叫"间隔效应"——同样的内容，分3次隔开复习，记忆效果是连续复习3次的3倍以上。你学理科其实也在用这个原理（做题→考试→期末复习），只是语言学习需要更刻意地安排。

#### 精听法的训练节奏

```
第1-2周：每天精听1段S1或S2错题段落（30-40分钟）
第3-4周：每天精听1段S2（不只是错题，完整段落都精听）
第5-6周：每2天精听1段S3错题段落
第7-8周：每2天精听1段S3或S4错题段落
第9-10周：只精听反复出错的"顽固段落"
```

## 信号词速查表

> 信号词是"答案要来了"的预警。听到这些词立刻集中注意力。

### 答案在转折后（最常见的出题套路）

```
but / however / actually / in fact / to be honest
having said that / on the other hand / although / mind you
the thing is / what I really mean is
→ 转折前的内容是干扰，转折后的才是答案
```

### 答案在纠正后（S1最常见的陷阱）

```
sorry, I mean... / no, wait / let me correct that
actually, it's not X, it's Y / I should say...
oh sorry, I got that wrong / hang on, that's not right
→ 纠正前是错误答案，纠正后是正确答案
→ 机考中如果已经打了旧答案，立刻删掉改新的
```

### 答案在强调后

```
the main thing is / the key point / what's important
especially / particularly / above all / most notably
what really matters is / the crucial thing
→ 强调后面的内容通常就是答案
```

### 多个答案连续出现

```
first / firstly / to begin with / one thing is
also / another / in addition / furthermore / as well as
finally / lastly / the last one / and the other
→ 听到列举信号就知道答案在连续轰炸，加快输入节奏
```

### 答案在总结中

```
so / overall / in conclusion / to sum up / in short
basically / essentially / the point is / in other words
→ 如果前面漏听了，总结句可能给你最后一次机会
```

## 每日训练流程

> 合并后只有两个训练，每天选一个做就行。也可以两个都做（如果时间允许）。

### 标准日（约90分钟）

```
做题法（50分钟）：
  审题预判 5min → 做1套S1+S2 15min → 复盘+整理同义替换 15min
  （前4周每天做，后面隔天做）

精听法（35分钟）：
  选今天做题的1-2段错题段落
  盲听 3min → 逐句听写 15min → 对照原文 5min → 跟读+加速 10min
```

### 轻量日（约50分钟，口语集中周或其他科目为主的周）

```
做题法（50分钟）：
  只做1套S2，完整流程
  不加精听，把时间留给其他科目
```

### 冲刺日（约60分钟，第8-10周）

```
完整套题模考（40分钟）：
  S1+S2+S3+S4 严格限时，模拟机考界面

复盘（20分钟）：
  对答案 → 错因分类 → 同义替换 → 挑1段最差的精听
```

## S2 跟不上：专项突破方案

如果你做S2连主线都跟不上，用以下顺序突破：

### 第一步：降低期望，只听答案

S2是独白，信息密度高，不可能每个词都听懂。你只需要在答案出现时"醒过来"。

```
怎么做：
1. 审题时在脑子里"装雷达"——知道下一个答案大概是什么（时间？地名？数字？）
2. 听的时候允许自己"模糊听"不相关的内容
3. 听到和预判相关的词就立刻集中注意力
4. 打个答案，立刻切回"扫描模式"等下一题
```

### 第二步：练"听→打→切"的三秒节奏

很多人S2丢分是因为打上一个答案时漏听了下一题。

```
专项练习（用已做过的S2）：
1. 重新听，这次不做题
2. 只练"听到答案→打出来→立刻眼睛回到下一题"的节奏
3. 答案只打缩写：Monday→Mon / swimming pool→sw / 9:30→930
4. 目标：打字动作不超过3秒
5. 连续练3套，这个节奏就会成为本能
```

### 第三步：用精听法的加速步骤突破语速

```
拿已经精听过、能听懂的S1段落：
1. 1.25x倍速听——目标能跟住80%
2. 回到1.0x——感受"变慢效应"
3. 达标后换S2材料：先1.0x精听→再1.1x→1.25x
4. 坚持2周，正常速度的S2就不会觉得快了
```

## 附录：机考做题时间感知

```
机考听力总时长约30分钟，没有额外誊写时间。

S1（约5分钟）
  看题：读例子时看Q1-Q5，中间停顿看Q6-Q10
  策略：最简单，必须拿8-10分，是你的"保底分"
  机考注意：填空答案打字后快速检查拼写

S2（约5-6分钟）
  看题：S1结束后有约30秒，赶紧预读S2全部题目
  策略：独白节奏快，审题预判是生命线
  机考注意：选择题可以先点一个最可能的，之后有把握再改

S3（约5-6分钟）
  看题：S2结束后有约30秒预读
  策略：注意"谁说了什么"，匹配题听说话人+态度
  机考注意：匹配题在屏幕上可能需要滚动，提前熟悉界面

S4（约5-6分钟）
  看题：S3结束后有约30秒——这是最后的预读机会
  策略：填空题为主，听信号词，答案通常是常见词不是学术词
  机考注意：S4结束后有约2分钟检查全部答案——
           优先检查拼写和大小写，不确定的题快速决定

最后2分钟检查策略：
  ① 先扫一遍所有填空题的拼写
  ② 检查大小写（人名/地名首字母大写）
  ③ 检查数字格式（日期、时间、价格）
  ④ 不确定的选择题凭第一直觉选，不要留空
```
