## 核心诊断

### 🚨 致命级错误（语义反转 / 答案信号句听错）

1. **Q11 答案句语义反转**：
   - 听成：`there aren't plenty seat for this afternoon`
   - 原文：`there aren't any places left for this afternoon's trip`
   - 语义完全反：plenty（很多）↔ any…left（没剩）
   - 直接解释做题时错选 C（only in good weather）

2. **Q15 数字 teens vs tens 致命错**：
   - 听成：`19 euros`
   - 原文：`90 euros`
   - nineteen /ˌnaɪnˈtiːn/ vs ninety /ˈnaɪnti/ 重音位置颠倒
   - number_drill 训练目标的典型案例

3. **Q16 答案句式听到但宾语漏**：
   - 听成：`even if you've never been xxx before`
   - 原文：`even if you've never been **on a horse** before`
   - 句式识别✅ 但关键宾语漏 → 做题时没抓到这个"适合新手"信号

### 🔴 致命词混淆（两字母差意完全反）

| 听成 | 原文 | 含义差 |
|---|---|---|
| guarded walk | guided walk | 守卫 vs 导游 |
| heel | hills | 脚后跟 vs 山 |
| by bike | to bike back | 方向丢失（下坡信号） |
| way | waves | 路 vs 浪 |
| fan | fun | 同音不同词 |

### 🔁 老问题再犯（和口语同源）

1. 第三人称 -s 漏：takes→take / costs→cost（本次 2 次）
2. 单复数：trip→trips / shoe→shoes / kilometre→kilometres / activity→activities
3. 冠词漏：the effort / the beach / the observatory
4. 介词错：into the ocean→**in** / at 6pm→**by** 6pm
5. 时态助动词漏：give→will give / are provide→will be provided
