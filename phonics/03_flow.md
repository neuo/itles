# 03. 每次练习：学什么 · 怎么学 · 怎么记

> 状态：**初版**（2026-11-14），练几次后按实际调整。
> 为什么这么设计，见 `02_method.md`。

---

## 1. 这次学什么

- **新规则**：`rules.md` 里下一条「未讲」的规则，每次只讲一条。
- **复检**：`pool.md` 里**到期**的规则（到期 = 本次编号 ≥ 「下次最早」）。
- **闸门**：复检错了一半以上，本次**不讲新规则**，改成把错的规则重讲一遍、再练。

## 2. 怎么学（约 15 分钟）

| 步 | 做什么 | 要点 |
|---|---|---|
| 0 | 教练开场 | 读 `pool.md` 和上一次的 session 文件，算出本次是第几次、哪些规则到期、讲哪条新规则 |
| 1 | **复检** | 每条到期规则出 2–3 个**新词**，混排，**不提示**考的是哪条规则 |
| 2 | **讲新规则** | 规则一句话 → 为什么这样 → 3 个真词当锚 → 常见例外。她有疑问就当场问 |
| 3 | **练习 10 题** | 新规则约 6 题 + 旧规则约 4 题（含已毕业的）；真词、假词都有；阶段 2 起两个方向都出 |
| 4 | **批改** | 逐题判。错的写出：违反哪条规则、标准答案、真词参照 |
| 5 | **收尾** | 写 session 文件 → 更新 `pool.md` 和 `rules.md` 的「讲于」→ 提交并推送到 main |

**作答规矩**：不查词典；每个词**先出声读**再写；没把握加 `?`，没头绪写 `X`。
- 看词读音：复制音标。
- 听音写词：教练给音标，她写拼写。
- 重音题：写重读音节的字母（如 `tri`），或写第几个音节，两种都收。

**判分**：
- ✅ 对；❌ 错；⚠️ 写法和词典不一致但读音对，不算错。
- 记号问题不算错（`:` 代 `ː`、`g` 代 `ɡ`、多打或少打长音符号这类）。

## 3. 复检节奏（按练习次数计，不按日期）

- 每条规则**讲过就进池**，放在第 1 格。
- 梯子：**1 → 2 → 4 → 8**。格数就是距离下次复检的最少练习次数。
- 一条规则的复检题**全对**才算对，否则算错（不分「半对」）。
  - 对：上一格；第 8 格再对 → **毕业**。
  - 错：回第 1 格。
- 到期太多时按这个顺序取：复检次数少的 → 等得久的 → 编号小的。
- 池里的规则在练习里错了 → 回第 1 格（复检对了也一样，以最后一次为准）。
- 已毕业的规则在练习里错了 → 回池，从第 1 格开始。

## 4. 怎么记

所有文件都在 `phonics/` 下。⛔ 一律手工逐条写，不用脚本批量生成。

### `sessions/NNN.md`：每次一份（001、002……）

```
# 第 N 次 · YYYY-MM-DD（日期只作记录，不参与计算）· 阶段 X

## 复检
| # | 题 | 她 | 标准 | 判 | 规则 | 错在哪 |
规则结果：S1 ✅ 第 1 格 → 第 2 格 · ……

## 新规则
S? —— 讲解要点见 rules.md

## 练习
| # | 题 | 她 | 标准 | 判 | 规则 | 错在哪 |

## 小结
- 复检 ✅x ❌y · 练习 ✅x ❌y ⚠️z
- 池的变化：进池 / 升格 / 回第 1 格 / 毕业
- 她的问题和教练的回答（如有）
```

她的作答**原样照录**，不改写。

### `pool.md`：规则池，每次收尾更新

| 列 | 含义 |
|---|---|
| 规则 | 编号（S1、P3……） |
| 格 | 1 / 2 / 4 / 8 / 毕业 |
| 进池 | 第几次讲的 |
| 上次复检 | 第几次 |
| 下次最早 | 第几次 |
| 记录 | 每次复检的结果，按顺序写，如 `✅✅❌✅` |

### `rules.md`：课表 + 规则正文

- 讲过的规则，把「讲于」改成第几次。
- 讲解要点写进「正文」区：规则、为什么、真词锚、例外。复检和练习时引用这里，不在 session 文件里重复讲。

### 提交

每次收尾提交一次，推送到 main。提交说明写：第几次 · 复检结果 · 新讲哪条规则 · 池的变化。
