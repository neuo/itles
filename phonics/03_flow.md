# 03. 每次练习：学什么 · 怎么学 · 怎么记

> 状态：**第 2 版**（2026-11-14，加入网页工具）。练几次后按实际调整。
> 为什么这么设计，见 `02_method.md`。

---

## 0. 数据和界面是分开的

**数据**在 `data/` 和 `rules.md`。**网页**（`app/`）和**对话框**都只是界面：她在哪边作答都一样，落到同一份数据里。

| 文件 | 谁写 | 内容 |
|---|---|---|
| `rules.md` | 教练 | 课表 + 规则正文 |
| `data/sessions/NNN.json` | 教练 | 这一次的题目（含答案、讲解、音标）+ 教练复核 `review` |
| `data/answers/NNN.json` | 网页 / 教练 | 她的作答。网页提交时自动写；她在对话里作答时由教练写（`via: "chat"`，原话记在 `chatRaw`） |
| `data/pool.json` | 教练 | 规则池 |

- 网页**只写** `data/answers/`，别的一概不动。
- 网页会当场给对错，那是**临时判定**（按答案比对）。**最后以教练复核为准**：教练可以改判、加备注。
- 网页不能通知教练。她做完后回对话说一声「第 N 次做完了」。

## 1. 这次学什么

- **新规则**：`rules.md` 里下一条「未讲」的规则，每次只讲一条。
- **复检**：`data/pool.json` 里**到期**的规则（到期 = 本次编号 ≥ `nextDue`）。
- **闸门**：复检错了一半以上，本次**不讲新规则**，改成把错的规则重讲一遍、再练。网页会自动拦住，让她回对话。

## 2. 怎么学（约 15 分钟）

| 步 | 谁 | 做什么 |
|---|---|---|
| 1 | 教练 | **出题**：读 `pool.json`，定哪些规则到期、讲哪条新规则。写 `data/sessions/NNN.json`，把新规则正文写进 `rules.md`。告诉她「第 N 次出好了」 |
| 2 | 她 | **复检**：每条到期规则 2–3 个**新词**，混排，不提示规则。在网页里点，或在对话里答 |
| 3 | 她 | **看新规则**：规则一句话 → 为什么 → 真词锚 → 常见例外。有疑问回对话问 |
| 4 | 她 | **练习 10 题**：新规则约 6 题 + 旧规则约 4 题（含已毕业的）；真词、假词都有；阶段 2 起两个方向都出 |
| 5 | 她 | 回对话说「第 N 次做完了」 |
| 6 | 教练 | **复核 + 收尾**：读 `data/answers/NNN.json`，逐题看。写 `review`，更新 `pool.json` 和 `rules.md` 的「讲于」，提交并推送到 main |

**出题时每道题要写的**（`data/sessions/NNN.json` 的 `items`）：

| 字段 | 含义 |
|---|---|
| `id` | `r1…`（复检）、`p1…`（练习） |
| `part` | `recheck` / `practice` |
| `type` | `stress`（点重读音节）· `read`（选读音）· `spell`（选拼写） |
| `word` · `pseudo` | 词；是不是假词 |
| `syllables` | 重音题的音节。按**中性切法**切（一个辅音归后面的音节），不按词典切，免得泄露重音 |
| `options` | 读音题、拼写题的选项 |
| `answer` | 正确的是第几个（从 1 数） |
| `ipa` | Oxford 美音音标；音节间用 `.`，主重音 `ˈ` 写在音节开头。音节数要和 `syllables` 一致。真词要在 Oxford 核对 |
| `rule` | 考的是哪条规则 |
| `explain` | 一句话讲解，她提交后才看得到 |

服务启动时会检查题目文件，写错了会在日志里报 `[题目]`。

**作答规矩**：不查词典；每个词**先出声读**再选。拿不准就勾「没把握」；完全不会点「不知道」。
在对话里作答也行：重音题写重读音节的字母或第几个音节，没把握加 `?`，没头绪写 `X`。

**判分**：
- ✅ 对；❌ 错；⚠️ 不算错（教练复核时才会给）。
- 「没把握但答对」算对，但教练复核时会看：没把握的多，那条规则可以不升格。

## 3. 复检节奏（按练习次数计，不按日期）

- 每条规则**讲过就进池**，放在第 1 格。
- 梯子：**1 → 2 → 4 → 8**。格数就是距离下次复检的最少练习次数。
- 一条规则的复检题**全对**才算对，否则算错（不分「半对」）。
  - 对：上一格；第 8 格再对 → **毕业**。
  - 错：回第 1 格。
- 到期太多时按这个顺序取：复检次数少的 → 等得久的 → 编号小的。
- 池里的规则在练习里错了 → 回第 1 格（复检对了也一样，以最后一次为准）。
- 已毕业的规则在练习里错了 → 回池，从第 1 格开始。

## 4. 复核时教练写什么

写在 `data/sessions/NNN.json` 的 `review` 里。⛔ 手工逐条写，不用脚本生成。

| 字段 | 内容 |
|---|---|
| `done` | `true` 表示复核完了；网页上「待教练复核」的标记随之消失 |
| `items` | 只写需要说话的题：`{ "p6": { "verdict": "wrong", "note": "…" } }`。`verdict` 可以改判（`ok` / `wrong` / `warn`）；`note` 写错在哪、为什么错 |
| `summary` | 小结，几句话 |
| `pool` | 规则池的变化 |
| `qa` | 她这次问的问题和回答 |

同时：
- `data/sessions/NNN.json` 的 `date` 填当天日期（只作记录，不参与计算）。
- `data/pool.json`：改 `session`、每条规则的 `box` / `lastReview` / `nextDue` / `log`。
- `rules.md`：新讲的规则把「讲于」改成第几次。
- 提交说明写：第几次 · 复检结果 · 新讲哪条规则 · 池的变化。

## 5. 网页工具

启动：`node phonics/app/server.js`，打开 http://localhost:4310 。需要本机装了 `espeak-ng`（按音标发音用）。

| 页 | 用途 |
|---|---|
| 练习 | 做当前这一次；下面是规则池 |
| 规则 | `rules.md` 全文 |
| 错题 | 所有错过的题，按规则分组；另列「答对但没把握」的 |
| 发音 | 查真词（美音真人录音 / 系统合成音 / 跳 Oxford）；按音标读（假词也能读，带音标键盘） |
| 记录 | 每一次的题、她的作答、教练复核 |

发音的三个来源：
- **真人录音**：Wikimedia 上志愿者录的，约六成的词有。
- **系统合成音**（Samantha）：只用于真词；重音一般对，不保证。
- **按音标合成**（espeak-ng）：声音机械，但每个音和重音位置是准的。假词、以及「你选的重音 vs 正确的重音」对比都用它。
