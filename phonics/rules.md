## 阶段 2：拼读全部规则（P）

到阶段 2 前再细化成一条一条的规则。大块顺序：

1. 辅音（含软 c / g、ch 三种读法、ph / gh 等）
2. 单元音长短：音节类型（闭音节 · 开音节 · 辅音 + e · 双写辅音 · -dge / -ge），**i / y 是重点**
3. 元音组合（**ou / ow、ew 是重点**）
4. r 控制元音（**ir / ire 是重点**）
5. 不发音字母（**wr- / gn- 是重点**）
6. 词尾（**-ed 读 t / d / ɪd 是重点**）
