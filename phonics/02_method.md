# 02. 学习方法

> 状态：**部分已定**（2026-11-14）。未定项在文末。
> 现状数据见 `baseline_2026-11-14.md`。

---

## 1. 原则

1. **学规则，不背单词表。**
2. **所有规则都系统学一遍，包括基线答对的。** 她没学过拼读规则；答对可能是拿认识的词类比出来的，不代表懂规则（suzy 2026-11-14 指出）。重音同理。
3. **假词测规则，真词测迁移。** 假词没法靠记忆蒙对；真词检查规则能不能用到实际单词上，也能抓出早就记错读音的旧词（如 ache）。
4. **进池的是规则，不是那个词。** 复检时出同一规则的**新词**，不重复出原题。
5. **新旧规则混着练。** 只练当天那一条，她会无脑套用；练习要逼她判断该用哪条（如 miper / mipper）。
6. **先复检，再前进。** 每个词**先出声读**，再写。

## 2. 顺序（suzy 2026-11-14 定）

| 阶段 | 内容 | 说明 |
|---|---|---|
| 1 | **重音：后缀定位置** | 基线错 12 / 24，错法有规律（-ate、同词族重音钉死、-eer / -ese） |
| 2 | **自然拼读全部规则，系统学一遍** | 辅音 → 单元音长短（音节类型）→ 元音组合 → r 控制 → 不发音字母 → 词尾（-ed 等） |
| | ↳ 重点：i / y 的长短 | 基线错最多，两对读反（miper / mipper、gyme / thrym）。练习量加大、在池里留得更久 |
| | ↳ 重点：ou、ew、ir / ire、wr- / gn-、-ed 读 t | 基线错过的零散几条 |
| 暂不处理 | r 漏读 | 英音的发音习惯，不是规则问题，拼读练不出来 |

i / y 和零散几条原本排在最后、单独成段，现在并进阶段 2 当重点：全规则学一遍时会讲到它们，再单独来一轮就重复了。

## 3. 每次练习（约 15 分钟）

1. **复检**：池里到期的规则，每条出 2–3 个新词。
2. **新规则**：一条，先讲清楚，再给 2–3 个真词当锚。
3. **练习**：10 题。新旧规则混排，假词和真词都有。
4. **批改并落盘**：错了的规则进池。

作答方式：复制音标（Oxford 美音写法，音标盘在 `baseline_2026-11-14.md`）；重音题写第几个音节。

## 4. 已知限制

教练听不到她读，只能判断「她知道它读什么」，判断不了「嘴上读得对不对」。
真词可以拿 Oxford 的音频自己对照，假词没有音频。

## 5. 规则能管多少词（背景事实，2026-11-14 核对）

- **Hanna 等 1966**：分析约 1.7 万个词，看的是「听音写词」方向。
  - 一半的词只靠音和字母的对应就能拼对。
  - 再有 34% 只错一处，通常错在元音。
  - 把词源、词义也算上，真正不规则的约 4%。
  - 出处：Moats, *How Spelling Supports Reading*, American Educator, 2005–06。
- **Clymer 1963**：检验了小学教材里常教的 45 条拼读规则，用的是约 2,600 个词。
  - 只有 18 条的命中率达到 75% 以上。
  - 10 条辅音规则里，9 条命中率在 95% 以上；元音规则差得多。
  - 后来有研究（Gates 1983）把「词尾不发音的 e」这条规则连例外一起说清，命中率到了 93%。
- **高频词反而更不规则**（老的盎格鲁-撒克逊词）；拉丁、法语来源的低频词更规则（Moats 同文）。

**对教法的含义**：
- 规则要连例外一起讲，讲成「默认读法 + 备选」，不讲成绝对。
- 元音是重点：她基线 17 个错里有 13 个是元音。辅音规则可靠，过得快一些。
