## #0009 suggest 的动词框架（原题：suggest sb to do → suggest that sb (should) do）
类别：搭配（动词框架）｜ **08-20 按她的提问扩容**（§3.1 同一句法点归老编号，不新建；扩容方向见 G22）
中文触发点①：医生建议他多休息。（绑定：用 suggest）
中文触发点②（08-20 新增，测一般规则）：他向我解释了这条规则。
她的：the data suggest them to hold it longer ｜ 正确：suggest that they should hold it longer ／ suggest holding it longer
备注（08-20 扩写 —— 她问"suggest 后面到底能接什么、为什么 advise 可以"）：
　　 **suggest 的合法框架**：✅ suggest + -ing（I suggest going early）｜ ✅ suggest (that) + 从句（he go / should go）
　　 ｜ ✅ suggest + 名词（a different approach）｜ ✅ suggest + wh- 从句（where we should stay）
　　 ｜ ✅ suggest **to sb** that…（He suggested **to me** that we leave）
　　 ⛔ suggest sb to do　⛔ suggest him that…
　　 **更大的规则（这条才是根）**——动词按"人能不能直接跟在后面"分两族：
　　 **A 族（V + sb + to do ✅）**：advise / tell / ask / urge / encourage / persuade / remind / warn / order / invite
　　 **B 族（人必须用 to sb 引出）**：**suggest** / recommend / propose / explain / describe / announce / mention / demand / insist
　　 **口诀测试**：能不能说 `explain me the rule`？不能 ⇒ explain 属 B 族 ⇒ `explain **to** me`。**suggest 和 explain 同族。**
　　 ⇒ 不是 suggest 特殊，是 advise 在 A 族、suggest 在 B 族。
　　 补充：B 族里 suggest/recommend/propose/demand/insist 的 that 从句用**原形**（虚拟）或 should：`I suggest that he **be** told`。
状态：上次复习 2026-08-20 ｜ 连对 1 ｜ 连错 0 ｜ 🎓否
- 2026-08-19 ❌ 首次（essay T1-08 第2次 S11）
