### 🔴 两个 ❌ 的共同结构
```
worsen  → 她写 worses     知道要 worsen 不要 deteriorate（难的部分对了）· 掉的是 -en
no choice but to hurt → 她写 but hurn   整个长块调对了 · 掉的是 to
```
**检索是对的，掉的是词尾和小词。** 与 08-10 诊断完全一致（"零件错，她 83% 本来就会"）。

### 她主动问的四个（第②类，最有价值）
1. **youth vs young** → `young`＝形容词；`youth`＝名词，只在固定块当定语（youth unemployment / hostel / club / culture）
2. **no + 复数？** → 都合法，看语义（预期一个→单数 / 预期多个→复数）；但 `no choice but to` 固定单数
3. **strain 配什么形容词** → 整块 `put a [severe/heavy/huge/financial] strain on X`
4. **a bit 是不是口语** → 是；学术写作换 `somewhat` 或直接删（对冲词把立场说软）
