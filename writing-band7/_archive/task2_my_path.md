## 3. Task 2 五种题型 — 最小骨架（30 秒能复述）

不背 docx 的完整模板，只记骨架。骨架背熟了，写的时候自然能填血肉。

### Type A — Agree / Disagree（最常考）

```
Intro:    改写题目 + 我的立场（largely agree / partly disagree / strongly disagree）
Body 1:   主要理由 + TEEL
Body 2:   次要理由 + TEEL  （或者：让步 + 反驳）
Conclude: 重申立场（换说法，不加新论点）
```

立场只有 3 种：largely agree / partly agree / largely disagree。**不要写 "balanced view"——会被判 Task Response 不达标。**

### Type B — Discuss Both Views（次常考）

```
Intro:    话题是争议 + 两边都谈 + 我偏向哪边
Body 1:   你不同意的那边 + TEEL（公正陈述，不要冷嘲热讽）
Body 2:   你同意的那边 + TEEL + 你的立场
Conclude: 承认对方有理 + 重申你的立场
```

**关键陷阱**：DBV 不是 A/D。如果你只写一边，Task Response 扣分。两边必须公平给笔墨。

### Type C — Problem / Solution

```
Intro:    改写问题 + 这篇会谈问题和方案
Body 1:   2-3 个问题（每个 1-2 句解释）
Body 2:   2-3 个对应方案（要和 Body 1 的问题匹配）
Conclude: 简短重申问题 + 方案
```

**关键**：方案要对得上问题。Body 1 说"教育不足"，Body 2 就要有"增加教育投入"。

### Type D — Causes / Effects（少见）

```
Intro:    改写现象 + 这篇会谈原因和影响
Body 1:   2-3 个原因
Body 2:   2-3 个影响
Conclude: 简短重申 + 一句预测
```

### Type E — Two-Part Question（少见）

```
Intro:    改写题目（提到两个问题）+ 这篇会分别回答
Body 1:   回答第一个问题
Body 2:   回答第二个问题
Conclude: 简短综合
```

**所有题型共享的 TEEL（每个 Body 段）**：

```
T  Topic sentence:  这段的中心主张（不要用 Firstly）
E  Explain:        为什么这样？怎么发生的？1-2 句因果链
E  Example:        具体例子（国家/政策/个人经验/假设场景，编的也行）
L  Link back:      这例子说明了什么 → 回扣到 T
```

**最容易忘的是 L**。大部分 5.5-6.0 的考生写到 Example 就结束了，缺 L 就停留在 6.0。

## 4. 三阶训练法（针对"主动输出弱"重新设计）

你的瓶颈不是"不会写"，是"想得到 → 落不到笔上"。所以训练要从"高度脚手架"逐步撤掉。**这套训练法和你口语的 cold production 训练同源**——都是把"理解"逼成"产出"。

### 阶段 1 — 仿写（脚手架最高）

**目的**：建立 TEEL 的肌肉记忆。不是抄，是结构对照下的复刻。

**流程**（每题 50 分钟）：
1. 选 **`task2_band7_examples.md`** 的一篇范文（20 篇，按话题分）。**不要用 docx 原文** —— docx 是冲满分写的（Band 8.5-9.0），这份是按 Band 7 降级过的，正是你的目标水平
2. 看 3 遍：第一遍读懂；第二遍画结构（每段功能 + TEEL 落到哪个句子）；第三遍合上原文
3. 自己写同题，不参考范文（25 min）
4. 对比：你的版本 vs 范文，分项打勾
   - 4 段结构✅/❌
   - 每段有 TEEL 4 要素✅/❌（最关键是 L）
   - 立场一致✅/❌
   - 250+ 词✅/❌
5. 把范文里有但你没用上的 1-2 个句式记到 `writing/coach/inventory.md`

**进入阶段 2 的标准**：连续 2 篇仿写，结构 + TEEL 都 ✅。

### 阶段 2 — 骨架填充（脚手架中等）

**目的**：拿掉"看着范文写"这个拐杖，但还有结构提示。

**流程**（每题 45 分钟）：
1. 我给你一个**骨架模板**（带每段第一句的 stem，比如 `It is often argued that ___. While I understand ___, I largely disagree because ___ and ___.`）
2. 你只填空、扩展 TEEL（30 min）
3. 我反馈：哪句 TEEL 不完整、立场是否一致、衔接是否生硬
4. 修改一遍（10 min）

**进入阶段 3 的标准**：连续 3 篇骨架填充，TEEL 完整 + 250+ 词 + 40 min 内完成（含修改）。

### 阶段 3 — Cold Production（无脚手架，模考态）

**目的**：完全模拟考试。

**流程**（40 min 严格限时）：
1. 我给题目和题型，没任何提示
2. 你 40 min 写完，立刻交
3. 反馈 + 自评（参考 §6 的 3 题自评单）

**进入考试的标准**：3 次 cold production，2 次拿到 Band 6.5 反馈。

## 5. 限量工具箱 — 先把这些用熟

> **原则**：少而精。docx 给了几十个表达，你记不住也用不出来。下面是**最小集合**——衔接词按 10 类功能 × 2-3 个 + 6 个核心句式 + 5 个"启动句"。这套东西用熟之后再扩。

### 5.1 衔接词速查（对应 docx Skill 6，每类只学 2-3 个）

> **原则**：docx Skill 6 每类给了 4-5 个选项，全背记不住也用不熟。下面每类**只挑 2-3 个**，先把这套用到肌肉记忆，再扩。

| 功能 | 用这个（2-3 选） | 不要用（5.5 级硬伤） |
|------|----------------|--------------------|
| 引入第 1 个论点 | The primary reason is that... / To begin with, | Firstly, |
| 加论点 | Furthermore, / Moreover, | Also, / And, |
| 引入第 2 个论点 | Another compelling argument is... / It is also worth noting that... | Secondly, |
| 转折 | However, / Nevertheless, | But, |
| 因果（给原因） | Owing to / Given that / Since | Because（句首） |
| 让步 | Admittedly, / Granted, | Although...（容易写残成残句） |
| 举例 | For instance, / A case in point is | For example,（不是不能用，但太多） |
| 表结果 | As a result, / Consequently, | So, |
| 强调 | Crucially, / It is worth noting that | Very important（不是衔接词） |
| 结论 | In conclusion, / On balance, | In a word,（中式） |

**用法纪律**：
- 一段不超过 1 个显性衔接词（除了 Body 段开头的 T 句不算）
- 同一篇文章不要重复用同一个（如已用 Furthermore，第二段加论点换 Moreover）
- 4 段全开头都用 Firstly/Secondly/Moreover/In conclusion = 自动 5.5

**进阶提示（6.5 之后再练）**：最好的衔接是"看不见的衔接"——靠句子之间的逻辑流动，而不是堆连接词。详见 docx Skill 6 后半段 "Invisible cohesion"。

### 5.2 六个核心句式（每个会用 = 6.5 起步）

```
1. It is often argued that [paraphrase topic].             — 开头万能起手
2. While I understand [opposing view], I [position].       — 表立场带让步
3. The primary reason for my position is that ___.          — Body 1 T
4. This is because ___. As a result, ___.                   — Explain 因果链
5. This demonstrates that ___.                              — L 回扣
6. In conclusion, [restate position in new words].          — 结尾起手
```

**这 6 个句式只要用对，4 段都有支撑句**。先把它们写到能不假思索地用，再加新的。

### 5.3 五个题型启动句（intro 第一句）

```
A/D:  It is often argued that ___.
DBV:  [Topic] is a subject of considerable debate.
P/S:  [Topic] has become an increasingly pressing issue in recent years.
C/E:  In recent decades, [trend] has [verb], prompting concern.
2-Pt: [Topic] raises two related questions: ___ and ___.
```

## 6. 三题自评单（每写完一篇问自己）

不用 docx 那种 4 维度全套自评。先就这 3 题：

1. **题型对不对**？（A/D / DBV / P/S / C/E / 2-Pt 之一，写下来）
2. **每个 Body 段有完整 TEEL 吗**？（特别检查 L 有没有）
3. **立场从 Intro 到 Conclusion 一致吗**？（不一致 = 5.5 天花板）

3 个都 ✅ → 6.0 起跳。
加上"无 5.5 级硬伤 + 250+ 词" → 6.5。
等这个稳定 3 篇之后，再开 docx 的全套 4 维度自评。
