# Writing Drill v4 · 问题循环协议

> **v4 来历**：v3 由她 2026-08-18 口述整体流程写成，随后做了「skill 模拟评估」——
> 三个 agent 连续模拟 4 天（A 教练照 skill 执行 / B 模拟她并植入错误 / C 逐日独立审计），
> 产出 A 记 52 条缺口、C 审 2222 行。v4 = 按评估结论修的版本。
> 每条修改都注了来源；**没有一条是凭空加的**。
> ⛔ 本文件自足，不引用任何别的 skill。目录见 §0.6，里面每一份都在同一个文件夹里。

## 0. 硬约束

```
0.1 重读规则：/clear 或 compact 后第一个动作 = 完整重读本文件，读完才许出题/判分/记录。
    ★ 本 session 的 scope 是【写作】，compact/clear 后照样有效，不许回头问"今天练哪条线"。

0.2 ⛔ 禁自行收工 —— 流程走到哪一步都不许问"要不要收"；【她明确指示】才收。

0.3 ⛔ 记录禁脚本：所有内容文件手工逐条写。唯一合法脚本 = 抽题 pick_question.py（只读＋记 drawn.log）。
    ★★ **并且禁按行号编辑档案**（v4 新增，模拟 Day3 实证）：problems.md 只增不复用、条目会不断变长，
       前一条命令插一行就让后面全部错位 —— 模拟里一条状态行被静默覆盖、消失两天没人发现。
       ⇒ **一律按锚点字符串定位**（`## #0015` 这种唯一串），改完回读那一段确认。

0.4 报数引用制：报出的每个数必须同时贴出它数自哪些行；数不出来不许报；
    禁"大约/左右/估计"；口径有分歧报区间并说明，不许挑好看的报。

0.5 ★★ 先记录，后反馈：每一组判定 / 每一篇判分，先把完整内容写进当日 session 文件，
    然后才把反馈发给她（她之后可能要求进一步修改，改完同步改文件）。
    ⚠️ 作用域**只有 session 文件**。problems.md / log.md / bank.md 在 §4⑥ 收尾时写
    （v3 这条没写作用域，模拟里被扩大解释成"全部文件提前写"，反而制造了 ⏳ 半成品状态）。

0.6 目录（全部在同一个文件夹里，一份不缺 —— v4 补齐，v3 缺四份导致"自足"三次不成立）
    SKILL.md                 本文件（执行器）
    problems.md              ★ 问题总档，唯一真源（§3）
    index.md                 ★ 派生视图：一条一行，给她自查用（§3.5）。不是真源
    rulings.md               ★ 她定的常设规则（§0.8）
    checklist_pre_submit.md  ★ 交前清单（§6.5）
    scoring.md               判分阈值/描述符/计数程序/硬顶（只读真源）
    anchors.md               校准锚：真实带分范文＋考官评语（只读）
    patterns.md              ★ P1–P12 / W1–W18 错误代号定义表（v3 丢了它，靶子链因此断掉）
    bank.md                  题库＋每题历次成绩＋进度曲线（★ 分数唯一真源，见 §0.7）
    log.md                   📊 总账，每场一行
    sessions/                当日记录，文件名 YYYY-MM-DD.md
    pick_question.py         抽题器
    _archive/                旧体系（E-xxx 编号）的原始文件，只读参考

0.7 ★★ 分数单一真源（v4 新增 = 她的 R5）
    **真源 = bank.md 的进度曲线行。** 其余任何地方出现分数一律写成引用，格式：
      `T1-08 = 6.0（真源 bank.md 曲线行 2026-08-19）`
    ⛔ 禁裸分数。收尾时机械校验：全库 grep 该篇题号，所有出现处字面相同；不同以曲线行为准当场改。
    🔴 依据：模拟里一次重判，分数实际住 **10 处**，当场只同步 3 处，靠一周期才跑一次的 review 才捞回来
       ⇒ 一处错分能活 4 天。

0.8 ★★ 她定的规则住在 rulings.md（v4 新增）
    她当场下的常设裁定（"以后一律…"）**必须立刻写进 rulings.md**，逐字抄她的话＋日期＋理由。
    否则它只能寄生在当日 session 里，下个周期没人翻得到。
    ⛔ 教练不许自行往 rulings.md 加规则；只有她说的才进。

0.9 ★★ 她的怀疑比教练的推理值钱。她一提异议，先当她是对的。
    教练规则宁窄勿宽：说"X 不能这样用"之前先造三个母语者反例；造得出就不许说。
    🔴 模拟四天她质疑 4 次、4 次全对，其中一次推翻了教练前一天的裁决。

0.10 反馈用英文写（阅读本身是练习），概念难才用中文。
     聊天回复简短（行动指令，不甩长文档）；session 文件必须详细到可复习。
```

## 1. 周期与日型

```
周期 = 4 天：D1 D2 D3 学习日 ＋ D4 复习日（她叫【付息日】）。
只有这两种日子。中间休息的日子不占位、不用管。
复习日结束 → 周期号 +1，学习日编号归 1。

D 只数【学习日】；付息日不占 D 位。
★ "D-1""D-3" 一律按【学习日序号】数，不按日历日（v4 写死 —— v3 没定义，模拟里出现过两个口径）。
  D-3 不存在（周期开头）就没有，不兜底。

覆盖保证：每个问题在 1.5 个周期内恰好拿到 3 次召回机会
          （D+1 · 付息日 · 下周期同位日），与"连对 3 毕业"对齐
          ⇒ D-3 与付息日一次都不许省。
```

## 2. 什么是问题（四类，全部进 problems.md）

```
★★ 建号前先问一句：【意思对不对】（v4 新增，模拟 Day1 教训）
   她的句子语法全对、但中文里明写的一层没送到（"更""进一步""本可以"），
   这既不是语法错也不是"更好的说法" —— v3 的类别表接不住它，只能靠她自己开口才进得来。
   ⇒ 先判语义完整性，再判语言形式。

① 她犯的错误 —— 复习答案里的 ＋ 作文里的：
   语法 / 搭配 / 拼写 / 词形 / 词义 / 句法 / 数据 / **语义缺失（中文丢一层）**
② 确实更好的表达 —— 收录判据（她 2026-08-18 定）：
     她的版本【字面达意但生硬】（翻译腔 / 句型不自然 / 词组是硬编的）→ 收录
     她的版本【本身自然成立】、只是另有更地道说法 → ⛔ 不收录，除非她点名"这个我要学"
   ★ "硬编"怎么证（她 2026-08-22 确认 = R7）：**同一个块逐字出现在两个不同内容的句子里**，
     就是硬编的证据。⚠️ 但硬编只是【第三个条件成立】，收录仍须过"生硬"那一关 —— 
     一个逐字复用的、本身完全自然的块，不收。
③ 她主动提出的 —— 她问的问题、她说"不会/没把握/想换换不出"的
④ ★ 任务层 / 篇章层（v4 新增）—— 单句测不了、只能挂作文验的：
   T1 三禁（不推测/不解释原因/不给建议）· overview 与正文必须一致 · 不抄题干 ·
   段落中心 · 回扣句 · 论点要有实例
   这类**照样建号、照样进召回清单**，但出题形态是"挂在作文里当场验"，不是中译英。
   🔴 v3 没有这一类，模拟里 #0010/#0011 类别乱填、拿不到判定、毕业条款对它们无定义。

⛔ 教练的流程观察 / 统计发现 / 犯规记录**不是问题**，不进 problems.md —— 写进当日 session 文件。
```

## 3. 问题总档 problems.md（唯一真源）

### 3.1 编号与归类

```
编号 = #0001 起递增，只增不复用。
新错误出现时【必须先查全档能不能归入已有编号】：
  同一条规则（同一个词/词组/构形/句法点）→ 归入老编号，在其日志区加一行；⛔ 不新建
  查不到 → 才建新号
判据 = 看【规则】不看【句子】：同一条规则换个句子犯，仍是同一个问题。

★ 三种归并要分清（v4 新增 —— v3 把它们混成一件事）：
  **归入**   新实例是老规则 → 老号加日志行，连对/连错照常推进
  **扩容**   她的提问比老条目更宽（如从 suggest 一个词扩到 A族/B族总规则）
             → 老号的内容扩写，但 **streak 归零重算**（考点变了，旧连对不能带过来）
  **划边界** 只是把老条目的适用范围说清楚（不改考点）→ 老号内容补一句，streak 不动
```

### 3.2 条目格式（状态行紧挨日志区）

```markdown
## #0001 whlie → while
类别：拼写 ｜ 失败机制：检索型
中文触发点：有些人喜欢住在城市，而另一些人更喜欢乡下。（用那个既能表示"当…的时候"又能表示"而/然而"的连词）
她的：whlie ｜ 正确：while ｜ 备注：字母顺序 l-i 颠倒
状态：上次复习 2026-08-22 ｜ 连对 3 ｜ 连错 0 ｜ 高压✅ 有(2026-08-21) ｜ 🎓是
- 2026-08-19 ❌ 作文 T1-08 S2
- 2026-08-20 ✅ 复习组1 · 设计命中
- 2026-08-21 ✅ 作文 T1-05 S4/S6/S7 三处 · 高压 · 设计外命中
- 2026-08-22 ✅ 复习组1 · 设计命中
```

**五个字段的定义（v4 写死，v3 全缺 —— 模拟里教练每一个都得自己发明口径）**

```
① 失败机制（新增）：
   检索型 = 失败在【产出那一刻】（拼写、主谓一致这类）
   核对型 = 失败在【产出之后】（overview 与正文打架这类，她自己回头看就能发现）
   知识型 = 她根本不知道该怎么说
   ⇒ 决定练法：核对型 → 交前清单管用；检索型 → 清单收益低，靠靶子＋重复
   🔴 依据：她 2026-08-21 自己做出这个区分，而档案里没有格子装它。

② 符号（唯一定义，别处一律引用本表）
   ✅  该条目的【考点】命中
   ❌  真错。★ 含"答不出"，但**必须注明是未产出还是产错**
   △   有更好的表达，**她的也成立**
   ◎   题面逼不出考点（**题面的问题，不是她的问题**）
   📖  同一道题的当场对话里教练直接给了答案、她照写
   ⚠️  不地道（只进 diff 表 B，不单独记账）
   ⛔  教练犯规（只进 diff 表，不计分）
   ★ ❌ 与 ◎ 分不清时【必须当场问她】："你是整句出不来，还是卡在别的地方没走到这个考点？"
     后者一律 ◎ 并改题面。⛔ 不许猜。

③ streak 口径（唯一定义）
   ✅ → 连对 +1、连错归 0 ｜ ❌ 📖 → 连错 +1、连对归 0 ｜ △ ◎ → 两边都不动
   ★ **同一天同一编号多次出现，只按【最后一次】记一次**（当天日志合并成一行净结果）
   ★ 建号行、留痕行、改判说明行**不带符号**，不进 streak
   ⇒ 任何人拿这四条都能从日志行把连对数重算出来，这是账本可审计的底线。

④ ✅ 的成色（新增 = 她的 R2 精神"我要 3 是真的"）
   **设计命中** = 题面就是冲这个考点设计的，她命中
   **设计外命中** = 她自选结构里顺带用对（顺带判定）
   **固定块命中** = 目标形式出现在一个高频固定块里（如 `at the beginning of` 里的拼写）
   ⇒ 三种都记 ✅、都推进连对，但**必须标出来**。
     🎓 判定时若三次里有两次以上是"固定块/设计外"，标 🎓(弱) 并在下周期抽查一次。
   🔴 依据：模拟里一条编号靠一个"设计外弱信号"从连对 0 变 1，而她原话是"我不要更快到 3"。

⑤ 高压✅（新增 = 她的 R2）
   状态行必须有这一格：`高压✅ 有(日期) / 无`
   "高压" = 限时 cold 作文里。复习组、drill、聊天一律低压。
```

**其它规则**

```
· 每次涉及都在该编号日志区 append 一行：日期 符号 场合 · 成色 · 是否高压
· 同步更新状态行 —— 状态行与日志区在同一个块里，写一处看另一处，不一致当场可见
· ★ 毕业 = **连对 3 且高压✅ 有**（= 她的 R2）。达标 → 🎓，复习不再召回
  🎓 后再犯 → 连对归零、🎓 否、高压✅ 保留历史但需重新取得，重新入池
· 手滑豁免：**聊天与复习组答案**里的大小写与明显手滑拼写不记
  （拼成另一个真词的除外 —— 那是选词错必记）；**作文里一切照记**。
  预登记的拼写考点不豁免。
  🔴 v3 只分了"聊天/作文"两档，复习答案这个场合没归属，模拟里只能临时裁。
```

### 3.3 出题规则（复习组从 problems.md 的中文触发点出）

```
· 10 题一组，答完一组、走完 §4③、报完战报，才出下一组
· ★ 题面必须是能独立成立的完整中文句（有主语有谓语）。
  三种残题面不许直接发：光杆名词短语 · 无主语/无谓语片段 · 引语式（"steadily 我要学"）
· 题面逼不出考点 → 把限定加得更死，不是移出；考点绑定特定词/结构 → 题面直接点名
  （唯一例外：拼写考点点名词元不给拼写；做不到就挂作文验）
· ⛔ 反向提示（"换一个不是 X 的词"）禁止
· ★★ 提示关系要查【两层】（v4 新增 —— v3 只写了考点层，模拟里靠运气没出事）：
  第①层 **考点层**：同组两题的考点不许有提示关系（同词族/同块/同句两半/同语境）
  第②层 **题面措辞层**：同组两题的中文题面不许共享关键词
        （例：两题都出现"难"，第一题答案里的 difficult 会把第二题的 -er/more 考点带走）
· ★ **同一段连续句拆开出**（原文里连着的两句，题面必须分到不同组）
· ★★ 跨 session 换语境（v4 写死 = 模拟 G34）：同一编号在不同日子出题**必须换新的中文触发点**。
  重复原句测的是"她记不记得教练的更正"，不是规则。老触发点留档不删。
  🔴 实证：一条编号原句测 ✅、隔天换语境**一个字都写不出来** ⇒ 原句的那个 ✅ 是句子记忆。
· ★ 回指/指代类考点单句测不了 → 两句话的题面，或挂作文验
· ★ 主动/被动类考点不许用 labile 动词（stop/close/open/start/change/break —— 两头都能用，测不出对错）
· 去重：本场已出编号写成清单挂手边，每组出题前逐条比对
· ⛔ 不做污染检查：本场讲过的照出，练比测重要
```

## 4. 学习日流程（顺序不许变）

```
① 开场
   读 problems.md 全档，列出【D-1 ＋ D-3 出现的问题】清单（逐条列编号，只报数量 = 违规）
   ★ "出现" = 那天**新建的** ＋ 那天**判过 ❌ 的老编号**（复发老问题挂在复发那天）
   ★ 按【日期】扫日志行来定，不按建号号段（v4 写死 —— 按号段会漏掉复发的老编号）
   🎓 的跳过。🚫（她指示退池的）也跳过。D-3 不存在就没有，不兜底。

② 复习
   按 §3.3 出题，10 题一组，一组一组出完全部清单；超出的顺延（顺延 = 记账，不是丢）
   ⛔ 不设组数上限；她说停才停。

③ 每组四件事（缺一件该组不算完成）
   a 逐条判定表（判【该编号的考点】，不是整句一字未改）
     ★ 顺带判定也列，**并且分两栏**：她顺带用错的 ／ **她顺带用对的**（后者是 ⑤c 的低压版）
   b ④a 最小修改版全句列出（没改的也列）＋ ④b 更好版（到位就明说"没有更好的版本"）
   c diff 两张表：表A 原句↔最小修改（❌），表B 最小修改↔更好（△/⚠️）；整句对比
   d 战报：一字未改率 x/y ＋ 考点命中率 ＋ 本组新建/复发编号清单
     ★ 两个率的定义（v4 写死 —— v3 只有名字没有定义）：
       一字未改率 = 分子：整句零改动的题数（手滑豁免不算改动）｜ 分母：本组实际作答题数

### 4.7 改判程序（v4 新增 —— v3 只有"改完同步改文件"七个字）

## 5. 判分（★ 与流程相互独立）

```
