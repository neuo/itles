# 清单本体（原件逐字，来自 `_archive/profile.md §4`）

## T1

```
1  句子片段（`Regarding X.` 后面是逗号不是句号）
2  `specific` → 删掉或换 one / a particular
3  `all of / both of` + 名词 → 加 the 或去掉 of
4  冠词（the + 已知名词 / an + 元音）
5  动词（rose/climbed/fell；每个分句都有限定动词）
6  时态（有年份 ⇒ 全篇过去时）
7  拼写 + 每个数字回图核一遍          ← ⚠️ Q1 冲突点
```

## T2（对着 P1–P12，代号定义见 patterns.md）

```
1  拼写扫一遍（尤其 import / neccessary / goverment / resouces）      ← P5 · ⚠️ Q1 冲突点
2  每个动词后的介词对不对                                             ← P1
3  每个可数名词有没有冠词                                             ← P2
4  主语和动词跨过长名词短语后还一致吗                                 ← P4
5  有没有逗号当句号用                                                 ← P7
6  每个 body 段最后有没有 `Therefore, ...`                            ← P8
7  词数 ≥ 250
8  每个换上去的词，是我见过的还是刚拼的？                             ← P11
9  并列的两边同形吗 · 句首大写了吗 · 修饰语在它该在的位置吗           ← P12
```
