# T1 复用池（固定小工具集 — 副词/动词/语法/结构）

> **契约（suzy 7/6 定）**：后续**所有 T1 成稿默认只从这个池里取词/句式**，尽量复用她已见过的，不随篇引入新词。**池慢慢长**——只有当某张图确实需要一个新表达时才加一条进来（加时标日期），这样她的学习范围一直是这一页。
> **池的作用**：篇**内**用池里成员保持多样（别一个词连用 5 次）；篇**间**反复用同一批（不扩散）。这样"要学的"始终是这一张纸。
> **来源**：从 7/6 三篇成稿（语言 / 她自己写 / 营养素）实际用过的词固化而来——她都见过。

>
> **⚠️ 池是 FLOOR 不是 CEILING（7/7 更正）**：池 = 你**卡住时**保底一定调得出的安全词。**你自己会、且用对的词，哪怕不在池里，随便用、不扣分、不用改**——它已在你脑子里，零学习成本，禁它没意义（你原话是"尽可能复用**以缩小要学的范围**"，复用一个你已会的词并不缩小任何范围）。池只管两件事：① 别让**我**塞你没学过的新词（那才增加你要学的）；② 你**自己想避开**的极少数词（见 C 组，各有具体原因，**不是"凡池外皆禁"**）。

## A. 升降动词（**有时间轴**的图；主语必须是"量"proportion/percentage/share/figure/number，❌ 别用 people）

| 方向 | 主用（先背这些） | 备用 |
|---|---|---|
| ↑ 升 | **rose / grew / increased** | went up · climbed |
| ↓ 降 | **fell / dropped / decreased** | declined |
| ↓↓ 暴跌 | **plummeted**（7/7 入池,折线图 6,500→600 逼出）| — |
| ↑ 回升 | **recovered to / a recovery**（7/7 入池）| rebounded |
| = 平 | **remained stable / stayed the same** | remained unchanged · held steady |
| 变平 | **levelled off**（7/7 入池,先动后平用这个）| — |
| 峰/谷 | **a peak of X / peaked at**（7/7 入池）· the highest/lowest point on the graph | — |
| 特殊 | **halved / doubled** | — |

配套名词（升降的"量"）：`a rise / an increase / a decline / a drop`（`there was a sharp rise in ___`）。

## B. 占比/分布动词（**无时间轴**的分布图；用**一般现在时**，别用 rose/fell）

- **accounts for** — `Dinner accounts for the largest share, at 43%.`
- **makes up / make up** — `Snacks make up 42%.`
- **contributes / provides / adds** — `Breakfast provides 14% of sodium.`
- **comes next** — 排名衔接 `Dinner comes next at 23%.`
- **is the (main) source of** — `Dinner is the main source of sodium.`

## C. 副词（**小而常见的保底集** — 你 7/6 点名管这个；池是 floor，你会用的词照用）

| 功能 | 保底用这些（卡住时的安全牌） |
|---|---|
| 幅度大 | **sharply / significantly**（markedly / dramatically 你会用也照用）|
| 幅度小 | **slightly** |
| 约数 | **roughly / about / just over / just under** |
| 配对两组 | **respectively**（她的招牌）|
| 比较强调 | **far**（far more/less）· **only / just** |
| "差不多" | **quite / fairly**（similar）|

- **唯一主动避开**：`broadly`——你 7/6 自己要求换成更常见的（→ quite/fairly）。
- **不是词的问题、是别叠**：`completely stable at exactly 10%` = 两个冗余强调词叠用 → 留一个（completely / exactly / stagnant / dramatic 这些词本身都没错）。

## D. 比较 / 最高级

- the **largest / smallest** share · the **highest / lowest**
- **one of the smallest / among the largest**（⚠️ 有 **tie 并列**时用这个，别说 the smallest — W12）
- **followed by** X at Y%
- **whereas / while**（对比枢纽）
- **more / less than** · **twice as much as** · **almost double** · **well above / far below**

## E. 连接 / 结构信号（固定就这几个，别堆砌）

- `Overall,` — 开 overview
- `In contrast, / Conversely,` — body 间转折
- `The remaining … :` — 冒号打包剩下的小项
- **分组 topic 句**（T1 高分手法，body 开头先声明分组逻辑再上数字）：
  - 相似组：`The patterns for A and B are quite similar.`
  - 不同组：`X follows a different pattern.`

## F. 语法框架（固定复用这 7 个）

1. Intro：`The chart(s) show(s) … in / over …`（改写题目）
2. `X accounts for the largest share, at Y%.`
3. `A and B rose from X to Y and from M to N respectively.`（respectively 配对）
4. `the figure for X rose / fell from … to …`（严谨主语=量）
5. `the proportion of students who … + 动词`（proportion of + 定语从句）
6. `…, followed by X at Y%.`（participle 排名，不另起句）
7. Overview：`Overall, X …, whereas Y …`（两根不同柱 + 对比）

## G. Process 图专用（无数字 → 现在时 + 被动 + 顺序词；7/8 加）

> Process 和数据图**完全两套**：没数字（不用 rise/fall/%/比大小），全程**一般现在时 + 被动语态**，靠顺序词串。

- **顺序词**：`First / To begin with` · `Next` · `After this / Then` · `Once X is done` · `At this stage` · `Finally`
- **被动框**：`X is [done]` · `X is then [done]` · `Y is added to X` · `X is turned into Y` · `X is used to [do sth]` · `X is released`
- **overview（不写数字）**：几个阶段 + 起点/终点 + **线性还是循环**。`The diagram shows how X is made in [N] stages, beginning with ___ and ending with ___.` → 循环则 `the process forms a (continuous) cycle`。
- **循环收尾**：`the CO₂ released is reabsorbed by the plants, so the cycle repeats` / `this completes the cycle`。
- **扩词 3 招（Process 天生易写短，都是加真信息不注水；~10 词/招）**：
  ① 加"目的/结果"——步骤后补 `to produce ___` / `so that ___` / `which produces ___`。
  ② 加"手段/地点/施动者"——被动步补 `using ___` / `in a ___` / `by ___`。
  ③ **循环意义收尾（最值）**——结尾补 `..., which makes ethanol a renewable fuel` / `so the whole process is renewable`（既扩词又是 so what）。

## H. Map 图专用（两图对比 → 变化 + 方位词 + 被动；7/8 加）

> Map 又不同：描述**两个时间点之间的变化**（不是数据、不是流程）。**1950 用过去时，today 用现在时**；变化用**被动**；靠**方位词**定位；**按区域分组**（别跳来跳去）。

- **变化动词（被动）**：`was built / constructed` · `was demolished / removed / knocked down` · `was replaced by` · `was converted / turned into` · `was extended` · `remained unchanged / was retained` · `were added`
- **方位词**：`in the north / south / east / west` · `to the north of X` · `in the top-right corner` · `next to / beside / adjacent to` · `opposite` · `alongside / along (the river/road)` · `in the centre`
- **overview 框架**：`Overall, the site was transformed from a [working farm] into a [tourist site], although [the crop fields in the west] remained unchanged.`

## 硬规则（每篇必守，来自 error_log）

1. **升降主语=量,不是人**：`the figure for X rose` ✅ / `those who spoke X rose` ❌（rise/fall/climb/drop 主语要 proportion/percentage/share/figure/number）。
2. **说 the largest/smallest 前查 tie**：有并列 → `one of the smallest / among the largest / tied with X`。
3. **无时间轴 = present tense + 比较语言**（accounts for/whereas），**有时间轴 = 过去时 + 升降语言**（rose/fell）。
4. **overview 抓两根不同柱**，含 **odd-one-out**（和别人不一样的那个）；先问"谁最大?谁不一样?"再动笔。
5. **数据全覆盖 + 准确**（每类给真实数字，别只说"占剩下的"）。
6. **两线/多线图 = 边描述边对比**（治 W6）：别两段各说一条线；**每描述一段就带一句跨线关系**——用 `whereas / meanwhile / in contrast / A outnumbered B → more X than Y`。题目"make comparisons"的分主要在这。（7/7 Gemini 版对照得出：它边描述边比，她两段分开说漏了对比。）
7. **别信 AI 的数**：AI（含 Gemini）写的 T1 数字也会读错图（7/7 它把 2015 关店 600 写成 500）→ 自己对着图核一遍。
8. **多图题（2–3 张图，7/8 加）**：① overview **必须覆盖每张图**（或抓跨图关系），不能只说一张 ② body 按「**静态快照 / 时间趋势**」分组 ③ 表格**别逐行报**，按大类合并 ④ **跨图错配最值分**（如"某群体占会员多却借得少"）。
