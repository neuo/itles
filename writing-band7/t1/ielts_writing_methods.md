**提分路径**：写作不需要最早启动——第3周开始阅读输入，第4周开始限时练习。用"先读后写"策略：没有方法论就盲写只会强化错误，先建立正确的结构认知再动笔。

## 三个核心训练法

> 和口语一样拆成三个递进的训练法：**范文输入法**、**限时仿写法**、**模考法**。前一个是后一个的前置条件。

---

### 训练一：范文输入法（被动输入，45-60分钟/天）

**目标**：建立写作的结构认知——知道Task 1和Task 2各自怎么写、什么结构、什么句式可用。

**什么时候用**：第3周（写作输入周）。只读不写。

#### 完整流程（7天）

```
Day 1：Task 1 基础框架（45min）
  Step 1 · 读 Task 1 Guide — Skill 1-2（30min）
    - Skill 1：四段式结构（改写题目→总览→Body 1→Body 2）
    - Skill 2：同义改写技巧（题目→第1段，不能照抄）
    - 边读边标记：每个Skill的核心句式抄1句
  Step 2 · 用自己的话总结四段结构（15min）
    - 写下每段的功能和大约词数

Day 2：Task 1 数据描述技巧（45min）
  Step 1 · 读 Task 1 Guide — Skill 3-4（30min）
    - Skill 3：Overview写法（概括总体趋势，不写具体数字）
    - Skill 4：常用句式库（上升/下降/波动/稳定/最高/最低）
  Step 2 · 把句式库中的10个核心表达抄下来读3遍（15min）
    - 上升：increased / rose / climbed / grew
    - 下降：decreased / fell / dropped / declined
    - 波动：fluctuated / varied
    - 稳定：remained stable / stayed constant
    - 约数：approximately / roughly / just over / slightly under

Day 3：Task 1 进阶技巧（45min）
  Step 1 · 读 Task 1 Guide — Skill 5-7（30min）
    - Skill 5：时态选择（过去/现在/将来看图表时间轴）
    - Skill 6：数据筛选（选最突出的3-4个数据点，不要面面俱到）
    - Skill 7：约数表达（around / approximately / just under/over）
  Step 2 · 自测：看一个Line Chart，口头说出四段各写什么（15min）

Day 4：Task 1 范文精读（60min）
  Step 1 · 读 Line Chart 和 Bar Chart 范文（30min）
    - 不是泛读——逐句看：这句在哪个段？用了什么句式？
    - 标记好句（至少标5句）
  Step 2 · 读 Pie Chart 和 Table 范文（30min）
    - 同样逐句分析+标记好句
  同时参考：third/雅思小作文万能句式、词汇总结.pdf

Day 5：Task 1 特殊图型（60min）
  Step 1 · 读 Process Diagram 和 Map 范文（30min）
    - 注意：Process用被动语态，Map用方位词
  Step 2 · 标记好句 + 自己复述结构（30min）

Day 6-7：Task 2 入门 → **不在这里**
  T2 的输入流程见 `task2_my_path.md` §8（必读的 docx Skill 1/3/4/5 + Skill 8 前 6 + 选一篇 task2_band7_examples.md 的范文拆结构）
  本文档原本的"读 docx Skill 1-8 + Type A/B/C 范文"流程已废弃，因为：
  • Skill 7 my_path 标为永远跳过（Band 7+ 语法会写残扣分）
  • 题型是 5 种（A/D, DBV, P/S, C/E, 2-Pt），不是 Type A/B/C
  • Day 6-7 改为按 my_path §8 节奏自由分配
```

#### 范文输入法的内部验收

| 检查项 | 达标标准 |
|---|---|
| Task 1 结构 | 说出四段各自的功能和大约词数 |
| Task 1 句式 | 背出上升/下降/波动/稳定/约数各1个表达 |
| Task 2 题型 | 详见 `task2_my_path.md` §3（5 种题型骨架，30 秒能复述） |
| Task 2 段落公式 | TEEL（Topic→Explain→Example→Link），详见 my_path §3 末尾 |
| 范文分析 | 能指出一篇范文中每段的功能 |

**验收通过 → 进入训练二：限时仿写法**

### 训练二：限时仿写法（主动输出，60分钟/天）

**目标**：从"看懂范文"到"自己能写"——在限定时间内写出结构清晰、词汇准确的文章。

**什么时候用**：第4周（Task 1），第6-7周（Task 2）。

**前置条件**：训练一范文输入法验收通过。

#### Task 1 限时仿写流程（35min/篇 含复盘）

```
Step 1 · 审题+规划（3min）
  - 看图，30秒判断图表类型和时态
  - 写下：总体趋势是什么？（一句话）
  - 列出2-3个最突出的数据特征

Step 2 · 写作（17min）
  - 第1段：改写题目（2句，≤30词）
  - 第2段：总览Overview（2句，概括总体趋势，不写具体数字）
  - 第3段：Body 1（3-4句，描述主要特征+数据）
  - 第4段：Body 2（3-4句，描述次要特征+数据）
  - 目标：≥ 150词

Step 3 · 检查（2min）
  - 快速通读：时态一致？数据准确？拼写错误？

Step 4 · 自评（13min）
  - 对照评分标准逐项打分：
    □ Task Achievement：有Overview吗？覆盖主要特征了吗？
    □ Coherence：四段结构清晰？衔接词使用了吗？
    □ Lexical Resource：有同义改写吗？约数表达用了吗？有没有重复用词？
    □ Grammar：时态/主谓一致/有复杂句吗？
  - 标记最大的1-2个问题，下一篇重点改进
```

### 训练三：模考法（评估，120分钟/天 含复盘）

**目标**：完整模拟考试写作环节（60min T1+T2），找到并修补最后薄弱点。

**什么时候用**：第8周。考前阶段定期进行。

**前置条件**：训练二限时仿写法验收通过。

#### 完整流程

```
Step 1 · 模考（60min 严格限时）
  - T1：20min（审题2min + 写作17min + 检查1min）
  - T2：40min（审题+提纲5min + 写作33min + 检查2min）
  - 不允许超时，到时间立刻停笔

Step 2 · 逐项自评（30min）
  T1 评分：
    □ Task Achievement（是否有效回应，有无Overview）
    □ Coherence（段落衔接，信息组织）
    □ Lexical Resource（词汇多样性，同义替换）
    □ Grammar（复杂句，错误密度）
  T2 评分：
    □ Task Response（是否正面回答，立场是否清晰一致）
    □ Coherence（论证逻辑，段落过渡）
    □ Lexical Resource（话题词汇，用词精准度）
    □ Grammar（句型多样性，准确度）

Step 3 · 制作纠错卡（15min）
  - 把反复出现的错误写成卡片
  - 格式：错误类型 | 错误示例 | 正确写法
  - 每次模考前翻一遍纠错卡

Step 4 · 针对性补练（15min）
  - 最弱的1个评分维度，找1篇范文重读
  - 或针对最弱话题重写1段Body
```

#### 模考训练节奏

```
第8周：
  Day 1：模考1（限时60min T1+T2）
  Day 2：自评模考1 + 逐项打分 + 制作纠错卡
  Day 3：模考2（换话题）
  Day 4：自评 + 对比模考1进步
  Day 5：模考3
  Day 6：总结三次模考共性错误 + 纠错卡更新
  Day 7：针对弱点话题限时写1篇
```

#### 模考法的内部验收

| 检查项 | 达标标准 |
|---|---|
| 模考次数 | ≥3次 |
| 时间控制 | T1 20min + T2 40min 不超时 |
| T1 质量 | 150+词，四段完整，数据准确 |
| T2 质量 | 250+词，论点清晰，语法错误≤3处/篇 |
| 纠错卡 | 已制作，反复错误已识别 |

## Task 1 六种图表类型速查

| 图表类型 | 时态 | Overview重点 | 常见陷阱 |
|----------|------|-------------|---------|
| Line Chart | 看时间轴 | 总体趋势（上升/下降/波动） | 不要逐年描述，选关键转折点 |
| Bar Chart | 看时间轴 | 最大/最小差异 | 分组对比，不要逐条描述 |
| Pie Chart | 通常无时间 | 最大/最小占比 | 必须写百分比，注意"其他"类 |
| Table | 看时间轴 | 极值+趋势 | 数据多，必须筛选，不能全写 |
| Process | 无时间 | 几个阶段+起终点 | 用被动语态+顺序词 |
| Map | 看是否有时间 | 主要变化+不变的部分 | 用方位词（north/adjacent to） |
