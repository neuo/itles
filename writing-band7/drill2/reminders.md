## R1 · 动词词尾被吞掉（构形，不是知识）

**扫什么**
```
have / has / had ＋ 下一个词       它是过去分词的样子吗？（-ed ／ 第三栏 risen grown fallen taken）
be 动词 ＋ 下一个词                 -ing 还是 -ed？被动有没有漏掉 -ed？
一般过去时的规则动词                -ed 在不在
```
**高危词**（只差一两个字母，掉了还像个词，回读扫不出来）
```
double/doubled · increase/increased · improve/improved · decline/declined
reduce/reduced · rise/risen · fall/fallen · grow/grown · change/changed
```
**实例账**
```
2026-08-22 组1 第 2 题　`the population … has double`　→ `has doubled`
```
**为什么不建条目**：她 08-19、08-20 两次写 `has doubled` 都对 ⇒ 规则在。

## R2 · 名词与主谓的 -s（构形，不是知识）

**扫什么**
```
每一个可数名词      该复数的写复数了吗
每一个谓语          主语是单是复？中心词是 of 前面那个吗？
第三人称单数        -s 在不在；-s/-sh/-ch/-x/-z 结尾要加 -es
```
**实例账**
```
2026-08-20 作文 S2　`the reward it yields **are** far greater`　→ `is`
2026-08-20 作文 S17　`drive these **cost** down`　→ `costs`
   ★ 同篇四个长／复杂主语全对 ⇒ **长句她会盯，短句不设防**
```
**⚠️ 与现有条目的关系（待她裁定，教练不自行处置）**
```
她 08-22 说「和单复数一样，重复练习没有用」。但 #0048 #0055 #0074 #0251 仍在复习池里，
而且「数的一致」还是当前靶子2。教练**没有自行把它们移出池子** —— 那是她的决定。
两条路，等她定：
  甲 保持现状：条目留在池里，R2 只作为额外的扫描动作
  乙 比照 #0322：把这几条移出复习池，只留 R2 常驻提醒
```
