# 常驻提醒清单（reminders.md）

> **2026-08-22 她定的机制。** 原话：
> 「**322 不建，这类（和单复数一样）重复练习没有用，关键在于你需要不断提醒。**」
>
> **这个文件解决的问题**：有一类错，她**规则本来就会**、低压也写得对，
> 只在压力下把词尾／标记吞掉。给这类错建条目 ⇒ 反复出题 ⇒ 她反复答对 ⇒ 毕业 ⇒ 下次照错。
> 复习池对它无效，**它需要的是教练在每一次判定里主动扫、主动点名**。
>
> ⇒ 这里的条目**不进 problems.md、不占编号、不进复习池、没有毕业线**。
> ⇒ 教练的义务：**每组判定必扫全部 R 项，扫到就在反馈里当场点名**（不管是不是本组考点）。
> ⇒ 判定档位照旧（❌／△），只是不建条目、不推进任何 streak。

## R1 · 动词词尾被吞掉（构形，不是知识）

**扫什么**
```
have / has / had ＋ 下一个词       它是过去分词的样子吗？（-ed ／ 第三栏 risen grown fallen taken）
be 动词 ＋ 下一个词                 -ing 还是 -ed？被动有没有漏掉 -ed？
一般过去时的规则动词                -ed 在不在
```
**高危词**（只差一两个字母，掉了还像个词，回读扫不出来）
```
double/doubled · increase/increased · improve/improved · decline/declined
reduce/reduced · rise/risen · fall/fallen · grow/grown · change/changed
```
**实例账**
```
2026-08-22 组1 第 2 题　`the population … has double`　→ `has doubled`
```
**为什么不建条目**：她 08-19、08-20 两次写 `has doubled` 都对 ⇒ 规则在。

## R2 · 名词与主谓的 -s（构形，不是知识）

**扫什么**
```
每一个可数名词      该复数的写复数了吗
每一个谓语          主语是单是复？中心词是 of 前面那个吗？
第三人称单数        -s 在不在；-s/-sh/-ch/-x/-z 结尾要加 -es
```
**实例账**
```
2026-08-20 作文 S2　`the reward it yields **are** far greater`　→ `is`
2026-08-20 作文 S17　`drive these **cost** down`　→ `costs`
   ★ 同篇四个长／复杂主语全对 ⇒ **长句她会盯，短句不设防**
```

## 用法（写死）

```
每组判定收尾前，教练拿这张表对她本组全部答案扫一遍。
扫到 → 写进当组「顺带判定」栏，注明 R 编号，并在反馈里当场点名。
扫不到 → 战报里写「R1/R2 本组零命中」。⛔ 不许不报。
```

## R3 · 固定块里那个小零件掉了（2026-08-22 新增）

**扫什么**
```
固定块里的 the      speak / tell **the** truth · in **the** long run · on **the** whole
                    ⛔ 但泛指抽象名词不加：`truth is relative` ✅（讲"真理"这个概念）
所有格撇号          five **years'** experience · two **weeks'** notice · a **day's** work
                    ＝ experience of five years，是所有格不是复数
连字符              a **five-year** plan（作定语，year 不加 s）↔ **five years** of planning
```
**实例账**
```
2026-08-22 组2 第 5 题　`speak truth`               → `speak the truth`
2026-08-22 组2 第 9 题　`5 years working experience` → `five years' work experience`
```
**为什么放这里不建条目**：三样都是"块本身记住了、块里那个不起眼的小零件掉了"，
与 R1 R2 同一个机制（压力下最轻的成分先掉），不是"不知道这个块"。
⚠️ **可推翻**：如果后面出现证据表明她根本不知道 `speak the truth` 这个块本身，
　 那就不是掉零件而是词汇缺口 ⇒ 从 R3 移出去，正式建条目。
