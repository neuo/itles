> 本文档从v5手册的全部回答中逆向提取模式，按"学习顺序"编排。
> 掌握这套模板后，面对任何题目都能快速组织出250词P2 + 4-5句P3。

# 一、P2 结构模板（5种题型 × 完整骨架）

---

## 模板1：描述一个人（覆盖约16题）

### 骨架（5段，共250词）

```
【第1段·引入 40词】
交代人物身份 + 你们的关系 + 认识多久

【第2段·这个人的核心特质 60词】
他/她最突出的特点是什么 + 日常表现

【第3段·一个具体故事 80词】
用一个完整的小故事来证明这个特质
（时间 → 背景 → 他/她做了什么 → 结果）

【第4段·细节延伸 40词】
这个故事之外的补充细节，或者这个特质的另一个体现

【第5段·你的感受/影响 30词】
他/她对你的影响 + 你的评价/感悟
```

### 实际句式库（从回答中提取）

**第1段·引入**
```
① I'd like to talk about my [college friend / grandfather / son], [Name].
   We [both studied CS at university / have known each other for nearly 20 years].
   He's now [a technical director at an AI startup].

② The person I want to describe is [Name] — [关系].
   [一句话交代背景].

③ I want to talk about [Name] [from a different angle this time / 
   specifically about his/her remarkable ___].
```

**第2段·核心特质**
```
① He is by far the most [organised / creative / generous] person I know.
   Every [January / weekend / evening], he [具体行为]...

② What distinguishes him from others is [his approach / his philosophy / 
   his unwavering commitment to ___].

③ He's the kind of person who [会做什么], even when [困难条件].

④ Although he [A身份], he's also [B意外特质] — [一句话描述].
```

**第3段·具体故事**
```
① The most impressive example was when [事件背景].
   [其他人怎么做]. [他/她怎么做].
   Within [时间], [结果]. 

② I remember one particular incident — [背景].
   Instead of [常规做法], he [不同做法].
   The result was [结果].

③ The best example happened [时间] at [地点].
   [2-3句描述事件经过].
   [1句结果].
```

**第4段·延伸**
```
① But his [特质] extends beyond [刚才的故事].
   He also [另一个例子]...

② What really sets him apart is [更深层的品质].
   He once told me: "[一句引用]."

③ On top of that, he [另一个习惯/行为]...
```

**第5段·感受**
```
① His [habit / philosophy / example] has genuinely influenced me.
   I've started to [你的改变]...

② I really admire [him/her] for this.
   In today's fast-paced world, [感悟].

③ [He/She] is a constant reminder that [一句道理].
```

## 模板2：描述一个事件/经历（覆盖约19题）

### 骨架（5段，共250词）

```
【第1段·引入+背景 40词】
时间 + 地点 + 和谁 + 什么情境

【第2段·事件开端 50词】
事情是怎么开始的 / 你当时的状态或期待

【第3段·核心经过 80词】
发生了什么（最重要的2-3个细节）
用感官描写：看到/听到/感受到

【第4段·转折或高潮 40词】
意外的部分 / 情感高峰 / 结果

【第5段·反思+感受 40词】
你从中学到了什么 / 这件事如何改变了你
```

### 实际句式库

**第1段·引入**
```
① This happened about [时间] ago, on a [天气/季节] [时间段]
   in [地点]. I was [doing what] with [谁].

② I'd like to describe something that happened during [事件/旅行/活动].
   It was [时间], and I was at [地点].

③ About [X] years ago, I faced [a situation / a decision / an experience]
   that [turned out to be / ended up becoming] [评价].
```

**第2段·事件开端**
```
① At first, everything seemed [normal / straightforward / simple].
   [描述初始状态]...

② I [wasn't expecting anything unusual / was feeling nervous / had mixed 
   feelings], because [原因].

③ The [event/day/trip] started with [具体细节]...
   My [son/wife/friend] was [doing what]...
```

**第3段·核心经过（感官描写）**
```
视觉：The [场景] was [形容词] — [具体描述].
      I could see [细节].
      
听觉：The sound of [什么] filled the [空间].
      My son was [saying/laughing/crying] "[引语]".
      
触觉/体感：My palms were sweating. / The air was [cold/warm/still].
           I could feel [tension/excitement/relief] building.

情感：I felt a rush of [accomplishment/happiness/anxiety].
      In that moment, [感受].
      My heart was [pounding/racing/full].
```

**第4段·转折**
```
① Then something [unexpected / beautiful / remarkable] happened.
   [描述转折]...

② What made it truly special was [细节].
   [1-2句描述].

③ The [turning point / highlight / most touching moment] was when
   [具体描述]...
```

**第5段·反思**
```
① That experience taught me that [一句道理].
   Since then, I've [行为改变].

② Looking back, I'm [grateful / glad] that [原因].
   It reminded me that [感悟].

③ [事件] became one of [our most treasured memories / 
   the most meaningful experiences of my life].
   Sometimes [哲理总结].
```

## 模板3：描述一个物品/事物（覆盖约6题）

### 骨架

```
【第1段·引入 30词】物品名称 + 什么 + 怎么得到的
【第2段·描述 50词】外观/功能/特点
【第3段·使用场景 60词】你怎么用它 / 在什么情境下用
【第4段·故事 60词】一个和它相关的具体故事
【第5段·意义 50词】它对你的意义 / 为什么重要
```

### 关键句式
```
引入：The [thing] I want to describe is [名].
      [I got it / My grandfather bought it / Zhang Wei recommended it] [时间].

描述：What makes it [special / different / valuable] is [特点].
      It [can do / has / features] [功能].

使用：I use it [频率] for [用途].
      In my daily [work / life], it [帮助方式].

故事：I remember when [具体场景]...
      [故事经过].

意义：For me, it represents [far more than / much more than] just a [物品类别].
      It [embodies / symbolises / connects me to] [深层意义].
```

## 模板4：描述一个地点（覆盖约7题）

### 骨架

```
【第1段·引入 30词】地点名 + 位置 + 你去过几次/多久去一次
【第2段·感官描写 70词】你看到/听到/感受到什么（至少3个感官）
【第3段·你在那做什么 50词】具体活动
【第4段·和家人/朋友的互动 50词】其他人在那的反应
【第5段·为什么喜欢 50词】它对你的意义 + 和你日常生活的对比
```

### 关键句式
```
引入：[The place / The city] I'd like to describe is [名], located [位置].
      I've [been there X times / visited regularly for X years].

感官：视觉 → The [landscape/architecture] is [形容词] — [细节].
      听觉 → The [only sound / atmosphere] is [声音/安静].
      触觉 → The air feels [clean/crisp/warm/humid].
      嗅觉 → You can smell [什么].

活动：I usually [活动] when I'm there.
      My [son/wife] [做什么], while I [做什么].

对比：As someone who [works in the fast-paced internet industry / 
      lives in a busy city], [地点] provides [the perfect counterbalance /
      exactly what I need — [安静/自然/慢节奏]].

意义：[It's not glamorous, but] it's one of the most important places
      in my life right now.
      Every visit [reminds me / teaches me] that [感悟].
```

## 模板5：描述一个计划/愿望（覆盖约6题）

### 骨架

```
【第1段·引入 30词】你想做什么 + 简要描述
【第2段·为什么想做 60词】动机（通常2-3个原因）
【第3段·具体计划 60词】怎么做 / 和谁 / 什么时候
【第4段·挑战 40词】可能遇到的困难
【第5段·意义 60词】做这件事对你意味着什么
```

### 关键句式
```
引入：If I had the opportunity, I'd [love to / want to] [计划].
      My [ideal / dream] [job / trip / goal] is [描述].
      What I'd most like to [do / achieve / experience] is [描述].

动机：The reason [this appeals to me / I want this] is [threefold / simple].
      First, [原因1]. Second, [原因2]. Beyond that, [原因3].

计划：I'd plan to [具体安排].
      Ideally, I'd [和谁] [做什么] during [时间段].
      The [route / approach / method] I have in mind is [描述].

挑战：The [challenges / obstacles] would be real — [具体困难].
      But I believe [why it's worth it].

意义：The core appeal comes down to [2-3个词]: [freedom, depth, curiosity].
      [This dream] is ultimately about [deeper meaning].
```

# 二、P3 回答模板（7种问题类型 × 完整句式）

> 每种类型4-5句话，约400字符，观点→原因→例子→收尾

---

## P3模板A：观点型（"Do you think...?" / "Is it important...?"）

```
结构：明确立场 → 核心原因 → 具体例子 → 补充/收尾

I [think / believe / would say] [立场], [primarily / mainly] because [核心原因].
[For example / For instance / In my own experience], [具体例子].
[补充句 或 收尾感悟].
```

**实际示范**（从回答中提取的高频模式）：
```
Definitely. In my experience [working in tech / raising a child], 
[观点论据]. For instance, [例子]. [收尾].

Very much so. [原因]. My [son / grandfather / friend] [例子].
[It's/This is] [an essential / a crucial] [skill / value / lesson].

I believe [观点]. [原因]. [例子]. That said, [补充/让步].
```

---

## P3模板B：让步型（"Should...?" / "Is it good...?"）

```
结构：部分同意 → 正面理由 → 转折 → 反面考量

To some extent, yes — [正面理由].
However, [转折条件/反面考量].
[举例说明].
[平衡性结论].
```

**实际示范**：
```
To some extent, yes, because [理由]. However, [转折].
For example, [例子]. The key is [balance / moderation / context].

It depends on the situation. For [情况A], [分析].
But for [情况B], [不同分析]. [总结].

I think there are both advantages and disadvantages. 
On one hand, [好处]. On the other, [坏处].
In my view, [你的立场].
```

---

## P3模板C：对比型（"What are the differences...?"）

```
结构：指出核心差异 → A的特点 → B的特点 → 你的倾向

The main difference is that [A特点], while/whereas [B特点].
[A展开1句]. [B展开1句].
[Personally / In my experience], I [tend to prefer / find that] [你的倾向].
```

**实际示范**：
```
[A] tends to [特点A], while [B] is more [特点B].
For example, [A的例子]. By contrast, [B的例子].
They serve different needs — I think [结论].

The key distinction lies in [核心差异].
[A] offers [优势A] but lacks [劣势A].
[B] provides [优势B] but [劣势B].
[Ideally / In my case], [你的选择和原因].
```

---

## P3模板D：原因分析型（"Why do...?" / "Why are...?"）

```
结构：核心原因 → 解释 → 例子 → 延伸

I think the main reason is [核心原因].
[展开解释1-2句].
[For instance / In my case / Take my [son/friend] for example], [具体例子].
[延伸思考].
```

**实际示范**：
```
[The primary driver / The biggest factor] is [原因].
[解释为什么]. [例子].
There's also [a secondary factor / an emotional component]: [补充原因].

It often comes down to [核心原因].
[解释]. [个人经验例子].
[I think this trend will [continue / change] because [理由].]
```

---

## P3模板E：建议型（"What should...?" / "What can...?"）

```
结构：具体建议 → 为什么有效 → 例子 → 注意事项

I think [行动者] should [建议].
This works because [为什么有效].
[例子 — 最好用个人经验].
[However / That said], [注意事项/补充].
```

---

## P3模板F：列举型（"What kinds of...?" / "What factors...?"）

```
结构：2-3个要素 → 每个简要解释 → 用个人经验串联

[Several factors / A few things] come to mind.
First, [要素1 + 简要解释].
[Second / Also / Beyond that], [要素2 + 简要解释].
[In my own experience / For me personally], [结合个人的总结].
```

---

## P3模板G：经验引入型（任何题目都可以用的万能开头）

```
① Speaking from my experience as a [father of a five-year-old / 
   fourteen-year tech veteran / someone who grew up in a small city], ...

② I actually have a relevant example — my [son / friend Zhang Wei / 
   grandfather] ...

③ In my case, [具体情况], so I tend to think ...

④ This is something I feel quite strongly about, because [个人原因] ...

⑤ I've seen this firsthand — [简述个人经验] ...
```

# 三、万能"弹药库"：6类高频P3话题的固定观点

> 不管P3具体问什么，绝大多数问题可以归入以下6类。
> 每类准备3-4个固定观点+例子，考场直接调用。

---

## 弹药库1：孩子/教育 （约40%的P3涉及）

| 观点 | 配套例子 |
|------|---------|
| 兴趣比成绩重要 | 儿子说想当"恐龙专家"，我觉得很好 |
| 言传身教比说教有效 | 外公带儿子捡垃圾，而非讲环保道理 |
| 不应该给孩子太多压力 | 对儿子的期望只有健康快乐平安 |
| 适当做家务培养责任感 | 儿子5岁收拾玩具、擦桌子 |
| 限制屏幕时间但不完全禁止 | 每天30分钟动画 |
| 鼓励尝试但不强迫 | 游泳用了3周渐进引导 |

**万能收尾句**：
```
My only expectation for my son is that he's healthy, happy, and safe.
Everything else will follow from those foundations.
```

---

## 弹药库2：科技/互联网（约20%的P3涉及）

| 观点 | 配套例子 |
|------|---------|
| 科技是双刃剑 | 方便但信息过载/隐私问题 |
| AI正在改变一切 | 用AI把儿子画的恐龙变"真实" |
| 终身学习是生存之本 | 张伟自学AI转岗成功 |
| 技术应该服务于人 | 张伟为老人设计三按钮App |

**万能收尾句**：
```
Technology is a powerful tool, but what matters most is 
how we choose to use it — to connect, to create, or to understand.
```

## 弹药库3：工作/职业（约15%的P3涉及）

| 观点 | 配套例子 |
|------|---------|
| 好工作 = 热爱+擅长+自由 | 理想是独立研究者 |
| 薪资重要但不是唯一 | 见过高薪但不开心的人 |

```
After fourteen years in the industry, I've learned that 
the most valuable professional asset isn't any specific skill — 
it's the willingness to keep learning and adapting.
```

Having a family taught me that the most meaningful achievements

# 四、P2 时间控制技巧

## 250词的段落分配

| 段落 | 功能 | 目标词数 | 用时 |
|------|------|---------|------|
| 第1段 | 引入 | 30-40 | 15秒 |
| 第2段 | 核心描述 | 50-60 | 25秒 |
| 第3段 | 具体故事 | 70-80 | 35秒 |
| 第4段 | 延伸/转折 | 40-50 | 20秒 |
| 第5段 | 感受/反思 | 30-40 | 15秒 |
| **合计** | | **220-270** | **110秒** |

## "说不下去"时的救命句式

```
① Actually, there's an interesting story behind this...
   （转入一个新的小故事）

② What I find particularly [interesting / meaningful / surprising] about 
   this is...（转入个人感悟）

③ I remember one specific detail that stayed with me...
   （补充一个感官细节）

④ This reminds me of something my [grandfather / friend] once said...
   （引用一句话展开）

⑤ Looking back on it now, I realise that...
   （转入反思模式，可以说很多）
```

# 六、学习路线建议

```
第1周：背熟5个P2骨架 + 7个P3句式 → 不求内容，只求结构自动化
第2周：背熟6个弹药库 → 能对任何P3话题在3秒内调出观点+例子
第3周：选10道高频题完整练习 → 录音 → 对照模板检查结构
第4周：模拟考全流程 → 重点练习"说不下去"时的救命句式
```
