## 你的起点和目标

| 项目 | 现状 | 10周后目标 |
|---|---|---|
| Part 1 | 有188题完整回答，但说不出 | 任何题3秒开口，18-20秒自然回答 |
| Part 2 | 有骨架但不熟，容易卡壳 | 1分钟准备后连说90-120秒 |
| Part 3 | 没练过 | 每题25-35秒，观点+原因+例子 |
| 整体 | 素材丰富但输出为零 | 6.5-7分 |

**提分路径**：口语不需要天天练——用1-5-9集中周节奏（第1/5/9周），集中周每天60-90min深度训练，非集中周每天15-20min维持。

---

## 三个核心训练法

> 以前没有系统方法，现在拆成三个递进的训练法：**框架输入法**、**关键词复述法**、**全流程模考法**。前一个是后一个的前置条件。

---

### 训练一：框架输入法（被动输入，60-90分钟/天）

**目标**：把口语回答的底层结构装进大脑——知道每种题型怎么开头、怎么展开、用什么素材。

**什么时候用**：第1周口语集中周，首次接触口语备考时。后续有新话题/新素材加入时补充。

#### 完整流程（7天）

```
Day 1：P1 骨架 + 开篇句式（90min）
  Step 1 · 通读 P1 泛化模板体系 v6 第一、二章（45min）
    - 理解4句骨架结构（接住→展开→转折→收尾）
    - 逐个看6种开篇类型，每种注意Q号出处
    - 每种类型选1个最顺口的句式，用手机录音读3遍
  Step 2 · 手抄6种开篇句式的代表句（30min）
    - 抄写的目的不是记忆，是让手和嘴同步加工
    - 边抄边出声读
  Step 3 · 自测：随机翻10个Q号，3秒内说出对应类型的开篇（15min）

Day 2：P1 弹药库（90min）
  Step 1 · 通读 v6 第三章弹药库（45min）
    - 4个一级弹药：每个看子方向表 + 高频实战句式 + 使用Q号
    - 5个二级弹药：每个看适用话题 + 什么时候不要用
  Step 2 · 每个弹药背1个"万能接入句"（30min）
    - 弹药1（儿子）：My five-year-old [does X]...
    - 弹药2（外公+宜宾）：Growing up in Yibin with my grandparents...
    - 弹药3（妻子）：My wife [says/does]...
    - 弹药4（自嘲）：I'm not really a [X] person.
    - 录音读10遍，直到不假思索
  Step 3 · 自测：说出4个一级弹药的名称+万能接入句（15min）

Day 3：P1 转折/收尾 + P2&3 骨架（90min）
  Step 1 · 通读 v6 第四、五章（转折句库+收尾句库）（20min）
    - 每种模式选1个最常用的句式记住
  Step 2 · 通读 P2&3 泛化模板体系 v6（60min）
    - 理解5种P2题型×4段骨架（190-220词口语版）
    - 理解P3的7种回答模板（50-70词口语版）
  Step 3 · 对比P1和P2P3：P1一句话提到 vs P2展开成60-70词段落（10min）

Day 4：P1 特化速查表（60min）
  Step 1 · 通读 v6 第六章 6类特化内容（40min）
    - 每个话题看Q号范围 + 必背词块 + 必背场景句
    - 每类选3个最有画面感的场景句出声读
  Step 2 · 朗读18个必背场景句（每句读3遍）（20min）

Day 5：P2&3 题库浏览（90min）
  Step 1 · 通读 P2&3 备考手册前10题回答（60min）
    - 标记5个最能复用你的素材的P2故事
    - 注意这些故事用了哪些弹药
  Step 2 · 看 v6 第七章共享素材对照表（30min）
    - 确认P1和P2P3的素材一致性

Day 6：P2 骨架 + P3 模板（90min）
  Step 1 · 背5种P2骨架的段落功能（45min）
    - 第1段引入→第2段核心特质→第3段具体故事→第4段细节延伸→第5段感受
    - 每种骨架选1个参考回答完整朗读
  Step 2 · 背P3的7种回答模板（30min）
    - 观点型 / 对比型 / 原因型 / 建议型 / 预测型 / 让步型 / 例证型
  Step 3 · 默写P2骨架5段的功能名称（15min）

Day 7：复习 + 自测（90min）
  Step 1 · 翻阅本周所有标记内容（45min）
  Step 2 · 自测（45min）
    - 随机5个P1题：3秒内开口+选对开篇类型+选对弹药
    - 说出5种P2骨架的段落功能
    - 说出4个一级弹药+各自万能接入句
    - 说出P3的3种常用模板
```

#### 框架输入法的内部验收

| 检查项 | 达标标准 |
|---|---|
| P1开篇 | 听到问题3秒内说出合适的开篇句式 |
| P1弹药 | 说出4个一级弹药名称+万能接入句 |
| P2骨架 | 说出5段的功能名称 |
| P3模板 | 说出至少3种回答模板 |
| 素材一致性 | 知道哪些素材P1-P3共用，P1简P2详 |

**验收通过 → 进入训练二：关键词复述法**

---

### 训练二：关键词复述法（主动输出，40-60分钟/天 or 维持15-20分钟/天）

**目标**：从"看懂"到"说出来"——只看关键词就能组装出完整回答，实现3秒反应。

**什么时候用**：第5周口语集中周（集中模式），非集中周（维持模式）。

**前置条件**：训练一框架输入法验收通过。

#### 集中模式完整流程（7天，每天60-90min）

```
每天的基本结构：
├─ 热身跟读（10min）：跟读自己之前录的P1/P2回答，找回语感
├─ 关键词复述（40-50min）：用 keywords 文件，三步递进
│   ├─ Step 1: 看关键词 + 瞄一眼原文 → 合上说
│   ├─ Step 2: 只看关键词 → 说
│   └─ Step 3: 只看题目 → 说（终极目标）
└─ 弹药组合练习（10min）：随机话题，用不同弹药组合展开

关键词复述的具体操作：
1. 打开 ielts_part1_keywords_v5.md
2. 选一道题，先看关键词列表
3. 设手机计时器18秒
4. 按下计时器，开始说——不追求完美，说满时间就是胜利
5. 如果卡壳超过3秒，允许瞄一眼 ielts_part1_188answers_v5.md 然后合上继续
6. 说完后立刻录音回听一遍，标记卡壳位置
7. 下一题

Day 1：热身复习30min + 关键词复述 Q1-Q26（Food/Pets/Sports/Hobby/Morning/Gifts）
Day 2：回听昨日录音标卡壳处20min + 重练卡壳题 + 复述 Q27-Q55（Reading→Views）
Day 3：复述 Q56-Q91（Life stages→Going out）+ P2计时练3题（2min独白不看稿）
Day 4：复述 Q92-Q129（Old people→Sharing）+ 录音
Day 5：复述 Q130-Q157（Photos→Work）+ P2计时练3题
Day 6：复述 Q158-Q188（Home→Dreams）+ 全流程模拟1次（P1+P2+P3录音）
Day 7：全流程模拟2次 + 标记仍然卡壳的题（预计20-30题）
```

#### 维持模式（非集中周，每天15-20min）

```
每天选以下一项做：
A. 朗读5题P1回答（出声读，保持语感）（10min）+ 默答3道P1（10min）
B. P2限时1题（1min准备+2min说）+ 出声练P3×2（15min）
C. 回听自己之前的录音 + 重练1-2个卡壳题（15min）

轮换节奏：Mon=A, Tue=B, Wed=A, Thu=B, Fri=C, Sat=A, Sun=休息
```

#### 关键词复述法的内部验收

| 检查项 | 达标标准 |
|---|---|
| P1覆盖率 | 188题全部过一遍 |
| P1流畅度 | 随机10题只看题目能说满18秒，卡顿≤2次 |
| P2独白 | 不看稿说满90秒，至少5题能做到 |
| P3回答 | 每题能说25-35秒，有结构（观点+原因+例子） |
| 卡壳题清单 | 已标记并重练 |

**验收通过 → 进入训练三：全流程模考法**

---

### 训练三：全流程模考法（评估，60-90分钟/天）

**目标**：完整模拟考试流程，评估真实水平，暴露系统性短板。

**什么时候用**：第9周口语集中周。考前阶段定期进行。

**前置条件**：训练二关键词复述法集中模式完成。

#### 完整流程（7天）

```
每次全流程模考的步骤（30min/次）：

Step 1 · 模拟考试（15min）
  - P1：4-5个话题，每题回答18-20秒（约5min）
  - P2：1个话题，1min准备+2min独白（3min）
  - P3：4-5个追问，每题25-35秒（约5min）
  - 全程录音，不暂停

Step 2 · 回听自评（10min）
  - 对照5项检查清单逐项打分：
    □ 开篇速度：问题结束后1-2秒内开口？
    □ 回答长度：P1 18-20秒 / P2 90-120秒 / P3 25-35秒？
    □ 语法错误：时态一致？主谓一致？
    □ 自然度：像聊天不像背书？
    □ 素材一致性：P1-P3人物/地点/时间线不矛盾？
  - 标记所有卡壳题和不自然处

Step 3 · 补强（5min）
  - 卡壳题：回到关键词速查，重新组装
  - 不自然处：改换措辞，再说一遍录音对比

Day 1：全流程模拟1 + 自评（记录所有卡壳题）
Day 2：针对卡壳题做关键词复述重练 + 补充不熟的特化词块
Day 3：全流程模拟2（换一套题组）+ 严格计时
Day 4：P2专项冲刺：练最不熟的5道P2（无提示说满90秒）
Day 5：全流程模拟3 + 录音
Day 6：根据反馈调整 + 全流程模拟4（最终状态确认）
Day 7：轻松复习——翻翻弹药库和关键词，不做新练习

模考题组（每次随机选1组）：
  组1：P1 Food+Hobby+Morning → P2 擅长做计划的人 → P3
  组2：P1 Walking+Building+Gifts → P2 重要的好朋友 → P3
  组3：P1 Scenery+Rules+Sharing → P2 近期看过的电影 → P3
  组4：P1 Life stages+Plants+Crowded → P2 喜欢画画的孩子 → P3
  组5：P1 Work+Home+Advertisement → P2 爱护自然之人 → P3
  组6：P1 Memory+Pets+Spare time → P2 机智解决问题的人 → P3
```

#### 全流程模考法的内部验收

| 检查项 | 达标标准 |
|---|---|
| 模拟次数 | ≥4次 |
| P1 | 任何题3秒内开口，说满18秒 |
| P2 | 不看稿说满90-120秒 |
| P3 | 每题说25-35秒，结构清晰 |
| 录音自评 | 最后一次模拟自评≥6.5 |
| 全流程时间 | 15分钟内完成 |

---

## 三个训练法的依赖关系

```
训练一：框架输入法（第1周）
  ↓ 内部验收通过
训练二：关键词复述法
  ├─ 集中模式（第5周，60-90min/天）
  └─ 维持模式（非集中周，15-20min/天）
  ↓ 集中模式验收通过
训练三：全流程模考法（第9周）
```

维持模式可以与其他训练并行——不需要大块时间，碎片时间即可。

---

## 口语录音自评5项检查清单

每次模拟或录音后使用：

| 检查项 | 达标标准 | 常见问题 |
|---|---|---|
| 开篇速度 | 问题结束后1-2秒内开始说 | 太长的"嗯..."或重复问题 |
| 回答长度 | P1: 18-20秒 / P2: 90-120秒 / P3: 25-35秒 | 太短（没展开）或太长（跑题） |
| 语法错误 | 时态一致、主谓一致 | 忘记过去式、he/she混用 |
| 自然度 | 像聊天不像背书 | 语速突变（背诵感）、无停顿无犹豫 |
| 素材一致性 | 人物/地点/时间线不矛盾 | P1说的细节和P2冲突 |

## 每日训练流程速查

### 集中周（第1/5/9周，60-90min/天）

```
第1周（框架输入法）：
  通读材料 → 手抄/朗读 → 自测
  见上面训练一的7天计划

第5周（关键词复述法集中模式）：
  热身跟读 10min → 关键词复述 40-50min → 弹药组合练习 10min
  每天覆盖约30题，7天覆盖全部188题

第9周（全流程模考法）：
  全流程模拟 15min → 回听自评 10min → 补强 5min
  隔天模拟，模拟间做补强训练
```

### 非集中周（15-20min/天）

```
维持模式轮换：
  Mon/Wed/Sat：朗读5题P1 + 默答3道P1
  Tue/Thu：P2限时1题 + 出声练P3×2
  Fri：回听录音 + 重练卡壳题
  Sun：休息
```
