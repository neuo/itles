# Session 2026-04-13

## What we did
- Initialized the entire learning system from scratch (CLAUDE.md, inventory.md, error_log.md)
- Two cold production outputs:
  1. Describe current work project
  2. Describe a disagreement with a PM
- One reformulation drill: learner reproduced the native version from memory, mostly successfully

## What was exposed
- **Double negation** ("didn't make no contribution") — L1 transfer, explained once
- **Verb too generic** — consistent across both outputs
- **State vs. action framing** ("there was no result") — new pattern identified this session, likely to recur
- **Skeleton sentences** — "My responsibility is writing code implementing the ideas from the PM"
- **Functional words absent** — `just` and `actually` didn't surface at all in spontaneous production

## What worked
- Reformulation + reproduce from memory: learner got "pushed back on" and "go back and forth" into the second attempt naturally
- Slip-ups were "backed down" → "went back" and "unresolved" → "unsolved" — close misses, not full failures

## What didn't transfer yet
- `back down` — substituted with "went back", needs more drilling
- `unresolved` vs `unsolved` distinction — used wrong one, needs one more exposure
- `just` and `actually` — zero appearances, not yet in spontaneous production system

## Key insight from this session
Learner has studied extensively before (compiled model answers, reformulation practice) but transfer to real situations is near zero. Root cause: all prior practice was *prepared retrieval*. Real speech needs *unprepared retrieval* — a different neural pathway. This shaped the entire training design.

## Where to pick up next session
1. Start with cold production immediately — give a prompt, no warm-up
2. Watch specifically for: state-vs-action framing, `back down`, `unresolved`
3. Check if `just` / `actually` surface naturally — if not, force them in with a targeted drill
4. The AI tech problem cold output was never completed — can use as the opening prompt next session
