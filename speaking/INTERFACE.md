# Speaking 域接口定义

> 本文件是 speaking/ 域的正式对外接口。plan/ 和 agent 通过此文件了解口语域提供的练习方法、时间特征和考核方式。
> 域内部的具体实现（模板、句式、题库）不在此文件中，由域内部文档承载。

---

## 练习方法

### 方法A：框架输入（被动输入）

**目标**：建立口语回答的底层结构认知——知道 Part 1/2/3 各自怎么答、有哪些句式和素材可用。

**时间特征**：大块时间（60-90min），适合集中周使用。

**适用阶段**：首次接触口语备考时必须先过一遍；后续有新话题/新素材加入时补充输入。

**做什么（能力描述）**：
- 阅读并理解 Part 1 万能骨架（开篇句式 + 展开弹药 + 转折/收尾）
- 阅读并理解 Part 2 骨架 + Part 3 回答模板
- 熟悉弹药库分类和覆盖范围
- 理解素材一致性要求（跨 Part 人设/故事保持一致）

**内部验收（封闭在方法内部）**：
- 能说出 Part 1 的4句骨架结构
- 能列出一级弹药（4个）和二级弹药（5个）的名称
- 能说出 Part 2 的展开骨架

**退出条件**：内部验收通过 → 可进入方法B。

---

### 方法B：关键词复述（主动输出）

**目标**：从"看懂"到"说出来"——只看关键词就能组装出完整回答，实现3秒反应。

**时间特征**：灵活。集中练习 40-60min，碎片维持 15-20min/天。

**适用阶段**：方法A完成后进入。集中周深度练习，非集中周降级为维持模式（每天朗读复习）。

**做什么（能力描述）**：
- 使用 Part 1 关键词速查，只看关键词尝试复述完整回答
- 录音对比：录下自己的回答，对比参考回答，发现卡点
- Part 2 限时练习：看题目 + 1分钟准备 + 2分钟独白
- Part 3 追问练习：针对话题做即兴回答

**两种运行模式**：
- **集中模式**（集中周）：每天 40-60min，系统过题，追求覆盖率
- **维持模式**（非集中周）：每天 15-20min，朗读已练过的回答，保持语感

**内部验收（封闭在方法内部）**：
- Part 1：随机抽10题，只看关键词能在5秒内开始说，内容覆盖骨架结构
- Part 2：能在1分钟准备后连续说满1.5分钟以上
- Part 3：能针对追问给出有结构的回答（观点+原因+例子）

**退出条件**：内部验收通过 → 可进入方法C。维持模式无退出条件，持续到考前。

---

### 方法C：全流程模考（评估）

**目标**：完整模拟考试流程，评估真实水平，暴露系统性短板。

**时间特征**：整块时间（60-90min），含模考 + 复盘。

**适用阶段**：方法B集中模式完成后。考前阶段定期进行。

**做什么（能力描述）**：
- 完整 Part 1 + Part 2 + Part 3 模拟（11-14分钟）
- 录音回放 + 自评/他评
- 识别薄弱环节：流利度、词汇多样性、语法准确性、发音
- 复盘后回到方法B补强具体话题

**内部验收（封闭在方法内部）**：
- 全流程能完成（不出现长时间卡壳/沉默）
- Part 1 每题回答时长 15-25秒
- Part 2 能说满 1.5 分钟
- 整体自然度可接受（不像背诵）

**退出条件**：无固定退出，考前持续进行。每次模考后产出复盘记录。

---

## 方法间依赖

```
方法A（框架输入）
   ↓ 内部验收通过
方法B（关键词复述）——— 可降级为维持模式（15-20min/天）
   ↓ 集中模式验收通过
方法C（全流程模考）——— 考前持续，复盘后可回到B补强
```

- A 是 B 的前置条件：不理解框架就无法复述
- B 是 C 的前置条件：不能脱稿说就不适合模考
- B 的维持模式可以与 C 并行

---

## 考核接口

plan 周期性调用，域返回当前状态和建议。

```
speaking.考核() → {
  当前阶段: "A" | "B-集中" | "B-维持" | "C",
  当前状态: "正常推进" | "卡住" | "已达标",
  建议: "继续当前节奏" | "需要加时间" | "可以减时间" | "建议进入下一阶段"
}
```

**判断逻辑**：
- 阶段A：内部验收是否通过 → 通过则建议进入B
- 阶段B-集中：10题抽查通过率 → ≥70% 建议进入C，<50% 建议加时间
- 阶段B-维持：是否每天有朗读 → 有则正常，连续3天没有则提醒
- 阶段C：模考完成度和自然度 → 正常则继续，卡壳多则回B补强
