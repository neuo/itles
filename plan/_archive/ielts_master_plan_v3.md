### 本周重点练习详解：S2跟不上怎么办

```
S2之所以难，是因为：
1. 独白形式——没有对话节奏的"喘息点"
2. 信息密度高——连续说很多细节
3. 答案间隔近——刚写完一个答案下一个就来了

对策（按优先级）：

第一步：别试图听懂每个词
  S2不需要100%听懂，你只需要在答案出现时"醒过来"
  方法：审题预判时就在脑子里"装好雷达"——知道下一个答案大概是什么类型
  听的时候大脑有一半在"扫描"预判的关键词/同义词

第二步：练习"边听边写"
  很多人S2丢分是因为写上一个答案时漏听了下一题
  练习方法：
  - 拿一套做过的S2，重新听
  - 这次不做题，只练"听到答案→写下答案→立刻切回听"的节奏
  - 答案只写缩写/首字母，不追求拼写完整
  - 目标：写的动作不超过3秒

第三步：用倍速训练（精听法加速步骤）打破语速瓶颈
  先拿已听懂的S1材料练倍速
  适应后再用S2材料练
  坚持一周就能感受到明显的"变慢效应"
```

### S3/S4 攻坚方法

```
S3和S4难在哪：
- S3：2-4人学术讨论，说话人切换快，有干扰项和态度变化
- S4：学术讲座独白，词汇专业，信息密度极高

S3训练重点——说话人识别：
1. 做题前：看题目判断需要听"谁"的观点
2. 做题时：在草稿纸写 A/B/C 代表不同说话人
3. 听到转折词（but, actually, I disagree）立刻警觉——答案往往在这里

S4训练重点——抓大放小：
1. S4信息量太大，不可能全听懂，接受这个事实
2. 重点听：每段开头第一句（主题句）+ 信号词后面的内容
3. 不认识的专有名词不要慌——它们通常不是答案本身
4. 填空题：答案通常是常见词，不是生僻学术词

共同策略：
- 每做完一套，用做题法复盘标注答案在原文的位置
- 总结S3/S4的答案出现规律——积累下来比盲听更高效
```

# 八、一句话原则

**听力先稳S1S2**：前4周只攻S1+S2，用审题预判+精听+倍速训练三板斧，目标是S1+S2拿到16/20，这就值6分的底盘了。

**口语三步走**：记住（Week 1）→ 说出（Week 5）→ 稳定（Week 9），关键词复述卡是第5周的核心武器。

**写作先读后写**：第3周只读范文做输入，第4周才开始限时写，避免在没有方法论的情况下盲写。

**阅读最小投入**：稳定7分的科目不值得投入大量时间，每周1篇维持手感即可。

**同义替换本是听力提分最快的武器**：从第1周开始积累，每做一套题就整理，考前这个本子比任何单词书都有用。
