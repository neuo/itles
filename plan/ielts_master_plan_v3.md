# 三、听力核心方法论（贯穿全程）

> 详细方法和工具见 `listening/` 域。本计划只引用听力域的两个核心能力（做题法、精听法），不引用具体文件。
>
> **注意：本计划为机考（CDI）备考。机考没有额外誊写时间，答案边听边打字输入。**

两个核心训练法（详见方法手册）：

**训练一：做题法**（审题→做题→复盘，45-50分钟/套）
  覆盖审题预判、信号词捕捉、同义替换积累、答案定位，合为一个完整流程。
  每次做新真题时用这个流程。

**训练二：精听法**（听写→对照→跟读→加速，30-40分钟/段）
  覆盖逐句听写、错误分类、跟读模仿、倍速适应，合为一个完整流程。
  做完题后挑错题段落用这个流程。

### 本周重点练习详解：S2跟不上怎么办

```
S2之所以难，是因为：
1. 独白形式——没有对话节奏的"喘息点"
2. 信息密度高——连续说很多细节
3. 答案间隔近——刚写完一个答案下一个就来了

对策（按优先级）：

第一步：别试图听懂每个词
  S2不需要100%听懂，你只需要在答案出现时"醒过来"
  方法：审题预判时就在脑子里"装好雷达"——知道下一个答案大概是什么类型
  听的时候大脑有一半在"扫描"预判的关键词/同义词

第二步：练习"边听边写"
  很多人S2丢分是因为写上一个答案时漏听了下一题
  练习方法：
  - 拿一套做过的S2，重新听
  - 这次不做题，只练"听到答案→写下答案→立刻切回听"的节奏
  - 答案只写缩写/首字母，不追求拼写完整
  - 目标：写的动作不超过3秒

第三步：用倍速训练（精听法加速步骤）打破语速瓶颈
  先拿已听懂的S1材料练倍速
  适应后再用S2材料练
  坚持一周就能感受到明显的"变慢效应"
```

### 写作Task1限时练方法

```
每次限时写作的完整流程（35min含复盘）：

Step 1 · 审题+规划（3min）
  - 看图，用30秒判断图表类型和时态
  - 写下：总体趋势是什么？（一句话）
  - 列出2-3个最突出的数据特征

Step 2 · 写作（17min）
  - 第1段：改写题目（2句，≤30词）
  - 第2段：总览Overview（2句，概括总体趋势）
  - 第3段：Body 1（3-4句，描述主要特征+数据）
  - 第4段：Body 2（3-4句，描述次要特征+数据）
  - 目标：≥ 150词

Step 3 · 检查（2min）
  - 快速通读，检查：时态一致？数据准确？有没有拼写错误？

Step 4 · 自评（13min）
  - 对照 Task 1 Guide 的评分标准逐项打分：
    □ Task Achievement：是否有Overview？是否覆盖主要特征？
    □ Coherence：四段结构清晰？衔接词使用？
    □ Lexical Resource：有无同义改写？约数表达？
    □ Grammar：时态/主谓一致/复杂句？
  - 标记最大的1-2个问题，下一篇重点改进
```

## 第 5 周：口语集中周2（关键词复述输出）

> **核心目标**：从"记住了"转化为"说得出"，关键词复述卡是本周核心武器
> **听力/写作**：缝隙维持

### 口语三阶段训练法（本周使用）

```
每天60-90分钟口语，按以下分配：

├─ 热身跟读（10min）：跟读自己之前录的P1/P2回答
├─ 关键词复述（40-50min）：用keywords文件，三步递进
│   ├─ Step 1: 看关键词 + 瞄一眼原文 → 合上说
│   ├─ Step 2: 只看关键词 → 说
│   └─ Step 3: 只看题目 → 说（终极目标）
└─ 弹药组合练习（10min）：随机话题词，用不同弹药展开

```
每次限时写作的完整流程（55min含复盘）：

Step 1 · 审题（2min）

Step 3 · 写作（35min）

### S3/S4 攻坚方法

```
S3和S4难在哪：
- S3：2-4人学术讨论，说话人切换快，有干扰项和态度变化
- S4：学术讲座独白，词汇专业，信息密度极高

S3训练重点——说话人识别：
1. 做题前：看题目判断需要听"谁"的观点
2. 做题时：在草稿纸写 A/B/C 代表不同说话人
3. 听到转折词（but, actually, I disagree）立刻警觉——答案往往在这里

S4训练重点——抓大放小：
1. S4信息量太大，不可能全听懂，接受这个事实
2. 重点听：每段开头第一句（主题句）+ 信号词后面的内容
3. 不认识的专有名词不要慌——它们通常不是答案本身
4. 填空题：答案通常是常见词，不是生僻学术词

共同策略：
- 每做完一套，用做题法复盘标注答案在原文的位置
- 总结S3/S4的答案出现规律——积累下来比盲听更高效
```

# 八、一句话原则

**听力先稳S1S2**：前4周只攻S1+S2，用审题预判+精听+倍速训练三板斧，目标是S1+S2拿到16/20，这就值6分的底盘了。

**口语三步走**：记住（Week 1）→ 说出（Week 5）→ 稳定（Week 9），关键词复述卡是第5周的核心武器。

**写作先读后写**：第3周只读范文做输入，第4周才开始限时写，避免在没有方法论的情况下盲写。

**阅读最小投入**：稳定7分的科目不值得投入大量时间，每周1篇维持手感即可。

**同义替换本是听力提分最快的武器**：从第1周开始积累，每做一套题就整理，考前这个本子比任何单词书都有用。
