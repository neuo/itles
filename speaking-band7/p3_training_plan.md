# P3 训练方案（cold-first + function-frame · 两轨制）

> **本文件 = P3 的训练 SCHEME**（怎么练，不是讲 frame 内容）。P2 没有对应的"plan 文件"——P2 的实战协议活在 [[../.claude/skills/speaking-coach/SKILL.md]] 的「🎯 P2 实战协议」块里。所以这份 P3 plan 的 **voice 对齐那个 SKILL 协议块**：薄壳执行器、她先 cold、卡住一拍接龙、答后扫、收尾写 session。
> **frame 内容真源** = [[function_driven_p3.md]]（METHOD：8 function + universal spine）/ [[p3_frames_and_swaps.md]]（填空骨架 + 降级词）/ [[p3_answers_tagged.md]]（GROUND TRUTH 逐句标签）。本文件**不重复** frame 内容，只编排"怎么把它们练进肌肉"。
> 选题真源 = [[question_bank.md]]（🚨 禁自编，只大陆题）。

---

## 🔑 一句话定位（P3 和 P2 最大的不同）

```
P2 = 有卡有 1min 准备 → 一题切 4 次（每 bullet 一个模式）→ 撑到 2min
P3 = 无卡零准备 → 一题切 1 次（整题一个 function）→ 3-5 句下车
```

**P3 的脚手架 = 那条 4 拍脊本身**，不是范文。她已经强在结构自监控（自己抓 coherence gap），所以 P3 是 **cold-first WITH A FRAMEWORK**——直接 cold，框架兜底，卡住才一拍接龙。**别给她读范文再复述**（那是 P2 Round 1 的打法，P3 不用）。

```
听 stem → 1 秒 STAND/SPLIT/SORT 分类 → 调 frame → STANCE 开口买时间 → 跑脊 → 答后扫
```

---

## 🧱 那条脊（每道 P3 都是这一条，背到自动）

```
① STANCE / DIRECT-ANSWER  →  ② BECAUSE（机制，不是 "because good"）  →  ③ e.g. / 第二点  →  ④（可选）LAND 让步收尾
```

| 拍 | = P2 类比 | 作用 | 谁负责 |
|---|---|---|---|
| ① **STANCE** | = **HOOK buys time** | 2-5 词先 commit 立场/数量，**堵死 freeze** | **背 opener glue**（教练点名喂） |
| ② **BECAUSE** | = EXPLAIN 的 because 行 | 给 HOW 它管用，不是 "because it's good" | **她自己 own**（不教连接词） |
| ③ **e.g. / 第二点** | = body bullet | 一个具体 `For instance/like…` 或 `Plus…` | **她自己 own** |
| ④ **LAND**（可选） | = EXPLAIN=LAND 收尾 | 一句让步收干净，不引入新词 | 通用 land tic（`To be fair` / `Having said that`） |

> ⭐ **STANCE = P3 唯一最该背到自动的东西**，理由完全同 P2 的 HOOK：freeze 风险最高的开口那一刻，它给你买 3-5 秒。corpus 里每张答案首 2-5 词都是一个 stance/数量 commit，无例外。

---

## 📌 核心方法论锚（贯穿整个 P3 训练，drafting/coaching 必须守）

> **「散句不垮、垮的是词」（6/23 ruling）。**

corpus + 6/23 实证：她在说理题上的**连接词（because / so / since / which / for instance / plus / whereas / on the other hand）全部已 cold 掌握**。每个被 flag 的 leak 都是 **abstract noun**（function / predictability / generation gap / sense of achievement / attention spans / highlight reel）。所以 P3 训练只投资两样：

1. **per-function 的 OPENER GLUE**（背我喂，买时间防 freeze）= P3 的"HOOK"。
2. **floor-level 的 abstract-noun 预载 swap**（卡的就是够到那个抽象名词的瞬间，预降成大白话）。

**❌ 绝不在 P3 重教连接词**——那不是她的 gap，给她加 budget 去想连接词反而占带宽。中段她自己 own。

# 🅰 轨一 · STANDALONE P3（cold-first-with-framework，一次一题）

> 单题 P3（或一组同域 P3）。这是日常维持轨，每次 session 都跑一组。

## A.1 单题执行流程（6 步）

```
0. 出题（question_bank,禁自编;P3 单题或一组同域;P3 配 question_bank 里成对的那几个）
1. 她听 stem → 自己跑 STAND/SPLIT/SORT 三动作 1 秒分类（⚠️ 教练不替她分——这是她要练的反应）
2. 教练点名 2 样（背我喂,封顶 2 个,别多）：
   ① 该 function 的 OPENER glue（先 commit 立场/数量,见 [[function_driven_p3.md]] §六「8 个 FRAME 的固定 glue」）
   ② 1 个该题真 leak 的 floor 名词（预降的大白话版,见 p3_frames_and_swaps 降级表）
3. 她 cold 答（~3-5 句 / ~30-50s）：STANCE → because → for instance → land
4. 死机 → 一拍接龙（P3 版,见 A.2）
5. 答后扫（说完才扫,见 A.3）
6. micro-scorecard（见 A.4）+ 捕获她自产地板词(→inventory cold+1) + 新错(→error_log)
```

## A.2 一拍接龙（P3 版 —— 完全沿用 P2 机制，拍序换成脊）

> 和 P2 同构：**一次只接一拍，给下一拍的 glue，她只填一颗珠子。** 区别只在拍序。

- **拍序 = STANCE → because → e.g. → land**（脊的 4 拍，不是 bullet 印刷序）。
- 她卡在哪拍，就喂**那拍的下一拍 glue**，让她"只说这一句"：
  - 卡在开口 → 喂 STANCE opener（`"Definitely."` / `"Loads, actually."` / `"They're worlds apart."`），她填话题词。
  - STANCE 出来卡住 → 喂 `"… because …"`，她填一个机制珠子。
  - because 出来卡住 → 喂 `"For instance, …"` 或 `"Plus, …"`，她填一颗例子珠子。
  - 想收尾卡住 → 喂 `"To be fair, …"` / `"Having said that, …"`，她填一句让步，停。
- **某拍够太高卡住**（够到抽象名词）→ "卡住 = 你够高了 → 降到能说的画面"（同 P2），别硬憋。
- 接到 land（或 e.g.）= 一篇完整，**下车**。别让她停在死机里，也别让她试图再列第 5 个点。

## A.3 答后扫（说完才扫，不实时打断 —— 完全沿用 P2）

整段说完才扫，按她当前 error zone 排序：

1. 🔴 **固定搭配 / 介词**（6/22-23 主 error zone）：`because OF + noun` vs `because + clause` / `worth it` / `got into it` / `keep in touch with` / `head to` / `top the list` / `go into a field`……（见 p3_frames_and_swaps §TARGET collocation）。
2. 🟡 **冠词 a/an**（偶尔 slip）。
3. ⚪ **-s 第三人称**（mostly held now，扫一眼即可，不再是重点）。

> ⚠️ **不扫连接词**——她的 because/so/whereas 都对，扫了浪费。只扫上面三类（搭配 > 冠词 > -s）。

## A.4 per-answer micro-scorecard（每题一张,5 个 yes/no,30 秒过）

> 不是 P2 的 8 维大 scorecard——P3 单题就这 5 个钩子：

| 钩子 | 问 | ✅ 标准 |
|---|---|---|
| 🎯 **stance committed?** | 头 2-5 词有没有甩一个立场/数量？ | 没有冷扫开局 = ✅ |
| ⚙️ **mechanism 不是 "because good"?** | because 后面是 HOW 它管用，还是空夸"因为好"？ | 给了机制 = ✅ |
| 🌰 **例子 or 第二点?** | 有没有一个 `for instance/like` 或 `Plus`？ | 有 = ✅ |
| 🧱 **floor vocab?** | 有没有为够某个抽象词卡死/中途死机？ | 全程能 cold 说 = ✅ |
| 📏 **长度在 band 内?** | ~3-5 句 / ~40-65 词 / 30-50s？ | 不"啪一下就完"(≤3 句/<~35 词)、也不注水铺两段 = ✅ |

5 个全 ✅ = 这题过。某项 ✗ → 下题同 function 再练那一项（别换题）。
> 📏 **长度 ✗ 的修法**：**太短** → 加一拍（给某点加一层展开 或 一句 `So honestly…/To be fair…` land，**绝不加第 5 个列举项、不换大词**，同 P2 EXPAND DON'T UPGRADE）；**太长/铺两段** → 跑完脊下车。**P3≠P2 三阶段加长。**

## A.5 session shape（一组 standalone P3 长这样）

> **~5-6 题 / 跨混合 function / 轮 function**（别一组全是 OPINION）。

```
① FREQUENCY/COUNTRY 暖场 ×1   ← 最 SAFE，最低 freeze，当 confidence opener
② OPINION ×2                  ← DOMINANT function（corpus 107 张），必练
③ ENUMERATE ×1                ← 2nd 高频（77 张），练"数量 opener → 列珠子"
④ REASON ×1                   ← 练 because OF/clause + 主因 commit（她 6/22-23 error 靶）
⑤ COMPARE 或 CHANGE 或 PREDICT ×1  ← 轮换补一个小样本 function
```

- **轮 function**：3 桶 OPINION opener（AGREE/DISAGREE/HEDGE）别每题都 `Definitely`，anti-机械。
- **FREQUENCY 永远当暖场**（plain/concrete/短，最低 freeze），用它把她带进状态再上 OPINION。
- ⚠️ **不加长**：P3 短而紧就是对的，跑完脊下车（≠ P2 三阶段加长）。别奖励注水。

# 🅱 轨二 · COMBINED P2 + P3（贴合考场 · 同域升抽象）

> 配对：先做一张 P2（cue-driven 协议），P2 跑完**立刻接它底部的 P3 follow-ups**。topic 已 warm，抽象度从 personal → general 升级。

## B.1 为什么要配对（不是凑数）

- **topic 保温**：P2 已经把 persona 珠子 + 词组激活了，P3 直接拿来当底料——她不用冷启动一个新话题。
- **抽象升级阶梯**：P2 = 你自己的具体经历（personal/concrete）→ P3 = people/society/趋势（general/abstract）。**同一个域内从具体爬到抽象**，正是考场 P2→P3 的真实跳变，练的就是这个跳。
- **slots into full_pass Round 2**：这正是 [[coach/full_pass.md]] **Round 2（"P2 + P3 一起，词组有底后 cold 比例拉高"）** 的设计。Round 1 用范文攒了词组，Round 2 把那些词组喂给 P3 当底料。

## B.2 🔗 桥（必须当场点名给她）：P2 的 EXPLAIN=LAND = P3 的 because-mechanism

> **这是两轨之间最重要的连续性，coaching 时必须显式讲出来：**

P2 末 bullet 的 **EXPLAIN=LAND**（`The reason I like it is [角度], because [机制——HOW 它管用,不是 "because good"]`）和 P3 第二拍的 **because-mechanism**（`… because [机制]`）是**同一块肌肉**。两个都在做一件事：**bare claim 之后立刻问"它到底 HOW 管用"**——不是空夸"because it's good / valuable"，是给机制。

- 她在 P2 LAND 里练的"给机制不给空夸"，搬到 P3 第二拍直接复用。
- 这也接上跨技能同源发现（CLAUDE.md）：bare claim 后立刻"再加一层"= 口语 P3 的 because-mechanism = 写作的 `…, making [展开]`。**一根肌肉，三处用。**

> coaching 动作：做完一张 P2 的 EXPLAIN=LAND，接 P3 时直接说 **"刚才 P2 收尾那个 because 机制，P3 第二拍一模一样的活，搬过来。"** 让她感到是同一个动作，不是新东西。

## B.3 ratio（cold 比例怎么定）

> Round 1 已用范文攒词组，Round 2 cold 比例拉高。

- 配对的 **P2 走 cue-driven 协议**（她先 cold，卡住一拍接龙）。
- P2 底部 **6 个 P3：至少 4 个她自己 cold 跑 frame**，卡住才一拍接龙；其余 2 个降级范文当 shadow 料（口齿/语感）。
- 比例随进度滑：词组越有底，cold 的那几问越往 6/6 推。**目标终态 = 6/6 全 cold。**

## B.4 怎么挂进 full_pass.md Round 2

> full_pass.md 现有 P2 进度表 + "配对 P3 覆盖（已过）"块。Round 2 时：

1. **每张 P2 行下挂它的 6 个 P3**，逐 function 标 frame（用本系统 8 function：OPINION/ENUMERATE/REASON/COMPARE/FREQUENCY/TWO-SIDED/CHANGE/PREDICT）。
2. P3 答案逐题捕获进 session 文件（逐字 → 诊断 → frame 标注）。
3. SKILL.md 的「▶ 进行中 campaign」块从"快速过全 54 P2"扩成 **"Round 2 = 54 P2 + 配对 P3 逐 function 过一遍"**。

## B.5 配对 session shape（一张 P2 + 它的 P3 follow-ups）

```
① P2（cue-driven，~2min）                ← 她先 cold，卡住一拍接龙，scorecard
② 🔗 点桥：P2 的 because 机制 = P3 第二拍同一块肌肉
③ P2 底部 6 个 P3（升抽象）：
   - 逐题：听 stem → STAND/SPLIT/SORT → frame → 脊 → 答后扫 → micro-scorecard
   - ≥4 题 cold，卡住一拍接龙；其余降级范文 shadow
④ 收尾：每个 P3 标 function + frame，捕获地板词/新错
```

# 📅 周节奏建议（weekly cadence）

> 现阶段（6/下旬，考前）：口语主攻，P3 是其中一条线。

| 频率 | 做什么 | 轨 |
|---|---|---|
| **每天** | 1 组 standalone P3（~5-6 题，跨 function 轮，含 1 个 FREQUENCY 暖场） | 🅰 |
| **每周 3-4 次** | 配对 P2 + P3（贴 full_pass Round 2，每次推进 1-2 张 P2 + 它的 6 P3） | 🅱 |
| **每周 1 次** | 弱点专项：抓 error_log 当周最高频 collocation（如 `because of/because` 限时 10 句对照 drill） | 🅰 变体 |
| **每周末** | 回扫本周 micro-scorecard：哪个 function 还有 ✗，下周加配它 | — |

- **轨二优先级 > 轨一**：配对更贴考场（P2→P3 真实跳变 + 桥）。轨一是 daily 维持。
- ⚠️ **不主动建议收工**（教练纪律）：工作量大≠该停，继续轮 function。

# 📂 session 文件要记什么（强制，加练也写）

> 落点：`speaking-band7/coach/sessions/YYYY-MM-DD.md`。P3 部分每题记：

1. **题目 + stem** → 标它触发哪个 function（OPINION/ENUMERATE/…）+ 哪个大动作（STAND/SPLIT/SORT）。
2. **suzy 逐字原句**（她真说的，不是修过的）。
3. **诊断 🔴🟡**：逐条列准确性硬错（搭配/介词/冠词/-s/直译），尤其 collocation。
4. **micro-scorecard 4 钩子结果**（stance? / mechanism? / 例子? / floor vocab?）。
5. **是否一拍接龙**（哪拍卡的、喂了什么 glue）。
6. **精修版**（原句小改，不重写）+ **clean 修复版**（可 shadow）。
7. **捕获**：她自产的地板好词（→ inventory cold+1）/ 新错 pattern（→ error_log）。

**同步更新**（同 P2 收尾铁律）：`coach/inventory.md` / `coach/error_log.md` / `daily_log.md` / `study_hub.md` 顶部"当前进度"块。配对时也更 `coach/full_pass.md`（P2 行 + 挂的 P3 frame）。

# 🎓 毕业 bar（graduation bar）

> 满足全部 = P3 这条线可降为维持频率。逐条 hard check，不达标不顺延。

| # | bar | 怎么判 |
|---|---|---|
| 1 | ⏱ **~3 秒内 commit 一个 stance** | 听完 stem 到开口 ≤3s，且头几词是 stance/数量 commit（不是 `um… well… I think maybe…`） |
| 2 | 🚫 **no freeze** | 全程无 >3s 死机空白；卡了能自己降到画面继续（不靠教练接龙） |
| 3 | ⚙️ **mechanism 不是 "because good"** | because 后面是 HOW 它管用（机制/downstream），不是空夸"因为它好/重要/有价值" |
| 4 | 🧱 **floor vocab** | 不为够抽象名词卡死——抽象点能用大白话兜（`what it's for` / `feels good when it works` / `how long they can focus`），不硬追 essay 词 |

**附加（非硬 bar，但要趋势向好）**：跨 5-6 题能轮 function（不每题都 OPINION）+ opener 不机械重复（不每题 `Definitely`）+ 答后扫自己能抓一半搭配错。
