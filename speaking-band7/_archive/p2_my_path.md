# P2 — 你的死机急救 + 三阶训练协议

> **范文源（2026-05-28 更新）**：现在以 `speaking-band7/examples/`（54 道 P2 + 324 道 P3，全部 Band 7 oral 校验通过，统一 7-persona 体系）为主要范文源，取代旧的 v7 手册。v6 骨架体系继续用于阶段 2。这份文档解决的是另一个问题：**死机时怎么把已有的东西真正调出来用**。
>
> **核心诊断**：P2 死机不是因为不会说，是因为 2 分钟独白需要在 60 秒思考时间内同时解决"选什么题材+怎么起手+怎么展开+怎么收尾"四件事，认知负荷直接爆掉。解决办法不是"练更多"，是"把这四件事的决策预先做完，到考场只剩'填具体内容'"。
>
> P3 不在这份文档范围内——你自己说 P3 还能接话，speaking-coach 的 cold production 模式继续用。

---

## 1. P2 死机的 4 个具体瓶颈

| 瓶颈 | 表现 | 解药 |
|------|------|------|
| **B1 选题材** | cue card 念完一遍，脑子空白，不知道选什么例子 | §2 的「5 个万能存货」——预先选好 5 个能套大多数题的素材 |
| **B2 起手句** | 知道要说什么但第一句崩，越想越说不出 | §3 的「5 个起手句」——任何题套一句进去就开机 |
| **B3 中段空** | 第一段说完没话了，对着 cue card 第 2 个 bullet 干瞪 | §4 的「延伸三连」——3 个万能过渡句撑过 5 秒思考 |
| **B4 收尾尬** | 时间没到不知道怎么继续，时间到了又突然停 | §5 的「5 个收尾句」——准备好结束的话 |

**关键认知**：B1-B4 全都是**决策疲劳**问题，不是英语水平问题。把这些决策预先做完，认知带宽就够说英语本身了。

## 2. 7 个万能 persona（预先选好题材，考场直接复用）

> `speaking-band7/examples/` 的 54 道范文全部从下面这 7 个 persona 里取材——**54 道题其实塌缩成 7 个人/地**。把这 7 个背成自己的"题库"，任何题先看能不能套上去。（完整角色 background + 9 个 S 存货细节见 `speaking-band7/personas.md`。）

| persona | 具体存货（S） | 能套的题型 |
|---------|--------------|-----------|
| **P1 wife（公务员）⭐主角，覆盖最广** | 健身(S1) / 烘焙(S2) / 城市管理(S3) | 完美工作 / 重要决定 / 团队 / 想颁布的法律 / 环保 / 擅长计划 / 鼓励别人 / 给建议 / 一起做事 / 影响你的人 / 特别场合食物 / 微笑场合 |
| **P2 Muye（5 岁儿子，害羞）** | 画画(S4) / 乐高(S5) | 喜欢画画的孩子 / 发挥想象力 / 创造活动 / 为家人骄傲 / 重要的东西 / 教别人 / 包含动物的书 |
| **P3 zhangwei（大学同学，developer）** | 自学 ML / CDN 解决问题 / Notion 计划 | 发小 / 朋友自学 / 机智解决问题 / 擅长做计划 / 成功事业 / 影响你的人 |
| **P4 外公** | 阳台种菜 | 种菜的人 / 老年人 / 坚持的事 / 家庭 / 影响你的人 |

| **P6 京都（去过 3 次）** | 清水寺 / 岚山 / 寺庙 | 旅行 / 城市 / 推荐旅行地 / 想再去 / 喜欢拜访但不想住 |
| **P7 成都（现居）** | 公园多 / 美食 / 节奏舒适 | 居住的城市 / 安静的地方 / 公共花园 / 社区 |
| **(speaker 自己 "I")** | CS 14 年 / 科幻小说 / 给儿子拍照 | 决定 / 规划 / 职业 / 长期目标 / 爱好(科幻/拍照) / 科技经历（**仅 decision/planning/career/爱好 题，其他题 downplay**） |

**死机自救流程**：
1. cue card 念完 → 立刻问自己：上面 7 个 persona（+speaker 自己）里**哪个最能套**？
2. 选好后，**60 秒准备时间只做一件事**：把这个素材的 1 个具体细节想清楚（哪一年、哪一次、哪个具体场景）
3. 不要再去想结构——结构按 §3-§5 的固定起手/过渡/收尾跑就行

**例**：题目 "Describe a creative person" → P2 Muye（喜欢画画、乐高搭东西时会自己想造型）→ 60 秒只想一个细节：上次他用乐高搭了什么东西

> ⚠️ **规划/决定题用 speaker 自己**，不用 Muye（5 岁孩子不做"重要决定"不真实）。**人物/描述他人题**主角用 wife / Muye / zhangwei，speaker 只作叙述者。

## 3. 5 个万能起手句（B2 解药）

> 任何 P2 题都能套一个进去。**背到不假思索**，开机就用。

```
1. So, the [person / place / thing] I'd like to talk about is ___.
2. The one that immediately springs to mind is ___.
3. I'd actually like to describe ___, because ___.
4. Hmm, let me think... I'll go with ___, because it's ___.   ← 买时间款
5. There are a few I could pick, but I'll talk about ___.       ← 买时间款
```

后两句的 "Let me think" / "There are a few I could pick" 是**合法的 P2 拖延语**——考官不会扣分（甚至是 fluency 的加分项，证明你在自然思考）。死机时**强行用这两句**，给自己 5 秒缓冲。

## 4. 延伸三连（B3 解药，中段没话时用）

```
1. So basically, ___.        ← 概括前面，准备展开
2. And the thing is, ___.    ← 引入一个原因/感受
3. Honestly, ___.            ← 给个人评价
```

这三句**按顺序连用**就能撑 30-40 秒。例：
> 说完第一段在儿子画画，没话了 →
> "So basically, he's really into drawing these days.
> And the thing is, I never push him — he just picks up a pencil whenever he feels like it.
> Honestly, that's what I love about it — it's completely his own thing."

不需要说得多深，3 句话就过去了，可以接下一段。

---

## 5. 5 个收尾句（B4 解药）

> 时间快到时切一句结束，**不要硬撑**。

```
1. So yeah, that's [the person / the place / it] I wanted to talk about.
2. I guess that's why ___ really sticks with me.
3. Looking back, ___ was just a really [memorable / meaningful] [experience / person].
4. So that's pretty much why I picked ___.
5. And I think that's all I really wanted to say about ___.
```

听到考官说 "Thank you" 之前不要主动结束——但有了这 5 句储备，发现时间快到时随时能收尾。

## 6. 三阶训练法（针对死机，从高脚手架→无脚手架）

类比 [[task2-my-path]] §4 的写作三阶法，逻辑同源。

### 阶段 1 — Shadow & Tweak（脚手架最高）

**目的**：把 v7 的范文"咽下去"，建立"P2 是怎么说的"的肌肉记忆。**不强迫主动产出**。

**流程**（每题 15 min）：
1. 选 v7 一题（按当周话题），朗读范文 1 遍
2. 跟读 1 遍（看着原文模仿语调）
3. 合上原文，**看着 cue card 自己说一遍**——允许慢、允许打磕巴、允许停顿
4. 不要对比、不要纠错——这阶段就是为了**建立"我刚才说出来了"的成功体验**

**进入阶段 2 的标准**：连续 5 题能完成第 3 步（不管说得怎么样，能撑到尾），不再空白死机

### 阶段 2 — 骨架填充（脚手架中等）

**目的**：拿掉范文这个拐杖，但还有 v6 的 4 段骨架在。

**流程**（每题 20 min）：
1. 我给一道**没听过的题** + cue card
2. 你按 §2 选万能存货（30 秒），按 §3 起手，按 v6 对应题型的 4 段骨架展开
3. 1 min prep（只想"哪个存货 + 1 个具体细节"，不要写句子）
4. 开口说 1-2 分钟
5. 反馈：起手是否用了 §3 / 中段是否用了 §4 延伸三连 / 收尾是否用了 §5 / 内容是否对应 cue card 4 个 bullet

**进入阶段 3 的标准**：连续 3 题能完成 90 秒以上、4 个 bullet 都触及、起手/延伸/收尾都用上工具箱

### 阶段 3 — Cold Production（无脚手架，模考态）

**目的**：完全模拟考试。

**流程**：按 speaking-coach 现有 cold production 模式跑。

**进入考试的标准**：3 次 cold，2 次能撑 100 秒以上 + 无死机停顿（>3 秒空白）

## 8. P2 死机现场的 3 秒清单

考场上 cue card 念完那一刻，**按顺序问自己**：

```
1. 7 个 persona 哪个能套？ → 选一个
2. 用哪个具体细节？  → 选一个细节
3. 哪句起手？        → 从 §3 选一句
→ 开始说（剩下的 50 秒 prep 时间放松、深呼吸，不要再想内容）
```

中段没话时：用 §4 延伸三连。
时间快到时：用 §5 收尾句。

**这 3 秒清单是你考场上唯一需要的东西**。其他全部预先记到不假思索。
