# Error Trace — Speaking 实时错误流水

> **用途**：练习 / Drill 时**实时记录**每个错误（不消化，原始流水）。
> **节奏**：练完一段我立刻 append；session 结束后总结进 `errors.md` 的 S2-X 模式。
> **不要在这里做模式归类**——这里是 raw，归类去 `errors.md`。
>
> 与 T2 `writing/t2-band7/log/error_trace.md` schema 同款。

## 格式

```markdown
### YYYY-MM-DD HH:MM 训练内容
- 原句片段 → 修后 [S2-X 编号]
- 原句片段 → 修后 [S2-X 编号]
```
