# 04. Speaking Toolkit — 限量工具集

> 训练时**keep open 当 cheat sheet**——不用全背。Band 7 看的是用对，不是用多。

---

## 1. 衔接词（discourse markers）— 6 大功能

> Band 7 要求"a range of connectives and discourse markers **with some flexibility**"。
> 每个 P2 / P3 round 用 **4-6 个不同功能**的衔接词。

| 功能 | 推荐 | 避免 |
|------|------|------|
| **起手 / 缓冲** | `Well,` / `So,` / `Right,` / `OK so,` | 沉默 ≥ 3 秒 |
| **加论点** | `On top of that,` / `Plus,` / `Also,` / `What's more,` | `Furthermore,` `Moreover,`（essay 词，太正式）|
| **转折** | `But,` / `Having said that,` / `Although,` / `That said,` | `However,` `Nevertheless,`（essay 词）|
| **举例** | `For example,` / `Like,` / `For instance,` / `Such as,` | （只用 1-2 次，多了 unnatural）|
| **解释 / 重述** | `I mean,` / `What I mean is,` / `In other words,` / `Basically,` / `Like,` | 直接重复同样的话 |
| **收尾 / 总结** | `So yeah,` / `So I'd say,` / `All in all,` / `At the end of the day,` | `In conclusion,`（essay 词）|

### 用法纪律

1. **不要重复用同一个**（如不要 4 个 `So,` 开头）
2. **同篇 P2 覆盖 4-6 个不同功能**
3. **句首位置主**（开头作缓冲）
4. **`like` / `you know` 等 filler 可以用**（Band 7 接受 oral 标记）但不要每句都用

## 2. 万能起手句（P2 死机急救 B2 解药）

> 任何 P2 题都能套一个。**背到不假思索**。

```
1. So, the [person / place / thing / event] I'd like to talk about is ___.

2. The one that immediately springs to mind is ___.

3. I'd actually like to describe ___, because ___.

4. Hmm, let me think... I'll go with ___, because it's ___.   ← 买时间款

5. There are a few I could pick, but I'll talk about ___.       ← 买时间款
```

### 用法纪律

- 60 秒思考时 **不要 brainstorm 起手句**——直接套 1-5 之一
- 这 5 句**背熟到秒出**
- 起手后立刻接 "and..." 或 "she/he/it is..."，**不要再停顿**
- **4 / 5 是合法的 P2 拖延语**（"Hmm, let me think" / "There are a few I could pick"）—— 考官不扣分（甚至是 fluency 加分项，证明你在自然思考）。死机时强行用，给自己 5 秒缓冲。

## 3. 中段过渡（B3 解药 — 卡顿时撑过 5 秒）

### 3a. 延伸三连（核心武器，按顺序连用撑 30-40 秒）

> 第一段说完没话时，按顺序套这 3 句就能过去：

```
1. So basically, ___.        ← 概括前面，准备展开
2. And the thing is, ___.    ← 引入一个原因/感受
3. Honestly, ___.            ← 给个人评价
```

**例**（儿子画画说完第一段没话了）：
> "So basically, he's really into drawing these days.
> And the thing is, I never push him — he just picks up a pencil whenever he feels like it.
> Honestly, that's what I love about it — it's completely his own thing."

3 句话就过去了，可以接下一段。**不需要说得多深**，按顺序套就行。

### 3b. 4 阶段梯度过渡（句间衔接）

| 阶段 | 过渡句 |
|------|--------|
| **从 setup → description** | "And what I'd like to mention is..." / "So let me tell you about..." |
| **从 description → example** | "A specific example would be..." / "There was this one time when..." |
| **从 example → impression** | "And looking back, that really..." / "So yeah, the reason this stuck with me is..." |
| **当不知道说什么** | "Hmm, what else..." / "Oh, and another thing is..." / "Now, the interesting thing is..." |

### 用法纪律

- **延伸三连**是死机优先武器，比 3b 梯度更"无脑可调用"
- 3b 不是必须——但 30% 概率会用到
- **不要连续用 2 个 3b**（"hmm, what else... oh and another thing..." 太啰嗦）

---

## 4. 收尾句（B4 解药 — 时间快到 / 已说够）

```
1. So yeah, that's [the person / the place / it] I wanted to talk about.

2. I guess that's why ___ really sticks with me.

3. Looking back, ___ was just a really [memorable / meaningful] [experience / person].

4. So that's pretty much why I picked ___.

5. And I think that's all I really wanted to say about ___.
```

### 用法纪律

- 时间剩 10 秒 → 套一个
- 时间剩 20 秒 → 不要收，继续展开
- 不要用 "thank you" 收尾（不需要）
- 听到考官说 "Thank you" 之前**不要主动结束**——但有这 5 句储备，时间快到时随时能切

---

## 5. 5 类题型 opener（Intro 第 1 句）

| 题型 | Opener |
|------|--------|
| **Person** | "So, the person I'd like to talk about is..." / "The first person who came to mind is..." |
| **Place** | "The place I'd like to talk about is..." / "I've been to / I've lived in..." |
| **Event** | "I'd like to talk about the time when..." / "One experience that comes to mind is..." |
| **Object** | "The thing I'd like to talk about is..." / "There's this [object] I've had / used..." |
| **Hypothetical / Future** | "Hmm, that's an interesting question. I'd say..." / "If I had to pick, I'd go with..." |

## 6. 词汇升级 20 组（极简 → mid-level）— 与 T2 §4.1 共享

| 极简词 | 升级（oral-friendly） |
|--------|---------------------|
| very good | pretty solid / really great / quite impressive |
| very bad | pretty terrible / really awful |
| very important | crucial / vital / really key |
| good / nice | wonderful / fantastic / amazing（但不滥用）|
| a lot of | a great deal of / plenty of / loads of（loads of 略 informal）|
| things | specific noun（**避免 placeholder**）|
| stuff | specific noun |
| people | individuals / folks（informal）|
| big | huge / massive / significant（significant 偏 essay，慎用）|
| small | tiny / modest |
| many | a fair number of / quite a few |
| difficult | tough / challenging / tricky |
| easy | straightforward / a piece of cake（idiomatic）|
| help | give a hand / lend a hand / support |
| use | rely on / make use of / take advantage of |
| start | kick off / get going |
| end | wrap up |
| like | be into / be a big fan of / enjoy |
| think | reckon / feel / suppose / be of the opinion that |
| say | mention / point out / put it that |

### 用法纪律

1. **每个 P2 用 3-5 个升级词**（不需要全 20 个都用）
2. **混用 register**：Band 7 是 mid-level，不是 academic。"plus" 比 "furthermore" 自然
3. **避免突兀升级**——`I be of the opinion that...` 在 oral 里假，不如 `Honestly, I reckon...`

## 7. 致命的 collocation 错误（必修）— 与 T2 §4.3 共享

| ❌ 错 | ✅ 对 |
|------|------|
| do a research | conduct research（informal: look into / research X）|
| make a homework | do homework |
| informations | information（不可数）|
| advices | advice（不可数）|
| equipments | equipment（不可数）|
| furnitures | furniture（不可数）|
| an useful | a useful |
| in nowadays | nowadays |
| in the same time | at the same time |
| open / close TV | turn on / turn off the TV |
| see a film | watch a film（see = 偶然看到 / watch = 主动看）|
| make a plan | make a plan（这个对）/ **plan to do X**（动词形态）|

## 8. 复杂句结构（GRA 上 7 必备）— oral 版

> Band 7 要求"a range of complex structures with **some flexibility**"。
> **至少稳定使用 3 种**。

### 3 种必会 + 1 个可选

#### A. 状语从句（最基础）

引导词：`because / although / while / since / when / if / as`

**oral 例**：
- "Although I'm not great at lifting weights, my wife keeps pushing me..."
- "Whenever Muye finishes a drawing, he runs to show us..."

#### B. 关系从句

引导词：`who / which / that / where`

**oral 例**：
- "There's this neighborhood near our home **that** has these old trees..."
- "My wife works in city management, **which** is more interesting than it sounds..."

⚠️ **不要 nested 关系从句**（who which that 套 3 层）—— oral 听众跟不上

#### C. 名词性从句（that-clause）

**oral 例**：
- "What I love about Kyoto is **that** it feels timeless..."
- "Honestly, **what struck me** was how patient Muye is with his LEGO..."

#### D. 条件句（可选，加分）

- "**If I had to pick** one moment, it'd be when..."
- "**If you were** to ask me again next year, I'd probably say the same..."

### 不用的 Band 8+ 结构

- ❌ **倒装句**（"Only when... had he...") - oral 用了反而别扭
- ❌ **Cleft sentence**（"It is X that...") - 不需要
- ❌ **Mixed conditional**（"If I had known X, I would be Y now"）- 用错频繁

## 11. P2 实战协议 — 三阶训练 + 死机 3 秒清单

> 这一节是**练 P2 的训练协议** + **考场死机自救流程**。所有 P2 训练必须走这个协议，不直接 cold production。

### 11a. P2 死机的 4 个具体瓶颈

| 瓶颈 | 表现 | 解药 |
|------|------|------|
| **B1 选题材** | cue card 念完一遍，脑子空白，不知道选什么例子 | [[personas.md]] 7 个万能 persona —— 预先选好 7 个能套大多数题的素材 |
| **B2 起手句** | 知道要说什么但第一句崩，越想越说不出 | §2 的 5 个起手句 —— 任何题套一句进去就开机 |
| **B3 中段空** | 第一段说完没话了，对着 cue card 第 2 个 bullet 干瞪 | §3a 的延伸三连 —— 3 句话撑 30-40 秒 |
| **B4 收尾尬** | 时间没到不知道怎么继续，时间到了又突然停 | §4 的 5 个收尾句 —— 时间快到时随时能切 |

**关键认知**：B1-B4 全都是**决策疲劳**问题，不是英语水平问题。把这些决策预先做完，认知带宽就够说英语本身了。

### 11b. 三阶训练法（脚手架递减）

类比写作 T2 的三阶法，逻辑同源。

#### 阶段 A — Shadow & Tweak（脚手架最高）

**目的**：把范文"咽下去"，建立"P2 是怎么说的"的肌肉记忆。**不强迫主动产出**。

**流程**（每题 15 min）：
1. 选 [[examples/]] 一题（按当周话题或 persona），朗读范文 1 遍
2. 跟读 1 遍（看着原文模仿语调）
3. 合上原文，**看着 cue card 自己说一遍**——允许慢、允许打磕巴、允许停顿
4. 不要对比、不要纠错——这阶段就是为了**建立"我刚才说出来了"的成功体验**

**进入阶段 B 的标准**：连续 **5 题**能完成第 3 步（不管说得怎么样，能撑到尾），不再空白死机。

#### 阶段 B — 骨架填充（脚手架中等）

**目的**：拿掉范文这个拐杖，但保留 §2/§3a/§4 toolkit + 题型骨架。

**流程**（每题 20 min）：
1. 教练给一道**没听过的题** + cue card
2. 按 [[personas.md]] 选 persona（30 秒），按 §2 起手，按 [[03_question_types.md]] 对应题型的 4 段骨架展开
3. 1 min prep（只想"哪个 persona + 1 个具体细节"，不要写句子）
4. 开口说 1-2 分钟
5. 反馈：起手是否用了 §2 / 中段是否用了 §3a 延伸三连 / 收尾是否用了 §4 / 4 bullet 触达数 / 时长

**进入阶段 C 的标准**：连续 **3 题** ≥ 90 秒 + 4/4 bullets 触及 + 起手/延伸/收尾 3 个工具全用上。

#### 阶段 C — Cold Production（无脚手架，模考态）

**目的**：完全模拟考试。

**流程**：speaking-coach 的 cold production 模式（Mode 1），但 P2 specific。完整 8 维诊断。

**进入考试的标准**：3 次 cold，2 次能撑 ≥ 100 秒 + 无死机停顿（> 3 秒空白）。

### 11c. P2 死机现场的 3 秒清单（考场上唯一需要的东西）

cue card 念完那一刻，**按顺序问自己**：

```
1. 7 个 persona 哪个能套？ → 选一个
2. 用哪个具体细节？        → 选一个细节（哪一年/哪一次/哪个场景）
3. 哪句起手？              → 从 §2 选一句
→ 开始说（剩下的 50 秒 prep 时间放松、深呼吸，不要再想内容）
```

中段没话时：用 §3a 延伸三连。
时间快到时：用 §4 收尾句。

**其他全部预先记到不假思索**。
