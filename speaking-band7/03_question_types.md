# 03. P2 4 类 + P3 5 类骨架

> P2 = 2 min 独白（**155-170 词** / 4 段结构）
> P3 = 30-45 秒/题（**45-65 词** / 3-4 句）

---

## P2 — 4 大题型骨架

> IELTS Speaking Part 2 题型本质 = "Describe a [person/place/event/object/activity]"
> 4 大类覆盖几乎所有 cue card。任何 cue card 念完先归类。

### 类型 A — Describe a Person

**典型 cue card**：
- Describe a person who [you admire / influenced you / is creative / is helpful...]
- You should say: Who they are / How you know them / What they do / Why you chose them

**4 段骨架**（155-170 词）：

```
段 1 — Setup（30-35 词）
  起手句（[T] umbrella）+ 这人是谁 + 你怎么认识 ta
  
段 2 — Description（45-55 词）
  ta 的具体特征 / 习惯 / 工作 / 性格（pick 1-2 个核心）
  
段 3 — Specific example（45-55 词）
  最重要的一段——讲一个 specific 故事 / 时刻 / 互动
  
段 4 — Why & impression（25-35 词）
  这人对你 / 别人的 影响 / 为什么 cue card 让你想到 ta
```

**Persona 适配**：
- wife（健身 / 烘焙 / 公务员）→ 大多数 person 题
- Muye（画画 / 乐高 / 5 岁害羞）→ 孩子 / 创意 / 想象力题

**起手模板**：
- "So, the person I'd like to talk about is my wife..."
- "The first person who came to mind is my five-year-old son Muye..."

---

### 类型 B — Describe a Place

**典型 cue card**：
- Describe a [city / quiet place / place you visited / place you'd recommend...]

**4 段骨架**（155-170 词）：

```
段 1 — Setup（30-35 词）
  起手句 + 这地方是哪里 + 怎么知道的 / 什么时候去的
  
段 2 — Description（45-55 词）
  地方特色（环境 / 气氛 / 食物 / 文化）pick 1-2 个
  
段 3 — Specific experience（45-55 词）
  最重要——讲一次 specific 体验（看到 / 做了什么）
  
段 4 — Why memorable（25-35 词）
  为什么这地方对你 / 为什么 cue card 让你想到这里
```

**Persona 适配**：
- 京都 3 次（S6）→ 旅行 / 推荐 / 想再去 / 喜欢但不想住
- 成都生活（S7）→ 居住 / 城市 / 安静 / 公园 / 社区

**起手模板**：
- "The place I'd like to talk about is Kyoto, in Japan..."
- "I've lived in Chengdu for a few years now, and it's the place I'd describe..."

---

### 类型 C — Describe an Event / Experience

**典型 cue card**：
- Describe an [event / experience / time when... / occasion when...]
- e.g. 早起经历 / 别人帮助你 / 改变想法 / 微笑的场合 / 重要决定

**4 段骨架**（155-170 词）：

```
段 1 — Setup（30-35 词）
  起手句 + 这事什么时候 + 哪里发生 + who 在场
  
段 2 — Build-up（40-50 词）
  事情怎么开始 / 当时情况
  
段 3 — Main event（55-65 词）
  最重要——具体发生了什么 / 关键时刻 / dialogue / 行为
  
段 4 — Aftermath & feeling（25-35 词）
  事情之后 / 你的感受 / 为什么记得
```

**Persona 适配**：
- S1-S3 wife / S4-S5 Muye / S8 一起健身 = 多数 event 题
- "重要决定" → S1 开始健身 / S3 wife 职业决定
- "鼓励别人" → S8 wife 鼓励 zhangwei

**起手模板**：
- "I'd like to talk about the time when my wife..."
- "One experience that comes to mind happened last year..."

---

### 类型 D — Describe an Object / Activity / Thing

**典型 cue card**：
- Describe a [thing you'd like to learn / app / book / piece of technology / something important to your family...]

**4 段骨架**（155-170 词）：

```
段 1 — Setup（30-35 词）
  起手句 + 这是什么 + 你怎么有/接触
  
段 2 — Description（40-50 词）
  具体特征 / 功能 / 长什么样
  
段 3 — Usage（45-55 词）
  你怎么用 / 用了多久 / 具体的一次使用
  
段 4 — Why important（25-35 词）
  为什么对你重要 / 为什么 cue card 让你想到它
```

**Persona 适配**：
- Muye 的乐高（S5）→ 玩具 / 创意 / 重要的东西
- wife 的烘焙工具 / 食谱 → 创造性活动 / 教别人
- App / 程序 → 用 wife 或 Muye 用的（如 wife 的 fitness app）

**起手模板**：
- "The thing I'd like to talk about is my son's LEGO collection..."
- "There's this baking recipe my wife has been using for years..."

## P3 — 5 大讨论 frame

> ⚠️ **已被取代（6/23）**：本节 5-frame（Compare / Cause-Effect / Agree-Disagree / Hypothetical / Prediction）漏了 corpus 实证最高频的 ENUMERATE（77 张）、TWO-SIDED、FREQUENCY；Hypothetical/Should 实为 OPINION。**P3 现行系统 = [[function_driven_p3.md]] 的 8-function frame（STAND/SPLIT/SORT）+ [[p3_frames_and_swaps.md]] + [[p3_answers_tagged.md]] + [[p3_training_plan.md]]**，全部 re-derived FROM 324 答案 corpus。本节退到参考。
>
> P3 = follow-up discussion，30-45 秒/题
> 5 大 frame 覆盖几乎所有 P3 题。听到问题先 frame 分类。

### Frame 1 — Compare/Contrast（X vs Y）

**典型 P3 题**：
- "What's the difference between X and Y?"
- "Do you think A is better than B?"
- "How are A and B different?"

**3-4 句结构**（45-65 词）：

```
S1: 总评 / 立场（X 和 Y 各有 X 之处）
S2: X 的特点（具体一点）
S3: Y 的特点（对比 X）
S4 (可选): 谁更好 / depends on...
```

**模板**：
- "Well, I'd say X and Y are different in a few ways. X tends to..., whereas Y..."
- "It really depends on... If you're after [goal A], then X works better. But for [goal B], Y is the way to go."

---

### Frame 2 — Cause-Effect / Why（X 为什么 / X 导致什么）

**典型 P3 题**：
- "Why do people [do X]?"
- "What causes [phenomenon]?"
- "What are the effects of [trend]?"

**3-4 句结构**（45-65 词）：

```
S1: 主因 1 + 简要解释
S2: 主因 2 / 补充
S3 (可选): example
S4 (可选): 后果 / lead to...
```

**模板**：
- "I think there are a couple of reasons. First, ... On top of that, ..."
- "Honestly, it boils down to two things. One is ..., and the other is ..."

---

### Frame 3 — Agree/Disagree（同意吗）

**典型 P3 题**：
- "Do you agree that...?"
- "Do you think it's important to...?"
- "Some people say X. What's your view?"

**3-4 句结构**（45-65 词）：

```
S1: 立场（同意 / 部分同意 / 不同意）+ 表态句
S2: 主要 reason
S3: 让步 / qualifier（避免极端）
S4 (可选): 收尾
```

**模板**：
- "Yeah, I'd say I largely agree. The main reason is... Having said that, ..."
- "Honestly, I'm not sure I'd go that far. While ... it ..."

⭐ **避免极端立场**——加 qualifier（in some cases / to some extent / depending on...）= Band 7 marker

---

### Frame 4 — Hypothetical / Should X / Imagine（假设题）

**典型 P3 题**：
- "Should the government do X?"
- "What would happen if...?"
- "If you could change one thing about..."

**3-4 句结构**（45-65 词）：

```
S1: 表态（应该 / 不应该 / 看情况）+ 关键 reason
S2: 假设展开 / 具体后果
S3 (可选): 限定条件
S4 (可选): 例子
```

**模板**：
- "I think they probably should, but only if ... Otherwise, ..."
- "Well, if I had to pick one, I'd say ... because ..."

---

### Frame 5 — Prediction / Future（未来题）

**典型 P3 题**：
- "What will happen in the future?"
- "Do you think X will change in the next 10 years?"

**3-4 句结构**（45-65 词）：

```
S1: 主预测 + 大方向
S2: 主要驱动力（technology / culture / policy 等）
S3 (可选): 限定（不会完全 / 可能 / 有些 dependencies）
S4 (可选): 例子
```

**模板**：
- "I reckon it's likely to ... mainly because ... But I wouldn't be surprised if ..."
- "It's hard to say for sure, but I'd guess ... given that ..."

⭐ **不要 100% 确定**——"likely to" / "I'd guess" / "probably" 比 "will definitely" 更 Band 7
