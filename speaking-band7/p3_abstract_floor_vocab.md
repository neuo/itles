# P3 抽象/经济话题 floor 词速查表（6/26 建 · 治"意思有、词出不来"）

> **怎么用**：这张表治**"意思有、词出不来"**——背右栏（floor），卡时**直接降级**，别翻中文找大词。
> **病根（6/26 精确定位）**：抽象/经济题你能给完整中文（idea 在），但 cold 调不出地道英文——一够那个 essay 名词就死机。解药不是背更多，是**预载 floor 版**，压力下直接抓右栏。
> ⚠️ **地板纪律**：中栏（别追）= 你会卡的 essay 词，**看到就降**；右栏（改说）= 大白话，**背成固定块**。散句不垮，垮的是这一下够词。**只降真生词**——标 KEEP 的（peace of mind / lead by example / second nature）你 cold 说得出，别压。

## ⭐ 她这周真实卡的词（6/24-26 · 最高优先 · 你亲身卡过 → 先背这 15 个）

| 想说（中文） | 你当时卡成 / 别追 | ⭐ 改说（floor，背这个） |
|---|---|---|
| 数量在增长 | "the lumber is growing up"（近音+错搭配） | 🔴 **the number's still going up**（数字用 go up，不用 grow up） |
| 让人随时随地下单 | "breaks geographical limit, enabling people placing orders…" | **you can buy from pretty much anywhere, anytime** |
| 容易买不需要的东西 | "makes people way easier buy something…"（结构断） | **makes it way too easy to buy stuff you don't really need** |
| 主动性 / 更有干劲 | 追 initiative / proactivity 拼不出 | **makes you way more driven**（主动性 = driven） |
| 自己当老板 | 词都认识但拼不出"run a business" | **you get to be your own boss and decide what you work on** |

| 迷上了 / 被勾住 | "stuck in it"（chunk 没自动化） | **hooked** |
| 习惯付现金 | "they use to pay"（漏 be used to+V-ing） | 🔴 **they're used to paying**（习惯于 = be used to **+ V-ing**） |
| 肤浅 / 浅 | 抓了 cheap（意思错） | **shallow** |
| 辨别不了真假 | "can't recognize"（飘） | **can't tell what's real** |
| 在一个地方做完所有事 | cold 调不出 | **do everything in one place** |
| 体会/吸收文化 | 追 immerse / experience | **take in the culture** |
| 慢慢享受 / 刚刚好 | 整题语言卡 | **slow down and enjoy** / **the sweet spot**（刚刚好） |
| 钱→创收→创就业→利经济 | 🔴 经济类一来就整题卡 | **Mainly money → brings in money → creates jobs → good for the economy**（背成一条链） |

## 🔑 万能壳（背这些 = 你最高杠杆 · 卡时套壳填珠子）

> 壳 = 固定 glue（对齐 corpus register），珠子 = 你填的内容。压力下**先甩壳买时间**，再填一颗珠子。

**① REASON 满壳（"为什么"题，经济题尤其救命）**
```
Mainly [主因], I'd say.  →  机制 because/since…  →  Plus, [第二因].  →  So overall, [一句收].
```
🔴 经济题专用链（你 6/26 卡的）：**Mainly money, I'd say → it brings in a lot of money → plus it creates loads of jobs → so overall it's good for the economy.**

**② LAND 收尾壳（P3 几乎每题都能收）**
```
So really, it's a mix of [A] and [B].   /   So really, most people do a bit of both.
So I'd recommend it to anyone who wants [X].   （P2 也用）
```

**③ ENUMERATE 列项 + 挂细节壳（"什么种类"题，防说一半卡住）**
```
列项 like A, B or C  +  反射挂 "where they can ___"（每个列出的项挂一个细节）
```
例：mountains, **where they can escape the heat and breathe fresh air**.

**④ STAND concede 让步壳（"好不好/同不同意"题）**
```
Definitely / Not really  →  让步(a few X issues / it can be…)  →  But honestly…  →  At the end of the day, … outweighs the downsides.
```

**⑤ TWO-SIDED 两面壳**
```
It cuts both ways, honestly.  →  On the plus side, [好处].  →  But the downside is [坏处].  →  Having said that, [一句让步收].
```

**⑥ 长度自判**：4 句 ~45-55 词 = 在 band 内不算短。太短就**加一拍展开/land**，别硬加列举项（冷扫死机）。

> 🔑 **区分测试**（先判这题在干嘛，再选壳）：答完你在**捍卫立场**[STAND→壳④⑤] 还是**列例子**[SORT→壳①③] 还是**对比两个东西**[SPLIT→壳②]？

## ⚠️ 答后必扫（你的固定 error zone · 1 秒自查）

1. **数字增长 = go up / go down**，不是 grow up（the number's going up）。
2. **习惯做某事 = be used to + V-ing**（they're used to paying，不是 "use to pay"）。
3. **mainly because of + 名词** vs **mainly because + 整句**——别混搭。
4. **遇到问题 = come across / run into**，不是中式 "meet a problem"。
5. **名词修饰名词先想形容词**（snow→snowy / sand→sandy）。
6. **a/an 看下个词的音**，元音音前用 an（本周漏 3 次）。
7. **单数主语带 -s 没？**（你最常在长句里掉）。
