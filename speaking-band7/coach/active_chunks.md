# 活跃 chunk 集（滚到自动 · 教练每 session 抽+点名+查）

> **来源（suzy 6/29 定的方法）= 范文 − 她 cold 的 diff**：挖自每张合练「我给的降级范文」vs「她 cold 真说出来」的差 = **她检索不出的那些块**（不是泛泛好词）。已逐题过 6/25–6/29 五张合练（123 条原始 diff → 去掉她已说对的 → curate 成下面三档）。
> **粘住的唯一路径（别默读！默读=喂强腿）**：每个 ① **出声说 3 遍** ② **用自己的事造 1 句**（套结构填你的内容，不背例句）。
> **判定"记住" = cold 里它自己冒出来 3 次**（像 6/29 你自纠 `AI helps` 那样）。**忘了正常**：忘→再捡→再用 = 巩固机制本身。

## ⭐ Tier 1 · 万能核心（本周滚死 · ≤10 个 · 任何题都用 · 最高 ROI）

| chunk | 啥时候用 | ⚠️ 你 cold 说成 |
|---|---|---|
| `It's a real mixed bag, honestly` | 利弊/好不好题开口 | "mixed bank" |
| `Mainly ___, I'd say` | REASON/"为啥"/首要项开口 | 只记碎片 I'd say，漏 Mainly |
| `Quite a few, actually` / `Oh, loads` / `Not as much as before` | 数量/列举/FREQUENCY 开口（**记者题**） | 判类错 / 没用秒开壳 |
| `it (all) comes down to ___` | 任何题收尾 land | "comes down **how**"（漏 to） |
| `To be fair, …` / `That said, …` / `Having said that, …` | 让步收尾（万能 closer） | 没产出让步层 |
| **`So overall, [A], but [B]`** | land = **把前面 recap 一句，不是找新内容** | 卡过两次（以为要新点子） |
| `Plus, …` / `On top of that, …` | 加第二个原因/点 | 抽查连漏 2 次 |
| `There are a couple of reasons …` | 进入列举/理由段的过渡壳 | 直接堆信息没过渡 |
| `So really, it's a mix of ___ and ___` / `most people do a bit of both` | 两因素综合时收尾 | 自己留 land 槽但填不出 |
| `there are loads of ___`（虚位 there）/ `it makes it easier to ___`（占位 it） | "有 X" / "让…变容易" | "**they** are loads of" / 想不到用 it |

## Tier 2 · 万能扩展（壳/过渡/连接 · 滚熟 Tier 1 后上）

| chunk | 啥时候用 |
|---|---|
| `As for X …` / `As for how I found it` | 切到下一个 bullet/子话题的过渡壳 |
| `What really makes X stand out is how it ___` | P2 CORE：说某物最突出的特点 |
| `One moment that really stuck with me was ___` | P2 ONE-MOMENT 引子 |
| `At first I couldn't get why ___, but after a while ___` | P2 情绪弧（困惑→沉浸） |
| `So I'd recommend it to anyone who wants ___` | P2 地点/经历 LAND 收尾 |
| `Not really, to be honest` | 否定 stance 的软化 opener |
| `mainly because of ___`（+名词） / `The main reason is ___` | REASON 给主因（注意 because **of**+名词 vs because+整句） |
| `whether it's X or Y` | 列举范围的口语对照壳 |
| `People tend to ___` | 概括人群行为 |
| `you can end up stuck` / `end up + 状态` | 描述坏结果 |
| `even if I keep the rest flexible` / `even for X, it's worth Y` | 让步收尾，表态更圆 |
| `it all adds up` | 积少成多（钱/小事累积） |
| `worth it` / `the whole thing was worth it` | 值得（⚠️ worth **it**，别漏 it） |
| 🔴 `pay attention to` / `be used to + V-ing` | 高频错搭配 → 当 reflex 滚 |
| 🔴 `what the local culture's like`（嵌入句陈述语序） | 间接问句别用疑问语序 |

## Tier 3 · 话题甜区库（按域 · 参考挑用 · 不强背 · 卡了来抓）

> 这些是 reuse=medium/low 的话题块。**不进 Tier 1 强背**，但答到对应域卡了就来抓（= 你两张 floor 表的口语成品版）。

**💰 经济/花钱**：`brings in a lot of money` · `creates loads of jobs` · `good for the economy` · `go over budget` · `don't come cheap` · `eats up a big chunk of their salary` · `a cushion when something goes wrong` / `a safety net` · `splash out on` · `money well spent` · `you can't put a price on it` · `driven by emotion` · `making wants feel like needs`

**✈️ 旅行**：`take in the culture` · `the sweet spot`（刚刚好） · `slow down and enjoy` · `head to the seaside` · `less crowded`（淡季/人少） · `historical sights` · `wander around the neighbourhoods` · `I've been there four times`（次数不加 for）

**👥 社交/友情**：`drift apart` · `get on with others`（on 不是 out） · `on the same wavelength` · `shallow`（浅，不是 cheap） · `communicate in person` · `nothing beats meeting in person`

**📱 科技/AI**：`hooked`（不是 stuck in it） · `search for ___` · `on the internet` · `you can do everything in one place` · `chip away at ___` · `a tool, not a crutch` · `track it down` · `the system went down` · `buzzing with alerts` · `copy and paste without thinking`

**📚 学习/EDU**：`think for themselves` · `like sponges, soaking it up` · `not afraid of making mistakes` · `get to grips with ___` · `keep up with the times` / `or you'll fall behind`

**🏛️ 管控/社会**：`with a light touch`（适度） · `set a daily time limit` · `encourage it, don't force it` · `at least up to a certain age`（限定）

# 🔧 机制（suzy 6/29 要求固化：后续怎么新增 + 怎么复习 + 怎么毕业）

## ① 新增（每张合练后 · 教练做）
- 每张合练收尾，把当张「**范文 − 你 cold 的 diff**」里的高复用块**追加进对应 Tier**：
  - 万能 opener/land/连接/过渡壳 → Tier 1（若已满 10）或 Tier 2
  - 话题专属地道块 → Tier 3 对应域库
- **来源永远是 diff（你没调出/说错的），不是泛泛好词。** 你已说对的不收。

## ② 复习（每 session 必做 · 你背、我喂 · "复习是学习生效的唯一机制")
1. **开场抽**：Tier 1 抽 2-3 个 + 上次软点（你先答我再对）。当前软点 = **FREQUENCY 记者/评委判类 + 可数/单复数 + land=recap**。
2. **答题前点名**："这题用上 ___"（指定 1 个 Tier 1/2 chunk）。
3. **复盘查**：答完核对用没用 → 用了标记（向毕业 +1）；没用下次再点。
4. **间隔节奏（遗忘曲线）**：今天学 → 明天抽 → 3 天后抽 → 一周后抽。忘了再捡 = 正常且必要。

## ③ 毕业（保持 Tier 1 ≤10，不贪多）
- 某 chunk 在 **cold 里自己冒出来 3 次** → 从 Tier 1 划掉 / 移 `inventory.md` 毕业区，空位补新的。
- Tier 1 永远只留 ~10 个"在滚的"；滚熟一批换一批。Tier 2/3 是储备，不强背。

## ④ 你的日常（5 分钟 · 出声，别默读）
- 每个 **Tier 1 出声 3 遍 + 用自己的事造 1 句**（如 `It comes down to whether I have time`）。
- 时间紧 → 只做 Tier 1。Tier 2 滚熟 Tier 1 后再上。Tier 3 不背，卡了来查。
