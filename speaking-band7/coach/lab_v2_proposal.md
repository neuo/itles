## 1. 日历与周期（她第 1 条）

```

```

- 中间**休息或没练**：那一天照常占位，当天没有产出就是"这一天没有问题产生"，周期照走。

- 周期起点：她定。默认建议 **2026-08-19 起算 L1**（08-18 已经是老规则下的学习日）。

**D 的定义（本稿唯一口径）**

在 4 天周期里，各天的 D-1/D-3 自动落在：
  L1 → D-1 = 上周期 R　  D-3 = 上周期 L2
  L2 → D-1 = L1          D-3 = 上周期 R

⇒ 每个学习日都同时复习"昨天"和"三天前"，无需任何现场推导。

## 2. 学习日流程（她第 2、3 条）

### ① 复习 D-1 ＋ D-3 出现的问题
- **对象**：那两天**被测到的、未毕业的**全部条目 —— 包括当天新建的问题、当天回潮的老问题、
  以及当天答对了但还没连对满 3 次的条目。
  > ⚠️ 她原话是"D-1 和 D-3 出现的问题（新问题和当天返的老问题）"。
  > 若严格读成"只复习那两天**犯错**的"，则答对过一次的条目再也不会出现，**连对 3 次永远达不到**，
  > 与她第 6 条自相矛盾 ⇒ 本稿取"被测到的"。见 §11-Q2。
- **不含**：已毕业（连对 ≥3）的条目。
- **出题**：10 题一组，一组答完再出下一组；出完为止，**她随时可以喊停**，没出完的进顺延队列（显式记账，见 §6）。

### ② 回看 D-1 新题（只读，她不产出、不计分）
输出四块，**逐字取自 D-1 的 session 文件，不许重新推导**：
```
① 题目原文（P2 含 bullets）
② 她的原话逐字
③ 最小修改版　＋　更好版
④ 分句 diff（每处给理由）
```
- D-1 是付息日（即今天是 L1）时没有新题 ⇒ 这一段跳过，明写"D-1 无新题"。

### ③ 新题 1 道（她第 3 条：从老 skill 的 3 道降为 1 道）
- **必须走抽题脚本** `python3 speaking-band7/coach/pick_question.py`，抽到什么练什么，不许重抽、不许换、不许自编。
- 抽签动作在**开场时就做完**（不发题面，只是先抽定），避免因为她提前喊停就整天没有自由产出。
- 走全套：她 cold 产出 → 诊断 → 最小修改版/更好版/diff → 每一处问题归号 → 记录。

### ④ 收尾核对（不发给她，写进 session 文件）
```
1 本篇/本日每一处问题都归到了一个编号？（列出"N 处 → N 个编号"，数字不等就是漏了）
2 每一题的最小修改版/更好版/diff 都在 session 文件里看得见？
3 顺延队列做差集：跟上一轮比，少掉的每一条都要写出去向
4 更新问题文件里被动过的条目状态（连对/连错/上次复习时间）
```

## 3. 付息日流程（她第 1、2、7 条）

```
⓪ 回看：本周期 3 道新题的四件套（只读）
a 复习本周期（L1+L2+L3）全部出现过的问题，10 题一组
b 回捞：距上次被测最久的未毕业条目（见 §11-Q3，这是实验里最严重的洞）
c 问题文件 review：重复项合并（含历史记录与状态数据）
```

**c 段合并规则（她第 7 条，老 skill 明令禁止合并，此处以她为准）**
```
判重：两条的【目标产出形式】逐字相同 ⇒ 重复，合并
      不同（哪怕看着像）⇒ 不合并，改题面区分
合并做法：保留编号较小的那个；被合并条目的**全部日志行按时间顺序并入**，一行不删
状态重算：合并后连对/连错**按并入后的日志重新算一遍**（不是取谁的，是重放）
留痕：被合并的编号写一行「→ 已并入 #N（YYYY-MM-DD）」，编号不复用、不删除
```

## 4. 什么算"问题"（她第 4 条）

```
① 我犯的错             语法 · 搭配 · 拼写 · 时态/单复数/冠词/介词 · 句子结构
② 我说得不地道         字面意思勉强能懂，但 local 不会这么说 —— **尤其句型和词组**
③ 我主动提出的         我问"这个怎么说更好""这句是不是怪"，也算一个问题
来源不限：复习题里冒出来的、答新题时冒出来的，一样对待
```

**这一条直接堵住了实验里的两个洞**：
- 老 skill 的 △（"有更好的表达"）不计连击、不入池、永远不会被再测 —— 报告 §S4 判为死条款。
  现在 ②「不地道」是**正式问题**，照常建号、照常复习。
- 老 skill 的落号机制**只对新题生效**，复习组里冒出来的新错挂了号也不会被测（报告 S1-e：
  "同一个错，落在新题里会留下，落在复习组就蒸发"）。现在来源不限。

**不算问题**（避免池子被噪音撑爆）：
```
· 打字手误（likr / brithday）—— 除非同一个词反复拼错，那就是拼写问题
· 口语里正常的句读/片段（打字材料里句号 vs 逗号不构成证据）
· 教练判错后撤销的（当场撤，不留号）
```

## 5. 问题文件（她第 6 条 —— 本次改动最大的一块）

### 5.1 一个文件，一条问题一个块

```markdown
### 12 · keep patient → stay patient
类型  搭配　｜　来源 2026-08-11 P2 自由产出　｜　旧号 B117b（迁移前）
题面  "他劝我耐心点。"（点名：用 stay 说）
状态  连对 2 · 连错 0 · 上次复习 2026-08-19 · 未毕业
日志
- 2026-08-11 首犯 · 自由产出 · `I keep patient` → stay patient
- 2026-08-16 复习 ❌ · 又写成 keep
- 2026-08-19 复习 ✅
- 2026-08-23 复习 ✅
```

- **状态行紧挨着日志行**（她原话"状态挨着记录行"）：状态是**日志重放出来的结果**，
  两边打架时**以日志为准**，状态行重算。
  > 这解决了老 skill 的死结：老规则"只写事件不存状态"是为了防两份事实不一致，
  > 代价是任何数字都要现场重放 9 行 📊 才能算出来（实验里 🎓 那一行差 2 条，查不出出处）。
  > 状态与日志同处一块 ⇒ 既可查，又不会分裂成两份事实。
- **每次犯错 / 每次被测都追加一行日志**，一行一次，不合并、不写"以此类推"。

### 5.2 归类粒度（她："不同单词不同词组都是新的标签"）

```
词汇 / 搭配 / 词组 / 拼写   →  按【具体的词或词组】归类
                              keep patient 是一条；bury into 是另一条；两条不合并
语法 / 结构                 →  按【规则】归类
                              "will lost"和"didn't found"是同一条（助动词后接原形）
                              "the words was"是另一条（主谓一致）
```
> 理由：语法类若按实例拆，池子会无限膨胀且永远测不完；词汇类若按规则并，
> 就变回老 B 表那种"一个号盖多个考点"的形状 —— 实验里这正是最难解的冲突（拆号四规则打架，
> Day2 一天 11 个父号要拆、16 个子号当天出不了题）。见 §11-Q4。

### 5.3 毕业与回潮
```
连对 3 次 → 毕业：复习不再召回（她第 6 条）
毕业后又犯 → 回潮：连对清零，重新入池，日志照记
她可以直接指定某条毕业（"这句毕业了，别问了"）—— 记「毕业·她指定」
```

### 5.4 新问题入库程序（她第 6.2 条）
```
每发现一个问题 → 先去问题文件里搜同族 → 能归就归（在那条下面追加日志行）
                                      → 归不上才新建编号
新建的条目【当天不测】，从次日起进池（当天教完当天测 ＝ 假 ✅）
```

## 6. 出题规则

```
· 10 题一组（她第 7 条），一组答完再出下一组；一天出几组由她喊停
· 题面【逐字取自问题文件的"题面"字段】，不许现编；要改题面必须先改文件再出题
· 题面必须是完整句（"他家离马路远远的。"，不是"离马路远远的"）
· 一句中文有第二个同样合法的译法 ⇒ 当场在题面里点名（点名词/句型/块），不许让她猜
· 组内排序：① 连错 ≥2　② 连对 2（差一次毕业）　③ 距上次被测最久　④ 其余
· 组内不许撞车：同一条规则/同一个词族一组里最多 2 题
· 讲评泄题扫描：上一组讲评里给过的判据/目标块，命中的条目本组不出（顺延）
· 顺延 ≠ 丢掉：顺延队列每轮与上一轮做差集，少掉的每一条要写出去向
```

## 7. 每一题的输出（她第 5 条）

**复习题和新题一视同仁**，每题三件套：
```
① 最小修改版   在她原句上动最少的地方 —— 让她看得出错在哪
② 更好版       换更地道的说法；没有就写"无更好版本"五个字（不许留空、不许写"同上"）
③ diff         先摆【原句】【改后】两行完整句，再逐片段列差异，每处给理由
```
**硬约束（沿用现行 skill，实验证明这几条有效）**
```
· 更好版必须【长在她的句子上】：主语和句子顺序与原文一一对应，不许整段重构
  真要给一个完全不同的写法 → 另起一栏叫「另一种说法」
· ❌ 必须给可迁移的理由（规则/判据/同族清单），不能只判对错
· 小词（介词/冠词）纠正时重复整个词组，不说"把 X 换成 Y"
```

### ★ 顺序写死（她第 5 条，本稿最重要的一条程序）
```
诊断做完 → **先把三件套原样写进 session 文件** → 再把反馈发给她
```
> 实验里最严重的两个漏洞都是同一形状：**"在聊天里给过 ≠ 落盘"**。
> 08-13→08-16 六道整题的完整版/diff 从没进过文件，回看时只能重新推导，
> 她读到的是"第二份天花板"。把落盘放在发送之前，这个漏洞在机制上就不存在了。

## 10. 实验诊断出的洞：v2 堵住了哪些、还剩哪些

| 实验发现 | v2 | 说明 |
|---|---|---|
| 完整版/diff 在聊天里给过但没落盘 | ✅ 堵住 | §7「先写文件再发送」 |
| 复习组里的新错挂了号也不会被测 | ✅ 堵住 | §4 来源不限 |
| △ 是死条款，条目永远出不去 | ✅ 堵住 | §4② |
| 🎓 数字不可复算 | ✅ 堵住 | §5.1 状态内联 + 日志重放 |
